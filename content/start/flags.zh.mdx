---
title: 标志管理
description: 说明如何在 Pixi’VN 中使用布尔标志来控制游戏流程。
---

Pixi’VN 提供了用于管理"游戏标志"的函数。 游戏标志是用于控制游戏流程或在游戏存储中保存其他布尔值的布尔值。

与使用普通存储相比，这种机制对存档大小的影响要小得多，因此建议将标志用于频繁更改的布尔值。

## 设置

要设置一个标志，使用 [`storage.flags.set`](/jsdoc/pixi-vn/index/interfaces/StorageFlagsInterface#set) 函数。

```ts
import { storage } from "@drincs/pixi-vn";

storage.flags.set("flag1", true);
```

## 获取

要获取一个标志，使用 [`storage.flags.get`](/jsdoc/pixi-vn/index/interfaces/StorageFlagsInterface#get) 函数。

```ts
import { storage } from "@drincs/pixi-vn";

const flag1 = storage.flags.get("flag1");
```
