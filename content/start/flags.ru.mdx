---
title: Управление флагами
description: Объясняет, как использовать булевы флаги в Pixi’VN для управления потоком игры.
---

Pixi’VN предоставляет функции для управления «игровыми флагами». Игровые флаги — это булевы значения, используемые для управления потоком игры или для хранения других булевых значений в хранилище игры.

Этот механизм оказывает намного меньшее влияние на размер сохранений, чем использование обычного хранилища, поэтому рекомендуется использовать флаги для булевых значений, которые часто изменяются.

## Установка

Чтобы установить флаг, используйте функцию [`storage.flags.set`](/jsdoc/pixi-vn/index/interfaces/StorageFlagsInterface#set).

```ts
import { storage } from "@drincs/pixi-vn";

storage.flags.set("flag1", true);
```

## Получить

Чтобы получить флаг, используйте функцию [`storage.flags.get`](/jsdoc/pixi-vn/index/interfaces/StorageFlagsInterface#get).

```ts
import { storage } from "@drincs/pixi-vn";

const flag1 = storage.flags.get("flag1");
```
