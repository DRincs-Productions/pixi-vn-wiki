La narrazione è il cuore di una visual novel. It consists of dialogues, choices, and input prompts shown to the player as the game progresses.

Con Pixi’VN, puoi utilizzare diversi linguaggi narrativi e persino passare da uno all'altro per sfruttare le caratteristiche di ciascuno.
