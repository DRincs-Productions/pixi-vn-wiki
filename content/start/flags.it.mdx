---
title: Gestione dei flag
description: Spiega come utilizzare i flag booleani in Pixi’VN per controllare il flusso del gioco.
---

Pixi’VN fornisce funzioni per gestire i "flag di gioco". I flag di gioco sono valori booleani utilizzati per controllare il flusso del gioco o per memorizzare altri valori booleani nell'archiviazione di gioco.

Questo meccanismo ha un impatto molto minore sulla dimensione dei salvataggi rispetto all'utilizzo dell'archiviazione normale, quindi è consigliato utilizzare i flag per i valori booleani che cambiano frequentemente.

## Impostare

Per impostare un flag, utilizza la funzione [`storage.flags.set`](/jsdoc/pixi-vn/index/interfaces/StorageFlagsInterface#set).

```ts
import { storage } from "@drincs/pixi-vn";

storage.flags.set("flag1", true);
```

## Ottenere

Per ottenere un flag, utilizza la funzione [`storage.flags.get`](/jsdoc/pixi-vn/index/interfaces/StorageFlagsInterface#get).

```ts
import { storage } from "@drincs/pixi-vn";

const flag1 = storage.flags.get("flag1");
```
