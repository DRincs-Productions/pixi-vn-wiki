title: Gestione dei flag

---

Pixi’VN fornisce funzioni per gestire i "flags di gioco". I flag di gioco sono valori booleani utilizzati per controllare il flusso del gioco o per memorizzare altri valori booleani nella memoria del gioco.

This mechanic has much less impact on save size than using the normal storage, so it is recommended to use flags for boolean values that are frequently changed.

## Impostare

To set a flag, use the [`storage.setFlag`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#setflag) function.

```ts
import { storage } from "@drincs/pixi-vn";

storage.setFlag("flag1", true);
```

## Ottenere

To get a flag, use the [`storage.getFlag`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#getflag) function.

```ts
import { storage } from "@drincs/pixi-vn";

const flag1 = storage.getFlag("flag1");
```
