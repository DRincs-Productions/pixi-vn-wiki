---
title: Flag-Verwaltung
description: Erklärt, wie man boolesche Flags in Pixi’VN verwendet, um den Spielablauf zu steuern.
---

Pixi’VN bietet Funktionen zur Verwaltung von „Spiel-Flags“. Spiel-Flags sind boolesche Werte, die verwendet werden, um den Spielablauf zu steuern oder um andere boolesche Werte im Spielspeicher zu speichern.

Dieser Mechanismus hat einen deutlich geringeren Einfluss auf die Speicherstandgröße als die Verwendung des normalen Speichers, daher wird empfohlen, Flags für boolesche Werte zu verwenden, die sich häufig ändern.

## Setzen

Um ein Flag zu setzen, verwenden Sie die Funktion [`storage.flags.set`](/jsdoc/pixi-vn/index/interfaces/StorageFlagsInterface#set).

```ts
import { storage } from "@drincs/pixi-vn";

storage.flags.set("flag1", true);
```

## Abrufen

Um ein Flag abzurufen, verwenden Sie die Funktion [`storage.flags.get`](/jsdoc/pixi-vn/index/interfaces/StorageFlagsInterface#get).

```ts
import { storage } from "@drincs/pixi-vn";

const flag1 = storage.flags.get("flag1");
```
