<Accordion title="UIとは何ですか？" id="what-is-ui">

UIとはUser Interface（ユーザーインターフェース）の略称です。 これは、ユーザーがデジタルデバイス、アプリケーション、またはウェブサイトと対話するための、視覚的な要素とインタラクティブなコンポーネントを指します。 ユーザーインターフェース（UI）には、ボタン、メニュー、アイコン、テキストフィールド、レイアウトなど、ユーザーが操作するすべてのものが含まれます。 ユーザーインターフェース（UI）デザインの目標は、見た目が美しく、かつ機能的なインターフェースを作り、ユーザーにシームレスで直感的な体験を提供することです。

</Accordion>

</Accordions>

Pixi’VNは、ゲームのユーザーインターフェース（UI）を作成するための組み込みコンポーネントを提供しておらず、JavaScriptエコシステムにすでに存在するものを再発明することもありません。 特定のフレームワークに縛るのではなく、好みの外部JavaScriptフレームワークを自由に使ってUIを構築できるため、ReactやVueなどのシステムを活用して、複雑で高性能な**UI画面**を作成できます。

この柔軟性により、Pixi’VNはAI支援開発にも最適です。UIは独自システムではなく、標準的で広く使われているフレームワークで構築されるため、AIコーディングアシスタントはこれらのツールをすでによく理解しており、UIコードを非常に効果的に生成、理解、変更できます。

<Accordion title="HTML UIレイヤーの追加" id="adding-html-ui-layers">

**HTML UIレイヤーとは何ですか？** HTML UIレイヤーは、PixiJSのキャンバスの上に追加されるHTML要素で、キャンバスと同じサイズを持ちます。 これにより、ReactやVueなどのJavaScriptフレームワークでUIを作成できます。

To add an HTML UI Layer, you can use the [`canvas.htmlLayers.add`](/jsdoc/pixi-vn/index/interfaces/CanvasHtmlLayersInterface#add) function.

```ts tab="main.ts"
const root = document.getElementById("root");
if (!root) {
    throw new Error("root element not found");
}
const htmlLayer = canvas.htmlLayers.add("ui", root, {
    position: "absolute",
    pointerEvents: "none",
    userSelect: "none",
});
```

```html tab="index.html"
<!doctype html>
<html lang="en">
    <body>
        <div id="root"></div>
        <script type="module" src="/src/main.ts"></script>
    </body>
</html>
```

To get the HTML element of the layer, you can use the [`canvas.htmlLayers.get`](/jsdoc/pixi-vn/index/interfaces/CanvasHtmlLayersInterface#get) function.

To remove an HTML UI Layer, you can use the [`canvas.htmlLayers.remove`](/jsdoc/pixi-vn/index/interfaces/CanvasHtmlLayersInterface#remove) function.

</Accordion>

<Accordion title="How to enable HTML UI interaction?" id="how-to-enable-ui-interaction">

By default, all HTML elements of the HTML UI Layers have the `pointer-events: none` style. This means that the HTML elements will not intercept any mouse or touch events, allowing the PixiJS canvas to receive all events. This is useful when you want to display an image or a video in the canvas and you don't want the UI to interfere with it.

So you must set the `pointer-events: auto` style only for the conponent that you want to interact with the user.

例：

```css tab="Shadcn - Tailwind CSS" title="styles.css"
@layer components {
    [data-slot="button"],
    [data-slot="card"],
    [data-slot="resizable-handle"],
    [data-slot="scroll-area"],
    [data-slot="scroll-area-scrollbar"],
    [data-slot="toggle"] {
        pointer-events: auto;
    }
}
```

```tsx tab="React"
export default function NextButton() {
    return (
        <button
            style={{
                pointerEvents: "auto",
            }}
        >
            Next
        </button>
    );
}
```

```vue tab="Vue"
<template>
    <button style="pointer-events: auto;">Next</button>
</template>
```

</Accordion>

<Accordion title="Adding PixiJS UI Layers" id="adding-pixijs-ui-layers">

**What is an PixiJS UI Layer?** It is PixiJS Container. Unlike the main Container dedicated only for Pixi’VN features:

* The current state of the Ul will not be included in saves.
* It has better performance. Pixi’VN will not do any checks on it.
* You can't use Pixi’VN features.
* Being a core PixiJS component, you can add all PixiJS compatible components.

To add a PixiJS UI Layer, you can use the [`canvas.layers.add`](/jsdoc/pixi-vn/index/interfaces/CanvasLayersInterface#add) function.

例：

```ts title="src/main.ts"
const container = canvas.layers.add("ui");
```

To get the PixiJS Container of the layer, you can use the [`canvas.layers.get`](/jsdoc/pixi-vn/index/interfaces/CanvasLayersInterface#get) function.

To remove a PixiJS UI Layer, you can use the [`canvas.layers.remove`](/jsdoc/pixi-vn/index/interfaces/CanvasLayersInterface#remove) function.

</Accordion>

## Differences between the UI and the canvas

As Pixi’VN was designed and conceived, the UI and the canvas are two distinct and independent elements. The UI is above the canvas and is used to create buttons, forms, etc. The canvas is used to display images, videos, etc.

All information about the current state of the canvas is included in the save and it is possible to restore the state of a previous step. The current state of the UI will not be included in the saves. So you have to <DynamicLink href="/start/interface-connect-storage">manage it yourself by saving the information</DynamicLink> you need to <DynamicLink href="/start/storage">game storage</DynamicLink> or browser storage.

In the canvas you can add components during each step. In the UI you can't do that, you can create several <DynamicLink href="/start/interface-connect-storage">"screens" and navigate between them</DynamicLink>.

In the canvas you can only add Pixi’VN components. In the UI you can add any HTML/PixiJS component or use any UI component library, so you can create much more complex interfaces.
