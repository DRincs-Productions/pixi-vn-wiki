Pixi’VN은 "게임 플래그"를 관리하기 위한 함수를 제공합니다. 게임 플래그는 게임의 흐름을 제어하거나 다른 불리언 값을 게임 저장소에 저장하는 데 사용되는 불리언 값입니다.

이 메커니즘은 일반 저장소를 사용하는 것보다 세이브 데이터 크기에 훨씬 적은 영향을 미치므로, 자주 변경되는 불리언 값에는 플래그를 사용하는 것이 권장됩니다.

## 설정

To set a flag, use the [`storage.flags.set`](/jsdoc/pixi-vn/index/interfaces/StorageFlagsInterface#set) function.

```ts
import { storage } from "@drincs/pixi-vn";

storage.flags.set("flag1", true);
```

## 가져오기

To get a flag, use the [`storage.flags.get`](/jsdoc/pixi-vn/index/interfaces/StorageFlagsInterface#get) function.

```ts
import { storage } from "@drincs/pixi-vn";

const flag1 = storage.flags.get("flag1");
```
