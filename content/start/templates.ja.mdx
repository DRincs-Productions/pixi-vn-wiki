## テンプレートの使い方

このページを読んでいる方は、すでにテンプレートからプロジェクトを生成していることでしょう。以下のセクションでは、プロジェクトを動作させるための最初の手順を説明します。

### 初期設定

IDE でプロジェクトフォルダーを開きます。以下の例では [Visual Studio Code](https://code.visualstudio.com/) を使用します。

プロジェクトを開くと、VS Code がいくつかの操作を自動的に提案します：

* **推奨拡張機能をインストール** — ワークスペースで推奨される拡張機能のインストールを求める通知が表示されます。インストールすることを強くおすすめします。通知が表示されない場合は、拡張機能パネルで[推奨拡張機能](https://code.visualstudio.com/docs/editor/extension-marketplace#_recommended-extensions)を絞り込んで手動でインストールできます。
* **起動タスクを実行** — VS Code から、設定済みの起動タスクの実行を求められる場合があります。これによりプロジェクトのすべての依存関係がインストールされます。手動で実行する場合は、次のコマンドを使用します：

```npm
npm install
```

:::warning[マルチプラットフォーム]

デスクトップまたはモバイル向けのテンプレートを選択した場合は、[Tauri](https://v2.tauri.app/start/prerequisites/) に必要な追加の依存関係（Rust ツールチェーンと各プラットフォーム固有のビルドツール）をインストールする必要があります。 Tauri はシステム環境と密接に連携するため、プロジェクトをデスクトップアプリとして起動できるようになるまで、**VS Code を 1 回以上再起動する**必要がある場合があります。

:::

### プロジェクトの実行

テンプレートには、VS Code 用の事前設定された**起動構成**が用意されています。起動構成を初めて使う場合：これは VS Code にプロジェクトの起動方法（必要に応じてデバッガーの接続方法）を指示するショートカットです。毎回ターミナルにコマンドを入力する必要がなくなります。**実行とデバッグ**パネル（左側のサイドバーにある再生アイコン、または `F5` キー）からアクセスできます。パネル上部のドロップダウンから使用する構成を選択し、緑色の再生ボタンを押します。

![実行とデバッグパネル](/launch-configuration-dropdown.png)

次の構成が利用できます：

* **Debug Game**：開発中に最もよく使用する設定です。ファイルを保存するたびに、ブラウザーが自動的に再読み込みされます。このモードでは、アニメーションが完全になめらかに動かない場合があり、アセットの読み込みも公開用の最終ビルドより遅くなることがあります。
* **Debug Game Preview**：公開後のゲームの動作を忠実に再現します。アニメーションがなめらかになり、読み込み時間は実際に近く、最適化も有効になります。公開前に表示や動作が意図どおりかを確認したいときは、この構成を使用してください。
* **Run as Desktop App (Dev)**：Rust/Tauri バックエンドをコンパイルし、ネイティブのデスクトップウィンドウでゲームを起動します。テンプレートがデスクトップまたはモバイル向けでない場合、この構成は表示されません。

### スタイルのカスタマイズ

テンプレートの UI はすべて [shadcn/ui](https://ui.shadcn.com/) で構築されているため、コンポーネントのコードを変更せずにカラーテーマをカスタマイズできます。

[shadcn/ui のテーマビルダー](https://ui.shadcn.com/create?template=vite\&base=base\&preset=b1s9eyGkS)を開き、好みの色に調整してから、ページの **Copy** セクションに移動し、生成された CSS コマンドをコピーしてください。そのコマンドをプロジェクトのルートから実行します：

```npm
npx shadcn@latest add <paste-the-generated-command-here>
```

適用した後は、ソースファイルを再フォーマットすることをおすすめします：

```npm
npm run format
```

フォントやグローバルスタイルなど、さらにカスタマイズする方法については <DynamicLink href="/start/interface-font">スタイルとフォント</DynamicLink> を参照してください。

### テンプレートの画面

テンプレートには、ビジュアルノベルに必要な基本機能をカバーする画面があらかじめ用意されています。各画面は、TanStack Router が管理するルートに接続された React コンポーネントです。

* **メインメニュー**（`/`）— プレイヤーがゲームを起動したときに最初に表示される画面です。新しいゲームの開始、セーブデータからの再開、設定の表示ができます。
* **ナレーション画面**（`/game/narration`）— ストーリーが表示されるゲームの中心となる画面です。セリフ、キャラクタースプライト、背景、選択肢を表示します。
* **設定** — 設定パネルには専用のルートがありません。代わりに [Search Params](https://tanstack.com/router/latest/docs/framework/react/guide/search-params) を使って、現在表示中の画面の上に重ねて表示します。この方法なら URL を簡潔に保ちながら、プレイヤーはゲーム内のどこからでも設定を開き、音声、表示、言語などの設定項目を切り替えられます。また、元の画面の位置も保持されます。
* **ナビゲーション画面**（`/game/navigation`）— *Point & Click* 専用です。プレイヤーは部屋を移動し、現在地で利用できるさまざまなアクションを実行できます。
* **マップ画面**（`/game/map`）— *Point & Click* 専用です。地図を表示し、プレイヤーが別の場所へ移動できるようにします。複数の地図の管理にも対応しています。
