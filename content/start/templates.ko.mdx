## 템플릿 사용 방법

이 페이지를 읽고 있다면 이미 템플릿으로 프로젝트를 생성했을 가능성이 높습니다. 다음 섹션에서는 프로젝트를 실행하기 위한 첫 단계를 안내합니다.

### 초기 설정

IDE에서 프로젝트 폴더를 엽니다. 아래 예제에서는 [Visual Studio Code](https://code.visualstudio.com/)를 사용합니다.

프로젝트를 열면 VS Code에서 몇 가지 작업을 자동으로 제안합니다:

* **권장 확장 프로그램 설치** — 작업 영역에 권장되는 확장 프로그램을 설치하라는 알림이 표시됩니다. 설치 요청을 수락하는 것이 좋습니다. 알림이 표시되지 않으면 확장 프로그램 패널에서 [권장 확장 프로그램](https://code.visualstudio.com/docs/editor/extension-marketplace#_recommended-extensions)으로 필터링해 직접 설치할 수 있습니다.
* **시작 작업 실행** — VS Code에서 구성된 시작 작업을 실행하라는 메시지가 나타날 수 있습니다. 이 작업을 실행하면 프로젝트의 모든 종속성이 설치됩니다. 수동으로 실행하려면 다음 명령어를 사용하세요:

```npm
npm install
```

:::warning[멀티플랫폼]

데스크톱 또는 모바일 플랫폼을 대상으로 하는 템플릿을 선택했다면 [Tauri](https://v2.tauri.app/start/prerequisites/)에 필요한 추가 종속성(Rust 도구 체인 및 플랫폼별 빌드 도구)을 설치해야 합니다. Tauri는 시스템 환경과 긴밀하게 통합되므로 프로젝트를 데스크톱 애플리케이션으로 실행하기 전에 **VS Code를 한 번 이상 다시 시작**해야 할 수 있습니다.

:::

### 프로젝트 실행

템플릿에는 VS Code용으로 미리 구성된 여러 **실행 구성**이 포함되어 있습니다. 실행 구성이 익숙하지 않다면, 이는 VS Code에 프로젝트 시작 방법과 선택적으로 디버거 연결 방법을 알려 주는 바로 가기입니다. 따라서 매번 터미널에 명령어를 입력할 필요가 없습니다. **실행 및 디버그** 패널(왼쪽 사이드바의 재생 아이콘 또는 `F5` 키)에서 접근할 수 있습니다. 패널 상단의 드롭다운에서 원하는 구성을 선택하고 녹색 재생 버튼을 누르세요.

![실행 및 디버그 패널](/launch-configuration-dropdown.png)

다음 구성을 사용할 수 있습니다:

* **Debug Game**: 개발 중 가장 자주 사용하는 실행 구성입니다. 파일을 저장할 때마다 브라우저가 자동으로 새로고침됩니다. 이 모드에서는 애니메이션이 완전히 부드럽지 않을 수 있고 애셋 로딩이 최종 출시 빌드보다 느릴 수 있습니다.
* **Debug Game Preview**: 출시 후 게임의 동작을 최대한 비슷하게 재현합니다. 애니메이션이 부드럽고 로딩 시간도 실제와 유사하며 최적화가 활성화됩니다. 출시 전에 화면과 동작이 의도한 대로인지 확인할 때 이 구성을 사용하세요.
* **Run as Desktop App (Dev)**: Rust/Tauri 백엔드를 컴파일하고 게임을 네이티브 데스크톱 창에서 실행합니다. 템플릿이 데스크톱 또는 모바일 플랫폼을 대상으로 하지 않으면 이 구성은 표시되지 않습니다.

| `npm run preview`    | `build:fast`를 실행한 뒤 결과물을 로컬에서 제공하여 출시된 웹 게임을 시뮬레이션합니다.    |

### 스타일 사용자 지정

템플릿의 UI는 전부 [shadcn/ui](https://ui.shadcn.com/)로 구성되어 있어 컴포넌트 코드를 수정하지 않고도 색상 테마를 사용자 지정할 수 있습니다.

[shadcn/ui 테마 빌더](https://ui.shadcn.com/create?template=vite\&base=base\&preset=b1s9eyGkS)를 열고 원하는 색상으로 조정한 다음, 페이지의 **Copy** 섹션으로 이동하여 생성된 CSS 명령어를 복사하세요. 프로젝트 루트에서 해당 명령어를 실행하세요:

```npm
npx shadcn@latest add <paste-the-generated-command-here>
```

적용한 후 소스 파일을 다시 포맷하는 것이 좋습니다:

```npm
npm run format
```

글꼴, 전역 스타일 등 추가 사용자 지정 방법은 <DynamicLink href="/start/interface-font">스타일 및 글꼴</DynamicLink>을 참고하세요.

### 템플릿 화면

템플릿에는 비주얼 노벨의 필수 요소를 다루는 미리 제작된 화면들이 포함되어 있습니다. 각 화면은 TanStack Router에서 관리하는 경로에 연결된 React 컴포넌트입니다.

* **메인 메뉴** (`/`) — 플레이어가 게임을 시작하면 처음 보게 되는 화면입니다. 새 게임 시작, 저장된 게임 이어하기, 설정 열기 기능을 제공합니다.
* **내레이션 화면** (`/game/narration`) — 이야기가 표시되는 핵심 게임 화면입니다. 대사, 캐릭터 스프라이트, 배경, 선택지를 표시합니다.
* **설정** — 설정 패널에는 별도의 전용 경로가 없습니다. 대신 [Search Params](https://tanstack.com/router/latest/docs/framework/react/guide/search-params)를 사용하여 현재 활성화된 화면 위에 설정 패널을 겹쳐 표시합니다. 이 방식은 URL을 간결하게 유지하면서도 플레이어가 게임 어디에서나 설정을 열고 오디오, 화면, 언어 등의 설정 항목을 이동할 수 있게 합니다. 또한 이전에 있던 위치를 잃지 않습니다.
* **탐색 화면** (`/game/navigation`) — *Point & Click* 전용입니다. 플레이어가 방 사이를 이동하고 현재 위치에서 가능한 여러 동작을 수행할 수 있습니다.
* **지도 화면** (`/game/map`) — *Point & Click* 전용입니다. 지도를 표시하고 플레이어가 한 위치에서 다른 위치로 이동할 수 있습니다. 여러 지도를 관리하는 기능도 지원합니다.
