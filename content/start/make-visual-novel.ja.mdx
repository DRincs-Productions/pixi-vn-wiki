このチュートリアルでは、最初のビジュアルノベルを作成するプロセスをご案内します。

<Accordions>

<Accordion title="ビジュアルノベルとは？" id="what-is-a-visual-novel">

ビジュアルノベル（VN）は、デジタルインタラクティブフィクションの一形態です。 ビジュアルノベルはしばしばビデオゲームというメディアに関連付けられますが、必ずしもそのように分類されるわけではありません。 テキストによるナラティブと、静止画またはアニメーションによるイラストレーション、そしてさまざまな度合いのインタラクティブ性を組み合わせています。 この形式は「ノベルゲーム」と呼ばれることもありますが、これは和製英語である noberu gēmu（ノベルゲーム）を転写したもので、日本語でより多く使われる呼び方です。

</Accordion>

</Accordions>

テスト目的として、このガイドではPixi’VNを使ってビジュアルノベル [Breakdown](https://joshpowlison.itch.io/breakdown) を再現します。 Breakdownは、ビジュアルノベルが備えるべきすべての機能を持つ短編ストーリーです。 Breakdownの作者であるJosh Powlison氏は、教育目的でそのナラティブを使用することを許可してくれました❤️。

:::tip

Pixi’VNでは、1つ以上の<DynamicLink href="/start/narration">利用可能なナラティブ言語</DynamicLink>を選んで独自のナラティブを書くことができるため、開発の各ステップで、現在利用可能な各言語ごとに例を示します。

:::

## 新しいプロジェクトを作成する

始める前に、<DynamicLink href="/start#prerequisites">前提条件</DynamicLink>をインストール済みであることを確認してください。

最初のステップは、新しいプロジェクトを作成することです。 以下を実行することで作成できます。

```npm
npm create pixi-vn@latest
```

そして `Visual Novel` テンプレートを選択します。

:::tip[VS Code]

VS Codeでプロジェクトを開くと、ワークスペースタスクの実行に同意するかどうか、およびプロジェクトの推奨拡張機能をインストールするかどうかを尋ねられます。 両方とも承諾することを強くお勧めします。

:::

テンプレート、タスク、拡張機能についての詳細は<DynamicLink href="/start/templates">こちら</DynamicLink>をご覧ください。

<Accordions>

<Accordion title="手動コマンド" id="manual-commands">

VS Codeのタスクを使いたくない場合は、プロジェクトのルートで以下のコマンドを実行することで同じ結果を得られます。

```npm
npm install
npm start
```

</Accordion>

</Accordions>

## キャラクターの作成

ここでは、このストーリーのキャラクターを定義します。 そのために、使用するキャラクターを `/content/characters.ts` ファイルで定義します。

<Accordions>

<Accordion title="`mc` とは何を意味しますか？" id="what-does-mc-mean">

`mc` は "Main Character"（主人公）の一般的な略語です。 ビジュアルノベルでは、主人公の名前として `mc` を使うのが一般的な慣習です。

</Accordion>

<Accordion title="`Character` モデルはどこで定義されていますか？" id="where-is-the-character-model-defined">

以下で使用する `Character` モデルは `models/Character.ts` で定義されています。 好みに応じて変更でき、例えばキャラクターに関連するプロパティ（例：`surname`、`age` など）を追加することもできます。 このファイルについての詳細は<DynamicLink href="/start/character#custom-class">こちら</DynamicLink>をご覧ください。

</Accordion>

</Accordions>

:::tip

キャラクターの作成と使用方法についての詳細は次を参照してください：<DynamicLink href="/start/character">Characters</DynamicLink>

:::

```ts title="content/characters.ts"
import Character from "@/models/Character";
import { RegisteredCharacters } from "@drincs/pixi-vn";

export const mc = new Character("mc", {
    name: "Me",
});

export const james = new Character("james", {
    name: "James",
    color: "#0084ac",
});

export const steph = new Character("steph", {
    name: "Steph",
    color: "#ac5900",
});

export const sly = new Character("sly", {
    name: "Sly",
    color: "#6d00ac",
});

RegisteredCharacters.add([mc, james, steph, sly]);
```

<Accordion title="ダイアログの'グルー'（glue）機能を使用する" id="use-the-glue-feature-of-dialogues">

ビジュアルノベルでは、現在のダイアログにテキストを継ぎ足すことがしばしば有用です。 例えば、会話を一時中断し、後続のナラティブステップ（`step`）で継続させたい場合です。 これを行うには、<DynamicLink href="/start/dialogue#dialogue-glue">グルー機能</DynamicLink>を使用できます。

以下がその例です。

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

james: Ooh, [mc]! Nice, firm handshake!
<>The last guy always gave me the dead fish.
<>I already think we're gonna get along fine.
james: Come on in and...

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    async () =>
        (narration.dialogue = {
            character: james,
            text: `Ooh, ${mc.name}! Nice, firm handshake!`,
        }),
    async () => {
        narration.dialogGlue = true;
        narration.dialogue = `The last guy always gave me the dead fish.`;
    },
    async () => {
        narration.dialogGlue = true;
        narration.dialogue = `I already think we're gonna get along fine.`;
    },
    async () =>
        (narration.dialogue = { character: james, text: `Come on in and...` }),
    // ...
]);
export default startLabel;
```

</Accordion>

### ナラティブを`labels`に分割する

（線形のビジュアルノベルであっても）非常に長いナラティブノード（`labels`）を作成することは推奨されません。むしろ、複数の小さなナラティブノード（`labels`）を作成し、必要に応じて<DynamicLink href="/start/labels-flow">ナラティブフロー制御機能</DynamicLink>で「呼び出す」ことが推奨されます。

そのため、今回のストーリーは線形ですが、2つのナラティブノード（`labels`）に分割します。最初のものは先ほど作成したもの（`start`）で、2つ目は `second_part` という名前になります。

以下がその例です。

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
james: You're my roommate's replacement, huh?
james: Don't worry, you don't have much to live up to. Just don't use heroin like the last guy, and you' fine!
mc: ...

He thrusts out his hand.

james: James!
mc: ...Peter.

// ...
-> second_part

=== second_part ===

She enters my room before I'VE even had a chance to. \\n\\n...I could've just come back and gotten the platter later...
She sets it on a desk. I throw my two paper bags down beside the empty bed.

steph: They got you a new mattress, right? That last guy was a druggie, did James tell you that?
sly: *We're* the reason he got expelled!
steph: Sly! If word gets out about that... well, actually, it wouldn't matter, *he's* the one who shot himself up.

I'm fumbling for a new subject.

// ...
-> DONE
```


## 選択肢メニュー

ここでは、プレイヤーにビジュアルノベルの第2部に進むかどうかを尋ねます。

To do this, we will set [`narration.choices`](/jsdoc/pixi-vn/index/interfaces/NarrationChoicesInterface#list) to an array of choice options created with [`newChoiceOption`](/jsdoc/pixi-vn/index/functions/newChoiceOption) (to jump or call a `label`) and [`newCloseChoiceOption`](/jsdoc/pixi-vn/index/functions/newCloseChoiceOption) (to close the choice menu without navigating anywhere).

:::tip

選択肢メニューについての詳細は<DynamicLink href="/start/choices">こちら</DynamicLink>をご覧ください。

:::

以下がその例です。

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

You want continue to the next part?
* Yes, I want to continue
-> second_part
* No, I want to stop here
-> END

=== second_part ===

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    async () => {
        narration.dialogue = `You want continue to the next part?`;
        narration.choices = [
            newChoiceOption(
                "Yes, I want to continue",
                secondPart,
                {},
                { type: "jump" },
            ),
            newCloseChoiceOption("No, I want to stop here"),
        ];
    },
]);
export default startLabel;

const secondPart = newLabel("second_part", [
    // ...
]);
```

## キャラクター情報を編集し変数として使用する

ここでは、プレイヤーに `mc` の名前を変更できるようにします。
そのために、プレイヤーに<DynamicLink href="/start/input">Pixi’VNの機能を使って入力ボックスに入力してもらいます</DynamicLink>。

入力値を取得した後、その値を使って<DynamicLink href="/start/character#edit">キャラクター名を設定</DynamicLink>できます。

:::tip

*ink* では、`_input_value_` はプレイヤーが入力した値を保持する特別な変数です。 詳細は<DynamicLink href="/ink/input">こちら</DynamicLink>をご覧ください。

:::

以下がその例です。

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

He thrusts out his hand.
# request input type string default Peter
What is your name?
# rename mc { _input_value_ }

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    () => {
        narration.dialogue = `He thrusts out his hand.`;
    },
    () => {
        narration.input.request({ type: "string" }, "Peter");
        narration.dialogue = `What is your name?`;
    },
    () => {
        mc.name = narration.input.value as string;
    },
    // ...
]);
export default startLabel;
```

これで、ダイアログ内で<DynamicLink href="/start/character#use">キャラクター名を使用</DynamicLink>できるようになりました。

:::tip

*ink* では、角括弧（例：`[sly]`）を使うことで<DynamicLink href="/ink/replacement">テキスト置換</DynamicLink>の仕組みを利用できます。デフォルトでは、テンプレートは角括弧の間のテキストがキャラクターの `id` と一致するかどうかを確認し、一致する場合はそのキャラクターの名前に置き換えます。

JS/TSでは、`${}` を使った[テンプレートリテラル](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Template_literals)（例：`` `${sly.name}` ``）を使うことで同じ結果を得られます。

:::

以下がその例です。

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
VAR steph_fullname = "Stephanie"

=== start ===
// ...

sly: I just wanted to see what the new guy was like. Hey, you, [mc]- be nice to our little brother, or you'll have to deal with *us*.
mc: ...
james: [mc], this is [sly]. Yes, that is her real name.

I put out my hand.

sly: I'm not shakin' your hand until I decide you're an all-right dude. Sorry, policy.
mc: Fair enough, I'm a pretty scary guy, or so l've been told.
james: The redhead behind her is [steph_fullname].
steph: Hey! Everyone calls me [steph]. I'll shake your hand.

She puts out her hand, and I take it.

mc: Thanks, good to meet you, [steph_fullname].
steph: WOW, that is, like, the most perfect handshake I've ever had! Firm, but also gentle. [sly], you *gotta* shake his hand!

// ...
-> DONE
```

## アセットを定義して読み込む

:::tip

アセット（画像、gif、動画など） を読み込んで操作するには、`Assets` を使用する必要があります。 `Assets` は多くの機能を持つクラスで、PixiJSライブラリに由来します。詳細を知りたい場合は[こちら](https://pixijs.com/8.x/guides/components/assets)をお読みください。

:::

最初のステップの一つは、ビジュアルノベルのアセットをどこに保存するかを選ぶことです。オンラインのホスティングサービスを使うか、プロジェクト内にローカルで保存するかのいずれかです。 両方の選択肢についての詳細は<DynamicLink href="/start/assets">こちら</DynamicLink>をご覧ください。

アセットをローカルに保存することを選ぶ場合は、`src/assets` の中に配置するだけで済みます。テンプレートは自動的にAssetPackを使ってファイルを解析し、`src/assets/manifest.gen.json` に定義します。 一方、オンラインで管理することを選ぶ場合は、`assets/index.ts` を手動で編集して登録する必要があります。

どちらの場合も、各アセットには1つ以上のエイリアス（`alias`）が割り当てられ、コード内でそのアセットを参照する際に使用できます。

<Files>

            <Folder name="assets" defaultOpen>
                <Folder name="images" defaultOpen>
                    <File name="icon.png" />
                </Folder>
                <File name="manifest.gen.json" />
                <File name="index.ts" />
            </Folder>
        </Folder>
    </Folder>
</Files>

<Accordions>

<Accordion title="`sprite` とは何ですか？" id="what-is-a-sprite">

コンピューターグラフィックスにおいて、スプライトとは、より大きなシーンに組み込まれる2次元のビットマップのことで、多くの場合2Dのビデオゲームで使われます。 Pixi’VNでは、キャンバス上に表示される1枚の画像（例えば背景や、キャラクターの体・目・口など）が `Sprite` です。

</Accordion>

<Accordion title="`container` とは何ですか？" id="what-is-a-container">

コンテナとは、他のコンポーネント（スプライトや、さらには他のコンテナ）をグループ化し、それらを単一のユニットとして配置・移動・操作できるようにしつつ、個々の子要素にも個別にアクセスして編集できるようにするコンポーネントです。

</Accordion>

</Accordions>

<Accordion title="アニメーションを構築する" id="building-an-animation">

ビジュアルノベルをより動的にするために、アニメーションを使用できます。 多くのプロパティを設定する必要がある場合は、より高い制御性、機能性、そして型のフィードバックが得られるため、TypeScriptの使用をお勧めします。

この例では、私のアニメーションは `steph` をシーンから退出させ、次のナラティブステップ（`step`）で再び登場させます。 また、正しい向きを向くようにx軸で反転させます。

`steph` を退出/登場させるために、`moveOut` と `moveIn` 関数を使用します。 ミラー効果には `canvas.animate` 関数を使用します。

まず、`canvas.animate` 関数を使用して、`scaleX` プロパティを `-1`（反転）から `1` に設定するアニメーションを作成します。すぐに開始しないように `autoplay: false` を指定します。

説明のためだけに、*ink* での同等の記述は次のようになります。

```ink tab="ink"
# animate steph scaleX 1 options autoplay false completeOnContinue true
```

```ts tab="Typescript"
canvas.animate<ImageContainer>(
    "steph",
    {
        scaleX: 1,
    },
    { autoplay: false, completeOnContinue: true },
);
```

次に、`moveIn` 関数を使って `steph` をシーンに移動させます。この際、トランジション完了後にアニメーションを再開できるよう、アニメーションの `tickerId` を渡します。

次のナラティブステップ（`step`）が実行される前にアニメーションが完了することを保証するために、`completeOnContinue: true` オプションを使用します。 `moveIn` はトランジションであるため、`completeOnContinue` はデフォルトで true です。

:::tip

アニメーションの使い方についての詳細は<DynamicLink href="/start/canvas-animations-effects">こちら</DynamicLink>をご覧ください。

:::

## サウンドと音楽

ビジュアルノベルにサウンドと音楽を追加するには、`sound` ユーティリティを使用できます。

サウンドチャンネルを定義することで、異なる種類のサウンド（例：BGM、SFX）を管理し、その音量、一時停止、再開などを制御できます。 チャンネルはゲームの開始時、例えば `Game.init` 関数の `then` コールバック内で定義することをお勧めします。

この例では、バックグラウンドミュージック（BGM）用とサウンドエフェクト（SFX）用の2つのチャンネルを定義します。 また、`defaultChannelAlias` をSFXチャンネルに設定するので、サウンドを再生する際にチャンネルを指定しなければ、デフォルトでSFXチャンネルで再生されます。 バックグラウンドチャンネルを定義するために、`background` プロパティを `true` に設定します。これにより、他のチャンネルとは異なり、各ナラティブステップ（`step`）の終わりでサウンドが停止されることはなく、一時停止または停止されるまで継続します。

```ts title="main.ts"
import { Game, sound } from "@drincs/pixi-vn";
import { BGM_CHANNEL_NAME, SFX_CHANNEL_NAME } from "@/constans";

Game.init(body, {
    // ...
}).then(() => {
    sound.channels.add(BGM_CHANNEL_NAME, { background: true });
    sound.channels.add(SFX_CHANNEL_NAME);
    sound.defaultChannelAlias = SFX_CHANNEL_NAME;
});
```

最後に、ナラティブノード（`labels`）内で `sound.play` 関数を使ってサウンドや音楽を再生できます。 また、チャンネルを使用して異なる種類のサウンド（例：BGM、SFX）を管理し、その音量、一時停止、再開などを制御することもできます。

:::
