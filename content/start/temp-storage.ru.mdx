---
title: Временное хранилище
description: Объясняет, как использовать временное хранилище в Pixi’VN для переменных, которые нужны только в течение определённого периода повествования.
---

Во многих случаях полезно использовать переменные только в течение определённого периода повествования. При использовании обычного хранилища такие переменные пришлось бы удалять вручную, когда они больше не нужны, чтобы сохранения оставались лёгкими и эффективными.

Для решения этой проблемы в Pixi’VN есть система временного хранилища. Временные переменные, инициализированные в нарративном узле (`label`), будут удалены при закрытии этого нарративного узла (`label`). Если из него вызывается другой нарративный узел (`label`), временная переменная останется доступной из дочернего нарративного узла (`label`). Однако если другой нарративный узел (`label`) вызывается с помощью `jump` (при этом текущий нарративный узел (`label`) будет закрыт, а новый — запущен), временная переменная станет недоступной.

## Установка

Чтобы установить временную переменную, используйте [`storage.setTempVariable`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#settempvariable).

```ts
import { storage } from "@drincs/pixi-vn";

storage.setTempVariable("myTempVariable", 42);
```

## Получить

Чтобы получить временную переменную, используйте обычную функцию [`storage.get`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#get).

## Удалить

Чтобы удалить временную переменную, используйте [`storage.removeTempVariable`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#removetempvariable).

```ts
import { storage } from "@drincs/pixi-vn";

storage.removeTempVariable("myTempVariable");
```
