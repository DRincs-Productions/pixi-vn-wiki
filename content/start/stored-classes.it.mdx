  Come creare classi le cui proprietà vengono archiviate utilizzando `StoredClassModel`.
---

Pixi’VN fornisce una classe astratta [`StoredClassModel`](/jsdoc/pixi-vn/index/classes/StoredClassModel) che puoi utilizzare per creare classi con proprietà salvate nell'archiviazione di gioco.

```ts
const CITY_CATEGORY = "city";

export default class City extends StoredClassModel {
    constructor(id: string, props: CityProps) {
        super(CITY_CATEGORY, id);
        // ...
    }
}
```

```ts
const milan = new City("milan", {
    // ...
});
```

## Proprietà di archiviazione

Per archiviare le proprietà di una classe nell'archiviazione di gioco, utilizza gli helper [`getStorageProperty`](/jsdoc/pixi-vn/index/classes/StoredClassModel#getstorageproperty) e [`setStorageProperty`](/jsdoc/pixi-vn/index/classes/StoredClassModel#setstorageproperty).

```ts
export default class City extends StoredClassModel {
    constructor(id: string, props: CityProps) {
        // ...
    }

    get inhabitants(): number {
        return this.getStorageProperty<string>("inhabitants") || "";
    }
    set inhabitants(value: number) {
        this.setStorageProperty("inhabitants", value);
    }
}
```

```ts
const milan = new City("milan", {
    // ...
});

milan.inhabitants = 100000;
```
