Como se explica con más detalle <DynamicLink href="/start/canvas#pixijs-differences">aquí</DynamicLink>, toda la parte de renderizado de Pixi’VN se basa en PixiJS. Aprovechando las <DynamicLink href="/start/interface#adding-pixijs-ui-layers">PixiJS Layers</DynamicLink>, puedes usar PixiJS para crear pantallas de UI personalizadas.

:::tip[Plantillas]

En todas las plantillas, se crea una PixiJS Layer llamada "ui" al iniciar. Puedes usar esta capa para crear tus pantallas de UI.

:::

También puedes combinar componentes de HTML Layer con los de PixiJS Layer. Para hacerlo, añade los componentes de PixiJS durante el primer renderizado de una pantalla HTML y limpia la PixiJS Layer cuando se cierre la pantalla.

Por ejemplo:

```tsx title="React"
import { useEffect } from "react";
import { Assets, canvas } from "@drincs/pixi-vn";
import { Sprite } from "pixi.js";

export default function MyScreen() {
    useEffect(() => {
        let layer = canvas.layers.get("ui");
        if (layer) {
            const texture = await Assets.load(
                "https://pixijs.com/assets/bunny.png",
            );

        }

            canvas.layers.get("ui")?.removeChildren();
        };
    });

    return null;
}
```
