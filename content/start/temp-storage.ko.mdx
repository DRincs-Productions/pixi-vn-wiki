---

많은 경우, 내러티브의 특정 기간 동안에만 변수를 사용하는 것이 유용합니다. 일반 저장소를 사용하면, 더 이상 필요하지 않을 때 이러한 변수를 수동으로 제거해야 세이브 데이터를 가볍고 효율적으로 유지할 수 있습니다.

이 문제를 해결하기 위해 Pixi’VN에는 임시 저장소 시스템이 있습니다. 내러티브 노드 (`label`)에서 초기화된 임시 변수는 해당 내러티브 노드 (`label`)가 닫힐 때 삭제됩니다. 그곳에서 다른 내러티브 노드 (`label`)가 호출되면, 임시 변수는 자식 내러티브 노드 (`label`)에서도 계속 접근할 수 있습니다. 그러나 `jump`로 다른 내러티브 노드 (`label`)가 호출되면(현재 내러티브 노드 (`label`)가 닫히고 새 노드가 시작되므로), 임시 변수는 더 이상 접근할 수 없습니다.

## 설정

To set a temporary variable, use [`storage.temp.set`](/jsdoc/pixi-vn/index/interfaces/StorageTempInterface#set).

```ts
import { storage } from "@drincs/pixi-vn";

storage.temp.set("myTempVariable", 42);
```

## 가져오기

임시 변수를 가져오려면 일반 [`storage.get`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#get) 함수를 사용하세요.

## 제거

To remove a temporary variable, use [`storage.temp.remove`](/jsdoc/pixi-vn/index/interfaces/StorageTempInterface#remove).

```ts
import { storage } from "@drincs/pixi-vn";

storage.temp.remove("myTempVariable");
```
