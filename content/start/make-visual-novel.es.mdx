Este tutorial te guiará a través del proceso de creación de tu primera Visual Novel.

<Accordions>

<Accordion title="¿Qué es una Visual Novel?" id="what-is-a-visual-novel">

Una visual novel (VN) es una forma de ficción interactiva digital. Los visual novels suelen asociarse con el medio de los videojuegos, pero no siempre se clasifican como tales. Combinan una narrativa textual con ilustraciones estáticas o animadas y un grado variable de interactividad. El formato se denomina más raramente novel game, una retranscripción del término wasei-eigo noberu gēmu (ノベルゲーム), que se usa más a menudo en japonés.

</Accordion>

</Accordions>

Con fines de prueba, en esta guía recrearemos la visual novel [Breakdown](https://joshpowlison.itch.io/breakdown) usando Pixi’VN. Breakdown es una historia corta que tiene todas las características que debería tener una visual novel. Josh Powlison, el creador de Breakdown, nos ha dado permiso para usar su narración con fines educativos❤️.

:::tip

Dado que Pixi’VN te da la posibilidad de escribir tu propia narración eligiendo uno o más <DynamicLink href="/start/narration">lenguajes narrativos disponibles</DynamicLink>, se realizarán ejemplos para cada lenguaje actualmente disponible en cada paso del desarrollo.

:::

## Crear un nuevo proyecto

Antes de empezar, asegúrate de haber instalado los <DynamicLink href="/start#prerequisites">requisitos previos</DynamicLink>.

El primer paso es crear un nuevo proyecto. Puedes hacerlo ejecutando:

```npm
npm create pixi-vn@latest
```

y seleccionando la plantilla `Visual Novel`.

:::tip[VS Code]

Si abres el proyecto con VS Code, se te pedirá que aceptes ejecutar algunas tareas del espacio de trabajo y que instales las extensiones recomendadas para el proyecto. Se recomienda encarecidamente aceptar ambas.

:::

Puedes encontrar más información sobre plantillas, tareas y extensiones <DynamicLink href="/start/templates">aquí</DynamicLink>.

<Accordions>

<Accordion title="Comandos manuales" id="manual-commands">

Si prefieres no usar las tareas de VS Code, puedes obtener el mismo resultado ejecutando los siguientes comandos desde la raíz del proyecto:

```npm
npm install
npm start
```

</Accordion>

</Accordions>

## Creación de personajes

Ahora definiremos los personajes de esta historia. Para ello, definiremos en el archivo `/content/characters.ts` los personajes que utilizaremos.

<Accordions>

<Accordion title="¿Qué significa `mc`?" id="what-does-mc-mean">

`mc` es una abreviatura común de "Main Character" (personaje principal). Es una práctica común en las visual novels usar `mc` como el nombre del personaje principal.

</Accordion>

<Accordion title="¿Dónde se define el modelo `Character`?" id="where-is-the-character-model-defined">

El modelo `Character` utilizado a continuación se define en `models/Character.ts`. Puedes modificarlo a tu gusto, por ejemplo para añadir más propiedades relacionadas con el personaje (por ejemplo, `surname`, `age`, ...). Puedes encontrar más información sobre este archivo <DynamicLink href="/start/character#custom-class">aquí</DynamicLink>.

</Accordion>

</Accordions>

:::tip

Para más información sobre cómo crear y usar personajes puedes consultar: <DynamicLink href="/start/character">Personajes</DynamicLink>

:::

```ts title="content/characters.ts"
import Character from "@/models/Character";
import { RegisteredCharacters } from "@drincs/pixi-vn";

export const mc = new Character("mc", {
    name: "Me",
});

export const james = new Character("james", {
    name: "James",
    color: "#0084ac",
});

export const steph = new Character("steph", {
    name: "Steph",
    color: "#ac5900",
});

export const sly = new Character("sly", {
    name: "Sly",
    color: "#6d00ac",
});

RegisteredCharacters.add([mc, james, steph, sly]);
```

## Primer borrador de la narrativa

:::tip[Markup]

Todas las plantillas tienen soporte para <DynamicLink href="/start/markup-markdown">Markdown</DynamicLink> y <DynamicLink href="/start/markup-tailwindcss">Tailwind CSS</DynamicLink>, así que lo usaremos para nuestra narración.

Ahora podemos empezar a escribir el "primer borrador" de la <DynamicLink href="/start/narration">narración</DynamicLink> de la visual novel.

<Accordion title="Usar la función `glue` de los diálogos" id="use-the-glue-feature-of-dialogues">

En las visual novels, a menudo resulta útil pegar texto en el diálogo actual. Por ejemplo, para pausar una conversación y hacer que continúe en un `step` posterior. Para ello, podemos usar la <DynamicLink href="/start/dialogue#dialogue-glue">funcionalidad de glue</DynamicLink>.

Este es el ejemplo:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

james: Ooh, [mc]! Nice, firm handshake!
<>The last guy always gave me the dead fish.
<>I already think we're gonna get along fine.
james: Come on in and...

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    async () =>
        (narration.dialogue = {
            character: james,
            text: `Ooh, ${mc.name}! Nice, firm handshake!`,
        }),
    async () => {
        narration.dialogGlue = true;
        narration.dialogue = `The last guy always gave me the dead fish.`;
    },
    async () => {
        narration.dialogGlue = true;
        narration.dialogue = `I already think we're gonna get along fine.`;
    },
    async () =>
        (narration.dialogue = { character: james, text: `Come on in and...` }),
    // ...
]);
export default startLabel;
```

</Accordion>

### Dividir la narrativa en `labels`

No es recomendable crear `labels` muy largos (incluso para visual novels lineales), sino que es recomendable crear múltiples `labels` pequeños y "llamarlos" cuando sea necesario con las <DynamicLink href="/start/labels-flow">funciones de control de flujo de la narración</DynamicLink>.

Por esta razón, aunque en nuestro caso nuestra historia es lineal, se dividirá en dos `labels`: el primero será el que acabamos de crear (`start`), mientras que el segundo se llamará `second_part`.

Este es el ejemplo:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
james: You're my roommate's replacement, huh?
james: Don't worry, you don't have much to live up to. Just don't use heroin like the last guy, and you' fine!
mc: ...

He thrusts out his hand.

james: James!
mc: ...Peter.

// ...
-> second_part

=== second_part ===

She enters my room before I'VE even had a chance to. \\n\\n...I could've just come back and gotten the platter later...
She sets it on a desk. I throw my two paper bags down beside the empty bed.

steph: They got you a new mattress, right? That last guy was a druggie, did James tell you that?
sly: *We're* the reason he got expelled!
steph: Sly! If word gets out about that... well, actually, it wouldn't matter, *he's* the one who shot himself up.

I'm fumbling for a new subject.

// ...
-> DONE
```


## Menús de elección

Ahora le preguntaremos al jugador si quiere continuar con la segunda parte de la visual novel.

Para ello, estableceremos [`narration.choices`](/jsdoc/pixi-vn/index/interfaces/NarrationManagerInterface#choices) con un array de opciones de elección creadas con [`newChoiceOption`](/jsdoc/pixi-vn/index/functions/newChoiceOption) (para saltar o llamar a un `label`) y [`newCloseChoiceOption`](/jsdoc/pixi-vn/index/functions/newCloseChoiceOption) (para cerrar el menú de elección sin navegar a ningún sitio).

:::tip

Puedes encontrar más información sobre los menús de elección <DynamicLink href="/start/choices">aquí</DynamicLink>.

:::

Este es el ejemplo:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

You want continue to the next part?
* Yes, I want to continue
-> second_part
* No, I want to stop here
-> END

=== second_part ===

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    async () => {
        narration.dialogue = `You want continue to the next part?`;
        narration.choices = [
            newChoiceOption(
                "Yes, I want to continue",
                secondPart,
                {},
                { type: "jump" },
            ),
            newCloseChoiceOption("No, I want to stop here"),
        ];
    },
]);
export default startLabel;

const secondPart = newLabel("second_part", [
    // ...
]);
```

## Editar la información del personaje y usarla como variable

Ahora le daré al jugador la posibilidad de cambiar el nombre del `mc`.
Para ello, le pediré al jugador que <DynamicLink href="/start/input">complete un cuadro de entrada usando las funciones de Pixi’VN</DynamicLink>.

Después de obtener el valor de entrada, puedes <DynamicLink href="/start/character#edit">establecer el nombre del personaje</DynamicLink> usando el valor obtenido.

:::tip

En *ink*, `_input_value_` es una variable especial que contiene el valor introducido por el jugador. Puedes leer más al respecto <DynamicLink href="/ink/input">aquí</DynamicLink>.

:::

Este es el ejemplo:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

He thrusts out his hand.
# request input type string default Peter
What is your name?
# rename mc { _input_value_ }

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    () => {
        narration.dialogue = `He thrusts out his hand.`;
    },
    () => {
        narration.requestInput({ type: "string" }, "Peter");
        narration.dialogue = `What is your name?`;
    },
    () => {
        mc.name = narration.inputValue as string;
    },
    // ...
]);
export default startLabel;
```

Ahora podríamos <DynamicLink href="/start/character#use">usar nombres de personajes</DynamicLink> dentro de los diálogos.

:::tip

En *ink*, puedes usar corchetes (por ejemplo, `[sly]`) para aprovechar el mecanismo de <DynamicLink href="/ink/replacement">reemplazo de texto</DynamicLink>: por defecto, las plantillas comprueban si el texto entre corchetes coincide con un `id` de personaje, y si es así, lo reemplazan con el nombre de ese personaje.

En JS/TS, puedes lograr el mismo resultado usando [template literals](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Template_literals) con `${}` (por ejemplo, `` `${sly.name}` ``).

:::

Este es el ejemplo:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
VAR steph_fullname = "Stephanie"

=== start ===
// ...

sly: I just wanted to see what the new guy was like. Hey, you, [mc]- be nice to our little brother, or you'll have to deal with *us*.
mc: ...
james: [mc], this is [sly]. Yes, that is her real name.

sly: I'm not shakin' your hand until I decide you're an all-right dude. Sorry, policy.

She puts out her hand, and I take it.

mc: Thanks, good to meet you, [steph_fullname].
steph: WOW, that is, like, the most perfect handshake I've ever had! Firm, but also gentle. [sly], you *gotta* shake his hand!

// ...
-> DONE
```

## Definir recursos y cargarlos

:::tip

Para cargar y manipular recursos (imágenes, gifs, vídeos...) necesitarás usar `Assets`. `Assets` es una clase con muchas funciones y proviene de la biblioteca PixiJS; si quieres más información, lee [aquí](https://pixijs.com/8.x/guides/components/assets).

:::

Uno de los primeros pasos es elegir dónde guardar los recursos de tu visual novel: puedes usar un servicio de alojamiento en línea o guardarlos localmente en el proyecto. Puedes encontrar más información sobre ambas opciones <DynamicLink href="/start/assets">aquí</DynamicLink>.

Si eliges guardar los recursos localmente, solo necesitas colocarlos dentro de `src/assets`: la plantilla usa automáticamente AssetPack para analizar los archivos y definirlos en `src/assets/manifest.gen.json`. Si en cambio eliges mantenerlos en línea, tendrás que editar manualmente `assets/index.ts` para registrarlos.

En ambos casos, a cada recurso se le asigna uno o más `alias`, que luego puedes usar en tu código para hacer referencia a ese recurso.

<Accordions>

<Accordion title="¿Qué es un `sprite`?" id="what-is-a-sprite">

En gráficos por computadora, un sprite es un mapa de bits bidimensional que se integra en una escena más grande, con mayor frecuencia en un videojuego 2D. En Pixi’VN, una única imagen mostrada en el canvas (por ejemplo, el fondo, o el cuerpo/ojos/boca de un personaje) es un `Sprite`.

</Accordion>

<Accordion title="¿Qué es un `container`?" id="what-is-a-container">

Un container es un componente que agrupa otros componentes (sprites o incluso otros containers) para que puedan posicionarse, moverse y manipularse como una sola unidad, sin dejar de poder acceder y editar cada elemento hijo individual.

</Accordion>

</Accordions>

<Accordion title="Construir una animación" id="building-an-animation">

Para hacer la visual novel más dinámica, puedes usar animaciones. Recomiendo usar TypeScript si necesitas establecer muchas propiedades, ya que esto te da más control, más funcionalidad y retroalimentación de tipos.

En este ejemplo, mi animación sacará a `steph` de la escena y la reinsertará en el siguiente `step`. También la reflejaré en el eje x para asegurarme de que mira en la dirección correcta.

Para sacar/meter a `steph`, usaré las funciones `moveOut` y `moveIn`. Para el efecto espejo, usaré la función `canvas.animate`.

Primero, uso la función `canvas.animate` para crear una animación que establece la propiedad `scaleX` de `-1` (reflejado) a `1`, con `autoplay: false` para que no se inicie inmediatamente.

Solo con fines explicativos, así es como se vería el equivalente en *ink*:

```ink tab="ink"
# animate steph scaleX 1 options autoplay false completeOnContinue true
```

```ts tab="Typescript"
canvas.animate<ImageContainer>(
    "steph",
    {
        scaleX: 1,
    },
    { autoplay: false, completeOnContinue: true },
);
```

Luego, uso la función `moveIn` para mover a `steph` hacia la escena, pasando el `tickerId` de la animación para que pueda reanudarse después de que la transición se complete.

Uso la opción `completeOnContinue: true` para asegurarme de que la animación se complete antes de que se ejecute el siguiente `step`. Para `moveIn`, al ser una transición, `completeOnContinue` es true por defecto.

:::tip

Para más información sobre cómo usar animaciones, consulta <DynamicLink href="/start/canvas-animations-effects">aquí</DynamicLink>.

:::

Dado que uso TypeScript para esta animación, creé un `label` para ella, de modo que también pueda llamarse desde otros lenguajes.

```ts title="labels/animation01.ts"
import { canvas, ImageContainer, moveIn, newLabel } from "@drincs/pixi-vn";

export const animation01 = newLabel("animation_01", [
    async () => {
        let tickerId = canvas.animate<ImageContainer>(
            "steph",
            {
                scaleX: 1,
            },
            { autoplay: false, completeOnContinue: true },
        );

        await moveIn(
            "steph",
            {
                value: ["fm02-body", "fm02-eyes-joy", "fm02-mouth-smile01"],
                options: {
                    xAlign: 0.8,
                    yAlign: 1,
                    scale: { y: 1, x: -1 },
                    anchor: 0.5,
                },
            },
            {
                direction: "right",
                ease: "easeInOut",
                tickerIdToResume: tickerId,
            },
        );
    },
]);
```

Como se explica <DynamicLink href="/ink/labels#use-the-call-script">aquí</DynamicLink>, desde *ink* puedes llamar a `labels` escritos en JS/TS y viceversa.

:::

## Sonidos y música

Para añadir sonidos y música a tu visual novel, puedes usar la utilidad `sound`.

Puedes definir canales de sonido para gestionar diferentes tipos de sonidos (por ejemplo, BGM, SFX) y controlar su volumen, pausa, reanudación, etc. Se recomienda definir los canales al inicio del juego, por ejemplo en el callback `then` de la función `Game.init`.

En este ejemplo, defino dos canales: uno para la música de fondo (BGM) y otro para los efectos de sonido (SFX). También establezco `defaultChannelAlias` en el canal SFX, de modo que si no especifico un canal al reproducir un sonido, se reproducirá en el canal SFX por defecto. Para definir el canal de fondo, establezco la propiedad `background` en `true`, de modo que, a diferencia de los otros canales, los sonidos no se detendrán al final de cada `step` narrativo, sino que continuarán hasta que se pausen o detengan.

```ts title="main.ts"
import { Game, sound } from "@drincs/pixi-vn";
import { BGM_CHANNEL_NAME, SFX_CHANNEL_NAME } from "@/constans";

Game.init(body, {
    // ...
}).then(() => {
    sound.addChannel(BGM_CHANNEL_NAME, { background: true });
    sound.addChannel(SFX_CHANNEL_NAME);
    sound.defaultChannelAlias = SFX_CHANNEL_NAME;
});
```
