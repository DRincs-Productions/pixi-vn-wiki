---
title: フラグ管理
description: Pixi’VN でゲームの流れを制御するためにブール型フラグを使用する方法を説明します。
---

Pixi’VN には「ゲームフラグ」を管理するための関数が用意されています。 ゲームフラグは、ゲームの流れを制御したり、他のブール値をゲームストレージに保存するために使用されるブール値です。

このメカニズムは通常のストレージを使用する場合よりもセーブデータのサイズへの影響がはるかに小さいため、頻繁に変更されるブール値にはフラグを使用することが推奨されます。

## 設定

フラグを設定するには、[`storage.setFlag`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#setflag) 関数を使用します。

```ts
import { storage } from "@drincs/pixi-vn";

storage.setFlag("flag1", true);
```

## 取得

フラグを取得するには、[`storage.getFlag`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#getflag) 関数を使用します。

```ts
import { storage } from "@drincs/pixi-vn";

const flag1 = storage.getFlag("flag1");
```
