## Как использовать шаблон

Если вы читаете эту страницу, скорее всего, вы уже создали проект по шаблону. В следующих разделах описаны первые шаги по запуску проекта.

### Первоначальная настройка

Откройте папку проекта в вашей IDE. В примерах ниже используется [Visual Studio Code](https://code.visualstudio.com/).

После открытия проекта VS Code автоматически предложит несколько действий:

* **Установить рекомендуемые расширения** — появится уведомление с предложением установить расширения, рекомендуемые для рабочей области. Настоятельно рекомендуем согласиться. Если уведомление не появится, расширения можно установить вручную через панель «Расширения», отфильтровав [рекомендуемые расширения](https://code.visualstudio.com/docs/editor/extension-marketplace#_recommended-extensions).
* **Выполнить задачи запуска** — VS Code может предложить запустить настроенные задачи запуска, которые установят все зависимости проекта. Если вы предпочитаете делать это вручную, выполните:

```npm
npm install
```

:::warning[Кроссплатформенная сборка]

Если вы выбрали шаблон для настольных или мобильных платформ, потребуется установить дополнительные зависимости [Tauri](https://v2.tauri.app/start/prerequisites/) (инструментарий Rust и инструменты сборки для соответствующих платформ). Поскольку Tauri тесно интегрируется с системным окружением, перед запуском проекта как настольного приложения вам, вероятно, потребуется **перезапустить VS Code один или несколько раз**.

:::

### Запуск проекта

Шаблон включает набор предварительно настроенных **конфигураций запуска** для VS Code. Если вы с ними не знакомы: конфигурации запуска — это ярлыки, которые указывают VS Code, как запускать проект (и при необходимости подключать отладчик), чтобы не вводить команды в терминале каждый раз. Открыть их можно на панели **Запуск и отладка** (значок воспроизведения на левой боковой панели или клавиша `F5`). Выберите нужную конфигурацию в раскрывающемся списке в верхней части панели и нажмите зелёную кнопку запуска.

![Панель запуска и отладки](/launch-configuration-dropdown.png)

Доступны следующие конфигурации:

* **Debug Game**: эта конфигурация чаще всего используется во время разработки — при каждом сохранении файла браузер автоматически обновляется. Имейте в виду, что в этом режиме анимации могут быть не вполне плавными, а загрузка ресурсов — более медленной, чем в окончательной опубликованной сборке.
* **Debug Game Preview**: эта конфигурация максимально точно имитирует поведение игры после публикации: анимации плавные, время загрузки реалистичное, оптимизации включены. Используйте эту конфигурацию, чтобы перед публикацией убедиться, что игра выглядит и работает так, как задумано.
* **Run as Desktop App (Dev)**: компилирует бэкенд Rust/Tauri и запускает игру в нативном окне настольного приложения. Если шаблон не предназначен для настольных или мобильных платформ, эта конфигурация будет отсутствовать.

### Настройка стиля

Интерфейс шаблона полностью построен на [shadcn/ui](https://ui.shadcn.com/), поэтому цветовую тему можно изменить без редактирования кода компонентов.

Откройте [конструктор тем shadcn/ui](https://ui.shadcn.com/create?template=vite\&base=base\&preset=b1s9eyGkS), настройте цвета по своему вкусу, затем перейдите в раздел **Copy** и скопируйте созданную команду CSS. Выполните эту команду из корневой папки проекта:

```npm
npx shadcn@latest add <paste-the-generated-command-here>
```

После применения рекомендуется заново отформатировать исходные файлы:

```npm
npm run format
```

О дополнительных настройках — шрифтах, глобальных стилях и многом другом — см. <DynamicLink href="/start/interface-font">Стили и шрифты</DynamicLink>.

### Экраны шаблона

Шаблон включает набор готовых экранов, охватывающих основные части визуальной новеллы. Каждый экран представляет собой компонент React, связанный с маршрутом, управляемым TanStack Router.

* **Главное меню** (`/`) — первый экран, который видит игрок при запуске игры. Позволяет начать новую игру, продолжить сохранённую и открыть настройки.
* **Экран повествования** (`/game/narration`) — основной игровой экран, на котором показывается история. Отображает диалоги, спрайты персонажей, фоны и варианты выбора.
* **Настройки** — у панели настроек нет отдельного маршрута. Вместо этого она использует [Search Params](https://tanstack.com/router/latest/docs/framework/react/guide/search-params) для отображения поверх любого активного экрана. Такой подход сохраняет простой URL и позволяет игроку открывать настройки из любой части игры и переключаться между их разделами (звук, изображение, язык и т. д.), не теряя контекст предыдущего экрана.
* **Экран навигации** (`/game/navigation`) — только для *Point & Click*. Позволяет игроку перемещаться между комнатами и выполнять различные действия, доступные в текущем месте.
* **Экран карты** (`/game/map`) — только для *Point & Click*. Показывает карту и позволяет игроку переходить из одного места в другое. Также поддерживает управление несколькими картами.
