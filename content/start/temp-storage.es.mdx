---
title: Almacenamiento temporal
description: Explica cómo usar el almacenamiento temporal en Pixi’VN para variables que solo se necesitan durante un período narrativo específico.
---

En muchos casos, es útil usar variables solo durante un cierto período de la narrativa. Usando el almacenamiento normal, tendrías que eliminar manualmente estas variables cuando ya no sean necesarias, para mantener las partidas guardadas ligeras y eficientes.

Para resolver este problema, Pixi’VN cuenta con un sistema de almacenamiento temporal. Las variables temporales inicializadas en una `label` se eliminarán cuando se cierre la `label`. Si se llama a otra `label` desde ella, la variable temporal seguirá siendo accesible desde la `label` hija. Sin embargo, si se llama a otra `label` con `jump` (de modo que la `label` actual se cerrará y se iniciará la nueva), la variable temporal ya no será accesible.

## Establecer

To set a temporary variable, use [`storage.temp.set`](/jsdoc/pixi-vn/index/interfaces/StorageTempInterface#set).

```ts
import { storage } from "@drincs/pixi-vn";

storage.temp.set("myTempVariable", 42);
```

## Obtener

Para obtener una variable temporal, usa la función normal [`storage.get`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#get).

## Eliminar

To remove a temporary variable, use [`storage.temp.remove`](/jsdoc/pixi-vn/index/interfaces/StorageTempInterface#remove).

```ts
import { storage } from "@drincs/pixi-vn";

storage.temp.remove("myTempVariable");
```
