---
title: 过渡效果
description: 了解 Pixi’VN 中用于显示和移除 canvas 组件的内置过渡效果，包括溶解、淡入淡出、移动、推动和缩放过渡。了解如何自定义或创建自己的过渡效果，以在你的游戏流程中实现高级视觉效果。
---

Pixi’VN 提供了多种过渡效果，用于显示或移除<DynamicLink href="/start/canvas-components">canvas 组件</DynamicLink>，同时也支持[创建你自己的过渡效果](#custom-functionality)。

The examples below use the `transitions` namespace introduced in the upcoming **v1.9.5**.
Import it from `@drincs/pixi-vn` or `@drincs/pixi-vn/canvas`. In v1.9.4, use the individual
function exports instead; those exports remain available but deprecated in v1.9.5.

<Accordions>

<Accordion title="溶解" id="dissolve">

溶解过渡效果：

* 显示组件时，会逐渐增加其 `alpha`。如果存在具有相同 alias 的组件，它将在新组件的过渡效果完成后被移除。
* 移除组件时，会逐渐减少其 `alpha`。

The [`transitions.showWithDissolve`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/showWithDissolve) function displays a canvas element with a dissolve transition.

The [`transitions.removeWithDissolve`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/removeWithDissolve) function removes a canvas element with a dissolve transition.

```ts tab="content/labels/start.label.ts"
import { newLabel, transitions } from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [
    async () => {
        await transitions.showWithDissolve("alien", "egg_head");
        await transitions.showWithDissolve("human", {
            value: ["m01-body", "m01-eyes", "m01-mouth"],
            options: { scale: 0.5, xAlign: 0.7 },
        });
    },
    async () => {
        await transitions.showWithDissolve("alien", "flower_top");
        transitions.removeWithDissolve("human");
    },
]);
```

<Accordion title="淡入淡出" id="fade">

淡入淡出过渡效果：

* 显示组件时，会逐渐增加其 `alpha`。如果存在具有相同 alias 的组件，现有组件将先以淡出效果被移除，然后再显示新组件。
* 移除组件时，会逐渐减少其 `alpha`。

The [`transitions.showWithFade`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/showWithFade) function displays a canvas element with a fade transition.

The [`transitions.removeWithFade`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/removeWithFade) function removes a canvas element with a fade transition.

```ts tab="content/labels/start.label.ts"
import { newLabel, transitions } from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [
    async () => {
        await transitions.showWithFade("alien", "egg_head", { duration: 5 });
        await transitions.showWithFade("human", {
            value: ["m01-body", "m01-eyes", "m01-mouth"],
            options: { scale: 0.5, xAlign: 0.7 },
        });
    },
    async () => {
        await transitions.showWithFade("alien", "flower_top");
        transitions.removeWithFade("human");
    },
]);
```

<Accordion title="移入/移出" id="move-in-out">

移入/移出过渡效果：

* 显示组件时，会将其从 canvas 外部（右侧、左侧、顶部或底部）移动到其在 canvas 上的位置。如果存在具有相同 alias 的组件，现有组件将先以移出效果被移除，然后再显示新组件。
* 移除组件时，会将其从当前位置移动到 canvas 外部。

The [`transitions.moveIn`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/moveIn) function displays a canvas element with a move-in transition.

The [`transitions.moveOut`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/moveOut) function removes a canvas element with a move-out transition.

```ts tab="content/labels/start.label.ts"
import { newLabel, transitions } from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [

        await transitions.moveIn("alien", "egg_head", { direction: "up" });

            value: ["m01-body", "m01-eyes", "m01-mouth"],
            options: { scale: 0.5, xAlign: 0.7 },
        });
    },
    async () => {
        await transitions.moveIn("alien", "flower_top", { direction: "up" });
        transitions.moveOut("human");
    },
]);
```

<Accordion title="Wipe in/out" id="wipe-in-out">

The wipe in/out transition reveals or conceals a component using a moving boundary. It is a single generic primitive rather than separate `wipeLeft`/`wipeRight` functions: the boundary's `angle` (or a `direction` shorthand), edge `softness`, and `invert` are all configurable, so the same primitive can produce horizontal, vertical, diagonal, hard-edged, or soft-edged reveals.

* When showing a component, progressively reveals it as the boundary sweeps across. 如果存在具有相同 alias 的组件，它将在新组件的过渡效果完成后被移除。
* When removing a component, progressively conceals it as the boundary sweeps across.

The [`transitions.wipeIn`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/wipeIn) function displays a canvas element with a wipe-in transition.

The [`transitions.wipeOut`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/wipeOut) function removes a canvas element with a wipe-out transition.

```ts tab="content/labels/start.label.ts"
import { newLabel, transitions } from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [

            value: ["m01-body", "m01-eyes", "m01-mouth"],
            options: { scale: 0.5, xAlign: 0.7 },
        });
    },
    async () => {
        await transitions.wipeIn("alien", "flower_top", { angle: 45, softness: 30 });
        transitions.wipeOut("human");
    },
]);
```

<Accordion title="Iris in/out" id="iris-in-out">

The iris in/out transition reveals or conceals a component using an expanding or contracting radial mask. A centered circular iris is only one configuration: moving `origin` off-center (normalized to the component's own bounds) makes the same primitive useful as a focus/reveal effect centered on a character, and `aspect` turns the circle into a wide or tall ellipse.

* When showing a component, the mask expands from `origin` to progressively reveal it. 如果存在具有相同 alias 的组件，它将在新组件的过渡效果完成后被移除。
* When removing a component, the mask contracts back towards `origin` to progressively conceal it.

The [`transitions.irisIn`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/irisIn) function displays a canvas element with an iris-in transition.

The [`transitions.irisOut`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/irisOut) function removes a canvas element with an iris-out transition.

```ts tab="content/labels/start.label.ts"
import { newLabel, transitions } from "@drincs/pixi-vn";

        await transitions.irisIn("human", {

            options: { scale: 0.5, xAlign: 0.7 },
        });
    },
    async () => {
        await transitions.irisIn("alien", "flower_top", {
            origin: { x: 0.2, y: 0.8 },

    },
]);
```

<Accordion title="Split in/out" id="split-in-out">

The split in/out transition reveals or conceals a component using two mask panels that move apart or together. It covers "curtain"-like effects without a dedicated, story-specific API: `orientation` picks whether the panels split vertically or horizontally, and `origin` moves the split line off-center.

* When showing a component, the two panels slide together from the edges to progressively reveal it, meeting at the split line once fully shown. 如果存在具有相同 alias 的组件，它将在新组件的过渡效果完成后被移除。
* When removing a component, the two panels retract apart towards the edges to progressively conceal it.

The [`transitions.splitIn`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/splitIn) function displays a canvas element with a split-in transition.

The [`transitions.splitOut`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/splitOut) function removes a canvas element with a split-out transition.

<Accordion title="Flash in/out" id="flash-in-out">

The flash in/out transition plays a configurable solid-color overlay that fades in, optionally holds, and fades back out — not limited to a white flash. White reads as a camera/explosion-like flash, black behaves like a blink/cut, and arbitrary colors work for damage, magic, memory, or UI transitions. `pulses` repeats the fade-in/hold/fade-out cycle for a multi-flash effect (e.g. a damage flash).

* When showing a component, the new component appears immediately and the overlay plays over it.
* When removing a component, the overlay plays over it and it is then removed.

The [`transitions.flashIn`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/flashIn) function displays a canvas element with a flash-in transition.

The [`transitions.flashOut`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/flashOut) function removes a canvas element with a flash-out transition.

```ts tab="content/labels/start.label.ts"
import { newLabel, transitions } from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [
    async () => {
        await transitions.flashIn("alien", "egg_head");
        await transitions.flashIn("human", {
            value: ["m01-body", "m01-eyes", "m01-mouth"],
            options: { scale: 0.5, xAlign: 0.7 },
        });
    },
    async () => {
        await transitions.flashIn("alien", "flower_top", {
            color: 0xff0033,
            holdDuration: 0.05,
            pulses: 3,
        });
        transitions.flashOut("human", { color: 0x000000 });
    },
]);
```

<Accordion title="Blur in/out" id="blur-in-out">

The blur in/out transition animates blur strength into or out of focus. It is a generic blur, not a "dream"/"flashback" transition specifically — combine it with `showWithFade` for that recipe (see [custom functionality](#custom-functionality) below for building recipes).

* When showing a component, it appears already blurred and sharpens into focus. 如果存在具有相同 alias 的组件，它将在新组件的过渡效果完成后被移除。
* When removing a component, it blurs out of focus before being removed.

The [`transitions.blurIn`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/blurIn) function displays a canvas element with a blur-in transition.

The [`transitions.blurOut`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/blurOut) function removes a canvas element with a blur-out transition.

```ts tab="content/labels/start.label.ts"
import { newLabel, transitions } from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [
    async () => {
        await transitions.blurIn("alien", "egg_head");
        await transitions.blurIn("human", {
            value: ["m01-body", "m01-eyes", "m01-mouth"],
            options: { scale: 0.5, xAlign: 0.7 },
        });

    async () => {
        await transitions.blurIn("alien", "flower_top", { strength: 60, quality: 6 });
```

创建你自己的过渡效果很简单：使用 <DynamicLink href="/start/canvas-motion">`canvas.animate`</DynamicLink> 来定义自定义效果。

To help you get started, here is a simplified version of [`transitions.showWithDissolve`](/jsdoc/pixi-vn/index/namespaces/transitions/functions/showWithDissolve):

```ts title="canvas/transitions/showWithDissolve.ts"
import { canvas, ImageSprite, UPDATE_PRIORITY } from "@drincs/pixi-vn";
import { AnimationOptions } from "@drincs/pixi-vn/motion";

export default async function showWithDissolve(
    alias: string,
    component: ImageSprite,
    props: AnimationOptions = {},
    priority?: UPDATE_PRIORITY,
): Promise<string[] | undefined> {
    let { completeOnContinue = true, ...options } = props;
    // add the new component
    canvas.add(alias, component);
    // edit the properties of the new component
    component.alpha = 0;
    // create the ticker and play it
    let id = canvas.animate(
        alias,
        {
            alpha: 1,
        },
        {
            ...options,
            completeOnContinue,
        },
        priority,
    );
    // load the image if the image is not loaded
    if (component.haveEmptyTexture) {
        await component.load();
    }
    // return the ids of the tickers
    if (id) {
        return [id];
    }
}
```

### 替换或移除之前的组件

如果已经存在具有相同 alias 的组件，你可以让它被替换，或者：

<Accordions>

<Accordion title="在完成后移除之前的组件" id="remove-the-previous-component-after-completion">

要在新组件的过渡效果完成后移除之前的组件，请使用 <DynamicLink href="/start/canvas-motion">`aliasToRemoveAfter` 属性</DynamicLink>。

```ts title="canvas/transitions/showWithDissolve.ts"
import { canvas, ImageSprite, UPDATE_PRIORITY } from "@drincs/pixi-vn";
import { AnimationOptions } from "@drincs/pixi-vn/motion";

export default async function showWithDissolve(
    alias: string,
    component: ImageSprite,
    props: AnimationOptions = {},
    priority?: UPDATE_PRIORITY,
): Promise<string[] | undefined> {
    let { completeOnContinue = true, ...options } = props;
    // check if the alias is already exist // [!code ++]
    let oldComponentAlias: string | undefined = undefined; // [!code ++]
    let oldComponent = canvas.find(alias); // [!code ++]
    if (oldComponent) {
        // [!code ++]
        oldComponentAlias = alias + "_temp_disolve"; // [!code ++]
        canvas.editAlias(alias, oldComponentAlias); // [!code ++]
    } // [!code ++]
    // add the new component and transfer the properties of the old component to the new component
    canvas.add(alias, component);
    oldComponent?.parent?.setChildIndex(
        oldComponent,
        oldComponent.parent.getChildIndex(oldComponent) - 0.1,
    ); // [!code ++]
    oldComponentAlias &&
        canvas.copyCanvasElementProperty(oldComponentAlias, alias); // [!code ++]
    oldComponentAlias &&
        canvas.tickers.transfer(oldComponentAlias, alias, "duplicate"); // [!code ++]
    // edit the properties of the new component
    component.alpha = 0;
    // create the ticker and play it
    let id = canvas.animate(
        alias,
        {
            alpha: 1,
        },
        {
            ...options,
            completeOnContinue,
        },
        priority,
    );
    // load the image if the image is not loaded
    if (component.haveEmptyTexture) {
        await component.load();
    }
    // return the ids of the tickers
    if (id) {
        return [id];
    }
}
```

<Accordion title="通过过渡效果移除之前的组件" id="remove-the-previous-component-with-a-transition">

要通过过渡效果移除之前的组件，请使用 <DynamicLink href="/start/canvas-motion">`canvas.animate`</DynamicLink> 运行另一个动画，并使用 <DynamicLink href="/start/canvas-motion">`tickerIdToResume` 属性</DynamicLink>。

```ts title="canvas/transitions/showWithFade.ts"
import { canvas, ImageSprite, UPDATE_PRIORITY } from "@drincs/pixi-vn";
import { AnimationOptions } from "@drincs/pixi-vn/motion";

export default async function showWithDissolve(
    alias: string,
    component: ImageSprite,
    props: AnimationOptions = {},
    priority?: UPDATE_PRIORITY,
): Promise<string[] | undefined> {
    let { completeOnContinue = true, ...options } = props;
    // check if the alias is already exist // [!code ++]
    let oldComponentAlias: string | undefined = undefined; // [!code ++]
    let oldComponent = canvas.find(alias); // [!code ++]
    if (oldComponent) {
        // [!code ++]
        return showWithDissolve(alias, component, props, priority); // [!code ++]
    } // [!code ++]
    let oldComponentAlias = alias + "_temp_fade"; // [!code ++]
    canvas.editAlias(alias, oldComponentAlias); // [!code ++]
    // add the new component and transfer the properties of the old component to the new component // [!code ++]
    canvas.add(alias, component);
    oldComponent?.parent?.setChildIndex(
        oldComponent,
        oldComponent.parent.getChildIndex(oldComponent) - 0.1,
    ); // [!code ++]
    oldComponentAlias &&
        canvas.copyCanvasElementProperty(oldComponentAlias, alias); // [!code ++]
    oldComponentAlias &&
        canvas.tickers.transfer(oldComponentAlias, alias, "duplicate"); // [!code ++]
    // edit the properties of the new component
    component.alpha = 0;
    // create the ticker and play it
    let id = canvas.animate(
        alias,
        {
            alpha: 1,
        },
        {
            ...options,
            completeOnContinue,
        },
        priority,
    );
    if (id) {
        // [!code ++]
        // pause the ticker // [!code ++]
        canvas.tickers.pause({ id: id }); // [!code ++]
        // remove the old component // [!code ++]
        canvas.animate(
            // [!code ++]
            alias, // [!code ++]
            {
                // [!code ++]
                alpha: 0, // [!code ++]
            }, // [!code ++]
            {
                // [!code ++]
                ...options, // [!code ++]
                tickerIdToResume: id, // [!code ++]
                aliasToRemoveAfter: oldComponentAlias, // [!code ++]
                completeOnContinue, // [!code ++]
            }, // [!code ++]
            priority, // [!code ++]
        ); // [!code ++]
    } // [!code ++]
    // load the image if the image is not loaded
    if (component.haveEmptyTexture) {
        await component.load();
    }
    // return the ids of the tickers
    if (id) {
        return [id];
    }
}
```
