<Accordion title="Markdown とは？" id="what-is-markdown">

**Markdown** は、プレーンテキストエディタを使ってフォーマットされたテキストを作成するための軽量マークアップ言語です。 John Gruber は 2004 年に Aaron Swartz と共同で Markdown を作成しました。これはソースコードの形式でも読みやすいマークアップ言語として設計されています。 Markdown はブログやインスタントメッセージングに広く使われており、オンラインフォーラム、コラボレーションソフトウェア、ドキュメントページ、readme ファイルなどにも活用されています。

</Accordion>

</Accordions>

Pixi’VN は特定のマークアップに縛られておらず、開発者が好みのマークアップを選択できる自由を提供しています。ただし、Markdown の使用を推奨します。

:::tip[テンプレート]

すべてのテンプレートにおいて、Markdown コンポーネントはすでに定義されています。

:::

:::tip[*ink*]

このメソッドは *ink* 構文で使用できます。詳細は<DynamicLink href="/ink/markup#markdown">こちら</DynamicLink>をご覧ください。

:::

以下は、JavaScript エコシステムにおける Markdown 実装のサンプルです：

```tsx tab="React"
// I use the @tanstack/markdown library to convert the Markdown to HTML
// read more about it here: https://www.npmjs.com/package/@tanstack/markdown
// Tables, strikethrough and task lists (GFM) are supported out of the box,
// `allowHtml` enables raw HTML (e.g. <span style="color:blue">...</span>).
import { Markdown } from "@tanstack/markdown/react";

export default function MarkdownComponent({ text }: { text: string }) {
    return <Markdown allowHtml>{text}</Markdown>;
}
```

```vue tab="Vue"
<!-- I use the vue-markdown-render library to convert the Markdown to HTML -->
<!-- read more about it here: https://www.npmjs.com/package/vue-markdown-render -->
<template>
    <div>
        <vue-markdown :source="src" />
    </div>
</template>

<script lang="ts">
import VueMarkdown from 'vue-markdown-render'

export default defineComponent({
  name: 'MyComponent',
  components: {
    VueMarkdown
  },
  setup(props, ctx) {
    const src = ref('---
title: header')
---

    return {
      src
    }
  }
})
</script>
```

```svelte tab="Svelte"
<!-- I use the svelte-markdown library to convert the Markdown to HTML -->
<!-- read more about it here: https://www.npmjs.com/package/svelte-markdown -->
<script>
  import SvelteMarkdown from 'svelte-markdown'
  const source = `
  ---
title: This is a header
---

This is a paragraph.

* This is a list
* With two items
  1. And a sublist
  2. That is ordered
    * With another
    * Sublist inside

| And this is | A table |
|-------------|---------|
| With two    | columns |`
</script>

<SvelteMarkdown {source} />
```

```tsx tab="Angular"
// I use the ngx-markdown library to convert the Markdown to HTML
// read more about it here: https://www.npmjs.com/package/ngx-markdown
import { Component, Input } from "@angular/core";
import { MarkdownModule } from "ngx-markdown";

@Component({
    selector: "app-markdown",
    template: ` <markdown [data]="text"></markdown> `,
})
export class MarkdownComponent {
    @Input() text: string;
}
```

## Markdown Typewriter

[Markdown Typewriter](https://www.npmjs.com/package/markdown-typewriter) is a library that combines Markdown and Typewriter. このライブラリは、React テンプレートの Markdown コンポーネントにタイプライター効果を追加するという私自身のニーズのために、私が作成しました。

It renders Markdown with [@tanstack/markdown](https://tanstack.com/markdown) and accepts its props. With `allowHtml`, raw HTML is typed out too, keeping its attributes: `<span style="color:blue">...</span>` is blue while it appears.

```bash
npm install markdown-typewriter motion @tanstack/markdown
```

```tsx title="React"
import { MarkdownTypewriter } from "markdown-typewriter/react";

export default function MarkdownComponent({ text }: { text: string }) {
    return <MarkdownTypewriter allowHtml>{text}</MarkdownTypewriter>;
}
```
