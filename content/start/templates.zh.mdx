## 如何使用模板

如果你正在阅读本页，很可能已经使用模板生成了一个项目。以下章节将指导你完成让项目运行起来的初始步骤。

### 初始设置

使用 IDE 打开项目文件夹。以下示例使用 [Visual Studio Code](https://code.visualstudio.com/)。

打开项目后，VS Code 会自动建议执行几项操作：

* **安装推荐扩展** — 系统将显示通知，提示你安装工作区推荐的扩展。强烈建议接受此提示。如果未出现通知，可以在“扩展”面板中筛选[推荐扩展](https://code.visualstudio.com/docs/editor/extension-marketplace#_recommended-extensions)，然后手动安装。
* **运行启动任务** — VS Code 可能会提示你运行已配置的启动任务，以安装项目的所有依赖项。如果希望手动完成，请运行：

```npm
npm install
```

:::warning[跨平台]

如果选择了面向桌面端或移动端的模板，还需要安装 [Tauri](https://v2.tauri.app/start/prerequisites/) 所需的额外依赖项（Rust 工具链以及特定平台的构建工具）。由于 Tauri 与系统环境深度集成，在将项目作为桌面应用启动之前，你可能需要**重启 VS Code 一次或多次**。

:::

### 运行项目

模板包含一组为 VS Code 预先配置好的**启动配置**。如果你不熟悉启动配置：它们是告诉 VS Code 如何启动项目（以及可选地附加调试器）的快捷方式，让你不必每次都在终端中输入命令。你可以在**运行和调试**面板中访问它们（左侧边栏中的播放图标，或按 `F5`）。在面板顶部的下拉菜单中选择所需的配置，然后点击绿色播放按钮。

![运行和调试面板](/launch-configuration-dropdown.png)

可以使用以下配置：

* **Debug Game**：这是开发期间最常用的配置。每次保存文件时，浏览器都会自动刷新。请注意，在此模式下，动画可能不够流畅，资源加载速度也可能比最终发布版本更慢。
* **Debug Game Preview**：尽可能真实地模拟游戏发布后的表现：动画流畅、加载时间接近实际情况，并且启用了优化。在发布前想要确认游戏的视觉效果和运行表现是否符合预期时，请使用此配置。
* **Run as Desktop App (Dev)**：编译 Rust/Tauri 后端，并在原生桌面窗口中启动游戏。如果你的模板不面向桌面端或移动端，则不会包含此配置。

| 命令                   | 说明                                           |
| -------------------- | -------------------------------------------- |
| `npm run build:fast` | 仅构建 Web 应用（不使用 Tauri）。构建速度快，适合发布到 Web。       |

### 自定义样式

模板的用户界面完全使用 [shadcn/ui](https://ui.shadcn.com/) 构建，因此你可以在不修改任何组件代码的情况下自定义颜色主题。

打开 [shadcn/ui 主题生成器](https://ui.shadcn.com/create?template=vite\&base=base\&preset=b1s9eyGkS)，根据喜好调整颜色，然后前往页面的 **Copy** 部分，复制生成的 CSS 命令。在项目根目录中运行该命令：

```npm
npx shadcn@latest add <paste-the-generated-command-here>
```

应用后，建议重新格式化源文件：

```npm
npm run format
```

如需进一步自定义字体、全局样式等，请参阅 <DynamicLink href="/start/interface-font">样式与字体</DynamicLink>。

### 模板界面

模板自带一组预先构建的界面，涵盖视觉小说的基本功能。每个界面都是一个 React 组件，连接到由 TanStack Router 管理的路由。

* **主菜单**（`/`）— 玩家启动游戏后首先看到的界面。它提供开始新游戏、继续已保存的游戏和打开设置的入口。
* **叙事界面**（`/game/narration`）— 展示故事内容的核心游戏界面。它会显示对话、角色立绘、背景和选项。
* **设置** — 设置面板没有专用的独立路由。相反，它使用 [Search Params](https://tanstack.com/router/latest/docs/framework/react/guide/search-params) 将设置面板叠加到当前活动的界面上。这种方式既能保持 URL 简洁，又允许玩家从游戏中的任意位置打开设置，并在音频、显示、语言等设置部分之间切换，同时不会丢失原来的浏览位置。
* **导航界面**（`/game/navigation`）— 仅适用于 *Point & Click*。玩家可以在房间之间移动，并执行当前位置提供的各种操作。
* **地图界面**（`/game/map`）— 仅适用于 *Point & Click*。它会显示地图，并允许玩家从一个地点移动到另一个地点。还支持管理多张地图。
