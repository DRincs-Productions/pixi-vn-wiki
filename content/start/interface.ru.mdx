<Accordion title="Что такое UI?" id="what-is-ui">

UI — сокращение от «User Interface», то есть пользовательский интерфейс (UI). Он обозначает визуальные элементы и интерактивные компоненты, через которые пользователь взаимодействует с цифровым устройством, приложением или веб-сайтом. UI включает в себя всё, с чем взаимодействуют пользователи, например кнопки, меню, значки, текстовые поля и макет. Цель UI-дизайна — создать интерфейс, который одновременно эстетически привлекателен и функционален, обеспечивая пользователям безупречный и интуитивно понятный опыт.

</Accordion>

</Accordions>

Pixi’VN не предоставляет встроенных компонентов для создания UI игры и не изобретает заново то, что уже существует в экосистеме JavaScript. Вместо того чтобы привязывать вас к конкретному фреймворку, он позволяет использовать любой внешний JavaScript-фреймворк на ваш выбор для создания UI, так что вы можете задействовать такие системы, как React, Vue и т. д., чтобы создавать сложные и высокопроизводительные **UI-экраны**.

Эта гибкость также делает Pixi’VN отличным решением для разработки с использованием ИИ: поскольку UI создаётся с помощью стандартных, широко используемых фреймворков, а не проприетарной системы, ИИ-ассистенты для написания кода уже хорошо знакомы с этими инструментами и могут очень эффективно генерировать, понимать и изменять код UI.

<Accordion title="Добавление HTML UI-слоёв" id="adding-html-ui-layers">

**Что такое HTML UI-слой?** HTML UI-слой — это HTML-элемент, который добавляется поверх холста PixiJS и имеет те же размеры, что и холст. Это позволяет создавать UI с помощью JavaScript-фреймворка, такого как React или Vue.

Чтобы добавить HTML UI-слой, вы можете использовать функцию [`canvas.htmlLayers.add`](/jsdoc/pixi-vn/index/interfaces/CanvasHtmlLayersInterface#add).

```ts tab="main.ts"
const root = document.getElementById("root");
if (!root) {
    throw new Error("root element not found");
}
const htmlLayer = canvas.htmlLayers.add("ui", root, {
    position: "absolute",
    pointerEvents: "none",
    userSelect: "none",
});
```

```html tab="index.html"
<!doctype html>
<html lang="en">
    <body>
        <div id="root"></div>
        <script type="module" src="/src/main.ts"></script>
    </body>
</html>
```

Чтобы получить HTML-элемент слоя, вы можете использовать функцию [`canvas.htmlLayers.get`](/jsdoc/pixi-vn/index/interfaces/CanvasHtmlLayersInterface#get).

Чтобы удалить HTML UI-слой, вы можете использовать функцию [`canvas.htmlLayers.remove`](/jsdoc/pixi-vn/index/interfaces/CanvasHtmlLayersInterface#remove).

</Accordion>

<Accordion title="Как включить взаимодействие с HTML UI?" id="how-to-enable-ui-interaction">

По умолчанию все HTML-элементы HTML UI-слоёв имеют стиль `pointer-events: none`. Это означает, что HTML-элементы не будут перехватывать события мыши или касания, позволяя холсту PixiJS получать все события. Это полезно, когда вы хотите отобразить изображение или видео на холсте и не хотите, чтобы UI мешал этому.

Поэтому необходимо задавать стиль `pointer-events: auto` только для того компонента, с которым должен взаимодействовать пользователь.

Например:

```css tab="Shadcn - Tailwind CSS" title="styles.css"
@layer components {
    [data-slot="button"],
    [data-slot="card"],
    [data-slot="resizable-handle"],
    [data-slot="scroll-area"],
    [data-slot="scroll-area-scrollbar"],
    [data-slot="toggle"] {
        pointer-events: auto;
    }
}
```

```tsx tab="React"
export default function NextButton() {
    return (
        <button
            style={{
                pointerEvents: "auto",
            }}
        >
            Next
        </button>
    );
}
```

```vue tab="Vue"
<template>
    <button style="pointer-events: auto;">Next</button>
</template>
```

</Accordion>

<Accordion title="Добавление PixiJS UI-слоёв" id="adding-pixijs-ui-layers">

**Что такое PixiJS UI-слой?** Это PixiJS Container. В отличие от основного Container, предназначенного исключительно для функций Pixi’VN:

* Текущее состояние UI не будет включено в сохранения.
* Он обладает более высокой производительностью. Pixi’VN не будет выполнять никаких проверок для него.
* Вы не можете использовать функции Pixi’VN.
* Поскольку это базовый компонент PixiJS, вы можете добавлять любые компоненты, совместимые с PixiJS.

Чтобы добавить PixiJS UI-слой, вы можете использовать функцию [`canvas.layers.add`](/jsdoc/pixi-vn/index/interfaces/CanvasLayersInterface#add).

Например:

```ts title="src/main.ts"
const container = canvas.layers.add("ui");
```

Чтобы получить PixiJS Container слоя, вы можете использовать функцию [`canvas.layers.get`](/jsdoc/pixi-vn/index/interfaces/CanvasLayersInterface#get).

Чтобы удалить PixiJS UI-слой, вы можете использовать функцию [`canvas.layers.remove`](/jsdoc/pixi-vn/index/interfaces/CanvasLayersInterface#remove).

</Accordion>

## Различия между UI и холстом

По замыслу и проекту Pixi’VN, UI и холст — это два отдельных и независимых элемента. UI находится поверх холста и используется для создания кнопок, форм и т. д. Холст используется для отображения изображений, видео и т. д.

Вся информация о текущем состоянии холста включается в сохранение, и её можно восстановить до состояния предыдущего шага. Текущее состояние UI не будет включено в сохранения. Поэтому вам нужно <DynamicLink href="/start/interface-connect-storage">управлять этим самостоятельно, сохраняя необходимую информацию</DynamicLink> в <DynamicLink href="/start/storage">хранилище игры</DynamicLink> или в хранилище браузера.

На холсте вы можете добавлять компоненты на каждом шаге. В UI так делать нельзя, но вы можете создать несколько <DynamicLink href="/start/interface-connect-storage">«экранов» и переключаться между ними</DynamicLink>.

На холсте можно добавлять только компоненты Pixi’VN. В UI можно добавлять любые компоненты HTML/PixiJS или использовать любую библиотеку UI-компонентов, что позволяет создавать гораздо более сложные интерфейсы.
