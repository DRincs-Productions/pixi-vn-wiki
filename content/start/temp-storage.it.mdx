---
title: Archiviazione temporanea
description: Spiega come utilizzare l'archiviazione temporanea in Pixi’VN per le variabili necessarie solo durante un periodo narrativo specifico.
---

In molti casi è utile utilizzare le variabili solo durante un certo periodo della narrazione. Utilizzando l'archiviazione normale, sarebbe necessario rimuovere manualmente queste variabili quando non sono più necessarie, per mantenere i salvataggi leggeri ed efficienti.

Per risolvere questo problema, Pixi’VN dispone di un sistema di archiviazione temporanea. Le variabili temporanee inizializzate in una `label` verranno eliminate quando la `label` viene chiusa. Se un'altra `label` viene chiamata da essa, la variabile temporanea sarà ancora accessibile dalla `label` figlia. Tuttavia, se un'altra `label` viene chiamata con `jump` (quindi la `label` corrente verrà chiusa e ne verrà avviata una nuova), la variabile temporanea non sarà più accessibile.

## Impostare

Per impostare una variabile temporanea, utilizza [`storage.setTempVariable`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#settempvariable).

```ts
import { storage } from "@drincs/pixi-vn";

storage.setTempVariable("myTempVariable", 42);
```

## Ottenere

Per ottenere una variabile temporanea, utilizza la normale funzione [`storage.get`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#get).

## Rimuovere

Per rimuovere una variabile temporanea, utilizza [`storage.removeTempVariable`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#removetempvariable).

```ts
import { storage } from "@drincs/pixi-vn";

storage.removeTempVariable("myTempVariable");
```
