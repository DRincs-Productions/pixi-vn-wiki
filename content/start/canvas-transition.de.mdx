title: Übergänge
description: Erfahren Sie mehr über die integrierten Übergangseffekte in Pixi’VN zum Anzeigen und Entfernen von canvas-Komponenten, einschließlich Dissolve-, Fade-, Move-, Push- und Zoom-Übergängen. Entdecken Sie, wie Sie eigene Übergänge anpassen oder erstellen können, um fortgeschrittene visuelle Effekte im Ablauf Ihres Spiels zu erzeugen.

Pixi’VN bietet verschiedene Übergangseffekte zum Anzeigen oder Entfernen einer <DynamicLink href="/start/canvas-components">canvas-Komponente</DynamicLink> sowie die Möglichkeit, [eigene Übergänge zu erstellen](#custom-functionality).

<Accordions>

<Accordion title="Dissolve" id="dissolve">

Der Dissolve-Übergang:

* Beim Anzeigen einer Komponente wird ihr `alpha`-Wert schrittweise erhöht. Wenn eine Komponente mit demselben alias existiert, wird sie entfernt, sobald der Übergang der neuen Komponente abgeschlossen ist.
* Beim Entfernen einer Komponente wird ihr `alpha`-Wert schrittweise verringert.

Die Funktion [`showWithDissolve`](/jsdoc/pixi-vn/index/functions/showWithDissolve) zeigt ein canvas-Element mit einem Dissolve-Übergang an.

Die Funktion [`removeWithDissolve`](/jsdoc/pixi-vn/index/functions/removeWithDissolve) entfernt ein canvas-Element mit einem Dissolve-Übergang.

```ts tab="content/labels/start.label.ts"
import {
    newLabel,
    removeWithDissolve,
    showWithDissolve,
} from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [
    async () => {
        await showWithDissolve("alien", "egg_head");
        await showWithDissolve("human", {
            value: ["m01-body", "m01-eyes", "m01-mouth"],
            options: { scale: 0.5, xAlign: 0.7 },
        });
    },
    async () => {
        await showWithDissolve("alien", "flower_top");
        removeWithDissolve("human");
    },
]);
```

<Accordion title="Ein-/Ausblenden" id="fade">

Der Fade-Übergang:

* Beim Anzeigen einer Komponente wird ihr `alpha`-Wert schrittweise erhöht. Wenn eine Komponente mit demselben alias existiert, wird die vorhandene Komponente mit einem Fade-out-Effekt entfernt, bevor die neue Komponente angezeigt wird.
* Beim Entfernen einer Komponente wird ihr `alpha`-Wert schrittweise verringert.

Die Funktion [`showWithFade`](/jsdoc/pixi-vn/index/functions/showWithFade) zeigt ein canvas-Element mit einem Fade-Übergang an.

Die Funktion [`removeWithFade`](/jsdoc/pixi-vn/index/functions/removeWithFade) entfernt ein canvas-Element mit einem Fade-Übergang.

```ts tab="content/labels/start.label.ts"
import { newLabel, removeWithFade, showWithFade } from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [
    async () => {
        await showWithFade("alien", "egg_head", { duration: 5 });
        await showWithFade("human", {
            value: ["m01-body", "m01-eyes", "m01-mouth"],
            options: { scale: 0.5, xAlign: 0.7 },
        });
    },
    async () => {
        await showWithFade("alien", "flower_top");
        removeWithFade("human");
    },
]);
```

<Accordion title="Move in/out" id="move-in-out">

Der Move in/out-Übergang:

* Beim Anzeigen einer Komponente wird sie von außerhalb (rechts, links, oben oder unten) an ihre Position auf dem canvas bewegt. Wenn eine Komponente mit demselben alias existiert, wird die vorhandene Komponente mit einem Move-out-Effekt entfernt, bevor die neue Komponente angezeigt wird.
* Beim Entfernen einer Komponente wird sie von ihrer Position nach außerhalb des canvas bewegt.

Die Funktion [`moveIn`](/jsdoc/pixi-vn/index/functions/moveIn) zeigt ein canvas-Element mit einem Move-in-Übergang an.

Die Funktion [`moveOut`](/jsdoc/pixi-vn/index/functions/moveOut) entfernt ein canvas-Element mit einem Move-out-Übergang.

```ts tab="content/labels/start.label.ts"
import { moveIn, moveOut, newLabel } from "@drincs/pixi-vn";

    async () => {
        await moveIn("alien", "egg_head", { direction: "up" });

            value: ["m01-body", "m01-eyes", "m01-mouth"],
            options: { scale: 0.5, xAlign: 0.7 },
        });

    async () => {
        await moveIn("alien", "flower_top", { direction: "up" });
```

<Accordion title="Push in/out" id="push-in-out">

<Accordion title="Zoom in/out" id="zoom-in-out">

Der Zoom in/out-Übergang:

* Beim Anzeigen einer Komponente wird sie von 0 (von außerhalb des canvas) auf ihre ursprüngliche Skalierung und Position skaliert. Wenn eine Komponente mit demselben alias existiert, wird die vorhandene Komponente entfernt, sobald der Übergang der neuen Komponente abgeschlossen ist.
* Beim Entfernen einer Komponente wird sie von ihrer ursprünglichen Größe auf 0 skaliert und dabei aus dem canvas herausbewegt.

Die Funktion [`zoomIn`](/jsdoc/pixi-vn/index/functions/zoomIn) zeigt ein canvas-Element mit einem Zoom-in-Übergang an.

Die Funktion [`zoomOut`](/jsdoc/pixi-vn/index/functions/zoomOut) entfernt ein canvas-Element mit einem Zoom-out-Übergang.

## Benutzerdefinierte Funktionalität

<Callout type="info">

Das Pixi’VN-Team freut sich über neue Vorschläge und Beiträge, um diese Bibliothek noch vollständiger zu machen. Teilen oder schlagen Sie Ihren Übergang gerne im Chat unten vor!

</Callout>

Einen eigenen Übergang zu erstellen ist einfach: Verwenden Sie <DynamicLink href="/start/canvas-motion">`canvas.animate`</DynamicLink>, um benutzerdefinierte Effekte zu definieren.

Um Ihnen den Einstieg zu erleichtern, hier eine vereinfachte Version von [`showWithDissolve`](/jsdoc/pixi-vn/index/functions/showWithDissolve):

```ts title="canvas/transitions/showWithDissolve.ts"
import { canvas, ImageSprite, UPDATE_PRIORITY } from "@drincs/pixi-vn";
import { AnimationOptions } from "@drincs/pixi-vn/motion";

export default async function showWithDissolve(
    alias: string,
    component: ImageSprite,
    props: AnimationOptions = {},
    priority?: UPDATE_PRIORITY,
): Promise<string[] | undefined> {
    let { completeOnContinue = true, ...options } = props;
    // add the new component
    canvas.add(alias, component);
    // edit the properties of the new component
    component.alpha = 0;
    // create the ticker and play it
    let id = canvas.animate(
        alias,
        {
            alpha: 1,
        },
        {
            ...options,
            completeOnContinue,
        },
        priority,
    );
    // load the image if the image is not loaded
    if (component.haveEmptyTexture) {
        await component.load();
    }
    // return the ids of the tickers
    if (id) {
        return [id];
    }
}
```

### Die vorherige Komponente ersetzen oder entfernen

Wenn bereits eine Komponente mit demselben alias existiert, können Sie sie ersetzen lassen, oder:

<Accordions>

<Accordion title="Die vorherige Komponente nach Abschluss entfernen" id="remove-the-previous-component-after-completion">

Um die vorherige Komponente zu entfernen, sobald der Übergang der neuen Komponente abgeschlossen ist, verwenden Sie die <DynamicLink href="/start/canvas-motion">`aliasToRemoveAfter`-Eigenschaft</DynamicLink>.

```ts title="canvas/transitions/showWithDissolve.ts"
import { canvas, ImageSprite, UPDATE_PRIORITY } from "@drincs/pixi-vn";
import { AnimationOptions } from "@drincs/pixi-vn/motion";

export default async function showWithDissolve(
    alias: string,
    component: ImageSprite,
    props: AnimationOptions = {},
    priority?: UPDATE_PRIORITY,
): Promise<string[] | undefined> {
    let { completeOnContinue = true, ...options } = props;
    // check if the alias is already exist // [!code ++]
    let oldComponentAlias: string | undefined = undefined; // [!code ++]
    let oldComponent = canvas.find(alias); // [!code ++]
    if (oldComponent) {
        // [!code ++]
        oldComponentAlias = alias + "_temp_disolve"; // [!code ++]
        canvas.editAlias(alias, oldComponentAlias); // [!code ++]
    } // [!code ++]
    // add the new component and transfer the properties of the old component to the new component
    canvas.add(alias, component);
    oldComponent?.parent?.setChildIndex(
        oldComponent,
        oldComponent.parent.getChildIndex(oldComponent) - 0.1,
    ); // [!code ++]
    oldComponentAlias &&
        canvas.copyCanvasElementProperty(oldComponentAlias, alias); // [!code ++]
    oldComponentAlias &&
        canvas.tickers.transfer(oldComponentAlias, alias, "duplicate"); // [!code ++]
    // edit the properties of the new component
    component.alpha = 0;
    // create the ticker and play it
    let id = canvas.animate(
        alias,
        {
            alpha: 1,
        },
        {
            ...options,
            completeOnContinue,
        },
        priority,
    );
    // load the image if the image is not loaded
    if (component.haveEmptyTexture) {
        await component.load();
    }
    // return the ids of the tickers
    if (id) {
        return [id];
    }
}
```

</Accordion>

<Accordion title="Die vorherige Komponente mit einem Übergang entfernen" id="remove-the-previous-component-with-a-transition">

Um die vorherige Komponente mit einem Übergang zu entfernen, führen Sie eine weitere Animation mit <DynamicLink href="/start/canvas-motion">`canvas.animate`</DynamicLink> aus und verwenden Sie die <DynamicLink href="/start/canvas-motion">`tickerIdToResume`-Eigenschaft</DynamicLink>.

```ts title="canvas/transitions/showWithFade.ts"
import { canvas, ImageSprite, UPDATE_PRIORITY } from "@drincs/pixi-vn";
import { AnimationOptions } from "@drincs/pixi-vn/motion";

export default async function showWithDissolve(
    alias: string,
    component: ImageSprite,
    props: AnimationOptions = {},
    priority?: UPDATE_PRIORITY,
): Promise<string[] | undefined> {
    let { completeOnContinue = true, ...options } = props;
    // check if the alias is already exist // [!code ++]
    let oldComponentAlias: string | undefined = undefined; // [!code ++]
    let oldComponent = canvas.find(alias); // [!code ++]
    if (oldComponent) {
        // [!code ++]
        return showWithDissolve(alias, component, props, priority); // [!code ++]
    } // [!code ++]
    let oldComponentAlias = alias + "_temp_fade"; // [!code ++]
    canvas.editAlias(alias, oldComponentAlias); // [!code ++]
    // add the new component and transfer the properties of the old component to the new component // [!code ++]
    canvas.add(alias, component);
    oldComponent?.parent?.setChildIndex(
        oldComponent,
        oldComponent.parent.getChildIndex(oldComponent) - 0.1,
    ); // [!code ++]
    oldComponentAlias &&
        canvas.copyCanvasElementProperty(oldComponentAlias, alias); // [!code ++]
    oldComponentAlias &&
        canvas.tickers.transfer(oldComponentAlias, alias, "duplicate"); // [!code ++]
    // edit the properties of the new component
    component.alpha = 0;
    // create the ticker and play it
    let id = canvas.animate(
        alias,
        {
            alpha: 1,
        },
        {
            ...options,
            completeOnContinue,
        },
        priority,
    );
    if (id) {
        // [!code ++]
        // pause the ticker // [!code ++]
        canvas.tickers.pause({ id: id }); // [!code ++]
        // remove the old component // [!code ++]
        canvas.animate(
            // [!code ++]
            alias, // [!code ++]
            {
                // [!code ++]
                alpha: 0, // [!code ++]
            }, // [!code ++]
            {
                // [!code ++]
                ...options, // [!code ++]
                tickerIdToResume: id, // [!code ++]
                aliasToRemoveAfter: oldComponentAlias, // [!code ++]
                completeOnContinue, // [!code ++]
            }, // [!code ++]
            priority, // [!code ++]
        ); // [!code ++]
    } // [!code ++]
    // load the image if the image is not loaded
    if (component.haveEmptyTexture) {
        await component.load();
    }
    // return the ids of the tickers
    if (id) {
        return [id];
    }
}
```
