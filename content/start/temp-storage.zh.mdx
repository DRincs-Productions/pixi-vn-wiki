---
title: 临时存储
description: 说明如何在 Pixi’VN 中使用临时存储，用于仅在特定叙事阶段需要的变量。
---

在许多情况下，仅在叙事的某个特定阶段使用变量是很有用的。 如果使用普通存储，你需要在这些变量不再需要时手动移除它们，以保持存档的轻量和高效。

为了解决这个问题，Pixi’VN 提供了一个临时存储系统。 在叙事节点（`label`）中初始化的临时变量，会在该叙事节点（`label`）关闭时被删除。 如果从该叙事节点（`label`）中调用了另一个叙事节点（`label`），则临时变量在子叙事节点（`label`）中仍然可以访问。 但是，如果使用 `jump` 调用另一个叙事节点（`label`）（这样当前的叙事节点（`label`）会被关闭，并启动新的叙事节点（`label`）），则临时变量将不再可访问。

## 设置

使用 [`storage.setTempVariable`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#settempvariable) 设置一个临时变量。

```ts
import { storage } from "@drincs/pixi-vn";

storage.setTempVariable("myTempVariable", 42);
```

## 获取

要获取临时变量，使用普通的 [`storage.get`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#get) 函数。

## 移除

使用 [`storage.removeTempVariable`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#removetempvariable) 移除一个临时变量。

```ts
import { storage } from "@drincs/pixi-vn";

storage.removeTempVariable("myTempVariable");
```
