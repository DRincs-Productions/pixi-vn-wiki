Wie du dein Spiel vertreiben möchtest, ist eine der wichtigsten Entscheidungen, die du vor Entwicklungsbeginn triffst: sie bestimmt, welche Spieler du erreichen kannst und wie sie dein Spiel spielen werden.

Da Pixi’VN-Spiele mit JavaScript/TypeScript erstellt werden, können sie nativ auf **jedem Gerät, das einen Browser ausführen kann**, vertrieben werden — das deckt bereits eine riesige Bandbreite an Plattformen ab. Discord zum Beispiel ist ein JavaScript/TypeScript-Projekt, das als Desktop-App, Web-App und mobile App ausgeliefert wird — dasselbe ist auch für dein Spiel möglich.
