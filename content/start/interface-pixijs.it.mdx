Come spiegato più in dettaglio <DynamicLink href="/start/canvas#pixijs-differences">qui</DynamicLink>, l'intera parte di rendering di Pixi’VN si basa su PixiJS. Sfruttando i <DynamicLink href="/start/interface#adding-pixijs-ui-layers">PixiJS Layers</DynamicLink>, puoi utilizzare PixiJS per creare schermate UI personalizzate.

:::tip[Templates]

In tutti i template, all'avvio viene creato un PixiJS Layer chiamato "ui". Puoi utilizzare questo livello per creare le tue schermate UI.

:::

Puoi anche combinare componenti HTML Layer con componenti PixiJS Layer. Per fare questo, aggiungi i componenti PixiJS durante il primo rendering di una schermata HTML e ripulisci il PixiJS Layer quando la schermata viene chiusa.

Ad esempio:

```tsx title="React"
import { useEffect } from "react";
import { Assets, canvas } from "@drincs/pixi-vn";
import { Sprite } from "pixi.js";

export default function MyScreen() {
    useEffect(() => {
        let layer = canvas.layers.get("ui");
        if (layer) {
            const texture = await Assets.load(
                "https://pixijs.com/assets/bunny.png",
            );
            const bunny = new Sprite(texture);

        }

        return () => {
            canvas.layers.get("ui")?.removeChildren();
        };
    });

    return null;
}
```

## Le migliori librerie di componenti PixiJS

Per creare una bellissima interfaccia utente, puoi utilizzare alcune delle migliori librerie di componenti PixiJS:

* [PixiJS](https://pixijs.com/)
* [PixiUI](https://github.com/pixijs/ui)
