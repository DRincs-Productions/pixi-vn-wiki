<Accordion title="Qu’est-ce que Live2D ?" id="what-is-live2d">

Live2D est une technologie qui permet de donner un mouvement naturel aux illustrations 2D, créant des animations fluides et expressives sans devoir redessiner chaque image. Contrairement à un squelette articulé (comme dans Spine 2D), un modèle Live2D est constitué d’une seule illustration dont les éléments sont déformés et combinés grâce à des **paramètres** (angle, ouverture des yeux, forme de la bouche, etc.), animés par des **mouvements** (séquences d’animation prédéfinies) et des **expressions** (préréglages de paramètres, notamment pour les expressions du visage).

Cette technologie est largement utilisée dans les visual novels, les jeux et les applications interactives (notamment par les VTubers) pour donner vie aux personnages.

Vous trouverez plus d’informations sur Live2D sur le [site officiel de Live2D](https://www.live2d.com/).

</Accordion>

</Accordions>

Dans votre projet **Pixi’VN**, vous pouvez utiliser l’intégration Live2D pour afficher et animer des modèles Live2D représentant vos personnages.
Cette intégration est une couche d’adaptation autour de [untitled-pixi-live2d-engine](https://github.com/Untitled-Story/untitled-pixi-live2d-engine) : il ne s’agit **pas d’un plugin officiel PixiJS/Live2D**, mais d’un moteur maintenu par la communauté qui relie Live2D à PixiJS et permet d’utiliser ses fonctionnalités directement dans votre projet Pixi’VN.

## Installation

Pour installer le paquet Live2D dans un projet JavaScript existant, utilisez l’une des commandes suivantes :

```npm
npm install @drincs/pixi-vn-live2d
```

:::danger

Vous devez appeler `extensions.add(Live2DPlugin)` au démarrage, dans votre fichier principal, avant d’appeler `Game.init`.

:::

```ts title="main.ts"
import { extensions } from "pixi.js";
import { Live2DPlugin } from "@drincs/pixi-vn-live2d/core";
extensions.add(Live2DPlugin);

Game.init(body, {
    // ...
});
```

## Utilisation

Vous pouvez utiliser le composant [`Live2D`](/jsdoc/pixi-vn-live2d/index/classes/Live2D) comme n’importe quel autre composant Pixi’VN. Contrairement à Spine, un modèle Live2D n’a pas besoin d’être préchargé avec `Assets.load` : il suffit d’enregistrer son alias avec `Assets.add`, car `Live2D` se charge de résoudre et de récupérer le modèle lui-même.

Comme cette récupération est asynchrone, vous ne pouvez pas utiliser le modèle en toute sécurité avant la résolution de sa promesse [`ready`](/jsdoc/pixi-vn-live2d/index/classes/Live2D#ready) : utilisez `await` juste après sa création, avant d’accéder aux données issues du modèle chargé (par exemple sa taille).

Par exemple :

```ts tab="Typescript" title="main.ts" groupId="narrative_language"
import { canvas } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

const live2d = new Live2D({
    source: "shizuku",
    xAlign: 0.5,
    yAlign: 1,
    scale: 0.5,
});
await live2d.ready;
canvas.add("shizuku", live2d);
```

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
# show live2d shizuku xAlign 0.5 yAlign 1 scale 0.5
-> DONE
```

```ts tab="src/assets/index.ts"
import { AssetsManifest } from "@drincs/pixi-vn";

 * Manifest for the assets used in the game.

    ],
};
```

<Accordion title="Mouvement" id="motion">

Les animations d’un modèle Live2D sont regroupées en **groupes de mouvements** (par ex. `idle`, `tap_body`), chacun contenant une ou plusieurs séquences d’animation. Vous pouvez lancer un mouvement avec la fonction [`motion`](/jsdoc/pixi-vn-live2d/index/classes/Live2D#motion) ; si vous omettez l’indice de la séquence, une séquence aléatoire du groupe est jouée.

Par défaut, le modèle joue automatiquement en boucle son groupe de mouvements `idle` (Cubism 2) ou `Idle` (Cubism 4). Ce comportement est configurable avec l’option `idleMotionGroup` : vous n’avez donc besoin d’appeler `motion` que pour déclencher une animation ponctuelle, par exemple en réaction à un appui ou à un clic.

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
import { canvas, newLabel } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

export const startLabel = newLabel("start", [
    async () => {
        const live2d = new Live2D({
            source: "shizuku",
            xAlign: 0.5,
            yAlign: 1,
            scale: 0.5,
        });
        await live2d.ready;
        canvas.add("shizuku", live2d);
    },
    () => {
        canvas.find<Live2D>("shizuku")?.motion("tap_body");
    },
]);
```

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
# show live2d shizuku xAlign 0.5 yAlign 1 scale 0.5
# pause
# play motion tap_body on live2d shizuku
# pause
-> DONE
```

<Accordion title="Expression" id="expression">

Un modèle Live2D peut définir plusieurs **expressions** — des préréglages de paramètres généralement utilisés pour les expressions du visage — que vous pouvez changer à l’exécution avec la fonction [`expression`](/jsdoc/pixi-vn-live2d/index/classes/Live2D#expression). Comme pour `motion`, omettre l’identifiant permet de choisir une expression aléatoire.

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
import { canvas, newLabel } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

export const startLabel = newLabel("start", [
    async () => {
        const live2d = new Live2D({
            source: "shizuku",
            xAlign: 0.5,
            yAlign: 1,
            scale: 0.5,
        });
        await live2d.ready;
        canvas.add("shizuku", live2d);
    },
    () => {
        canvas.find<Live2D>("shizuku")?.expression("f01");
    },
]);
```

<Accordion title="Animations Live2D + motion.js" id="motion-js">

Vous pouvez combiner les mouvements Live2D avec les animations classiques de Pixi’VN fondées sur le mouvement ([`canvas.animate`](/jsdoc/pixi-vn/index/interfaces/CanvasManagerInterface#animate)), comme dans l’exemple ci-dessous.

Pour des jeux plus avancés, vous pouvez également piloter directement Live2D à l’aide d’un ticker déclenché par un événement, comme l’appui sur un bouton, plutôt que de dépendre uniquement de séquences prédéfinies.

```ts title="content/labels/start.label.ts" groupId="narrative_language"
import { canvas, newLabel } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

export const startLabel = newLabel("start", [
    async () => {
        const live2d = new Live2D({
            source: "shizuku",
            xAlign: 0.3,
            yAlign: 1,
            scale: 0.5,
        });
        await live2d.ready;
        canvas.add("shizuku", live2d);
        canvas.animate(
            live2d,
            [
                [{ x: canvas.width * 0.7 }, { duration: 2, ease: "linear" }],
                [{ x: canvas.width * 0.3 }, { duration: 2, ease: "linear" }],
            ],
            { repeat: Infinity },
        );
    },
]);
```

<Accordion title="Arrêter les mouvements" id="stop-motions">

Vous pouvez arrêter tous les mouvements en cours sur un modèle, ainsi que tout son de synchronisation labiale, à l’aide de la fonction [`stopMotions`](/jsdoc/pixi-vn-live2d/index/classes/Live2D#stopmotions).

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
import { canvas, newLabel } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

export const startLabel = newLabel("start", [
    async () => {
        const live2d = new Live2D({
            source: "shizuku",
            xAlign: 0.5,
            yAlign: 1,
            scale: 0.5,
        });
        await live2d.ready;
        canvas.add("shizuku", live2d);
        live2d.motion("tap_body");
    },
    () => {
        canvas.find<Live2D>("shizuku")?.stopMotions();
    },
]);
```
