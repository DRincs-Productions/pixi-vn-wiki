<Accordion title="什么是游戏存储？" id="what-is-storage">

游戏存储是一个可以保存你希望在游戏会话之间保留的变量的地方。

</Accordion>

</Accordions>

必须理解的是，如果变量没有保存在游戏内存中，那么当你<DynamicLink href="/start/save#load">加载存档</DynamicLink>或<DynamicLink href="/start/labels-flow#go-back">返回</DynamicLink>时，引擎将无法处理它们。

此外，在游戏存档中，你可以保存除 `class` 和 `function` 之外的任何类型的变量（因为它们无法转换为 JSON），例如：`string`、`number`、`boolean`、`object`、`array` 等。 如果你想保存"标志"（布尔值），建议使用<DynamicLink href="/start/flags">标志功能</DynamicLink>，这是一个性能非常高的标志管理系统。

<Callout title="ink" type="info">

你可以在 *ink* 语法中使用此方法。 在<DynamicLink href="/ink/storage">这里</DynamicLink>了解更多。

</Callout>

## 设置

要在游戏存储中设置变量，请使用 [`storage.set`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#set)。

```ts
import { storage } from "@drincs/pixi-vn";

storage.set("myVariable", 42);
```

## 获取

要从游戏存储中获取变量，请使用 [`storage.get`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#get)。

```ts
import { storage } from "@drincs/pixi-vn";

const myVariable = storage.get("myVariable");
```

## 移除

要从游戏存储中移除变量，请使用 [`storage.remove`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#remove)。

```ts
import { storage } from "@drincs/pixi-vn";

storage.remove("myVariable");
```

## 其他功能

<Accordions>

<Accordion title="系统变量" id="system-variables">

在游戏存储中，有一些由游戏引擎使用的系统变量。 所有系统变量都以 `___` 前缀开头。
因此请避免在你的变量中使用此前缀。

你可以从 [`SYSTEM_RESERVED_STORAGE_KEYS`](/jsdoc/pixi-vn/index/variables/SYSTEM_RESERVED_STORAGE_KEYS) 常量获取所有系统变量的键。

</Accordion>

<Accordion title="Keyv" id="keyv">

整个存储系统是使用 `Map`（一个原生 JavaScript 对象）开发的，因此你可以使用 Keyv 与游戏存储进行交互。

**什么是 Keyv？** Keyv 是一个简单的键值存储。 它是一个非常易于使用的系统，在 Node.js 社区中非常流行。 Keyv 可以与其他库结合使用，例如 [Cacheable](https://cacheable.org/)（基于 Keyv 的 Node.js 缓存）。 你可以在 [Keyv 网站](https://keyv.org/)上了解更多信息。

**如何在 Pixi’VN 中使用 Keyv？** 你可以通过创建一个新的 Keyv 实例并将存储对象作为参数传递来在 Pixi’VN 中使用 Keyv。

```ts
import { storage } from "@drincs/pixi-vn";
import Keyv from "keyv";

const keyvStorage = new Keyv({ store: storage.base });

keyvStorage.get<string>("myValue").then((value) => {
    console.log(value);
});
```

</Accordion>

<Accordion title="默认存储变量" id="default-storage-variables">

你可以设置存储变量的初始值。

这些变量将具有以下特性：

* 如果它们被移除或设置为 undefined 或 null，其值将自动设置为默认值（因此它们永远不会是 undefined 或 null）。
* 默认值不会保存在存档中，因此你可以在不同版本之间更改它们而不会出现任何问题。

你可以使用 [`storage.default`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#default) 对象设置默认存储变量。

```ts
import { storage } from "@drincs/pixi-vn";

storage.default = {
    myVariable: 42,
    anotherVariable: "Hello, world!",
};
```

</Accordion>
