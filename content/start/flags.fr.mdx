---
title: Gestion des drapeaux
description: Explique comment utiliser des drapeaux booléens dans Pixi’VN pour contrôler le déroulement du jeu.
---

Pixi’VN fournit des fonctions pour gérer les « drapeaux de jeu ». Les drapeaux de jeu sont des valeurs booléennes utilisées pour contrôler le déroulement du jeu ou pour stocker d'autres valeurs booléennes dans le stockage du jeu.

Ce mécanisme a un impact bien moindre sur la taille des sauvegardes que l'utilisation du stockage normal, il est donc recommandé d'utiliser des drapeaux pour les valeurs booléennes qui changent fréquemment.

## Définir

Pour définir un drapeau, utilisez la fonction [`storage.setFlag`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#setflag).

```ts
import { storage } from "@drincs/pixi-vn";

storage.setFlag("flag1", true);
```

## Obtenir

Pour obtenir un drapeau, utilisez la fonction [`storage.getFlag`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#getflag).

```ts
import { storage } from "@drincs/pixi-vn";

const flag1 = storage.getFlag("flag1");
```
