This guide shows how to create an interactive fiction project with Pixi’VN. The reader should feel as if they are reading a book: prose flows through paragraphs, and the player advances the story by reading, making choices, and following story links. Illustrations can appear between passages as vignettes.

<Accordions>

<Accordion title="What is Interactive Fiction?" id="what-is-interactive-fiction">

Interactive Fiction is a narrative experience where the reader makes choices that influence the story. Unlike a traditional visual novel, it focuses on text and player interaction, often with a book-like presentation.

</Accordion>

<Accordion title="Project setup" id="project-setup">

Use the interactive fiction template when creating a new project:

```bash
npm create pixi-vn@latest
```

Choose **Interactive Fiction** from the available templates.

</Accordion>

</Accordions>

## Build the story

Write the narrative in Ink. Organize passages and choices according to the project’s story design, then compile and preview the game using the existing template scripts.

## Reading presentation

The template presents prose as flowing book-style text. Choices and links let readers navigate the story, while illustrations can appear between passages as vignettes.

## Next steps

Interactive Fiction and Visual Novel projects share Pixi’VN's narrative engine. The book template changes the reading presentation: prose is the page, and illustrations can punctuate it as vignettes.
