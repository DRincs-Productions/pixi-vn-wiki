Questo tutorial ti guiderà attraverso il processo di creazione della tua prima Visual Novel.

<Accordions>

<Accordion title="What is a Visual Novel?" id="what-is-a-visual-novel">

A visual novel (VN) is a form of digital interactive fiction. Le visual novel sono spesso associate al medium dei videogiochi, ma non sempre vengono etichettate come tali. Combinano una narrazione testuale con illustrazioni statiche o animate e un grado variabile di interattività. Il formato è più raramente indicato come novel game, una ritrascrizione del termine wasei-eigo noberu gēmu (ノベルゲーム), che è più spesso usato in giapponese.

</Accordion>

</Accordions>

A scopo di test, in questa guida ricreeremo la visual novel [Breakdown](https://joshpowlison.itch.io/breakdown) utilizzando Pixi'VN. Breakdown è un racconto breve che ha tutte le caratteristiche che una visual novel dovrebbe avere. Josh Powlison, il creatore di Breakdown, ci ha dato il permesso di utilizzare la sua narrazione per scopi didattici❤️.

:::tip

Poiché Pixi’VN ti dà la possibilità di scrivere la tua narrazione scegliendo un o più <DynamicLink href="/start/narration">linguaggio narrative disponibili</DynamicLink>, verranno realizzati esempi per ciascun linguaggio attualmente disponibile in ogni fase di sviluppo.

:::

## Crea un nuovo progetto

Before starting, make sure you have installed the <DynamicLink href="/start#prerequisites">prerequisites</DynamicLink>.

Il primo passo è creare un nuovo progetto. You can do this by running:

```npm
npm create pixi-vn@latest
```

and selecting the `Visual Novel` template.

:::tip[VS Code]

If you open the project with VS Code, you will be asked to consent to running some workspace tasks and to install the recommended extensions for the project. It is strongly advised to accept both.

:::

You can find more information about templates, tasks, and extensions <DynamicLink href="/start/templates">here</DynamicLink>.

<Accordions>

<Accordion title="Manual commands" id="manual-commands">

If you prefer not to use the VS Code tasks, you can achieve the same result by running the following commands from the root of the project:

```npm
npm install
npm start
```

</Accordion>

</Accordions>

## Creazione dei personaggi

Adesso definiremo i personaggi di questa storia. To do this, we will define in the `/content/characters.ts` file the characters that we will be using.

<Accordions>

<Accordion title="Cosa significa `mc`?" id="what-does-mc-mean">

`mc` is a common abbreviation for "Main Character". It is a common practice in visual novels to use `mc` as the main character's name.

</Accordion>

<Accordion title="Where is the `Character` model defined?" id="where-is-the-character-model-defined">

The `Character` model used below is defined in `models/Character.ts`. You can modify it to your liking, for example to add more properties related to the character (e.g. `surname`, `age`, ...). You can find more information about this file <DynamicLink href="/start/character#custom-class">here</DynamicLink>.

</Accordion>

</Accordions>

:::tip

Per maggiori informazioni su come creare e utilizzare i personaggi puoi consultare: <DynamicLink href="/start/character">Personaggi</DynamicLink>

:::

```ts title="content/characters.ts"
import Character from "@/models/Character";
import { RegisteredCharacters } from "@drincs/pixi-vn";

export const mc = new Character("mc", {
    name: "Me",
});

export const james = new Character("james", {
    name: "James",
    color: "#0084ac",
});

export const steph = new Character("steph", {
    name: "Steph",
    color: "#ac5900",
});

export const sly = new Character("sly", {
    name: "Sly",
    color: "#6d00ac",
});

RegisteredCharacters.add([mc, james, steph, sly]);
```

<Accordion title="Use the `glue` feature of dialogues" id="use-the-glue-feature-of-dialogues">

Nelle visual novel è spesso utile incollare del testo nel dialogo corrente. Ad esempio, per mettere in pausa una conversazione e farla proseguire in uno `step` successivo. Per farlo, possiamo usare la <DynamicLink href="/start/dialogue#dialogue-glue">funzionalità glue</DynamicLink>.

Questo è l'esempio:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

james: Ooh, [mc]! Nice, firm handshake!
<>The last guy always gave me the dead fish.
<>I already think we're gonna get along fine.
james: Come on in and...

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    async () =>
        (narration.dialogue = {
            character: james,
            text: `Ooh, ${mc.name}! Nice, firm handshake!`,
        }),
    async () => {
        narration.dialogGlue = true;
        narration.dialogue = `The last guy always gave me the dead fish.`;
    },
    async () => {
        narration.dialogGlue = true;
        narration.dialogue = `I already think we're gonna get along fine.`;
    },
    async () =>
        (narration.dialogue = { character: james, text: `Come on in and...` }),
    // ...
]);
export default startLabel;
```

</Accordion>

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
    async () => {
        narration.dialogue = undefined;
    },
    // ...
```

### Dividi la narrazione in più `labels`

Non è consigliabile creare `labels` molto lunghe (anche per visual novel lineari), ma è consigliabile creare più `labels` piccole e "chiamarle" quando necessario con le <DynamicLink href="/start/labels-flow">funzionalità di controllo del flusso di narrazione</DynamicLink>.

Per questo motivo, anche se nel nostro caso la nostra storia è lineare, verrà divisa in due `labels`, la prima sarà quella che abbiamo appena creato (`start`), mentre la seconda si chiamerà `second_part`.

Questo è l'esempio:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
james: You're my roommate's replacement, huh?
james: Don't worry, you don't have much to live up to. Just don't use heroin like the last guy, and you' fine!
mc: ...

He thrusts out his hand.

james: James!
mc: ...Peter.

// ...
-> second_part

=== second_part ===

She enters my room before I'VE even had a chance to. \\n\\n...I could've just come back and gotten the platter later...
She sets it on a desk. I throw my two paper bags down beside the empty bed.

steph: They got you a new mattress, right? That last guy was a druggie, did James tell you that?
sly: *We're* the reason he got expelled!
steph: Sly! If word gets out about that... well, actually, it wouldn't matter, *he's* the one who shot himself up.

I'm fumbling for a new subject.

// ...
-> DONE
```

## Menu di scelta

Ora chiederemo al giocatore se desidera continuare con la seconda parte della visual novel.

To do this, we will set [`narration.choices`](/jsdoc/pixi-vn/index/interfaces/NarrationManagerInterface#choices) to an array of choice options created with [`newChoiceOption`](/jsdoc/pixi-vn/index/functions/newChoiceOption) (to jump or call a `label`) and [`newCloseChoiceOption`](/jsdoc/pixi-vn/index/functions/newCloseChoiceOption) (to close the choice menu without navigating anywhere).

:::tip

You can find more information about choice menus <DynamicLink href="/start/choices">here</DynamicLink>.

:::

Questo è l'esempio:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

You want continue to the next part?
* Yes, I want to continue
-> second_part
* No, I want to stop here
-> END

=== second_part ===

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    async () => {
        narration.dialogue = `You want continue to the next part?`;
        narration.choices = [
            newChoiceOption(
                "Yes, I want to continue",
                secondPart,
                {},
                { type: "jump" },
            ),
            newCloseChoiceOption("No, I want to stop here"),
        ];
    },
]);
export default startLabel;

const secondPart = newLabel("second_part", [
    // ...
]);
```

## Modifica le informazioni del personaggio e usalo come variabile

Ora darò al giocatore la possibilità di cambiare il nome del `mc`.
Per fare ciò, chiederò al giocatore di <DynamicLink href="/start/input">completare una casella di input utilizzando le funzionalità di Pixi’VN</DynamicLink>.

Dopo aver ottenuto il valore di input, puoi <DynamicLink href="/start/character#edit">impostare il nome del personaggio</DynamicLink> utilizzando il valore ottenuto.

:::tip

In *ink*, `_input_value_` is a special variable that holds the value entered by the player. You can read more about it <DynamicLink href="/ink/input">here</DynamicLink>.

:::

Questo è l'esempio:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

He thrusts out his hand.
# request input type string default Peter
What is your name?
# rename mc { _input_value_ }

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    () => {
        narration.dialogue = `He thrusts out his hand.`;
    },
    () => {
        narration.requestInput({ type: "string" }, "Peter");
        narration.dialogue = `What is your name?`;
    },
    () => {
        mc.name = narration.inputValue as string;
    },
    // ...
]);
export default startLabel;
```

Ora potremmo <DynamicLink href="/start/character#use">utilizzare i nomi dei personaggi</DynamicLink> nei dialoghi.

:::tip

In *ink*, you can use square brackets (e.g. `[sly]`) to take advantage of the <DynamicLink href="/ink/replacement">text replacement</DynamicLink> mechanism: by default, the templates check whether the text between the brackets matches a character `id`, and if so, replace it with that character's name.

In JS/TS, you can achieve the same result using [template literals](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Template_literals) with `${}` (e.g. `` `${sly.name}` ``).

:::

Questo è l'esempio:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
VAR steph_fullname = "Stephanie"

=== start ===
// ...

mc: ...

-> DONE
```

## Definisci gli assets e caricali

:::tip

Per caricare e manipolare risorse (immagini, gif, video...) sarà necessario utilizzare `Assets`. `Assets` è una classe con molte funzionalità e proviene dalla libreria PixiJS, se vuoi maggiori informazioni leggi [qui](https://pixijs.com/8.x/guides/components/assets).

:::

One of the first steps is choosing where to save your visual novel assets: you can use an online hosting service or save them locally in the project. You can find more information about both options <DynamicLink href="/start/assets">here</DynamicLink>.

If you choose to save the assets locally, you just need to place them inside `src/assets`: the template automatically uses AssetPack to analyze the files and define them in `src/assets/manifest.gen.json`. If instead you choose to keep them online, you will need to manually edit `assets/index.ts` to register them.

In both cases, each asset is assigned one or more `alias`, which you can then use in your code to reference that asset.

        <File name="vite.config.ts" />
    </Folder>
</Files>

## Aggiungere lo sfondo e le immagini dei personaggi

Ora è il momento di pensare anche all'aspetto visivo. We will add the background and character images to the visual novel canvas.

<Accordions>

<Accordion title="What is a `sprite`?" id="what-is-a-sprite">

In computer graphics, a sprite is a two-dimensional bitmap that is integrated into a larger scene, most often in a 2D video game. In Pixi’VN, a single image shown on the canvas (e.g. the background, or the body/eyes/mouth of a character) is a `Sprite`.

</Accordion>

<Accordion title="What is a `container`?" id="what-is-a-container">

A container is a component that groups other components (sprites or even other containers) so that they can be positioned, moved, and manipulated as a single unit, while still being able to access and edit each individual child.

</Accordion>

</Accordions>

In our case, each character is composed of 3 sprites: the body, the eyes and the mouth. We use <DynamicLink href="/start/canvas-image-container">ImageContainer</DynamicLink>, a `Container` that groups `Sprite` children, to group them together and compose the character. Puoi trovare maggiori informazioni su come aggiungere componenti canvas in <DynamicLink href="/start/canvas-components">questa documentazione</DynamicLink>.

<Accordion title="Building an animation" id="building-an-animation">

Per rendere più dinamica la visual novel, è possibile utilizzare le animazioni. I recommend using TypeScript if you need to set many properties, as this gives you more control, more functionality, and type feedback.

In this example, my animation will take `steph` out of the scene and reinsert her in the next `step`. I'll also mirror her on the x-axis to make sure she's facing the right way.

To take `steph` out/in, I will use the `moveOut` and `moveIn` functions. For the mirror effect, I will use the `canvas.animate` function.

First, I use the `canvas.animate` function to create an animation that sets the `scaleX` property from `-1` (mirrored) to `1`, with `autoplay: false` so it does not start immediately.

Just for explanation purposes, this is what the equivalent would look like in *ink*:

```ink tab="ink"
# animate steph scaleX 1 options autoplay false completeOnContinue true
```

```ts tab="Typescript"
canvas.animate<ImageContainer>(
    "steph",
    {
        scaleX: 1,
    },
    { autoplay: false, completeOnContinue: true },
);
```

Quindi, utilizzo la funzione `moveIn` per spostare `steph` nella scena, passando il `tickerId` dell'animazione in modo che possa essere ripresa una volta completata la transizione.

Utilizzo l'opzione `completeOnContinue: true` per garantire che l'animazione venga completata prima che venga eseguito lo `step` successivo. Poiché `moveIn` è una transizione, `completeOnContinue` è true per impostazione predefinita.

:::tip

Per maggiori informazioni su come utilizzare le animazioni, vedere <DynamicLink href="/start/canvas-animations-effects">qui</DynamicLink>.

:::

Poiché per questa animazione utilizzo TypeScript, ho creato una `label` per essa, in modo che possa essere richiamata anche da altri linguaggi.

```ts title="labels/animation01.ts"
import { canvas, ImageContainer, moveIn, newLabel } from "@drincs/pixi-vn";

export const animation01 = newLabel("animation_01", [
    async () => {
        let tickerId = canvas.animate<ImageContainer>(
            "steph",
            {
                scaleX: 1,
            },
            { autoplay: false, completeOnContinue: true },
        );

        await moveIn(
            "steph",
            {
                value: ["fm02-body", "fm02-eyes-joy", "fm02-mouth-smile01"],
                options: {
                    xAlign: 0.8,
                    yAlign: 1,
                    scale: { y: 1, x: -1 },
                    anchor: 0.5,
                },
            },
            {
                direction: "right",
                ease: "easeInOut",
                tickerIdToResume: tickerId,
            },
        );
    },
]);
```

:::tip[*ink*]

Come spiegato <DynamicLink href="/ink/labels#use-the-call-script">qui</DynamicLink>, da *ink* puoi chiamare le `labels` (etichette) scritte in JS/TS e viceversa.

:::

## Sounds and music

Per aggiungere suoni e musica alla tua visual novel, puoi utilizzare l'utilità `sound`.

You can define sound channels to manage different types of sounds (e.g., BGM, SFX) and control their volume, pause, resume, etc. Si consiglia di definire i canali all'inizio del gioco, ad esempio nella richiamata `then` della funzione `Game.init`.

In questo esempio, definisco due canali: uno per la musica di sottofondo (BGM) e uno per gli effetti sonori (SFX). Inoltre, imposterò `defaultChannelAlias` al canale SFX, così che se non specifico un canale durante la riproduzione di un suono, questo sarà riprodotto nel canale SFX di default. Per definire il canale di sottofondo, ho impostato la proprietà `background` a `true`, quindi, a differenza che negli altri canali, i suoni non saranno interrotti al termine di ogni `step` (passaggio) narrativo, ma continueranno finché non saranno messi in pausa o interrotti.

```ts title="main.ts"
import { Game, sound } from "@drincs/pixi-vn";
import { BGM_CHANNEL_NAME, SFX_CHANNEL_NAME } from "@/constans";

Game.init(body, {
    // ...
}).then(() => {
    sound.addChannel(BGM_CHANNEL_NAME, { background: true });
    sound.addChannel(SFX_CHANNEL_NAME);
    sound.defaultChannelAlias = SFX_CHANNEL_NAME;
});
```

Infine, puoi riprodurre i suoni e la musica nelle `labels` utilizzando la funzione `sound.play`. Inoltre, puoi utilizzare i canali per gestire diversi tipi di suono (es., BGM, SFX) e controllarne il volume, metterli in pausa, riprenderne la riproduzione, etc.

:::tip

Puoi trovare ulteriori informazioni su come utilizzarle <DynamicLink href="/start/sound">qui</DynamicLink>.

:::
