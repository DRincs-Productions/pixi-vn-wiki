Questo tutorial ti guiderà attraverso il processo di creazione della tua prima Visual Novel.

<Accordions>

<Accordion title="Cos'è una Visual Novel?" id="what-is-a-visual-novel">

Una visual novel (VN) è una forma di narrativa interattiva digitale. Le visual novel sono spesso associate al medium dei videogiochi, ma non sempre vengono etichettate come tali. Combinano una narrazione testuale con illustrazioni statiche o animate e un grado variabile di interattività. Il formato viene più raramente definito novel game, una trascrizione del termine wasei-eigo noberu gēmu (ノベルゲーム), che è più spesso usato in giapponese.

</Accordion>

</Accordions>

A scopo di test, in questa guida ricreeremo la visual novel [Breakdown](https://joshpowlison.itch.io/breakdown) utilizzando Pixi’VN. Breakdown è una breve storia che possiede tutte le caratteristiche che una visual novel dovrebbe avere. Josh Powlison, il creatore di Breakdown, ci ha dato il permesso di utilizzare la sua narrazione per scopi didattici❤️.

:::tip

Dato che Pixi’VN ti dà la possibilità di scrivere la tua narrazione scegliendo uno o più <DynamicLink href="/start/narration">linguaggi narrativi disponibili</DynamicLink>, verranno forniti esempi per ciascun linguaggio attualmente disponibile a ogni passaggio dello sviluppo.

:::

## Crea un nuovo progetto

Prima di iniziare, assicurati di aver installato i <DynamicLink href="/start#prerequisites">prerequisiti</DynamicLink>.

Il primo passo è creare un nuovo progetto. Puoi farlo eseguendo:

```npm
npm create pixi-vn@latest
```

e selezionando il template `Visual Novel`.

:::tip[VS Code]

Se apri il progetto con VS Code, ti verrà chiesto di acconsentire all'esecuzione di alcuni task del workspace e di installare le estensioni consigliate per il progetto. Si consiglia vivamente di accettare entrambe le cose.

:::

Puoi trovare maggiori informazioni su template, task ed estensioni <DynamicLink href="/start/templates">qui</DynamicLink>.

<Accordions>

<Accordion title="Comandi manuali" id="manual-commands">

Se preferisci non utilizzare i task di VS Code, puoi ottenere lo stesso risultato eseguendo i seguenti comandi dalla root del progetto:

```npm
npm install
npm start
```

</Accordion>

</Accordions>

## Creazione dei personaggi

Ora definiremo i personaggi di questa storia. Per farlo, definiremo nel file `/content/characters.ts` i personaggi che useremo.

<Accordions>

<Accordion title="Cosa significa `mc`?" id="what-does-mc-mean">

`mc` è un'abbreviazione comune per "Main Character" (personaggio principale). È una pratica comune nelle visual novel usare `mc` come nome del personaggio principale.

</Accordion>

<Accordion title="Dove è definito il modello `Character`?" id="where-is-the-character-model-defined">

Il modello `Character` usato qui sotto è definito in `models/Character.ts`. Puoi modificarlo a tuo piacimento, ad esempio per aggiungere ulteriori proprietà relative al personaggio (ad es. `surname`, `age`, ...). Puoi trovare maggiori informazioni su questo file <DynamicLink href="/start/character#custom-class">qui</DynamicLink>.

</Accordion>

</Accordions>

:::tip

Per maggiori informazioni su come creare e utilizzare i personaggi puoi consultare: <DynamicLink href="/start/character">Characters</DynamicLink>

:::

```ts title="content/characters.ts"
import Character from "@/models/Character";
import { RegisteredCharacters } from "@drincs/pixi-vn";

export const mc = new Character("mc", {
    name: "Me",
});

export const james = new Character("james", {
    name: "James",
    color: "#0084ac",
});

export const steph = new Character("steph", {
    name: "Steph",
    color: "#ac5900",
});

export const sly = new Character("sly", {
    name: "Sly",
    color: "#6d00ac",
});

RegisteredCharacters.add([mc, james, steph, sly]);
```

:::tip[Markup]

<Accordion title="Usa la funzionalità `glue` dei dialoghi" id="use-the-glue-feature-of-dialogues">

Nelle visual novel, è spesso utile incollare del testo al dialogo corrente. Ad esempio, per mettere in pausa una conversazione e farla continuare in uno `step` successivo. Per fare questo, possiamo usare la <DynamicLink href="/start/dialogue#dialogue-glue">funzionalità glue</DynamicLink>.

Questo è l'esempio:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

james: Ooh, [mc]! Nice, firm handshake!
<>The last guy always gave me the dead fish.
<>I already think we're gonna get along fine.
james: Come on in and...

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    async () =>
        (narration.dialogue = {
            character: james,
            text: `Ooh, ${mc.name}! Nice, firm handshake!`,
        }),
    async () => {
        narration.dialogGlue = true;
        narration.dialogue = `The last guy always gave me the dead fish.`;
    },
    async () => {
        narration.dialogGlue = true;
        narration.dialogue = `I already think we're gonna get along fine.`;
    },
    async () =>
        (narration.dialogue = { character: james, text: `Come on in and...` }),
    // ...
]);
export default startLabel;
```

</Accordion>

<Accordion title="Crea un effetto pausa" id="create-a-pause-effect">

È anche possibile creare un effetto "pausa", nascondendo per un momento la scheda del dialogo. In *ink*, puoi usare <DynamicLink href="/ink/other-narrative-features#pause">`# pause`</DynamicLink>, mentre in JS/TS puoi <DynamicLink href="/start/dialogue#delete">impostare `narration.dialogue` su `undefined`</DynamicLink>.

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

# pause

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"

    // ...
    async () => {
        narration.dialogue = undefined;
    },
    // ...
]);
export default startLabel;
```

### Suddividere la narrazione in `labels`

Non è consigliabile creare `labels` molto lunghe (anche per le visual novel lineari), ma è consigliabile creare più `labels` piccole e "chiamarle" quando necessario con le <DynamicLink href="/start/labels-flow">funzionalità di controllo del flusso narrativo</DynamicLink>.

Per questo motivo, anche se nel nostro caso la storia è lineare, verrà divisa in due `labels`: la prima sarà quella che abbiamo appena creato (`start`), mentre la seconda si chiamerà `second_part`.

Questo è l'esempio:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
james: You're my roommate's replacement, huh?
james: Don't worry, you don't have much to live up to. Just don't use heroin like the last guy, and you' fine!
mc: ...

He thrusts out his hand.

james: James!
mc: ...Peter.

// ...
-> second_part

=== second_part ===

She enters my room before I'VE even had a chance to. \\n\\n...I could've just come back and gotten the platter later...
She sets it on a desk. I throw my two paper bags down beside the empty bed.

steph: They got you a new mattress, right? That last guy was a druggie, did James tell you that?
sly: *We're* the reason he got expelled!
steph: Sly! If word gets out about that... well, actually, it wouldn't matter, *he's* the one who shot himself up.

I'm fumbling for a new subject.

// ...
-> DONE
```


## Menu di scelta

Ora chiederemo al giocatore se vuole continuare con la seconda parte della visual novel.

Per fare questo, imposteremo [`narration.choices`](/jsdoc/pixi-vn/index/interfaces/NarrationManagerInterface#choices) su un array di opzioni di scelta create con [`newChoiceOption`](/jsdoc/pixi-vn/index/functions/newChoiceOption) (per saltare a o chiamare una `label`) e [`newCloseChoiceOption`](/jsdoc/pixi-vn/index/functions/newCloseChoiceOption) (per chiudere il menu di scelta senza navigare da nessuna parte).

:::tip

Puoi trovare maggiori informazioni sui menu di scelta <DynamicLink href="/start/choices">qui</DynamicLink>.

:::

Questo è l'esempio:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

You want continue to the next part?
* Yes, I want to continue
-> second_part
* No, I want to stop here
-> END

=== second_part ===

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    async () => {
        narration.dialogue = `You want continue to the next part?`;
        narration.choices = [
            newChoiceOption(
                "Yes, I want to continue",
                secondPart,
                {},
                { type: "jump" },
            ),
            newCloseChoiceOption("No, I want to stop here"),
        ];
    },
]);
export default startLabel;

const secondPart = newLabel("second_part", [
    // ...
]);
```

## Modificare le informazioni del personaggio e usarle come variabile

Ora darò al giocatore la possibilità di cambiare il nome di `mc`.
Per fare questo, chiederò al giocatore di <DynamicLink href="/start/input">compilare una casella di input usando le funzionalità di Pixi’VN</DynamicLink>.

Dopo aver ottenuto il valore di input, puoi <DynamicLink href="/start/character#edit">impostare il nome del personaggio</DynamicLink> usando il valore ottenuto.

:::tip

In *ink*, `_input_value_` è una variabile speciale che contiene il valore inserito dal giocatore. Puoi leggere di più a riguardo <DynamicLink href="/ink/input">qui</DynamicLink>.

:::

Questo è l'esempio:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

He thrusts out his hand.
# request input type string default Peter
What is your name?
# rename mc { _input_value_ }

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    () => {
        narration.dialogue = `He thrusts out his hand.`;
    },
    () => {
        narration.requestInput({ type: "string" }, "Peter");
        narration.dialogue = `What is your name?`;
    },
    () => {
        mc.name = narration.inputValue as string;
    },
    // ...
]);
export default startLabel;
```

Ora potremmo <DynamicLink href="/start/character#use">usare i nomi dei personaggi</DynamicLink> all'interno dei dialoghi.

:::tip

In *ink*, puoi usare le parentesi quadre (ad es. `[sly]`) per sfruttare il meccanismo di <DynamicLink href="/ink/replacement">sostituzione del testo</DynamicLink>: per impostazione predefinita, i template controllano se il testo tra le parentesi corrisponde a un `id` di un personaggio, e in tal caso lo sostituiscono con il nome di quel personaggio.

In JS/TS, puoi ottenere lo stesso risultato usando i [template literals](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Template_literals) con `${}` (ad es. `` `${sly.name}` ``).

:::

## Definire gli asset e caricarli

:::tip

Per caricare e manipolare gli asset (immagini, gif, video...) sarà necessario utilizzare `Assets`. `Assets` è una classe con molte funzionalità e proviene dalla libreria PixiJS; se vuoi maggiori informazioni leggi [qui](https://pixijs.com/8.x/guides/components/assets).

:::

Uno dei primi passi è scegliere dove salvare gli asset della tua visual novel: puoi usare un servizio di hosting online oppure salvarli localmente nel progetto. Puoi trovare maggiori informazioni su entrambe le opzioni <DynamicLink href="/start/assets">qui</DynamicLink>.

Se scegli di salvare gli asset localmente, devi solo posizionarli all'interno di `src/assets`: il template utilizza automaticamente AssetPack per analizzare i file e definirli in `src/assets/manifest.gen.json`. Se invece scegli di tenerli online, dovrai modificare manualmente `assets/index.ts` per registrarli.

In entrambi i casi, a ogni asset viene assegnato uno o più `alias`, che potrai poi usare nel tuo codice per fare riferimento a quell'asset.

<Accordions>

<Accordion title="Cos'è uno `sprite`?" id="what-is-a-sprite">

Nella computer grafica, uno sprite è una bitmap bidimensionale integrata in una scena più ampia, il più delle volte in un videogioco 2D. In Pixi’VN, una singola immagine mostrata sul canvas (ad es. lo sfondo, o il corpo/occhi/bocca di un personaggio) è uno `Sprite`.

</Accordion>

<Accordion title="Cos'è un `container`?" id="what-is-a-container">

Un container è un componente che raggruppa altri componenti (sprite o anche altri container) in modo che possano essere posizionati, spostati e manipolati come una singola unità, pur potendo ancora accedere e modificare ogni singolo figlio.

</Accordion>

</Accordions>

<Accordion title="Creare un'animazione" id="building-an-animation">

Per rendere la visual novel più dinamica, puoi usare le animazioni. Ti consiglio di usare TypeScript se hai bisogno di impostare molte proprietà, perché ti dà più controllo, più funzionalità e feedback sui tipi.

In questo esempio, la mia animazione farà uscire `steph` dalla scena e la reinserirà nello `step` successivo. La rispecchierò anche sull'asse x per assicurarmi che sia rivolta nella direzione giusta.

Per far uscire/entrare `steph`, userò le funzioni `moveOut` e `moveIn`. Per l'effetto specchio, userò la funzione `canvas.animate`.

Per prima cosa, uso la funzione `canvas.animate` per creare un'animazione che imposta la proprietà `scaleX` da `-1` (specchiata) a `1`, con `autoplay: false` in modo che non parta immediatamente.

Solo a scopo esplicativo, ecco come apparirebbe l'equivalente in *ink*:

```ink tab="ink"
# animate steph scaleX 1 options autoplay false completeOnContinue true
```

```ts tab="Typescript"
canvas.animate<ImageContainer>(
    "steph",
    {
        scaleX: 1,
    },
    { autoplay: false, completeOnContinue: true },
);
```

Poi, uso la funzione `moveIn` per far entrare `steph` nella scena, passando il `tickerId` dell'animazione in modo che possa essere ripresa dopo il completamento della transizione.

Uso l'opzione `completeOnContinue: true` per assicurarmi che l'animazione si completi prima che venga eseguito lo `step` successivo. Per `moveIn`, essendo una transizione, `completeOnContinue` è vero per impostazione predefinita.

:::tip

Per maggiori informazioni su come usare le animazioni, vedi <DynamicLink href="/start/canvas-animations-effects">qui</DynamicLink>.

:::

Dato che uso TypeScript per questa animazione, ho creato una `label` apposita, in modo che possa essere chiamata anche da altri linguaggi.

```ts title="labels/animation01.ts"
import { canvas, ImageContainer, moveIn, newLabel } from "@drincs/pixi-vn";

export const animation01 = newLabel("animation_01", [
    async () => {
        let tickerId = canvas.animate<ImageContainer>(
            "steph",
            {
                scaleX: 1,
            },
            { autoplay: false, completeOnContinue: true },
        );

        await moveIn(
            "steph",
            {
                value: ["fm02-body", "fm02-eyes-joy", "fm02-mouth-smile01"],
                options: {
                    xAlign: 0.8,
                    yAlign: 1,
                    scale: { y: 1, x: -1 },
                    anchor: 0.5,
                },
            },
            {
                direction: "right",
                ease: "easeInOut",
                tickerIdToResume: tickerId,
            },
        );
    },
]);
```

:::tip[*ink*]

Come spiegato <DynamicLink href="/ink/labels#use-the-call-script">qui</DynamicLink>, da *ink* puoi chiamare `labels` scritte in JS/TS e viceversa.

:::

Ora puoi chiamare questa `label` (`animation_01`) dalla `label` principale (`start`).

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"

```

## Suoni e musica

Per aggiungere suoni e musica alla tua visual novel, puoi usare l'utility `sound`.

Puoi definire canali audio per gestire diversi tipi di suoni (ad es. BGM, SFX) e controllarne il volume, la pausa, la ripresa, ecc. Si consiglia di definire i canali all'inizio del gioco, ad esempio nel callback `then` della funzione `Game.init`.

In questo esempio, definisco due canali: uno per la musica di sottofondo (BGM) e uno per gli effetti sonori (SFX). Imposto anche `defaultChannelAlias` sul canale SFX, in modo che se non specifico un canale quando riproduco un suono, questo venga riprodotto per impostazione predefinita nel canale SFX. Per definire il canale di sottofondo, imposto la proprietà `background` su `true`, in modo che, a differenza degli altri canali, i suoni non vengano interrotti alla fine di ogni `step` narrativo, ma continuino finché non vengono messi in pausa o interrotti.

```ts title="main.ts"
import { Game, sound } from "@drincs/pixi-vn";
import { BGM_CHANNEL_NAME, SFX_CHANNEL_NAME } from "@/constans";

Game.init(body, {
    // ...
}).then(() => {
    sound.addChannel(BGM_CHANNEL_NAME, { background: true });
    sound.addChannel(SFX_CHANNEL_NAME);
    sound.defaultChannelAlias = SFX_CHANNEL_NAME;
});
```
