<Accordion title="UI란 무엇인가요?" id="what-is-ui">

UI는 사용자 인터페이스(UI)의 약자입니다. 이는 사용자가 디지털 기기, 애플리케이션 또는 웹사이트와 상호작용하는 시각적 요소와 인터랙티브 구성 요소를 의미합니다. UI에는 버튼, 메뉴, 아이콘, 텍스트 필드, 레이아웃 등 사용자가 상호작용하는 모든 것이 포함됩니다. UI 디자인의 목표는 미적으로 만족스러우면서도 기능적인 인터페이스를 만들어, 사용자에게 매끄럽고 직관적인 경험을 제공하는 것입니다.

</Accordion>

</Accordions>

Pixi’VN은 게임 UI를 만들기 위한 내장 구성 요소를 제공하지 않으며, JavaScript 생태계에 이미 존재하는 것을 다시 만들어내지 않습니다. 특정 프레임워크에 종속시키는 대신, 원하는 외부 JavaScript 프레임워크를 사용하여 UI를 만들 수 있게 해주므로 React, Vue 등의 시스템을 활용하여 복잡하고 고성능인 **UI 화면**을 만들 수 있습니다.

이러한 유연성 덕분에 Pixi’VN은 AI 지원 개발에도 매우 적합합니다. UI가 독자적인 시스템이 아니라 표준적이고 널리 사용되는 프레임워크로 구축되므로, AI 코딩 어시스턴트가 이러한 도구들을 이미 잘 알고 있어 UI 코드를 매우 효과적으로 생성, 이해, 수정할 수 있습니다.

Pixi’VN은 다른 JavaScript 프레임워크와의 호환성을 향상시키는 기능을 제공합니다:

<Accordion title="HTML UI 레이어 추가하기" id="adding-html-ui-layers">

**What is an HTML UI Layer?** HTML UI 레이어는 PixiJS 캔버스 위에 추가되는 HTML 요소로, 캔버스와 동일한 크기를 가집니다. 이를 통해 React나 Vue와 같은 JavaScript 프레임워크로 UI를 만들 수 있습니다.

HTML UI 레이어를 추가하려면 [`canvas.htmlLayers.add`](/jsdoc/pixi-vn/index/interfaces/CanvasHtmlLayersInterface#add) 함수를 사용할 수 있습니다.

```ts tab="main.ts"
const root = document.getElementById("root");
if (!root) {
    throw new Error("root element not found");
}
const htmlLayer = canvas.htmlLayers.add("ui", root, {
    position: "absolute",
    pointerEvents: "none",
    userSelect: "none",
});
```

```html tab="index.html"
<!doctype html>
<html lang="en">
    <body>
        <div id="root"></div>
        <script type="module" src="/src/main.ts"></script>
    </body>
</html>
```

레이어의 HTML 요소를 가져오려면 [`canvas.htmlLayers.get`](/jsdoc/pixi-vn/index/interfaces/CanvasHtmlLayersInterface#get) 함수를 사용할 수 있습니다.

HTML UI 레이어를 제거하려면 [`canvas.htmlLayers.remove`](/jsdoc/pixi-vn/index/interfaces/CanvasHtmlLayersInterface#remove) 함수를 사용할 수 있습니다.

</Accordion>

<Accordion title="HTML UI 상호작용을 활성화하는 방법은?" id="how-to-enable-ui-interaction">

기본적으로 HTML UI 레이어의 모든 HTML 요소는 `pointer-events: none` 스타일을 가집니다. 즉, HTML 요소가 마우스나 터치 이벤트를 가로채지 않으므로 PixiJS 캔버스가 모든 이벤트를 받을 수 있습니다. 이는 캔버스에 이미지나 비디오를 표시하고 싶고 UI가 이를 방해하지 않기를 원할 때 유용합니다.

따라서 사용자와 상호작용하기를 원하는 구성 요소에만 `pointer-events: auto` 스타일을 설정해야 합니다.

예를 들어:

```css tab="Shadcn - Tailwind CSS" title="styles.css"
@layer components {
    [data-slot="button"],
    [data-slot="card"],
    [data-slot="resizable-handle"],
    [data-slot="scroll-area"],
    [data-slot="scroll-area-scrollbar"],
    [data-slot="toggle"] {
        pointer-events: auto;
    }
}
```

```tsx tab="React"
export default function NextButton() {
    return (
        <button
            style={{
                pointerEvents: "auto",
            }}
        >
            Next
        </button>
    );
}
```

```vue tab="Vue"
<template>
    <button style="pointer-events: auto;">Next</button>
</template>
```

</Accordion>

<Accordion title="PixiJS UI 레이어 추가하기" id="adding-pixijs-ui-layers">

**What is an PixiJS UI Layer?** 이는 PixiJS Container입니다. Pixi’VN 기능 전용의 메인 Container와 달리:

* UI의 현재 상태는 저장 데이터에 포함되지 않습니다.
* 성능이 더 우수합니다. Pixi’VN은 이에 대해 어떠한 검사도 수행하지 않습니다.
* Pixi’VN 기능을 사용할 수 없습니다.
* 핵심 PixiJS 구성 요소이므로 PixiJS와 호환되는 모든 구성 요소를 추가할 수 있습니다.

PixiJS UI 레이어를 추가하려면 [`canvas.layers.add`](/jsdoc/pixi-vn/index/interfaces/CanvasLayersInterface#add) 함수를 사용할 수 있습니다.

예를 들어:

```ts title="src/main.ts"
const container = canvas.layers.add("ui");
```

레이어의 PixiJS Container를 가져오려면 [`canvas.layers.get`](/jsdoc/pixi-vn/index/interfaces/CanvasLayersInterface#get) 함수를 사용할 수 있습니다.

PixiJS UI 레이어를 제거하려면 [`canvas.layers.remove`](/jsdoc/pixi-vn/index/interfaces/CanvasLayersInterface#remove) 함수를 사용할 수 있습니다.

</Accordion>

## UI와 캔버스의 차이점

Pixi’VN이 설계되고 구상된 방식에 따라, UI와 캔버스는 서로 다른 독립적인 두 요소입니다. UI는 캔버스 위에 위치하며 버튼, 폼 등을 만드는 데 사용됩니다. 캔버스는 이미지, 비디오 등을 표시하는 데 사용됩니다.

캔버스의 현재 상태에 대한 모든 정보는 저장 데이터에 포함되며, 이전 단계의 상태를 복원할 수 있습니다. UI의 현재 상태는 저장 데이터에 포함되지 않습니다. 따라서 <DynamicLink href="/start/interface-connect-storage">필요한 정보를 저장하여 직접 관리</DynamicLink>하려면 <DynamicLink href="/start/storage">게임 저장소</DynamicLink> 또는 브라우저 저장소를 사용해야 합니다.

캔버스에서는 각 단계마다 구성 요소를 추가할 수 있습니다. UI에서는 그렇게 할 수 없으며, 여러 개의 <DynamicLink href="/start/interface-connect-storage">"화면"을 만들어 그 사이를 이동</DynamicLink>할 수 있습니다.

캔버스에서는 Pixi’VN 구성 요소만 추가할 수 있습니다. UI에서는 원하는 HTML/PixiJS 구성 요소를 추가하거나 원하는 UI 구성 요소 라이브러리를 사용할 수 있으므로 훨씬 더 복잡한 인터페이스를 만들 수 있습니다.
