Ce tutoriel vous guidera à travers le processus de création de votre premier Visual Novel.

<Accordions>

<Accordion title="Qu'est-ce qu'un Visual Novel ?" id="what-is-a-visual-novel">

Un visual novel (VN) est une forme de fiction interactive numérique. Les visual novels sont souvent associés au médium des jeux vidéo, mais ne sont pas toujours désignés comme tels. Ils combinent une narration textuelle avec des illustrations statiques ou animées et un degré variable d'interactivité. Ce format est plus rarement appelé novel game, une retranscription du terme wasei-eigo noberu gēmu (ノベルゲーム), plus souvent utilisé en japonais.

</Accordion>

</Accordions>

À des fins de test, dans ce guide nous allons recréer le visual novel [Breakdown](https://joshpowlison.itch.io/breakdown) en utilisant Pixi’VN. Breakdown est une courte histoire qui possède toutes les caractéristiques qu'un visual novel devrait avoir. Josh Powlison, le créateur de Breakdown, nous a donné la permission d'utiliser sa narration à des fins éducatives❤️.

:::tip

Puisque Pixi’VN vous donne la possibilité d'écrire votre propre narration en choisissant un ou plusieurs <DynamicLink href="/start/narration">langages narratifs disponibles</DynamicLink>, des exemples seront proposés pour chaque langage actuellement disponible à chaque étape de développement.

:::

## Créer un nouveau projet

Avant de commencer, assurez-vous d'avoir installé les <DynamicLink href="/start#prerequisites">prérequis</DynamicLink>.

La première étape consiste à créer un nouveau projet. Vous pouvez le faire en exécutant :

```npm
npm create pixi-vn@latest
```

puis en sélectionnant le modèle `Visual Novel`.

:::tip[VS Code]

Si vous ouvrez le projet avec VS Code, il vous sera demandé de consentir à l'exécution de certaines tâches d'espace de travail et d'installer les extensions recommandées pour le projet. Il est fortement conseillé d'accepter les deux.

:::

Vous trouverez plus d'informations sur les modèles, les tâches et les extensions <DynamicLink href="/start/templates">ici</DynamicLink>.

<Accordions>

<Accordion title="Commandes manuelles" id="manual-commands">

Si vous préférez ne pas utiliser les tâches VS Code, vous pouvez obtenir le même résultat en exécutant les commandes suivantes depuis la racine du projet :

```npm
npm install
npm start
```

</Accordion>

</Accordions>

## Création des personnages

Nous allons maintenant définir les personnages de cette histoire. Pour ce faire, nous définirons dans le fichier `/content/characters.ts` les personnages que nous utiliserons.

<Accordions>

<Accordion title="Que signifie `mc` ?" id="what-does-mc-mean">

`mc` est une abréviation courante pour « Main Character » (personnage principal). Il est courant dans les visual novels d'utiliser `mc` comme nom du personnage principal.

</Accordion>

<Accordion title="Où le modèle `Character` est-il défini ?" id="where-is-the-character-model-defined">

Le modèle `Character` utilisé ci-dessous est défini dans `models/Character.ts`. Vous pouvez le modifier à votre guise, par exemple pour ajouter davantage de propriétés liées au personnage (par exemple `surname`, `age`, ...). Vous trouverez plus d'informations sur ce fichier <DynamicLink href="/start/character#custom-class">ici</DynamicLink>.

</Accordion>

</Accordions>

:::tip

Pour plus d'informations sur la façon de créer et d'utiliser des personnages, vous pouvez consulter : <DynamicLink href="/start/character">Personnages</DynamicLink>

:::

```ts title="content/characters.ts"
import Character from "@/models/Character";
import { RegisteredCharacters } from "@drincs/pixi-vn";

export const mc = new Character("mc", {
    name: "Me",
});

export const james = new Character("james", {
    name: "James",
    color: "#0084ac",
});

export const steph = new Character("steph", {
    name: "Steph",
    color: "#ac5900",
});

export const sly = new Character("sly", {
    name: "Sly",
    color: "#6d00ac",
});

RegisteredCharacters.add([mc, james, steph, sly]);
```

## Premier brouillon de la narration

:::tip[Markup]

Tous les modèles prennent en charge <DynamicLink href="/start/markup-markdown">Markdown</DynamicLink> et <DynamicLink href="/start/markup-tailwindcss">Tailwind CSS</DynamicLink>, nous allons donc les utiliser pour notre narration.

Nous pouvons maintenant commencer à écrire le « premier brouillon » de la <DynamicLink href="/start/narration">narration</DynamicLink> du visual novel.

<Accordion title="Utiliser la fonctionnalité `glue` des dialogues" id="use-the-glue-feature-of-dialogues">

Dans les visual novels, il est souvent utile de coller du texte dans le dialogue en cours. Par exemple, pour mettre en pause une conversation et la faire continuer dans un `step` ultérieur. Pour ce faire, nous pouvons utiliser la <DynamicLink href="/start/dialogue#dialogue-glue">fonctionnalité glue</DynamicLink>.

Voici l'exemple :

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

james: Ooh, [mc]! Nice, firm handshake!
<>The last guy always gave me the dead fish.
<>I already think we're gonna get along fine.
james: Come on in and...

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    async () =>
        (narration.dialogue = {
            character: james,
            text: `Ooh, ${mc.name}! Nice, firm handshake!`,
        }),
    async () => {
        narration.dialogGlue = true;
        narration.dialogue = `The last guy always gave me the dead fish.`;
    },
    async () => {
        narration.dialogGlue = true;
        narration.dialogue = `I already think we're gonna get along fine.`;
    },
    async () =>
        (narration.dialogue = { character: james, text: `Come on in and...` }),
    // ...
]);
export default startLabel;
```

</Accordion>

<Accordion title="Créer un effet de pause" id="create-a-pause-effect">

Il est également possible de créer un effet de « pause », en masquant la carte de dialogue pendant un instant. Dans *ink*, vous pouvez utiliser <DynamicLink href="/ink/other-narrative-features#pause">`# pause`</DynamicLink>, tandis qu'en JS/TS vous pouvez <DynamicLink href="/start/dialogue#delete">définir `narration.dialogue` sur `undefined`</DynamicLink>.

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"

// ...

# pause

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
    // ...
    async () => {
        narration.dialogue = undefined;
    },
    // ...
]);

```

### Diviser la narration en `labels`

Il n'est pas recommandé de créer des `labels` très longs (même pour des visual novels linéaires), mais il est recommandé de créer plusieurs petits `labels` et de les « appeler » en cas de besoin avec les <DynamicLink href="/start/labels-flow">fonctionnalités de contrôle du flux narratif</DynamicLink>.

Pour cette raison, même si dans notre cas notre histoire est linéaire, elle sera divisée en deux `labels`, le premier étant celui que nous venons de créer (`start`), tandis que le second s'appellera `second_part`.

Voici l'exemple :

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
james: You're my roommate's replacement, huh?
james: Don't worry, you don't have much to live up to. Just don't use heroin like the last guy, and you' fine!
mc: ...

He thrusts out his hand.

james: James!
mc: ...Peter.

// ...
-> second_part

=== second_part ===

She enters my room before I'VE even had a chance to. \\n\\n...I could've just come back and gotten the platter later...
She sets it on a desk. I throw my two paper bags down beside the empty bed.

steph: They got you a new mattress, right? That last guy was a druggie, did James tell you that?
sly: *We're* the reason he got expelled!
steph: Sly! If word gets out about that... well, actually, it wouldn't matter, *he's* the one who shot himself up.

I'm fumbling for a new subject.

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    () =>
        (narration.dialogue = {
            character: james,
```

## Menus de choix

Nous allons maintenant demander au joueur s'il souhaite continuer avec la deuxième partie du visual novel.

Pour ce faire, nous définirons [`narration.choices`](/jsdoc/pixi-vn/index/interfaces/NarrationManagerInterface#choices) comme un tableau d'options de choix créées avec [`newChoiceOption`](/jsdoc/pixi-vn/index/functions/newChoiceOption) (pour sauter vers ou appeler un `label`) et [`newCloseChoiceOption`](/jsdoc/pixi-vn/index/functions/newCloseChoiceOption) (pour fermer le menu de choix sans naviguer nulle part).

:::tip

Vous trouverez plus d'informations sur les menus de choix <DynamicLink href="/start/choices">ici</DynamicLink>.

:::

Voici l'exemple :

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

You want continue to the next part?
* Yes, I want to continue
-> second_part
* No, I want to stop here
-> END

=== second_part ===

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    async () => {
        narration.dialogue = `You want continue to the next part?`;
        narration.choices = [
            newChoiceOption(
                "Yes, I want to continue",
                secondPart,
                {},
                { type: "jump" },
            ),
            newCloseChoiceOption("No, I want to stop here"),
        ];
    },
]);
export default startLabel;

const secondPart = newLabel("second_part", [
    // ...
]);
```

## Modifier les informations d'un personnage et les utiliser comme variable

Je vais maintenant donner au joueur la possibilité de changer le nom du `mc`.
Pour ce faire, je demanderai au joueur de <DynamicLink href="/start/input">remplir une boîte de saisie en utilisant les fonctionnalités de Pixi’VN</DynamicLink>.

Après avoir obtenu la valeur saisie, vous pouvez <DynamicLink href="/start/character#edit">définir le nom du personnage</DynamicLink> en utilisant la valeur obtenue.

:::tip

Dans *ink*, `_input_value_` est une variable spéciale qui contient la valeur saisie par le joueur. Vous pouvez en savoir plus à ce sujet <DynamicLink href="/ink/input">ici</DynamicLink>.

:::

Voici l'exemple :

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

He thrusts out his hand.
# request input type string default Peter
What is your name?
# rename mc { _input_value_ }

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    () => {
        narration.dialogue = `He thrusts out his hand.`;
    },
    () => {
        narration.requestInput({ type: "string" }, "Peter");
        narration.dialogue = `What is your name?`;
    },
    () => {
        mc.name = narration.inputValue as string;
    },
    // ...
]);
export default startLabel;
```

Nous pourrions maintenant <DynamicLink href="/start/character#use">utiliser les noms des personnages</DynamicLink> au sein des dialogues.

:::tip

Dans *ink*, vous pouvez utiliser des crochets (par exemple `[sly]`) pour tirer parti du mécanisme de <DynamicLink href="/ink/replacement">remplacement de texte</DynamicLink> : par défaut, les modèles vérifient si le texte entre les crochets correspond à un `id` de personnage, et si c'est le cas, le remplacent par le nom de ce personnage.

En JS/TS, vous pouvez obtenir le même résultat en utilisant les [littéraux de gabarit](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Template_literals) avec `${}` (par exemple `` `${sly.name}` ``).

:::

Voici l'exemple :

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
VAR steph_fullname = "Stephanie"

=== start ===
// ...

sly: I just wanted to see what the new guy was like. Hey, you, [mc]- be nice to our little brother, or you'll have to deal with *us*.
mc: ...
james: [mc], this is [sly]. Yes, that is her real name.

I put out my hand.

sly: I'm not shakin' your hand until I decide you're an all-right dude. Sorry, policy.
mc: Fair enough, I'm a pretty scary guy, or so l've been told.
james: The redhead behind her is [steph_fullname].
steph: Hey! Everyone calls me [steph]. I'll shake your hand.

She puts out her hand, and I take it.

mc: Thanks, good to meet you, [steph_fullname].
steph: WOW, that is, like, the most perfect handshake I've ever had! Firm, but also gentle. [sly], you *gotta* shake his hand!

// ...
-> DONE
```

## Définir les ressources et les charger

:::tip

Pour charger et manipuler des ressources (images, gifs, vidéos...) vous devrez utiliser `Assets`. `Assets` est une classe dotée de nombreuses fonctionnalités et provient de la bibliothèque PixiJS ; si vous souhaitez plus d'informations, lisez [ici](https://pixijs.com/8.x/guides/components/assets).

:::

L'une des premières étapes consiste à choisir où enregistrer les ressources de votre visual novel : vous pouvez utiliser un service d'hébergement en ligne ou les enregistrer localement dans le projet. Vous trouverez plus d'informations sur ces deux options <DynamicLink href="/start/assets">ici</DynamicLink>.

Si vous choisissez d'enregistrer les ressources localement, il vous suffit de les placer dans `src/assets` : le modèle utilise automatiquement AssetPack pour analyser les fichiers et les définir dans `src/assets/manifest.gen.json`. Si à la place vous choisissez de les conserver en ligne, vous devrez modifier manuellement `assets/index.ts` pour les enregistrer.

Dans les deux cas, chaque ressource se voit attribuer un ou plusieurs `alias`, que vous pourrez ensuite utiliser dans votre code pour référencer cette ressource.

## Ajouter des images d'arrière-plan et de personnages

<Accordions>

<Accordion title="Qu'est-ce qu'un `sprite` ?" id="what-is-a-sprite">

En infographie, un sprite est une image matricielle bidimensionnelle intégrée dans une scène plus large, le plus souvent dans un jeu vidéo 2D. Dans Pixi’VN, une seule image affichée sur le canvas (par exemple l'arrière-plan, ou le corps/les yeux/la bouche d'un personnage) est un `Sprite`.

</Accordion>

<Accordion title="Qu'est-ce qu'un `container` ?" id="what-is-a-container">

Un container est un composant qui regroupe d'autres composants (des sprites ou même d'autres containers) afin qu'ils puissent être positionnés, déplacés et manipulés comme une seule unité, tout en conservant la possibilité d'accéder à chaque enfant individuel et de le modifier.

</Accordion>

</Accordions>

Dans notre cas, chaque personnage est composé de 3 sprites : le corps, les yeux et la bouche. Nous utilisons <DynamicLink href="/start/canvas-image-container">ImageContainer</DynamicLink>, un `Container` qui regroupe des enfants `Sprite`, pour les regrouper et composer le personnage. Vous trouverez plus d'informations sur la façon d'ajouter des composants de canvas dans <DynamicLink href="/start/canvas-components">cette documentation</DynamicLink>.

<Accordion title="Créer une animation" id="building-an-animation">

Pour rendre le visual novel plus dynamique, vous pouvez utiliser des animations. Je recommande d'utiliser TypeScript si vous devez définir de nombreuses propriétés, car cela vous offre plus de contrôle, plus de fonctionnalités et un retour de type (type feedback).

Dans cet exemple, mon animation fera sortir `steph` de la scène puis la réinsérera au `step` suivant. Je vais également la refléter sur l'axe des x pour m'assurer qu'elle est orientée dans le bon sens.

Pour faire sortir/entrer `steph`, j'utiliserai les fonctions `moveOut` et `moveIn`. Pour l'effet miroir, j'utiliserai la fonction `canvas.animate`.

Tout d'abord, j'utilise la fonction `canvas.animate` pour créer une animation qui fait passer la propriété `scaleX` de `-1` (reflétée) à `1`, avec `autoplay: false` afin qu'elle ne démarre pas immédiatement.

À titre d'explication uniquement, voici à quoi ressemblerait l'équivalent en *ink* :

```ink tab="ink"
# animate steph scaleX 1 options autoplay false completeOnContinue true
```

```ts tab="Typescript"
canvas.animate<ImageContainer>(
    "steph",
    {
        scaleX: 1,
    },
    { autoplay: false, completeOnContinue: true },
);
```

Ensuite, j'utilise la fonction `moveIn` pour déplacer `steph` dans la scène, en passant le `tickerId` de l'animation afin qu'elle puisse être reprise une fois la transition terminée.

J'utilise l'option `completeOnContinue: true` pour m'assurer que l'animation se termine avant que le `step` suivant ne soit exécuté. Pour `moveIn`, étant une transition, `completeOnContinue` est vrai par défaut.

:::tip

Pour plus d'informations sur la façon d'utiliser les animations, voir <DynamicLink href="/start/canvas-animations-effects">ici</DynamicLink>.

:::

Puisque j'utilise TypeScript pour cette animation, j'ai créé un `label` pour celle-ci, afin qu'il puisse également être appelé depuis d'autres langages.

```ts title="labels/animation01.ts"
import { canvas, ImageContainer, moveIn, newLabel } from "@drincs/pixi-vn";

export const animation01 = newLabel("animation_01", [
    async () => {
        let tickerId = canvas.animate<ImageContainer>(
            "steph",
            {
                scaleX: 1,
            },
            { autoplay: false, completeOnContinue: true },
        );

        await moveIn(
            "steph",
            {
                value: ["fm02-body", "fm02-eyes-joy", "fm02-mouth-smile01"],
                options: {
                    xAlign: 0.8,
                    yAlign: 1,
                    scale: { y: 1, x: -1 },
                    anchor: 0.5,
                },
            },
            {
                direction: "right",
                ease: "easeInOut",
                tickerIdToResume: tickerId,
            },
        );
    },
]);
```

:::tip[*ink*]

Comme expliqué <DynamicLink href="/ink/labels#use-the-call-script">ici</DynamicLink>, depuis *ink* vous pouvez appeler des `labels` écrits en JS/TS et vice versa.

:::

Vous pouvez maintenant appeler ce `label` (`animation_01`) depuis le `label` principal (`start`).

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"

# show imagecontainer james [m01-body m01-eyes-grin m01-mouth-grin00]
# show imagecontainer sly [fm01-body fm01-eyes-smile fm01-mouth-smile00]

<> and returns with a HUGE tinfoil-covered platter.

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"

            "fm01-body",
```

## Sons et musique

Pour ajouter des sons et de la musique à votre visual novel, vous pouvez utiliser l'utilitaire `sound`.

Vous pouvez définir des canaux sonores pour gérer différents types de sons (par exemple, BGM, SFX) et contrôler leur volume, les mettre en pause, les reprendre, etc. Il est recommandé de définir les canaux au début du jeu, par exemple dans le callback `then` de la fonction `Game.init`.

Dans cet exemple, je définis deux canaux : un pour la musique de fond (BGM) et un pour les effets sonores (SFX). Je définis également `defaultChannelAlias` sur le canal SFX, de sorte que si je ne spécifie pas de canal lors de la lecture d'un son, il sera joué par défaut dans le canal SFX. Pour définir le canal de fond, je définis la propriété `background` sur `true`, de sorte que, contrairement aux autres canaux, les sons ne seront pas arrêtés à la fin de chaque `step` narratif, mais continueront jusqu'à ce qu'ils soient mis en pause ou arrêtés.

```ts title="main.ts"
import { Game, sound } from "@drincs/pixi-vn";
import { BGM_CHANNEL_NAME, SFX_CHANNEL_NAME } from "@/constans";

Game.init(body, {
    // ...
}).then(() => {
    sound.addChannel(BGM_CHANNEL_NAME, { background: true });
    sound.addChannel(SFX_CHANNEL_NAME);
    sound.defaultChannelAlias = SFX_CHANNEL_NAME;
});
```

Enfin, vous pouvez jouer les sons et la musique dans les `labels` en utilisant la fonction `sound.play`. Vous pouvez également utiliser des canaux pour gérer différents types de sons (par exemple, BGM, SFX) et contrôler leur volume, les mettre en pause, les reprendre, etc.
