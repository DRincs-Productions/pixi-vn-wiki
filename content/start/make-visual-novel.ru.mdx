Это руководство проведёт вас через процесс создания вашей первой визуальной новеллы.

<Accordions>

<Accordion title="Что такое визуальная новелла?" id="what-is-a-visual-novel">

Визуальная новелла (VN) — это форма цифровой интерактивной литературы. Визуальные новеллы часто ассоциируются со средой видеоигр, но не всегда обозначаются как таковые. Они сочетают текстовое повествование со статичными или анимированными иллюстрациями и различной степенью интерактивности. Этот формат реже называют novel game — ретранскрипцией васэй-эйго термина noberu gēmu (ノベルゲーム), который чаще используется в японском языке.

</Accordion>

</Accordions>

Для целей тестирования в этом руководстве мы воссоздадим визуальную новеллу [Breakdown](https://joshpowlison.itch.io/breakdown) с помощью Pixi’VN. Breakdown — это короткая история, которая обладает всеми особенностями, какие должна иметь визуальная новелла. Джош Поулисон, создатель Breakdown, дал нам разрешение использовать его повествование в образовательных целях❤️.

:::tip

Поскольку Pixi’VN даёт вам возможность писать собственное повествование, выбирая один или несколько <DynamicLink href="/start/narration">доступных языков повествования</DynamicLink>, примеры будут приводиться для каждого доступного на данный момент языка на каждом этапе разработки.

:::

## Создание нового проекта

Прежде чем начать, убедитесь, что у вас установлены <DynamicLink href="/start#prerequisites">предварительные требования</DynamicLink>.

Первый шаг — создать новый проект. Сделать это можно, выполнив:

```npm
npm create pixi-vn@latest
```

и выбрав шаблон `Visual Novel`.

:::tip[VS Code]

Если вы откроете проект в VS Code, вам будет предложено дать согласие на выполнение некоторых рабочих задач (workspace tasks) и установить рекомендуемые расширения для проекта. Настоятельно рекомендуется согласиться и на то, и на другое.

:::

Больше информации о шаблонах, задачах и расширениях можно найти <DynamicLink href="/start/templates">здесь</DynamicLink>.

<Accordions>

<Accordion title="Команды вручную" id="manual-commands">

Если вы предпочитаете не использовать задачи VS Code, вы можете добиться того же результата, выполнив следующие команды из корня проекта:

```npm
npm install
npm start
```

## Создание персонажей

Теперь мы определим персонажей этой истории. Для этого мы определим в файле `/content/characters.ts` персонажей, которых будем использовать.

<Accordions>

<Accordion title="Что означает `mc`?" id="what-does-mc-mean">

`mc` — распространённое сокращение от "Main Character" (главный герой). В визуальных новеллах принято использовать `mc` в качестве имени главного героя.

</Accordion>

<Accordion title="Где определена модель `Character`?" id="where-is-the-character-model-defined">

Используемая ниже модель `Character` определена в файле `models/Character.ts`. Вы можете изменить её по своему усмотрению, например, добавить дополнительные свойства, связанные с персонажем (например, `surname`, `age`, ...). Больше информации об этом файле можно найти <DynamicLink href="/start/character#custom-class">здесь</DynamicLink>.

</Accordion>

</Accordions>

:::tip

Больше информации о том, как создавать и использовать персонажей, можно найти здесь: <DynamicLink href="/start/character">Персонажи</DynamicLink>

:::

```ts title="content/characters.ts"
import Character from "@/models/Character";
import { RegisteredCharacters } from "@drincs/pixi-vn";

export const mc = new Character("mc", {
    name: "Me",
});

export const james = new Character("james", {
    name: "James",
    color: "#0084ac",
});

export const steph = new Character("steph", {
    name: "Steph",
    color: "#ac5900",
});

export const sly = new Character("sly", {
    name: "Sly",
    color: "#6d00ac",
});

RegisteredCharacters.add([mc, james, steph, sly]);
```

<Accordion title="Использование функции 'клея' (`glue`) в диалогах" id="use-the-glue-feature-of-dialogues">

В визуальных новеллах часто полезно "склеивать" текст с текущим диалогом. Например, чтобы приостановить разговор и продолжить его в последующем нарративном шаге (`step`). Для этого мы можем использовать <DynamicLink href="/start/dialogue#dialogue-glue">функциональность "клея"</DynamicLink>.

Вот пример:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

james: Ooh, [mc]! Nice, firm handshake!
<>The last guy always gave me the dead fish.
<>I already think we're gonna get along fine.
james: Come on in and...

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    async () =>
        (narration.dialogue = {
            character: james,
            text: `Ooh, ${mc.name}! Nice, firm handshake!`,
        }),
    async () => {
        narration.dialogGlue = true;
        narration.dialogue = `The last guy always gave me the dead fish.`;
    },
    async () => {
        narration.dialogGlue = true;
        narration.dialogue = `I already think we're gonna get along fine.`;
    },
    async () =>
        (narration.dialogue = { character: james, text: `Come on in and...` }),
    // ...
]);
export default startLabel;
```

### Разделение повествования на нарративные узлы (`labels`)

Не рекомендуется создавать очень длинные нарративные узлы (`labels`) (даже для линейных визуальных новелл), но рекомендуется создавать несколько небольших нарративных узлов (`labels`) и "вызывать" их по мере необходимости с помощью <DynamicLink href="/start/labels-flow">функций управления потоком повествования</DynamicLink>.

По этой причине, даже если в нашем случае история линейна, она будет разделена на два нарративных узла (`labels`): первый — тот, который мы только что создали (`start`), а второй будет называться `second_part`.

Вот пример:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
james: You're my roommate's replacement, huh?
james: Don't worry, you don't have much to live up to. Just don't use heroin like the last guy, and you' fine!
mc: ...

He thrusts out his hand.

james: James!
mc: ...Peter.

// ...
-> second_part

=== second_part ===

She enters my room before I'VE even had a chance to. \\n\\n...I could've just come back and gotten the platter later...
She sets it on a desk. I throw my two paper bags down beside the empty bed.

steph: They got you a new mattress, right? That last guy was a druggie, did James tell you that?
sly: *We're* the reason he got expelled!
steph: Sly! If word gets out about that... well, actually, it wouldn't matter, *he's* the one who shot himself up.

I'm fumbling for a new subject.

// ...
-> DONE
```


## Меню выбора

Теперь мы спросим игрока, хочет ли он продолжить со второй частью визуальной новеллы.

Для этого мы установим [`narration.choices`](/jsdoc/pixi-vn/index/interfaces/NarrationChoicesInterface#list) в массив вариантов выбора, созданных с помощью [`newChoiceOption`](/jsdoc/pixi-vn/index/functions/newChoiceOption) (для перехода к нарративному узлу или его вызова) и [`newCloseChoiceOption`](/jsdoc/pixi-vn/index/functions/newCloseChoiceOption) (для закрытия меню выбора без перехода куда-либо).

:::tip

Больше информации о меню выбора можно найти <DynamicLink href="/start/choices">здесь</DynamicLink>.

:::

Вот пример:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

You want continue to the next part?
* Yes, I want to continue
-> second_part
* No, I want to stop here
-> END

=== second_part ===

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    async () => {
        narration.dialogue = `You want continue to the next part?`;
        narration.choices = [
            newChoiceOption(
                "Yes, I want to continue",
                secondPart,
                {},
                { type: "jump" },
            ),
            newCloseChoiceOption("No, I want to stop here"),
        ];
    },
]);
export default startLabel;

const secondPart = newLabel("second_part", [
    // ...
]);
```

## Редактирование информации о персонаже и использование её как переменной

Теперь я дам игроку возможность изменить имя `mc`.
Для этого я попрошу игрока <DynamicLink href="/start/input">заполнить поле ввода, используя возможности Pixi’VN</DynamicLink>.

После получения введённого значения вы можете <DynamicLink href="/start/character#edit">установить имя персонажа</DynamicLink>, используя полученное значение.

:::tip

В *ink* `_input_value_` — это специальная переменная, которая хранит значение, введённое игроком. Подробнее об этом можно узнать <DynamicLink href="/ink/input">здесь</DynamicLink>.

:::

Вот пример:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

He thrusts out his hand.
# request input type string default Peter
What is your name?
# rename mc { _input_value_ }

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    () => {
        narration.dialogue = `He thrusts out his hand.`;
    },
    () => {
        narration.input.request({ type: "string" }, "Peter");
        narration.dialogue = `What is your name?`;
    },
    () => {
        mc.name = narration.input.value as string;
    },
    // ...
]);
export default startLabel;
```

Теперь мы могли бы <DynamicLink href="/start/character#use">использовать имена персонажей</DynamicLink> внутри диалогов.

:::tip

В *ink* вы можете использовать квадратные скобки (например, `[sly]`), чтобы воспользоваться механизмом <DynamicLink href="/ink/replacement">замены текста</DynamicLink>: по умолчанию шаблоны проверяют, соответствует ли текст между скобками `id` персонажа, и если да, заменяют его на имя этого персонажа.

В JS/TS вы можете добиться того же результата, используя [шаблонные литералы](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Template_literals) с `${}` (например, `` `${sly.name}` ``).

:::

Вот пример:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"

=== start ===
// ...

mc: Thanks, good to meet you, [steph_fullname].
steph: WOW, that is, like, the most perfect handshake I've ever had! Firm, but also gentle. [sly], you *gotta* shake his hand!

// ...
-> DONE
```

## Определение и загрузка ресурсов

:::tip

Для загрузки и обработки ресурсов (изображений, gif, видео...) необходимо использовать `Assets`. `Assets` — это класс со множеством возможностей, происходящий из библиотеки PixiJS; если хотите узнать больше, прочтите [здесь](https://pixijs.com/8.x/guides/components/assets).

:::

Один из первых шагов — выбрать, где хранить ресурсы вашей визуальной новеллы: вы можете использовать онлайн-хостинг или сохранить их локально в проекте. Больше информации об обоих вариантах можно найти <DynamicLink href="/start/assets">здесь</DynamicLink>.

Если вы решите сохранять ресурсы локально, вам просто нужно поместить их внутрь `src/assets`: шаблон автоматически использует AssetPack для анализа файлов и определения их в `src/assets/manifest.gen.json`. Если же вы решите хранить их онлайн, вам нужно будет вручную отредактировать `assets/index.ts`, чтобы зарегистрировать их.

## Добавление фона и изображений персонажей

Теперь пора подумать и о визуальной части. Мы добавим изображения фона и персонажей на холст (canvas) визуальной новеллы.

<Accordions>

<Accordion title="Что такое `sprite`?" id="what-is-a-sprite">

В компьютерной графике спрайт — это двумерное растровое изображение, интегрированное в более крупную сцену, чаще всего в 2D-видеоигре. В Pixi’VN одно изображение, отображаемое на холсте (например, фон или тело/глаза/рот персонажа), — это `Sprite`.

</Accordion>

<Accordion title="Что такое `container`?" id="what-is-a-container">

Контейнер — это компонент, который группирует другие компоненты (спрайты или даже другие контейнеры), чтобы их можно было позиционировать, перемещать и обрабатывать как единое целое, сохраняя при этом возможность обращаться к каждому отдельному дочернему элементу и редактировать его.

</Accordion>

</Accordions>

В нашем случае каждый персонаж состоит из 3 спрайтов: тела, глаз и рта. Мы используем <DynamicLink href="/start/canvas-image-container">ImageContainer</DynamicLink> — `Container`, который группирует дочерние элементы `Sprite`, — чтобы объединить их и собрать персонажа. Больше информации о том, как добавлять компоненты холста, можно найти в <DynamicLink href="/start/canvas-components">этой документации</DynamicLink>.

<Accordion title="Использование переходов" id="use-transitions">

Чтобы сделать визуальную новеллу более динамичной, вы можете использовать переходы, чтобы показывать или удалять компоненты холста (изображения, контейнеры, ...) с анимированным эффектом, вместо того чтобы они появлялись или исчезали резко. Pixi’VN предоставляет несколько встроенных переходов — таких как растворение, затухание, движение внутрь/наружу, выталкивание внутрь/наружу и приближение/отдаление — а также позволяет создавать собственные пользовательские переходы.

Чтобы сделать визуальную новеллу более динамичной, вы можете использовать анимации. Рекомендую использовать TypeScript, если вам нужно задать много свойств, так как это даёт больше контроля, больше возможностей и обратную связь по типам.

В этом примере моя анимация уберёт `steph` со сцены и вернёт её обратно на следующем нарративном шаге (`step`). Я также отражу её по оси x, чтобы убедиться, что она смотрит в правильную сторону.

Чтобы убрать/вернуть `steph`, я буду использовать функции `moveOut` и `moveIn`. Для эффекта зеркального отражения я буду использовать функцию `canvas.animate`.

Сначала я использую функцию `canvas.animate`, чтобы создать анимацию, которая задаёт свойству `scaleX` значение от `-1` (отражено) до `1`, с `autoplay: false`, чтобы она не начиналась немедленно.

Просто для наглядности, вот как выглядел бы эквивалент в *ink*:

```ink tab="ink"
# animate steph scaleX 1 options autoplay false completeOnContinue true
```

```ts tab="Typescript"
canvas.animate<ImageContainer>(
    "steph",
    {
        scaleX: 1,
    },
    { autoplay: false, completeOnContinue: true },
);
```

Затем я использую функцию `moveIn`, чтобы переместить `steph` в сцену, передавая `tickerId` анимации, чтобы её можно было возобновить после завершения перехода.

Я использую опцию `completeOnContinue: true`, чтобы убедиться, что анимация завершится до выполнения следующего нарративного шага (`step`). Для `moveIn`, поскольку это переход, `completeOnContinue` по умолчанию равен true.

:::tip

Больше информации о том, как использовать анимации, см. <DynamicLink href="/start/canvas-animations-effects">здесь</DynamicLink>.

:::

Поскольку я использую TypeScript для этой анимации, я создал для неё нарративный узел (`label`), чтобы его можно было вызывать и из других языков.

```ts title="labels/animation01.ts"
import { canvas, ImageContainer, moveIn, newLabel } from "@drincs/pixi-vn";

export const animation01 = newLabel("animation_01", [
    async () => {
        let tickerId = canvas.animate<ImageContainer>(
            "steph",
            {
                scaleX: 1,
            },
            { autoplay: false, completeOnContinue: true },
        );

        await moveIn(
            "steph",
            {
                value: ["fm02-body", "fm02-eyes-joy", "fm02-mouth-smile01"],
                options: {
                    xAlign: 0.8,
                    yAlign: 1,
                    scale: { y: 1, x: -1 },
                    anchor: 0.5,
                },
            },
            {
                direction: "right",
                ease: "easeInOut",
                tickerIdToResume: tickerId,
            },
        );
    },
]);
```

:::tip[*ink*]

Как объясняется <DynamicLink href="/ink/labels#use-the-call-script">здесь</DynamicLink>, из *ink* вы можете вызывать нарративные узлы (`labels`), написанные на JS/TS, и наоборот.

:::

## Звуки и музыка

Чтобы добавить звуки и музыку в вашу визуальную новеллу, вы можете использовать утилиту `sound`.

Вы можете определить звуковые каналы для управления различными типами звуков (например, BGM, SFX) и контролировать их громкость, паузу, возобновление и т. д. Рекомендуется определять каналы в начале игры, например, в колбэке `then` функции `Game.init`.

В этом примере я определяю два канала: один для фоновой музыки (BGM) и один для звуковых эффектов (SFX). Я также устанавливаю `defaultChannelAlias` на канал SFX, чтобы, если я не указываю канал при воспроизведении звука, он по умолчанию воспроизводился в канале SFX. Чтобы определить фоновый канал, я устанавливаю свойство `background` в `true`, поэтому, в отличие от других каналов, звуки не будут останавливаться в конце каждого нарративного шага (`step`), а продолжат звучать, пока не будут приостановлены или остановлены.

```ts title="main.ts"
import { Game, sound } from "@drincs/pixi-vn";
import { BGM_CHANNEL_NAME, SFX_CHANNEL_NAME } from "@/constans";

Game.init(body, {
    // ...
}).then(() => {
    sound.channels.add(BGM_CHANNEL_NAME, { background: true });
    sound.channels.add(SFX_CHANNEL_NAME);
    sound.defaultChannelAlias = SFX_CHANNEL_NAME;
});
```

Наконец, вы можете воспроизводить звуки и музыку в нарративных узлах (`labels`), используя функцию `sound.play`. Вы также можете использовать каналы для управления различными типами звуков (например, BGM, SFX) и контролировать их громкость, паузу, возобновление и т. д.

:::
