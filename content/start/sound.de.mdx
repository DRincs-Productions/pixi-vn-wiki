---
title: Sounds und Musik
description: Wie man Sounds und Musik in Pixi’VN mithilfe von media, channels und dem sound-Manager abspielt, pausiert, fortsetzt, bearbeitet und stoppt, einschließlich Fade-Übergängen und Filtern, aufbauend auf Tone.js.
---

:::warning

Das gesamte Audiosystem wurde in Version 1.6.0/1.8.0 überarbeitet.

:::

Das Sound-Modul ist ein Wrapper um die Bibliothek [Tone.js](https://tonejs.github.io/examples/). Es bietet eine einfache Schnittstelle zum Abspielen von Sounds und speichert den aktuellen Zustand bei jedem <DynamicLink href="/start/labels">`step`</DynamicLink>.

:::tip[*ink*]

Sie können diese Methode mit der *ink*-Syntax verwenden. Mehr dazu <DynamicLink href="/ink/sound">hier</DynamicLink>.

:::

<Accordions>

<Accordion title="Nomenklatur" id="nomenclature">

Es besteht aus den folgenden Elementen, auf die später Bezug genommen wird:

* `sound` (Manager) ist der Controller des gesamten Audiosystems. Es wird verwendet, um `channels` zu verwalten, musikalische `media` zu starten und zu steuern sowie um Informationen abzurufen oder Sound-`assets` zu ändern. Sie können Werte festlegen, um die Gesamtlautstärke anzupassen. Diese Einstellungen werden nicht in Speicherdateien gespeichert und sind hauptsächlich für die Spieleinstellungen gedacht.
* `channels` ist eine Unterebene des Sound-Managers und kann als Container betrachtet werden. Es wird verwendet, um musikalische `media` zu enthalten, zu starten und zu verwalten. Sie können Werte festlegen, die sich nur auf die enthaltenen Medien auswirken. Diese Einstellungen werden nicht in Speicherdateien gespeichert und sind hauptsächlich für die Spieleinstellungen gedacht.
* `media` sind Instanzen eines Sounds, der gestartet wurde. Sie können Werte festlegen, die nur für sie selbst gelten. Alle auf sie angewendeten Einstellungen werden im Spielstand gespeichert. Diese Einstellungen sind hauptsächlich dafür vorgesehen, während des Spiels geändert zu werden. Sie sind in einem `channel` in einer Eins-zu-viele-Beziehung enthalten. Jedes Medium hat einen eindeutigen `alias`.
* `assets` (Sound-Assets) sind, wie der Name schon sagt, die Assets, die während des Spiels zum Abspielen von Sounds verwendet werden. Sie können Werte festlegen, die alle Medien beeinflussen, die dieses Asset verwenden. Diese Einstellungen werden nicht gespeichert und sind hauptsächlich dafür vorgesehen, während der Spielinitialisierung beim Laden der Assets konfiguriert zu werden.

</Accordion>

</Accordions>

```ts tab="content/labels/start.label.ts"
import { narration, newLabel, sound } from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [
    async () => {
        await sound.play("sfx_whoosh", { delay: 0.1 });
        await sound.play("bgm_cheerful", { loop: true, channel: "bgm" });
        narration.dialogue =
            "Hello, I'm a cheerful background music that will loop forever until you stop me.";
    },
    () => {
        sound.pause("bgm_cheerful");
        narration.dialogue = "I'm paused, but I can be resumed.";
    },
    () => {
        sound.resume("bgm_cheerful");
        narration.dialogue = "I'm back!";
    },
]);
```

## Initialisierung

<Accordions>

<Accordion title="Assets" id="assets">

Wie bei anderen Komponenten, die Assets verwenden, müssen Sie diese in den <DynamicLink href="/start/assets">Assets</DynamicLink> definieren. Danach wird empfohlen, <DynamicLink href="/start/assets-management#load-assets-in-the-background-at-project-start">die Hauptsounds im Hintergrund zu laden</DynamicLink>, und zwar beim Spielstart, mithilfe der von [`sound`](/jsdoc/pixi-vn/index/variables/sound) bereitgestellten Funktionen.

```ts tab="utils/assets-utility.ts"
import { manifest } from "@/assets";
import { AUDIO_BUNDLE_NAME } from "@/constants";
import { Assets, sound } from "@drincs/pixi-vn";

let assetsInitialized = false;

/**
 * Define all the assets that will be used in the game.
 * This function will be called before the game starts.
 * You can read more about assets management in the documentation: https://pixi-vn.com/start/assets-management.html
 */
export async function defineAssets() {
    if (!assetsInitialized) {
        const origin = `${location.protocol}//${location.host}/`;
        Assets.resolver.rootPath = origin;
        await Assets.init({ manifest, basePath: `${origin}assets/` });
        assetsInitialized = true;
    }

    // The audio bundle will be loaded in the background, so it will be available when needed, but it won't block the game start.
    sound.backgroundLoadBundle(AUDIO_BUNDLE_NAME);
}
```

Es wird außerdem empfohlen, `channels` unmittelbar nach der Spielinitialisierung zu definieren. Dazu können Sie die Funktion [`sound.channels.add`](/jsdoc/pixi-vn/index/interfaces/SoundChannelsInterface#add) verwenden.

```ts title="main.ts"
import { Game, sound } from "@drincs/pixi-vn";

Game.init(body, {
    // ...
}).then(() => {
    sound.channels.add("bgm", { background: true });
    sound.channels.add("sfx");
    sound.defaultChannelAlias = "sfx";
});
```

## Abspielen

:::tip

Wenn während der `play`-Funktion kein `channel` angegeben wird, wird das `media` [`sound.defaultChannelAlias`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#defaultchannelalias) zugewiesen.

:::

Die grundlegende Funktion besteht darin, einen Sound (`asset`) zu starten. Dies kann mithilfe der `play`-Funktion erfolgen. Die `play`-Funktion erzeugt eine `media`-Instanz, mit der Sie interagieren können, um den erzeugten Sound zu steuern.

<Accordions>

<Accordion title="channel" id="channel-play">

[`channel.play`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface#play) startet ein `media` direkt auf einem bestimmten `channel`, sodass Sie selbst keine `channel`-Option übergeben müssen.

```ts
import { sound } from "@drincs/pixi-vn";

await sound.channels.find("sfx").play("sfx_whoosh", { delay: 0.1 });
await sound.channels.find("bgm").play("bgm", "bgm_cheerful", { loop: true });
```

</Accordion>

<Accordion title="`sound` (Manager)" id="sound-manager-play">

[`sound.play`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#play) startet ein `media` vom Manager aus. Verwenden Sie die `channel`-Option, um es einem bestimmten `channel` zuzuweisen, andernfalls wird auf [`sound.defaultChannelAlias`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#defaultchannelalias) zurückgegriffen.

```ts
import { sound } from "@drincs/pixi-vn";

await sound.play("sfx_whoosh", { delay: 0.1 });
await sound.play("bgm", "bgm_cheerful", { loop: true, channel: "bgm" });
```

</Accordion>

</Accordions>

## Übergänge

<Accordions>

<Accordion title="Ein-/Ausblenden" id="fade">

Sie können ein `media` mit einem Fade-Übergang starten, indem Sie die Optionen [`fadeIn`](/jsdoc/pixi-vn/index/interfaces/SoundPlayOptions#fadein)/[`fadeOut`](/jsdoc/pixi-vn/index/interfaces/SoundPlayOptions#fadeout) von `play` verwenden. `fadeIn` wirkt sich nur auf den Start aus, während `fadeOut` beim `media` erhalten bleibt und automatisch angewendet wird, sowohl wenn es natürlich endet als auch wenn Sie später `stop()` aufrufen.

```ts
import { sound } from "@drincs/pixi-vn";

const music = await sound.play("theme", {
    loop: true,
    fadeIn: 2, // 2s fade-in on start
    fadeOut: 3, // 3s fade-out, applied both on manual stop() and on natural end
});

// later...
sound.stop("theme"); // automatically fades out over the 3s set above
```

</Accordion>

</Accordions>

## Pausieren und Fortsetzen

Es gibt verschiedene Möglichkeiten, einzelne oder mehrere `media` zu pausieren.

<Accordions>

<Accordion title="media" id="media-pause">

Das Setzen von [`media.paused`](/jsdoc/pixi-vn/index/interfaces/MediaInterface#paused) pausiert oder setzt diese einzelne `media`-Instanz direkt fort.

```ts
import { sound } from "@drincs/pixi-vn";

const bgmMedia = sound.find("bgm_cheerful");
if (bgmMedia) bgmMedia.paused = true;
// ...
if (bgmMedia) bgmMedia.paused = false;
```

</Accordion>

<Accordion title="channel" id="channel-pause">

[`channel.pauseAll`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface#pauseall)/[`channel.resumeAll`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface#resumeall) pausieren oder setzen jedes in diesem `channel` enthaltene `media` fort.

```ts
import { sound } from "@drincs/pixi-vn";

sound.channels.find("sfx").pauseAll();
sound.channels.find("sfx").resumeAll();
```

</Accordion>

<Accordion title="`sound` (Manager)" id="sound-manager-pause">

[`sound.pause`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#pause)/[`sound.resume`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#resume) zielen über den `alias` auf ein einzelnes `media` ab, während [`sound.pauseAll`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#pauseall)/[`sound.resumeAll`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#resumeall) jedes `media` über alle `channels` hinweg betreffen.

```ts
import { sound } from "@drincs/pixi-vn";

sound.pause("bgm_cheerful");
sound.pauseAll();

sound.resume("bgm_cheerful");
sound.resumeAll();
```

</Accordion>

</Accordions>

## Bearbeiten

:::tip

Nur `media`-Einstellungen werden in Spielstanddateien gespeichert.

:::

Es ist möglich, fast alle Einstellungen jederzeit für verschiedene Zwecke zu bearbeiten.

<Accordions>

<Accordion title="media" id="media-edit">

Einstellungen, die direkt einer [`media`](/jsdoc/pixi-vn/index/interfaces/MediaInterface)-Instanz zugewiesen werden (wie `volume`), wirken sich nur auf diese Instanz aus und werden im Spielstand gespeichert.

```ts
import { sound } from "@drincs/pixi-vn";

const bgmMedia = sound.find("bgm_cheerful");
if (bgmMedia) bgmMedia.volume.value = 90;
```

</Accordion>

<Accordion title="channel" id="channel-edit">

Einstellungen, die einem [`channel`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface) zugewiesen werden (wie `volume`), wirken sich auf jedes darin enthaltene `media` aus, ohne gespeichert zu werden.

```ts
import { sound } from "@drincs/pixi-vn";

sound.channels.find("sfx").volume = 90;
```

</Accordion>

<Accordion title="`sound` (Manager)" id="sound-manager-edit">

Einstellungen, die dem [`sound`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface)-Manager zugewiesen werden (wie `volumeAll`), wirken sich global auf jeden `channel`/jedes `media` aus, ohne gespeichert zu werden.

```ts
import { sound } from "@drincs/pixi-vn";

sound.volumeAll = 90;
```

</Accordion>

</Accordions>

## Stoppen

Um einen Sound zu stoppen, können Sie die `stop`-Funktion verwenden.

<Accordions>

<Accordion title="media" id="media-stop">

[`media.stop`](/jsdoc/pixi-vn/index/interfaces/MediaInterface#stop) stoppt diese einzelne `media`-Instanz direkt.

```ts
import { sound } from "@drincs/pixi-vn";

sound.find("bgm_cheerful")?.stop();
```

</Accordion>

<Accordion title="channel" id="channel-stop">

[`channel.stopAll`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface#stopall) stoppt jedes in diesem `channel` enthaltene `media`.

```ts
import { sound } from "@drincs/pixi-vn";
sound.channels.find("sfx").stopAll();
```

</Accordion>

<Accordion title="`sound` (Manager)" id="sound-manager-stop">

[`sound.stop`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#stop) stoppt ein einzelnes `media` über den `alias`, während [`sound.stopAll`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#stopall) jedes `media` über alle `channels` hinweg stoppt.

```ts
import { sound } from "@drincs/pixi-vn";
sound.stop("bgm_cheerful");
sound.stopAll();
```

</Accordion>

</Accordions>

## Filter

:::warning

Derzeit können sie nur beim Starten eines Mediums geändert werden.

:::

Filter sind Elemente, die eine erweiterte Anpassung von Sounds ermöglichen.

<Accordions>

<Accordion title="media" id="media-edit">

Das Übergeben von `filters` an [`sound.play`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#play) wendet sie nur auf diese `media`-Instanz an.

```ts
import { sound, filters } from "@drincs/pixi-vn";

await sound.play("sfx_whoosh", { filters: [new filters.ReverbFilter()] });
```

</Accordion>

<Accordion title="channel" id="channel-edit">

Das Übergeben von `filters` an [`sound.channels.add`](/jsdoc/pixi-vn/index/interfaces/SoundChannelsInterface#add) wendet sie auf jedes `media` an, das auf diesem `channel` gestartet wird.

```ts
import { sound, filters } from "@drincs/pixi-vn";

sound.channels.add("bgm", {
    filters: [new filters.ReverbFilter()],
});
```

</Accordion>

</Accordions>

## Weitere Funktionen

<Accordions>

<Accordion title="Menüfunktionen" id="menu-functions">

Es sind auch Funktionen zur Verwaltung von Sounds in Menüs verfügbar, etwa im Einstellungsbildschirm.

Alle von diesen Funktionen vorgenommenen Änderungen werden nicht in Spielständen gespeichert. Wenn also ein Spielstand geladen wird, kehren die Sounds in den Zustand zurück, in dem sie sich befanden, bevor sie durch diese Funktionen geändert wurden.

Die Funktionen [`sound.unsaved.pauseAll`](/jsdoc/pixi-vn/index/interfaces/SoundUnsavedInterface#pauseall) und [`sound.unsaved.resumeAll`](/jsdoc/pixi-vn/index/interfaces/SoundUnsavedInterface#resumeall) sind dafür vorgesehen, beim Öffnen und Schließen eines Menüs verwendet zu werden, etwa der Einstellungen. Die erste Funktion pausiert alle Sounds, die noch nicht pausiert sind, während die zweite alle Sounds fortsetzt, die von der ersten Funktion pausiert wurden.

Die Funktionen [`sound.unsaved.playTransient`](/jsdoc/pixi-vn/index/interfaces/SoundUnsavedInterface#playtransient) und [`sound.unsaved.stopTransientAll`](/jsdoc/pixi-vn/index/interfaces/SoundUnsavedInterface#stoptransientall) sind hingegen für temporäre Sounds gedacht, etwa UI-Interaktionsgeräusche. Die erste Funktion spielt einen Sound ab, der nicht in Spielständen gespeichert wird, während die zweite alle mit der ersten Funktion gestarteten Sounds stoppt.

</Accordion>

</Accordions>
