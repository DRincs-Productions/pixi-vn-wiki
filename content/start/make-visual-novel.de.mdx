Dieses Tutorial führt dich durch den Prozess der Erstellung deines ersten Visual Novels.

<Accordions>

<Accordion title="Was ist ein Visual Novel?" id="what-is-a-visual-novel">

Ein Visual Novel (VN) ist eine Form der digitalen interaktiven Fiktion. Visual Novels werden oft mit dem Medium der Videospiele in Verbindung gebracht, werden aber nicht immer selbst als solche bezeichnet. Sie kombinieren eine textuelle Erzählung mit statischen oder animierten Illustrationen und einem unterschiedlichen Grad an Interaktivität. Das Format wird seltener als Novel Game bezeichnet, eine Rückübertragung des wasei-eigo-Begriffs noberu gēmu (ノベルゲーム), der im Japanischen häufiger verwendet wird.

</Accordion>

</Accordions>

Zu Testzwecken werden wir in diesem Leitfaden das Visual Novel [Breakdown](https://joshpowlison.itch.io/breakdown) mit Pixi’VN nachbauen. Breakdown ist eine Kurzgeschichte, die alle Merkmale aufweist, die ein Visual Novel haben sollte. Josh Powlison, der Schöpfer von Breakdown, hat uns die Erlaubnis erteilt, seine Erzählung zu Bildungszwecken zu verwenden❤️.

:::tip

Da Pixi’VN dir die Möglichkeit gibt, deine eigene Erzählung zu schreiben, indem du eine oder mehrere <DynamicLink href="/start/narration">verfügbare Erzählsprachen</DynamicLink> wählst, werden bei jedem Entwicklungsschritt Beispiele für jede derzeit verfügbare Sprache erstellt.

:::

## Neues Projekt erstellen

Bevor du beginnst, stelle sicher, dass du die <DynamicLink href="/start#prerequisites">Voraussetzungen</DynamicLink> installiert hast.

Der erste Schritt besteht darin, ein neues Projekt zu erstellen. Du kannst dies tun, indem du Folgendes ausführst:

```npm
npm create pixi-vn@latest
```

und die Vorlage `Visual Novel` auswählst.

:::tip[VS Code]

Wenn du das Projekt mit VS Code öffnest, wirst du gebeten, der Ausführung einiger Workspace-Tasks zuzustimmen und die empfohlenen Erweiterungen für das Projekt zu installieren. Es wird dringend empfohlen, beides zu akzeptieren.

:::

Weitere Informationen zu Vorlagen, Tasks und Erweiterungen findest du <DynamicLink href="/start/templates">hier</DynamicLink>.

<Accordions>

<Accordion title="Manuelle Befehle" id="manual-commands">

Wenn du die VS Code-Tasks nicht verwenden möchtest, kannst du das gleiche Ergebnis erzielen, indem du die folgenden Befehle im Stammverzeichnis des Projekts ausführst:

```npm
npm install
npm start
```

</Accordion>

</Accordions>

## Erstellung der Charaktere

Jetzt werden wir die Charaktere dieser Geschichte definieren. Dazu definieren wir in der Datei `/content/characters.ts` die Charaktere, die wir verwenden werden.

<Accordions>

<Accordion title="Was bedeutet `mc`?" id="what-does-mc-mean">

`mc` ist eine gängige Abkürzung für „Main Character“ (Hauptcharakter). Es ist in Visual Novels üblich, `mc` als Namen des Hauptcharakters zu verwenden.

</Accordion>

<Accordion title="Wo wird das `Character`-Modell definiert?" id="where-is-the-character-model-defined">

Das unten verwendete `Character`-Modell wird in `models/Character.ts` definiert. Du kannst es nach Belieben ändern, um beispielsweise weitere Eigenschaften des Charakters hinzuzufügen (z. B. `surname`, `age`, ...). Weitere Informationen zu dieser Datei findest du <DynamicLink href="/start/character#custom-class">hier</DynamicLink>.

</Accordion>

</Accordions>

:::tip

Weitere Informationen zur Erstellung und Verwendung von Charakteren findest du unter: <DynamicLink href="/start/character">Charaktere</DynamicLink>

:::

```ts title="content/characters.ts"
import Character from "@/models/Character";
import { RegisteredCharacters } from "@drincs/pixi-vn";

export const mc = new Character("mc", {
    name: "Me",
});

export const james = new Character("james", {
    name: "James",
    color: "#0084ac",
});

export const steph = new Character("steph", {
    name: "Steph",
    color: "#ac5900",
});

export const sly = new Character("sly", {
    name: "Sly",
    color: "#6d00ac",
});

RegisteredCharacters.add([mc, james, steph, sly]);
```

<Accordion title="Verwende die `glue`-Funktion der Dialoge" id="use-the-glue-feature-of-dialogues">

In Visual Novels ist es oft nützlich, Text an den aktuellen Dialog anzuhängen. Zum Beispiel, um ein Gespräch zu pausieren und es in einem nachfolgenden `step` fortzusetzen. Dazu können wir die <DynamicLink href="/start/dialogue#dialogue-glue">glue-Funktionalität</DynamicLink> verwenden.

Dies ist das Beispiel:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

james: Ooh, [mc]! Nice, firm handshake!
<>The last guy always gave me the dead fish.
<>I already think we're gonna get along fine.
james: Come on in and...

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    async () =>
        (narration.dialogue = {
            character: james,
            text: `Ooh, ${mc.name}! Nice, firm handshake!`,
        }),
    async () => {
        narration.dialogGlue = true;
        narration.dialogue = `The last guy always gave me the dead fish.`;
    },
    async () => {
        narration.dialogGlue = true;
        narration.dialogue = `I already think we're gonna get along fine.`;
    },
    async () =>
        (narration.dialogue = { character: james, text: `Come on in and...` }),
    // ...
]);
export default startLabel;
```

</Accordion>

<Accordion title="Erstelle einen Pause-Effekt" id="create-a-pause-effect">

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
    // ...
    async () => {
        narration.dialogue = undefined;
    },
    // ...
]);

```

### Teile die Erzählung in `labels` auf

Es ist nicht ratsam, sehr lange `labels` zu erstellen (auch nicht für lineare Visual Novels), sondern es ist ratsam, mehrere kleine `labels` zu erstellen und sie bei Bedarf mithilfe der <DynamicLink href="/start/labels-flow">Funktionen zur Steuerung des Erzählflusses</DynamicLink> „aufzurufen“.

Aus diesem Grund wird unsere Geschichte, auch wenn sie in unserem Fall linear ist, in zwei `labels` unterteilt: Das erste ist das, das wir gerade erstellt haben (`start`), während das zweite `second_part` heißen wird.

Dies ist das Beispiel:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
james: You're my roommate's replacement, huh?
james: Don't worry, you don't have much to live up to. Just don't use heroin like the last guy, and you' fine!
mc: ...

He thrusts out his hand.

james: James!
mc: ...Peter.

// ...
-> second_part

=== second_part ===

She enters my room before I'VE even had a chance to. \\n\\n...I could've just come back and gotten the platter later...
She sets it on a desk. I throw my two paper bags down beside the empty bed.

steph: They got you a new mattress, right? That last guy was a druggie, did James tell you that?
sly: *We're* the reason he got expelled!
steph: Sly! If word gets out about that... well, actually, it wouldn't matter, *he's* the one who shot himself up.

I'm fumbling for a new subject.

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    () =>
        (narration.dialogue = {
            character: james,
```

## Auswahlmenüs

Jetzt werden wir den Spieler fragen, ob er mit dem zweiten Teil des Visual Novels fortfahren möchte.

Dazu setzen wir [`narration.choices`](/jsdoc/pixi-vn/index/interfaces/NarrationManagerInterface#choices) auf ein Array von Auswahloptionen, die mit [`newChoiceOption`](/jsdoc/pixi-vn/index/functions/newChoiceOption) (um zu einem `label` zu springen oder es aufzurufen) und [`newCloseChoiceOption`](/jsdoc/pixi-vn/index/functions/newCloseChoiceOption) (um das Auswahlmenü zu schließen, ohne irgendwohin zu navigieren) erstellt wurden.

:::tip

Weitere Informationen zu Auswahlmenüs findest du <DynamicLink href="/start/choices">hier</DynamicLink>.

:::

Dies ist das Beispiel:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

You want continue to the next part?
* Yes, I want to continue
-> second_part
* No, I want to stop here
-> END

=== second_part ===

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    async () => {
        narration.dialogue = `You want continue to the next part?`;
        narration.choices = [
            newChoiceOption(
                "Yes, I want to continue",
                secondPart,
                {},
                { type: "jump" },
            ),
            newCloseChoiceOption("No, I want to stop here"),
        ];
    },
]);
export default startLabel;

const secondPart = newLabel("second_part", [
    // ...
]);
```

## Charakterinformationen bearbeiten und als Variable verwenden

Jetzt gebe ich dem Spieler die Möglichkeit, den Namen des `mc` zu ändern.
Dazu werde ich den Spieler bitten, <DynamicLink href="/start/input">ein Eingabefeld mithilfe der Funktionen von Pixi’VN auszufüllen</DynamicLink>.

Nachdem der Eingabewert ermittelt wurde, kannst du <DynamicLink href="/start/character#edit">den Charakternamen setzen</DynamicLink>, indem du den erhaltenen Wert verwendest.

:::tip

In *ink* ist `_input_value_` eine spezielle Variable, die den vom Spieler eingegebenen Wert enthält. Mehr darüber erfährst du <DynamicLink href="/ink/input">hier</DynamicLink>.

:::

Dies ist das Beispiel:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
// ...

He thrusts out his hand.
# request input type string default Peter
What is your name?
# rename mc { _input_value_ }

// ...
-> DONE
```

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
const startLabel = newLabel("start", [
    // ...
    () => {
        narration.dialogue = `He thrusts out his hand.`;
    },
    () => {
        narration.requestInput({ type: "string" }, "Peter");
        narration.dialogue = `What is your name?`;
    },
    () => {
        mc.name = narration.inputValue as string;
    },
    // ...
]);
export default startLabel;
```

Jetzt könnten wir <DynamicLink href="/start/character#use">Charakternamen</DynamicLink> innerhalb von Dialogen verwenden.

:::tip

In *ink* kannst du eckige Klammern (z. B. `[sly]`) verwenden, um den Mechanismus der <DynamicLink href="/ink/replacement">Textersetzung</DynamicLink> zu nutzen: Standardmäßig prüfen die Vorlagen, ob der Text zwischen den Klammern mit einer Charakter-`id` übereinstimmt, und ersetzen ihn gegebenenfalls durch den Namen dieses Charakters.

In JS/TS kannst du das gleiche Ergebnis erzielen, indem du [Template-Literale](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Template_literals) mit `${}` verwendest (z. B. `` `${sly.name}` ``).

:::

Dies ist das Beispiel:

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
VAR steph_fullname = "Stephanie"

=== start ===
// ...

sly: I just wanted to see what the new guy was like. Hey, you, [mc]- be nice to our little brother, or you'll have to deal with *us*.
mc: ...
james: [mc], this is [sly]. Yes, that is her real name.

I put out my hand.

sly: I'm not shakin' your hand until I decide you're an all-right dude. Sorry, policy.
mc: Fair enough, I'm a pretty scary guy, or so l've been told.
james: The redhead behind her is [steph_fullname].
steph: Hey! Everyone calls me [steph]. I'll shake your hand.

She puts out her hand, and I take it.

mc: Thanks, good to meet you, [steph_fullname].
steph: WOW, that is, like, the most perfect handshake I've ever had! Firm, but also gentle. [sly], you *gotta* shake his hand!

// ...
-> DONE
```

## Assets definieren und laden

:::tip

Um Assets (Bilder, GIFs, Videos...) zu laden und zu verarbeiten, müssen Sie `Assets` verwenden. `Assets` ist eine Klasse mit vielen Funktionen aus der PixiJS-Bibliothek. Wenn du mehr Informationen möchtest, lies [hier](https://pixijs.com/8.x/guides/components/assets).

:::

Einer der ersten Schritte besteht darin, zu entscheiden, wo du die Assets deines Visual Novels speicherst: Du kannst einen Online-Hosting-Dienst verwenden oder sie lokal im Projekt speichern. Weitere Informationen zu beiden Optionen findest du <DynamicLink href="/start/assets">hier</DynamicLink>.

Wenn du dich entscheidest, die Assets lokal zu speichern, musst du sie nur in `src/assets` ablegen: Die Vorlage verwendet automatisch AssetPack, um die Dateien zu analysieren und sie in `src/assets/manifest.gen.json` zu definieren. Wenn du dich stattdessen dafür entscheidest, sie online zu behalten, musst du `assets/index.ts` manuell bearbeiten, um sie zu registrieren.

In beiden Fällen wird jedem Asset ein oder mehrere `alias` zugewiesen, die du dann in deinem Code verwenden kannst, um auf dieses Asset zu verweisen.

<Files>

                </Folder>
                <File name="manifest.gen.json" />
                <File name="index.ts" />
            </Folder>
        </Folder>
    </Folder>
</Files>

## Hintergrund- und Charakterbilder hinzufügen

Jetzt ist es an der Zeit, auch über den visuellen Teil nachzudenken. Wir werden die Hintergrund- und Charakterbilder zur Canvas des Visual Novels hinzufügen.

<Accordions>

<Accordion title="Was ist ein `sprite`?" id="what-is-a-sprite">

In der Computergrafik ist ein Sprite eine zweidimensionale Bitmap, die in eine größere Szene integriert wird, meist in einem 2D-Videospiel. In Pixi’VN ist ein einzelnes auf der Canvas angezeigtes Bild (z. B. der Hintergrund oder der Körper/die Augen/der Mund eines Charakters) ein `Sprite`.

</Accordion>

<Accordion title="Was ist ein `container`?" id="what-is-a-container">

Ein Container ist eine Komponente, die andere Komponenten (Sprites oder sogar andere Container) gruppiert, sodass sie als eine einzige Einheit positioniert, bewegt und bearbeitet werden können, während weiterhin auf jedes einzelne Kind zugegriffen und dieses bearbeitet werden kann.

</Accordion>

</Accordions>

In unserem Fall besteht jeder Charakter aus 3 Sprites: dem Körper, den Augen und dem Mund. Wir verwenden <DynamicLink href="/start/canvas-image-container">ImageContainer</DynamicLink>, einen `Container`, der `Sprite`-Kinder gruppiert, um sie zusammenzufassen und den Charakter zusammenzusetzen. Weitere Informationen zum Hinzufügen von Canvas-Komponenten findest du in <DynamicLink href="/start/canvas-components">dieser Dokumentation</DynamicLink>.

<Accordion title="Eine Animation erstellen" id="building-an-animation">

Um das Visual Novel dynamischer zu gestalten, kannst du Animationen verwenden. Ich empfehle die Verwendung von TypeScript, wenn du viele Eigenschaften festlegen musst, da dies mehr Kontrolle, mehr Funktionalität und Typ-Feedback bietet.

In diesem Beispiel wird meine Animation `steph` aus der Szene entfernen und sie im nächsten `step` wieder einfügen. Außerdem werde ich sie auf der x-Achse spiegeln, um sicherzustellen, dass sie in die richtige Richtung schaut.

Um `steph` heraus-/hereinzunehmen, werde ich die Funktionen `moveOut` und `moveIn` verwenden. Für den Spiegeleffekt werde ich die Funktion `canvas.animate` verwenden.

Zuerst verwende ich die Funktion `canvas.animate`, um eine Animation zu erstellen, die die Eigenschaft `scaleX` von `-1` (gespiegelt) auf `1` setzt, mit `autoplay: false`, damit sie nicht sofort startet.

Nur zu Erklärungszwecken, so würde das Äquivalent in *ink* aussehen:

```ink tab="ink"
# animate steph scaleX 1 options autoplay false completeOnContinue true
```

```ts tab="Typescript"
canvas.animate<ImageContainer>(
    "steph",
    {
        scaleX: 1,
    },
    { autoplay: false, completeOnContinue: true },
);
```

Dann verwende ich die Funktion `moveIn`, um `steph` in die Szene zu bewegen, wobei ich die `tickerId` der Animation übergebe, damit sie fortgesetzt werden kann, nachdem der Übergang abgeschlossen ist.

Ich verwende die Option `completeOnContinue: true`, um sicherzustellen, dass die Animation abgeschlossen wird, bevor der nächste `step` ausgeführt wird. Bei `moveIn`, das ein Übergang ist, ist `completeOnContinue` standardmäßig true.

:::tip

Weitere Informationen zur Verwendung von Animationen findest du <DynamicLink href="/start/canvas-animations-effects">hier</DynamicLink>.

:::

Da ich für diese Animation TypeScript verwende, habe ich dafür ein `label` erstellt, damit es auch von anderen Sprachen aufgerufen werden kann.

```ts title="labels/animation01.ts"
import { canvas, ImageContainer, moveIn, newLabel } from "@drincs/pixi-vn";

export const animation01 = newLabel("animation_01", [
    async () => {
        let tickerId = canvas.animate<ImageContainer>(
            "steph",
            {
                scaleX: 1,
            },
            { autoplay: false, completeOnContinue: true },
        );

        await moveIn(
            "steph",
            {
                value: ["fm02-body", "fm02-eyes-joy", "fm02-mouth-smile01"],
                options: {
                    xAlign: 0.8,
                    yAlign: 1,
                    scale: { y: 1, x: -1 },
                    anchor: 0.5,
                },
            },
            {
                direction: "right",
                ease: "easeInOut",
                tickerIdToResume: tickerId,
            },
        );
    },
]);
```

:::tip[*ink*]

Wie <DynamicLink href="/ink/labels#use-the-call-script">hier</DynamicLink> erklärt, kannst du von *ink* aus in JS/TS geschriebene `labels` aufrufen und umgekehrt.

:::

## Sounds und Musik

Um deinem Visual Novel Sounds und Musik hinzuzufügen, kannst du das `sound`-Utility verwenden.

Du kannst Sound-Kanäle definieren, um verschiedene Arten von Sounds (z. B. BGM, SFX) zu verwalten und ihre Lautstärke, Pause, Fortsetzung usw. zu steuern. Es wird empfohlen, die Kanäle zu Beginn des Spiels zu definieren, zum Beispiel im `then`-Callback der Funktion `Game.init`.

In diesem Beispiel definiere ich zwei Kanäle: einen für die Hintergrundmusik (BGM) und einen für die Soundeffekte (SFX). Außerdem setze ich `defaultChannelAlias` auf den SFX-Kanal, sodass ein Sound, wenn ich beim Abspielen keinen Kanal angebe, standardmäßig im SFX-Kanal abgespielt wird. Um den Hintergrundkanal zu definieren, setze ich die Eigenschaft `background` auf `true`, sodass die Sounds im Gegensatz zu den anderen Kanälen nicht am Ende jedes narrativen `step` gestoppt werden, sondern weiterlaufen, bis sie pausiert oder gestoppt werden.

```ts title="main.ts"
import { Game, sound } from "@drincs/pixi-vn";
import { BGM_CHANNEL_NAME, SFX_CHANNEL_NAME } from "@/constans";

Game.init(body, {
    // ...
}).then(() => {
    sound.addChannel(BGM_CHANNEL_NAME, { background: true });
    sound.addChannel(SFX_CHANNEL_NAME);
    sound.defaultChannelAlias = SFX_CHANNEL_NAME;
});
```

Schließlich kannst du die Sounds und die Musik in den `labels` mithilfe der Funktion `sound.play` abspielen. Du kannst auch Kanäle verwenden, um verschiedene Arten von Sounds (z. B. BGM, SFX) zu verwalten und ihre Lautstärke, Pause, Fortsetzung usw. zu steuern.
