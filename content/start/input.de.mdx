In Visual Novels kann es erforderlich sein, den Spieler zur Eingabe von Text, Zahlen, Datumsangaben oder anderen Werten aufzufordern.

Pixi’VN stellt Funktionen zur Verarbeitung von Eingabeaufforderungen bereit. Der Entwickler kann verlangen, dass der Spieler einen Wert eingibt (das Spiel wird erst fortgesetzt, wenn ein Wert angegeben wurde), während die <DynamicLink href="/start/interface">UI</DynamicLink> für die Anzeige der Aufforderung zuständig ist.

## Request

To prompt the player for input, use the [`narration.input.request`](/jsdoc/pixi-vn/index/interfaces/NarrationInputInterface#request) function.

```ts title="content/labels/start.label.ts"
import { narration, newLabel } from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [
    () => {
        narration.dialogue = "Hello";
    },
    () => {
        narration.dialogue = "What is your name?";
        narration.input.request({ type: "string" });
    },
    () => {
        narration.dialogue = `My name is ${narration.input.value}`;
    },
    () => {
        narration.dialogue = "How old are you?";
        narration.input.request({ type: "number" }, 18);
    },
    () => {
        narration.dialogue = `I am ${narration.input.value} years old`;
    },
    () => {
        narration.dialogue = "Describe who you are:";
        narration.input.request({ type: "html textarea" });
    },
    () => {
        narration.dialogue = `${narration.input.value}`;
    },
    () => {
        narration.dialogue = "Restart";
    },
]);
```

## Abrufen

To get input prompt information, use:

* [`narration.input.isRequired`](/jsdoc/pixi-vn/index/interfaces/NarrationInputInterface#isrequired)
* [`narration.input.type`](/jsdoc/pixi-vn/index/interfaces/NarrationInputInterface#type)

```ts
if (narration.input.isRequired) {
    openInputModal(narration.input.type);
}
```

## Entfernen

To remove the input prompt request, use [`narration.input.removeRequest`](/jsdoc/pixi-vn/index/interfaces/NarrationInputInterface#removerequest).

```ts
narration.input.removeRequest();
```
