title: Sons et musique
description: Comment jouer, mettre en pause, reprendre, modifier et arrêter des sons et de la musique dans Pixi’VN à l'aide des media, des channels et du gestionnaire sound, y compris les transitions en fondu et les filtres, construit sur Tone.js.
---

:::warning

L'ensemble du système audio a été révisé dans la version 1.6.0/1.8.0.

:::

Le module sound est un wrapper autour de la bibliothèque [Tone.js](https://tonejs.github.io/examples/). Il fournit une interface simple pour jouer des sons et enregistre l'état actuel à chaque <DynamicLink href="/start/labels">`step`</DynamicLink>.

:::tip[*ink*]

Vous pouvez utiliser cette méthode avec la syntaxe *ink*. Voir plus <DynamicLink href="/ink/sound">ici</DynamicLink>.

:::

<Accordions>

<Accordion title="Terminologie" id="nomenclature">

Il est composé des éléments suivants, qui seront référencés plus tard :

* `sound` (gestionnaire) est le contrôleur de l'ensemble du système audio. Il est utilisé pour gérer les `channels`, démarrer et contrôler les `media` musicaux, et récupérer des informations ou modifier les `assets` sonores. Vous pouvez définir des valeurs pour ajuster le niveau audio global. Ces paramètres ne sont pas stockés dans les fichiers de sauvegarde et sont principalement destinés aux paramètres du jeu.
* `channels` est un sous-niveau du gestionnaire sound et peut être considéré comme un conteneur. Il est utilisé pour contenir, démarrer et gérer les `media` musicaux. Vous pouvez définir des valeurs qui affectent uniquement les media contenus. Ces paramètres ne sont pas stockés dans les fichiers de sauvegarde et sont principalement destinés aux paramètres du jeu.
* `media` sont des instances d'un son qui a été démarré. Vous pouvez définir des valeurs qui s'appliquent uniquement à eux-mêmes. Tous les paramètres qui leur sont appliqués sont enregistrés dans la sauvegarde du jeu. Ces paramètres sont principalement destinés à être modifiés pendant le jeu. Ils sont contenus dans un `channel` selon une relation un-à-plusieurs. Chaque media possède un `alias` unique.
* `assets` (assets sonores), comme leur nom l'indique, sont les assets utilisés pendant le jeu pour jouer des sons. Vous pouvez définir des valeurs qui influencent tous les media utilisant cet asset. Ces paramètres ne sont pas sauvegardés et sont principalement destinés à être configurés lors de l'initialisation du jeu, au chargement des assets.

</Accordion>

</Accordions>

```ts tab="content/labels/start.label.ts"
import { narration, newLabel, sound } from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [
    async () => {
        await sound.play("sfx_whoosh", { delay: 0.1 });
        await sound.play("bgm_cheerful", { loop: true, channel: "bgm" });
        narration.dialogue =
            "Hello, I'm a cheerful background music that will loop forever until you stop me.";
    },
    () => {
        sound.pause("bgm_cheerful");
        narration.dialogue = "I'm paused, but I can be resumed.";
    },
    () => {
        sound.resume("bgm_cheerful");
        narration.dialogue = "I'm back!";
    },
]);
```

## Initialisation

<Accordions>

<Accordion title="Assets" id="assets">

Comme pour les autres composants qui utilisent des assets, vous devez les définir dans les <DynamicLink href="/start/assets">assets</DynamicLink>. Ensuite, il est recommandé de <DynamicLink href="/start/assets-management#load-assets-in-the-background-at-project-start">charger les sons principaux en arrière-plan</DynamicLink> au démarrage du jeu à l'aide des fonctions fournies par [`sound`](/jsdoc/pixi-vn/index/variables/sound).

```ts tab="utils/assets-utility.ts"
import { manifest } from "@/assets";
import { AUDIO_BUNDLE_NAME } from "@/constants";
import { Assets, sound } from "@drincs/pixi-vn";

let assetsInitialized = false;

/**
 * Define all the assets that will be used in the game.
 * This function will be called before the game starts.
 * You can read more about assets management in the documentation: https://pixi-vn.com/start/assets-management.html
 */
export async function defineAssets() {
    if (!assetsInitialized) {
        const origin = `${location.protocol}//${location.host}/`;
        Assets.resolver.rootPath = origin;
        await Assets.init({ manifest, basePath: `${origin}assets/` });
        assetsInitialized = true;
    }

    // The audio bundle will be loaded in the background, so it will be available when needed, but it won't block the game start.
    sound.backgroundLoadBundle(AUDIO_BUNDLE_NAME);
}
```

Il est également recommandé de définir les `channels` immédiatement après l'initialisation du jeu. Pour ce faire, vous pouvez utiliser la fonction [`sound.channels.add`](/jsdoc/pixi-vn/index/interfaces/SoundChannelsInterface#add).

```ts title="main.ts"
import { Game, sound } from "@drincs/pixi-vn";

Game.init(body, {
    // ...
}).then(() => {
    sound.channels.add("bgm", { background: true });
    sound.channels.add("sfx");
    sound.defaultChannelAlias = "sfx";
});
```

## Lecture

:::tip

Si aucun `channel` n'est spécifié lors de l'appel de la fonction `play`, le `media` sera assigné à [`sound.defaultChannelAlias`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#defaultchannelalias).

:::

La fonctionnalité de base consiste à démarrer un son (`asset`). Cela peut être fait à l'aide de la fonction `play`. La fonction `play` génère une instance `media` avec laquelle vous pouvez interagir pour contrôler le son produit.

<Accordions>

<Accordion title="channel" id="channel-play">

[`channel.play`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface#play) démarre un `media` directement sur un `channel` spécifique, vous n'avez donc pas besoin de passer vous-même une option `channel`.

```ts
import { sound } from "@drincs/pixi-vn";

await sound.channels.find("sfx").play("sfx_whoosh", { delay: 0.1 });
await sound.channels.find("bgm").play("bgm", "bgm_cheerful", { loop: true });
```

</Accordion>

<Accordion title="`sound` (gestionnaire)" id="sound-manager-play">

[`sound.play`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#play) démarre un `media` depuis le gestionnaire. Utilisez l'option `channel` pour l'assigner à un `channel` spécifique, sinon il revient par défaut à [`sound.defaultChannelAlias`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#defaultchannelalias).

```ts
import { sound } from "@drincs/pixi-vn";

await sound.play("sfx_whoosh", { delay: 0.1 });
await sound.play("bgm", "bgm_cheerful", { loop: true, channel: "bgm" });
```

</Accordion>

</Accordions>

## Transitions

<Accordions>

<Accordion title="Fondu" id="fade">

Vous pouvez démarrer un `media` avec une transition en fondu à l'aide des options [`fadeIn`](/jsdoc/pixi-vn/index/interfaces/SoundPlayOptions#fadein)/[`fadeOut`](/jsdoc/pixi-vn/index/interfaces/SoundPlayOptions#fadeout) de `play`. `fadeIn` n'affecte que le démarrage, tandis que `fadeOut` est conservé sur le `media` et appliqué automatiquement à la fois lorsqu'il se termine naturellement et lorsque vous appelez `stop()` plus tard.

```ts
import { sound } from "@drincs/pixi-vn";

const music = await sound.play("theme", {
    loop: true,
    fadeIn: 2, // 2s fade-in on start
    fadeOut: 3, // 3s fade-out, applied both on manual stop() and on natural end
});

// later...
sound.stop("theme"); // automatically fades out over the 3s set above
```

</Accordion>

</Accordions>

## Pause et reprise

Il existe plusieurs façons de mettre en pause un ou plusieurs `media`.

<Accordions>

<Accordion title="media" id="media-pause">

Définir [`media.paused`](/jsdoc/pixi-vn/index/interfaces/MediaInterface#paused) met en pause ou reprend directement cette instance `media`.

```ts
import { sound } from "@drincs/pixi-vn";

const bgmMedia = sound.find("bgm_cheerful");
if (bgmMedia) bgmMedia.paused = true;
// ...
if (bgmMedia) bgmMedia.paused = false;
```

</Accordion>

<Accordion title="channel" id="channel-pause">

[`channel.pauseAll`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface#pauseall)/[`channel.resumeAll`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface#resumeall) met en pause ou reprend tous les `media` contenus dans ce `channel`.

```ts
import { sound } from "@drincs/pixi-vn";

sound.channels.find("sfx").pauseAll();
sound.channels.find("sfx").resumeAll();
```

</Accordion>

<Accordion title="`sound` (gestionnaire)" id="sound-manager-pause">

[`sound.pause`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#pause)/[`sound.resume`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#resume) ciblent un seul `media` par `alias`, tandis que [`sound.pauseAll`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#pauseall)/[`sound.resumeAll`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#resumeall) affectent tous les `media` à travers tous les `channels`.

```ts
import { sound } from "@drincs/pixi-vn";

sound.pause("bgm_cheerful");
sound.pauseAll();

sound.resume("bgm_cheerful");
sound.resumeAll();
```

</Accordion>

</Accordions>

## Modifier

:::tip

Seuls les paramètres `media` seront enregistrés dans les fichiers de sauvegarde du jeu.

:::

Il est possible de modifier presque tous les paramètres à tout moment, à différentes fins.

<Accordions>

<Accordion title="media" id="media-edit">

Les paramètres assignés directement sur une instance [`media`](/jsdoc/pixi-vn/index/interfaces/MediaInterface) (comme `volume`) n'affectent que cette instance, et sont enregistrés dans la sauvegarde du jeu.

```ts
import { sound } from "@drincs/pixi-vn";

const bgmMedia = sound.find("bgm_cheerful");
if (bgmMedia) bgmMedia.volume.value = 90;
```

</Accordion>

<Accordion title="channel" id="channel-edit">

Les paramètres assignés sur un [`channel`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface) (comme `volume`) affectent tous les `media` qu'il contient, sans être enregistrés.

```ts
import { sound } from "@drincs/pixi-vn";

sound.channels.find("sfx").volume = 90;
```

</Accordion>

<Accordion title="`sound` (gestionnaire)" id="sound-manager-edit">

Les paramètres assignés sur le gestionnaire [`sound`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface) (comme `volumeAll`) affectent globalement tous les `channel`/`media`, sans être enregistrés.

```ts
import { sound } from "@drincs/pixi-vn";

sound.volumeAll = 90;
```

</Accordion>

</Accordions>

## Arrêt

Pour arrêter un son, vous pouvez utiliser la fonction `stop`.

<Accordions>

<Accordion title="media" id="media-stop">

[`media.stop`](/jsdoc/pixi-vn/index/interfaces/MediaInterface#stop) arrête directement cette instance `media`.

```ts
import { sound } from "@drincs/pixi-vn";

sound.find("bgm_cheerful")?.stop();
```

</Accordion>

<Accordion title="channel" id="channel-stop">

[`channel.stopAll`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface#stopall) arrête tous les `media` contenus dans ce `channel`.

```ts
import { sound } from "@drincs/pixi-vn";
sound.channels.find("sfx").stopAll();
```

</Accordion>

<Accordion title="`sound` (gestionnaire)" id="sound-manager-stop">

[`sound.stop`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#stop) arrête un seul `media` par `alias`, tandis que [`sound.stopAll`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#stopall) arrête tous les `media` à travers tous les `channels`.

```ts
import { sound } from "@drincs/pixi-vn";
sound.stop("bgm_cheerful");
sound.stopAll();
```

</Accordion>

</Accordions>

## Filtres

:::warning

Actuellement, ils ne peuvent être modifiés qu'au démarrage d'un media.

:::

Les filtres sont des éléments qui permettent une personnalisation avancée des sons.

<Accordions>

<Accordion title="media" id="media-edit">

Passer des `filters` à [`sound.play`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#play) ne les applique qu'à cette instance `media`.

```ts
import { sound, filters } from "@drincs/pixi-vn";

await sound.play("sfx_whoosh", { filters: [new filters.ReverbFilter()] });
```

</Accordion>

<Accordion title="channel" id="channel-edit">

Passer des `filters` à [`sound.channels.add`](/jsdoc/pixi-vn/index/interfaces/SoundChannelsInterface#add) les applique à tous les `media` démarrés sur ce `channel`.

```ts
import { sound, filters } from "@drincs/pixi-vn";

sound.channels.add("bgm", {
    filters: [new filters.ReverbFilter()],
});
```

</Accordion>

</Accordions>

## Autres fonctionnalités

<Accordions>

<Accordion title="Fonctions de menu" id="menu-functions">

Il existe également des fonctions disponibles pour gérer les sons dans les menus, comme dans l'écran des paramètres.

Tous les changements effectués par ces fonctions ne sont pas enregistrés dans les sauvegardes du jeu, donc lorsqu'une sauvegarde est chargée, les sons reviennent à l'état dans lequel ils étaient avant d'être modifiés par ces fonctions.

Les fonctions [`sound.unsaved.pauseAll`](/jsdoc/pixi-vn/index/interfaces/SoundUnsavedInterface#pauseall) et [`sound.unsaved.resumeAll`](/jsdoc/pixi-vn/index/interfaces/SoundUnsavedInterface#resumeall) sont destinées à être utilisées lors de l'ouverture et de la fermeture d'un menu, comme les paramètres. La première fonction met en pause tous les sons qui ne sont pas déjà en pause, tandis que la seconde reprend tous les sons qui ont été mis en pause par la première fonction.

Par ailleurs, les fonctions [`sound.unsaved.playTransient`](/jsdoc/pixi-vn/index/interfaces/SoundUnsavedInterface#playtransient) et [`sound.unsaved.stopTransientAll`](/jsdoc/pixi-vn/index/interfaces/SoundUnsavedInterface#stoptransientall) sont destinées aux sons temporaires, comme les sons d'interaction UI. La première fonction joue un son qui ne sera pas enregistré dans les sauvegardes du jeu, tandis que la seconde arrête tous les sons démarrés par la première fonction.

</Accordion>

</Accordions>
