title: サウンドと音楽
description: Pixi’VN で media、channels、sound マネージャーを使用してサウンドや音楽を再生・一時停止・再開・編集・停止する方法。フェードトランジションやフィルターも含み、Tone.js をベースに構築されています。
---

:::warning

オーディオシステム全体は、バージョン1.6.0/1.8.0で見直されました。

:::

sound モジュールは、[Tone.js](https://tonejs.github.io/examples/) ライブラリをラップしたものです。 シンプルなインターフェースでサウンドを再生し、各<DynamicLink href="/start/labels">`step`</DynamicLink>で現在の状態を保存します。

:::tip[*ink*]

このメソッドは *ink* 構文で使用できます。 詳しくは<DynamicLink href="/ink/sound">こちら</DynamicLink>をご覧ください。

:::

<Accordions>

<Accordion title="用語説明" id="nomenclature">

これは以下の要素で構成されており、後ほど参照されます：

* `sound`（マネージャー）は、オーディオシステム全体のコントローラーです。 `channels` を管理し、音楽の `media` を開始・制御し、サウンドの `assets` に関する情報を取得または変更するために使用されます。 オーディオ全体のレベルを調整するための値を設定できます。 これらの設定はセーブファイルには保存されず、主にゲーム設定用として意図されています。
* `channels` は sound マネージャーの下位レベルであり、コンテナと見なすことができます。 音楽の `media` を格納・開始・管理するために使用されます。 含まれる media にのみ影響を与える値を設定できます。 これらの設定はセーブファイルには保存されず、主にゲーム設定用として意図されています。
* `media` は、再生が開始されたサウンドのインスタンスです。 自分自身にのみ適用される値を設定できます。 それらに適用されたすべての設定は、ゲームのセーブデータに保存されます。 これらの設定は主にゲームプレイ中に変更されることを想定しています。 これらは1対多の関係で `channel` に含まれます。 各 media は一意のエイリアス（`alias`）を持ちます。
* `assets`（サウンドアセット）は、その名の通り、ゲーム中にサウンドを再生するために使用されるアセットです。 このアセットを使用するすべての media に影響を与える値を設定できます。 これらの設定は保存されず、主にアセットの読み込み時、ゲームの初期化中に設定することを想定しています。

</Accordion>

</Accordions>

```ts tab="content/labels/start.label.ts"
import { narration, newLabel, sound } from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [
    async () => {
        await sound.play("sfx_whoosh", { delay: 0.1 });
        await sound.play("bgm_cheerful", { loop: true, channel: "bgm" });
        narration.dialogue =
            "Hello, I'm a cheerful background music that will loop forever until you stop me.";
    },
    () => {
        sound.pause("bgm_cheerful");
        narration.dialogue = "I'm paused, but I can be resumed.";
    },
    () => {
        sound.resume("bgm_cheerful");
        narration.dialogue = "I'm back!";
    },
]);
```

## 初期化

<Accordions>

<Accordion title="アセット" id="assets">

アセットを使用する他のコンポーネントと同様に、<DynamicLink href="/start/assets">assets</DynamicLink> 内でそれらを定義する必要があります。 その後、[`sound`](/jsdoc/pixi-vn/index/variables/sound) が提供する関数を使用して、ゲーム起動時に<DynamicLink href="/start/assets-management#load-assets-in-the-background-at-project-start">メインのサウンドをバックグラウンドで読み込む</DynamicLink>ことをお勧めします。

```ts tab="utils/assets-utility.ts"
import { manifest } from "@/assets";
import { AUDIO_BUNDLE_NAME } from "@/constants";
import { Assets, sound } from "@drincs/pixi-vn";

let assetsInitialized = false;

/**
 * Define all the assets that will be used in the game.
 * This function will be called before the game starts.
 * You can read more about assets management in the documentation: https://pixi-vn.com/start/assets-management.html
 */
export async function defineAssets() {
    if (!assetsInitialized) {
        const origin = `${location.protocol}//${location.host}/`;
        Assets.resolver.rootPath = origin;
        await Assets.init({ manifest, basePath: `${origin}assets/` });
        assetsInitialized = true;
    }

    // The audio bundle will be loaded in the background, so it will be available when needed, but it won't block the game start.
    sound.backgroundLoadBundle(AUDIO_BUNDLE_NAME);
}
```

ゲームの初期化直後に `channels` を定義することもお勧めします。 そのためには、[`sound.channels.add`](/jsdoc/pixi-vn/index/interfaces/SoundChannelsInterface#add) 関数を使用できます。

```ts title="main.ts"
import { Game, sound } from "@drincs/pixi-vn";

Game.init(body, {
    // ...
}).then(() => {
    sound.channels.add("bgm", { background: true });
    sound.channels.add("sfx");
    sound.defaultChannelAlias = "sfx";
});
```

## 再生

:::tip

`play` 関数の実行時に `channel` が指定されない場合、`media` は [`sound.defaultChannelAlias`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#defaultchannelalias) に割り当てられます。

:::

基本的な機能は、サウンド（`asset`）を開始することです。 これは `play` 関数を使用して行うことができます。 `play` 関数は `media` インスタンスを生成し、それを操作して再生されたサウンドを制御できます。

<Accordions>

<Accordion title="channel" id="channel-play">

[`channel.play`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface#play) は特定の `channel` 上で直接 `media` を開始するため、自分で `channel` オプションを渡す必要はありません。

```ts
import { sound } from "@drincs/pixi-vn";

await sound.channels.find("sfx").play("sfx_whoosh", { delay: 0.1 });
await sound.channels.find("bgm").play("bgm", "bgm_cheerful", { loop: true });
```

</Accordion>

<Accordion title="`sound`（マネージャー）" id="sound-manager-play">

[`sound.play`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#play) はマネージャーから `media` を開始します。 `channel` オプションを使用して特定の `channel` に割り当てることができ、指定しない場合は [`sound.defaultChannelAlias`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#defaultchannelalias) にフォールバックします。

```ts
import { sound } from "@drincs/pixi-vn";

await sound.play("sfx_whoosh", { delay: 0.1 });
await sound.play("bgm", "bgm_cheerful", { loop: true, channel: "bgm" });
```

</Accordion>

</Accordions>

## トランジション

<Accordions>

<Accordion title="フェード" id="fade">

`play` の [`fadeIn`](/jsdoc/pixi-vn/index/interfaces/SoundPlayOptions#fadein)/[`fadeOut`](/jsdoc/pixi-vn/index/interfaces/SoundPlayOptions#fadeout) オプションを使用して、フェードトランジション付きで `media` を開始できます。 `fadeIn` は開始時のみに影響しますが、`fadeOut` は `media` に保持され、自然に終了したときと、後で `stop()` を呼び出したときの両方で自動的に適用されます。

```ts
import { sound } from "@drincs/pixi-vn";

const music = await sound.play("theme", {
    loop: true,
    fadeIn: 2, // 2s fade-in on start
    fadeOut: 3, // 3s fade-out, applied both on manual stop() and on natural end
});

// later...
sound.stop("theme"); // automatically fades out over the 3s set above
```

</Accordion>

</Accordions>

## 一時停止と再開

個々の、または複数の `media` を一時停止する方法にはさまざまなものがあります。

<Accordions>

<Accordion title="media" id="media-pause">

[`media.paused`](/jsdoc/pixi-vn/index/interfaces/MediaInterface#paused) を設定すると、その単一の `media` インスタンスを直接一時停止または再開できます。

```ts
import { sound } from "@drincs/pixi-vn";

const bgmMedia = sound.find("bgm_cheerful");
if (bgmMedia) bgmMedia.paused = true;
// ...
if (bgmMedia) bgmMedia.paused = false;
```

</Accordion>

<Accordion title="channel" id="channel-pause">

[`channel.pauseAll`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface#pauseall)/[`channel.resumeAll`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface#resumeall) は、その `channel` に含まれるすべての `media` を一時停止または再開します。

```ts
import { sound } from "@drincs/pixi-vn";

sound.channels.find("sfx").pauseAll();
sound.channels.find("sfx").resumeAll();
```

</Accordion>

<Accordion title="`sound`（マネージャー）" id="sound-manager-pause">

[`sound.pause`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#pause)/[`sound.resume`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#resume) はエイリアス（`alias`）によって単一の `media` を対象としますが、[`sound.pauseAll`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#pauseall)/[`sound.resumeAll`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#resumeall) はすべての `channels` にまたがるすべての `media` に影響します。

```ts
import { sound } from "@drincs/pixi-vn";

sound.pause("bgm_cheerful");
sound.pauseAll();

sound.resume("bgm_cheerful");
sound.resumeAll();
```

</Accordion>

</Accordions>

## 編集

:::tip

ゲームのセーブファイルに保存されるのは `media` の設定のみです。

:::

さまざまな目的のために、ほぼすべての設定をいつでも編集することができます。

<Accordions>

<Accordion title="media" id="media-edit">

[`media`](/jsdoc/pixi-vn/index/interfaces/MediaInterface) インスタンスに直接割り当てられた設定（`volume` など）は、そのインスタンスにのみ影響し、ゲームのセーブデータに保存されます。

```ts
import { sound } from "@drincs/pixi-vn";

const bgmMedia = sound.find("bgm_cheerful");
if (bgmMedia) bgmMedia.volume.value = 90;
```

</Accordion>

<Accordion title="channel" id="channel-edit">

[`channel`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface) に割り当てられた設定（`volume` など）は、それに含まれるすべての `media` に影響しますが、保存はされません。

```ts
import { sound } from "@drincs/pixi-vn";

sound.channels.find("sfx").volume = 90;
```

</Accordion>

<Accordion title="`sound`（マネージャー）" id="sound-manager-edit">

[`sound`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface) マネージャーに割り当てられた設定（`volumeAll` など）は、すべての `channel`/`media` にグローバルに影響しますが、保存はされません。

```ts
import { sound } from "@drincs/pixi-vn";

sound.volumeAll = 90;
```

</Accordion>

</Accordions>

## 停止

サウンドを停止するには、`stop` 関数を使用できます。

<Accordions>

<Accordion title="media" id="media-stop">

[`media.stop`](/jsdoc/pixi-vn/index/interfaces/MediaInterface#stop) は、その単一の `media` インスタンスを直接停止します。

```ts
import { sound } from "@drincs/pixi-vn";

sound.find("bgm_cheerful")?.stop();
```

</Accordion>

<Accordion title="channel" id="channel-stop">

[`channel.stopAll`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface#stopall) は、その `channel` に含まれるすべての `media` を停止します。

```ts
import { sound } from "@drincs/pixi-vn";
sound.channels.find("sfx").stopAll();
```

</Accordion>

<Accordion title="`sound`（マネージャー）" id="sound-manager-stop">

[`sound.stop`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#stop) はエイリアス（`alias`）によって単一の `media` を停止しますが、[`sound.stopAll`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#stopall) はすべての `channels` にまたがるすべての `media` を停止します。

```ts
import { sound } from "@drincs/pixi-vn";
sound.stop("bgm_cheerful");
sound.stopAll();
```

</Accordion>

</Accordions>

## フィルター

:::warning

現在、これらは media の開始時にのみ変更できます。

:::

フィルターは、サウンドの高度なカスタマイズを可能にする要素です。

<Accordions>

<Accordion title="media" id="media-edit">

`filters` を [`sound.play`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#play) に渡すと、その `media` インスタンスにのみ適用されます。

```ts
import { sound, filters } from "@drincs/pixi-vn";

await sound.play("sfx_whoosh", { filters: [new filters.ReverbFilter()] });
```

</Accordion>

<Accordion title="channel" id="channel-edit">

`filters` を [`sound.channels.add`](/jsdoc/pixi-vn/index/interfaces/SoundChannelsInterface#add) に渡すと、その `channel` で開始されたすべての `media` に適用されます。

```ts
import { sound, filters } from "@drincs/pixi-vn";

sound.channels.add("bgm", {
    filters: [new filters.ReverbFilter()],
});
```

</Accordion>

</Accordions>

## その他の機能

<Accordions>

<Accordion title="メニュー機能" id="menu-functions">

設定画面など、メニュー内でサウンドを管理するための関数も用意されています。

これらの関数によって行われた変更はゲームのセーブデータには保存されないため、セーブデータを読み込むと、サウンドはこれらの関数によって変更される前の状態に戻ります。

[`sound.unsaved.pauseAll`](/jsdoc/pixi-vn/index/interfaces/SoundUnsavedInterface#pauseall) と [`sound.unsaved.resumeAll`](/jsdoc/pixi-vn/index/interfaces/SoundUnsavedInterface#resumeall) の関数は、設定画面などのメニューを開閉する際に使用することを想定しています。 最初の関数はまだ一時停止されていないすべてのサウンドを一時停止し、2つ目の関数は最初の関数によって一時停止されたすべてのサウンドを再開します。

一方、[`sound.unsaved.playTransient`](/jsdoc/pixi-vn/index/interfaces/SoundUnsavedInterface#playtransient) と [`sound.unsaved.stopTransientAll`](/jsdoc/pixi-vn/index/interfaces/SoundUnsavedInterface#stoptransientall) の関数は、UI操作音などの一時的なサウンドを対象としています。 最初の関数はゲームのセーブデータに保存されないサウンドを再生し、2つ目の関数は最初の関数によって開始されたすべてのサウンドを停止します。

</Accordion>

</Accordions>
