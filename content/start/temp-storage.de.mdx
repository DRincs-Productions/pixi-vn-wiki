---
title: Temporärer Speicher
description: Erklärt, wie man den temporären Speicher in Pixi’VN für Variablen verwendet, die nur während eines bestimmten Erzählabschnitts benötigt werden.
---

In vielen Fällen ist es sinnvoll, Variablen nur während eines bestimmten Zeitraums der Erzählung zu verwenden. Bei der Verwendung des normalen Speichers müssten diese Variablen manuell entfernt werden, wenn sie nicht mehr benötigt werden, um die Spielstände leicht und effizient zu halten.

Um dieses Problem zu lösen, verfügt Pixi’VN über ein temporäres Speichersystem. Temporäre Variablen, die in einer `label` initialisiert werden, werden gelöscht, wenn die `label` geschlossen wird. Wird von dort aus eine andere `label` aufgerufen, bleibt die temporäre Variable weiterhin über die untergeordnete `label` zugänglich. Wird jedoch eine andere `label` mit `jump` aufgerufen (wodurch die aktuelle `label` geschlossen und die neue gestartet wird), ist die temporäre Variable nicht mehr zugänglich.

## Setzen

Um eine temporäre Variable zu setzen, verwenden Sie [`storage.setTempVariable`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#settempvariable).

```ts
import { storage } from "@drincs/pixi-vn";

storage.setTempVariable("myTempVariable", 42);
```

## Abrufen

Um eine temporäre Variable abzurufen, verwenden Sie die normale Funktion [`storage.get`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#get).

## Entfernen

Um eine temporäre Variable zu entfernen, verwenden Sie [`storage.removeTempVariable`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#removetempvariable).

```ts
import { storage } from "@drincs/pixi-vn";

storage.removeTempVariable("myTempVariable");
```
