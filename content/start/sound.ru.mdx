title: Звуки и музыка
description: Как воспроизводить, приостанавливать, возобновлять, редактировать и останавливать звуки и музыку в Pixi’VN с помощью media, channels и sound-менеджера, включая fade-переходы и filters, на основе Tone.js.
---

:::warning

Вся звуковая система была переработана в версии 1.6.0/1.8.0.

:::

Модуль звука представляет собой обёртку вокруг библиотеки [Tone.js](https://tonejs.github.io/examples/). Он предоставляет простой интерфейс для воспроизведения звуков и сохраняет текущее состояние на каждом <DynamicLink href="/start/labels">`step`</DynamicLink>.

:::tip[*ink*]

Этот метод можно использовать с синтаксисом *ink*. Подробнее <DynamicLink href="/ink/sound">здесь</DynamicLink>.

:::

<Accordions>

<Accordion title="Терминология" id="nomenclature">

Она состоит из следующих элементов, на которые будут даны ссылки далее:

* `sound` (менеджер) — это контроллер всей звуковой системы. Он используется для управления `channels`, запуска и управления музыкальными `media`, а также для получения информации или изменения звуковых `assets`. Вы можете задавать значения для регулировки общего уровня звука. Эти настройки не сохраняются в файлах сохранения и в основном предназначены для настроек игры.
* `channels` — это подуровень звукового менеджера, который можно рассматривать как контейнер. Он используется для хранения, запуска и управления музыкальными `media`. Вы можете задавать значения, которые влияют только на содержащиеся media. Эти настройки не сохраняются в файлах сохранения и в основном предназначены для настроек игры.
* `media` — это экземпляры звука, который был запущен. Вы можете задавать значения, которые применяются только к ним самим. Все настройки, применённые к ним, сохраняются в сохранении игры. Эти настройки в основном предназначены для изменения во время игрового процесса. Они содержатся в `channel` в отношении «один ко многим». Каждый media имеет уникальный псевдоним (`alias`).
* `assets` (звуковые assets), как следует из названия, — это assets, которые используются в игре для воспроизведения звуков. Вы можете задавать значения, которые влияют на все media, использующие этот asset. Эти настройки не сохраняются и в основном предназначены для настройки во время инициализации игры при загрузке assets.

</Accordion>

</Accordions>

```ts tab="content/labels/start.label.ts"
import { narration, newLabel, sound } from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [
    async () => {
        await sound.play("sfx_whoosh", { delay: 0.1 });
        await sound.play("bgm_cheerful", { loop: true, channel: "bgm" });
        narration.dialogue =
            "Hello, I'm a cheerful background music that will loop forever until you stop me.";
    },
    () => {
        sound.pause("bgm_cheerful");
        narration.dialogue = "I'm paused, but I can be resumed.";
    },
    () => {
        sound.resume("bgm_cheerful");
        narration.dialogue = "I'm back!";
    },
]);
```

## Инициализация

<Accordions>

<Accordion title="Ресурсы" id="assets">

Как и в случае с другими компонентами, использующими assets, вам нужно определить их в разделе <DynamicLink href="/start/assets">assets</DynamicLink>. После этого рекомендуется <DynamicLink href="/start/assets-management#load-assets-in-the-background-at-project-start">загружать основные звуки в фоновом режиме</DynamicLink> при запуске игры, используя функции, предоставляемые [`sound`](/jsdoc/pixi-vn/index/variables/sound).

```ts tab="utils/assets-utility.ts"
import { manifest } from "@/assets";
import { AUDIO_BUNDLE_NAME } from "@/constants";
import { Assets, sound } from "@drincs/pixi-vn";

let assetsInitialized = false;

/**
 * Define all the assets that will be used in the game.
 * This function will be called before the game starts.
 * You can read more about assets management in the documentation: https://pixi-vn.com/start/assets-management.html
 */
export async function defineAssets() {
    if (!assetsInitialized) {
        const origin = `${location.protocol}//${location.host}/`;
        Assets.resolver.rootPath = origin;
        await Assets.init({ manifest, basePath: `${origin}assets/` });
        assetsInitialized = true;
    }

    // The audio bundle will be loaded in the background, so it will be available when needed, but it won't block the game start.
    sound.backgroundLoadBundle(AUDIO_BUNDLE_NAME);
}
```

Также рекомендуется определять `channels` сразу после инициализации игры. Для этого вы можете использовать функцию [`sound.channels.add`](/jsdoc/pixi-vn/index/interfaces/SoundChannelsInterface#add).

```ts title="main.ts"
import { Game, sound } from "@drincs/pixi-vn";

Game.init(body, {
    // ...
}).then(() => {
    sound.channels.add("bgm", { background: true });
    sound.channels.add("sfx");
    sound.defaultChannelAlias = "sfx";
});
```

## Воспроизведение

:::tip

Если во время работы функции `play` не указан `channel`, `media` будет привязан к [`sound.defaultChannelAlias`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#defaultchannelalias).

:::

Базовая функциональность заключается в запуске звука (`asset`). Это можно сделать с помощью функции `play`. Функция `play` создаёт экземпляр `media`, с которым можно взаимодействовать для управления воспроизводимым звуком.

<Accordions>

<Accordion title="channel" id="channel-play">

[`channel.play`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface#play) запускает `media` напрямую на конкретном `channel`, поэтому вам не нужно самостоятельно передавать опцию `channel`.

```ts
import { sound } from "@drincs/pixi-vn";

await sound.channels.find("sfx").play("sfx_whoosh", { delay: 0.1 });
await sound.channels.find("bgm").play("bgm", "bgm_cheerful", { loop: true });
```

</Accordion>

<Accordion title="`sound` (менеджер)" id="sound-manager-play">

[`sound.play`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#play) запускает `media` из менеджера. Используйте опцию `channel`, чтобы назначить его конкретному `channel`, в противном случае используется [`sound.defaultChannelAlias`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#defaultchannelalias).

```ts
import { sound } from "@drincs/pixi-vn";

await sound.play("sfx_whoosh", { delay: 0.1 });
await sound.play("bgm", "bgm_cheerful", { loop: true, channel: "bgm" });
```

</Accordion>

</Accordions>

## Переходы

<Accordions>

<Accordion title="Затухание" id="fade">

Вы можете запустить `media` с плавным переходом, используя параметры [`fadeIn`](/jsdoc/pixi-vn/index/interfaces/SoundPlayOptions#fadein)/[`fadeOut`](/jsdoc/pixi-vn/index/interfaces/SoundPlayOptions#fadeout) функции `play`. `fadeIn` влияет только на начало, тогда как `fadeOut` сохраняется на `media` и применяется автоматически как при естественном завершении, так и при последующем вызове `stop()`.

```ts
import { sound } from "@drincs/pixi-vn";

const music = await sound.play("theme", {
    loop: true,
    fadeIn: 2, // 2s fade-in on start
    fadeOut: 3, // 3s fade-out, applied both on manual stop() and on natural end
});

// later...
sound.stop("theme"); // automatically fades out over the 3s set above
```

</Accordion>

</Accordions>

## Пауза и возобновление

Существуют различные способы приостановить отдельные или несколько `media`.

<Accordions>

<Accordion title="media" id="media-pause">

Установка [`media.paused`](/jsdoc/pixi-vn/index/interfaces/MediaInterface#paused) напрямую приостанавливает или возобновляет этот отдельный экземпляр `media`.

```ts
import { sound } from "@drincs/pixi-vn";

const bgmMedia = sound.find("bgm_cheerful");
if (bgmMedia) bgmMedia.paused = true;
// ...
if (bgmMedia) bgmMedia.paused = false;
```

</Accordion>

<Accordion title="channel" id="channel-pause">

[`channel.pauseAll`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface#pauseall)/[`channel.resumeAll`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface#resumeall) приостанавливают или возобновляют все `media`, содержащиеся в этом `channel`.

```ts
import { sound } from "@drincs/pixi-vn";

sound.channels.find("sfx").pauseAll();
sound.channels.find("sfx").resumeAll();
```

</Accordion>

<Accordion title="`sound` (менеджер)" id="sound-manager-pause">

[`sound.pause`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#pause)/[`sound.resume`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#resume) воздействуют на отдельный `media` по псевдониму (`alias`), тогда как [`sound.pauseAll`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#pauseall)/[`sound.resumeAll`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#resumeall) воздействуют на все `media` во всех `channels`.

```ts
import { sound } from "@drincs/pixi-vn";

sound.pause("bgm_cheerful");
sound.pauseAll();

sound.resume("bgm_cheerful");
sound.resumeAll();
```

</Accordion>

</Accordions>

## Редактировать

:::tip

Только настройки `media` будут сохраняться в файлах сохранения игры.

:::

Можно редактировать почти все настройки в любое время для разных целей.

<Accordions>

<Accordion title="media" id="media-edit">

Настройки, назначенные напрямую экземпляру [`media`](/jsdoc/pixi-vn/index/interfaces/MediaInterface) (например, `volume`), влияют только на этот экземпляр и сохраняются в сохранении игры.

```ts
import { sound } from "@drincs/pixi-vn";

const bgmMedia = sound.find("bgm_cheerful");
if (bgmMedia) bgmMedia.volume.value = 90;
```

</Accordion>

<Accordion title="channel" id="channel-edit">

Настройки, назначенные на [`channel`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface) (например, `volume`), влияют на все `media`, которые он содержит, без сохранения.

```ts
import { sound } from "@drincs/pixi-vn";

sound.channels.find("sfx").volume = 90;
```

</Accordion>

<Accordion title="`sound` (менеджер)" id="sound-manager-edit">

Настройки, назначенные на менеджер [`sound`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface) (например, `volumeAll`), глобально влияют на все `channel`/`media`, без сохранения.

```ts
import { sound } from "@drincs/pixi-vn";

sound.volumeAll = 90;
```

</Accordion>

</Accordions>

## Остановка

Чтобы остановить звук, вы можете использовать функцию `stop`.

<Accordions>

<Accordion title="media" id="media-stop">

[`media.stop`](/jsdoc/pixi-vn/index/interfaces/MediaInterface#stop) напрямую останавливает этот отдельный экземпляр `media`.

```ts
import { sound } from "@drincs/pixi-vn";

sound.find("bgm_cheerful")?.stop();
```

</Accordion>

<Accordion title="channel" id="channel-stop">

[`channel.stopAll`](/jsdoc/pixi-vn/index/interfaces/AudioChannelInterface#stopall) останавливает все `media`, содержащиеся в этом `channel`.

```ts
import { sound } from "@drincs/pixi-vn";
sound.channels.find("sfx").stopAll();
```

</Accordion>

<Accordion title="`sound` (менеджер)" id="sound-manager-stop">

[`sound.stop`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#stop) останавливает отдельный `media` по псевдониму (`alias`), тогда как [`sound.stopAll`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#stopall) останавливает все `media` во всех `channels`.

```ts
import { sound } from "@drincs/pixi-vn";
sound.stop("bgm_cheerful");
sound.stopAll();
```

</Accordion>

</Accordions>

## Фильтры

:::warning

В настоящее время их можно изменить только при запуске media.

:::

Filters — это элементы, позволяющие выполнять расширенную настройку звуков.

<Accordions>

<Accordion title="media" id="media-edit">

Передача `filters` в [`sound.play`](/jsdoc/pixi-vn/index/interfaces/SoundManagerInterface#play) применяет их только к этому экземпляру `media`.

```ts
import { sound, filters } from "@drincs/pixi-vn";

await sound.play("sfx_whoosh", { filters: [new filters.ReverbFilter()] });
```

</Accordion>

<Accordion title="channel" id="channel-edit">

Передача `filters` в [`sound.channels.add`](/jsdoc/pixi-vn/index/interfaces/SoundChannelsInterface#add) применяет их ко всем `media`, запущенным на этом `channel`.

```ts
import { sound, filters } from "@drincs/pixi-vn";

sound.channels.add("bgm", {
    filters: [new filters.ReverbFilter()],
});
```

</Accordion>

</Accordions>

## Другие возможности

<Accordions>

<Accordion title="Функции меню" id="menu-functions">

Также доступны функции для управления звуками в меню, например на экране настроек.

Все изменения, внесённые этими функциями, не сохраняются в сохранениях игры, поэтому при загрузке сохранения звуки вернутся в то состояние, в котором они были до изменения этими функциями.

Функции [`sound.unsaved.pauseAll`](/jsdoc/pixi-vn/index/interfaces/SoundUnsavedInterface#pauseall) и [`sound.unsaved.resumeAll`](/jsdoc/pixi-vn/index/interfaces/SoundUnsavedInterface#resumeall) предназначены для использования при открытии и закрытии меню, например настроек. Первая функция приостанавливает все звуки, которые ещё не приостановлены, а вторая возобновляет все звуки, которые были приостановлены первой функцией.

В свою очередь, функции [`sound.unsaved.playTransient`](/jsdoc/pixi-vn/index/interfaces/SoundUnsavedInterface#playtransient) и [`sound.unsaved.stopTransientAll`](/jsdoc/pixi-vn/index/interfaces/SoundUnsavedInterface#stoptransientall) предназначены для временных звуков, например звуков взаимодействия с UI. Первая функция воспроизводит звук, который не будет сохранён в сохранениях игры, а вторая останавливает все звуки, запущенные первой функцией.

</Accordion>

</Accordions>
