<Accordion title="什么是 Live2D？" id="what-is-live2d">

Live2D 是一种让二维插画自然运动的技术，无需逐帧重绘，就能创建流畅且富有表现力的动画。与 Spine 2D 使用骨骼结构不同，Live2D 模型是一幅完整的插画，其各个部分通过**参数**（角度、眼睛张开程度、嘴型等）进行变形和混合，并由**动作**（预先定义的动画片段）和**表情**（预设的参数组合，例如面部表情）驱动。

它广泛应用于视觉小说、游戏和交互式应用（尤其是 VTuber 相关应用），用于让角色更加生动。

你可以在 [Live2D 官方网站](https://www.live2d.com/)了解有关 Live2D 的更多信息。

</Accordion>

</Accordions>

在你的 **Pixi’VN** 项目中，可以使用 Live2D 集成来显示角色的 Live2D 模型并为其制作动画。此集成是对 [untitled-pixi-live2d-engine](https://github.com/Untitled-Story/untitled-pixi-live2d-engine) 的封装。请注意，这**并非 PixiJS/Live2D 官方插件**，而是一个由社区维护、用于连接 Live2D 与 PixiJS 的引擎，使你能够直接在 Pixi’VN 项目中使用其功能。

## 安装

要在现有的 JavaScript 项目中安装 Live2D 软件包，请使用以下命令之一：

```npm
npm install @drincs/pixi-vn-live2d
```

:::danger

必须在启动时于主文件中调用 `extensions.add(Live2DPlugin)`，并确保它在 `Game.init` 调用之前执行。

:::

```ts title="main.ts"
import { extensions } from "pixi.js";
import { Live2DPlugin } from "@drincs/pixi-vn-live2d/core";
extensions.add(Live2DPlugin);

Game.init(body, {
    // ...
});
```

## 使用方法

你可以像使用其他 Pixi’VN 组件一样使用 [`Live2D`](/jsdoc/pixi-vn-live2d/index/classes/Live2D) 组件。与 Spine 不同，Live2D 模型无需通过 `Assets.load` 预先加载。只需使用 `Assets.add` 注册别名，`Live2D` 就会自行解析并获取模型。

由于获取模型的过程是异步的，在 [`ready`](/jsdoc/pixi-vn-live2d/index/classes/Live2D#ready) Promise 完成之前，不能安全地使用模型。请在创建模型后立即使用 `await` 等待加载完成，然后再读取依赖已加载模型的信息（例如模型尺寸）。

例如：

```ts tab="Typescript" title="main.ts" groupId="narrative_language"
import { canvas } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

const live2d = new Live2D({
    source: "shizuku",
    xAlign: 0.5,
    yAlign: 1,
    scale: 0.5,
});
await live2d.ready;
canvas.add("shizuku", live2d);
```

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
# show live2d shizuku xAlign 0.5 yAlign 1 scale 0.5
-> DONE
```

```ts tab="src/assets/index.ts"
import { AssetsManifest } from "@drincs/pixi-vn";

/**
 * Manifest for the assets used in the game.
 * You can read more about the manifest here: https://pixijs.com/8.x/guides/components/assets#loading-multiple-assets

export const manifest: AssetsManifest = {
    bundles: [
        {
            name: "start",
            assets: [
                {
                    alias: "shizuku",

                },
            ],
        },
    ],
};
```

<Accordion title="动作" id="motion">

Live2D 模型的动画按**动作组**（例如 `idle`、`tap_body`）组织，每个组包含一个或多个动作片段。可以通过 [`motion`](/jsdoc/pixi-vn-live2d/index/classes/Live2D#motion) 函数播放动作；省略片段索引时，会从该组中随机播放一个片段。

默认情况下，模型会自动循环播放 `idle`（Cubism 2）或 `Idle`（Cubism 4）动作组。你可以通过 `idleMotionGroup` 选项配置此行为，因此只需在需要触发一次性动画（例如响应轻触或点击）时调用 `motion`。

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
import { canvas, newLabel } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

export const startLabel = newLabel("start", [
    async () => {
        const live2d = new Live2D({
            source: "shizuku",
            xAlign: 0.5,
            yAlign: 1,
            scale: 0.5,
        });
        await live2d.ready;
        canvas.add("shizuku", live2d);
    },
    () => {
        canvas.find<Live2D>("shizuku")?.motion("tap_body");
    },
]);
```

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
# show live2d shizuku xAlign 0.5 yAlign 1 scale 0.5
# pause
# play motion tap_body on live2d shizuku
# pause
-> DONE
```

<Accordion title="表情" id="expression">

Live2D 模型可以定义多个**表情**，即通常用于面部表情的参数值预设。你可以使用 [`expression`](/jsdoc/pixi-vn-live2d/index/classes/Live2D#expression) 函数在运行时切换这些表情。与 `motion` 一样，如果省略标识符，就会随机选择一个表情。

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
import { canvas, newLabel } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

export const startLabel = newLabel("start", [
    async () => {
        const live2d = new Live2D({
            source: "shizuku",
            xAlign: 0.5,
            yAlign: 1,
            scale: 0.5,
        });
        await live2d.ready;
        canvas.add("shizuku", live2d);
    },
    () => {
        canvas.find<Live2D>("shizuku")?.expression("f01");
    },
]);
```

<Accordion title="Live2D + motion.js 动画" id="motion-js">

你可以将 Live2D 动作与 Pixi’VN 传统的基于运动的动画（[`canvas.animate`](/jsdoc/pixi-vn/index/interfaces/CanvasManagerInterface#animate)）结合使用，如下例所示。

对于更高级的游戏，你还可以通过由事件（例如按钮点击）触发的更新器直接控制 Live2D，而不仅仅依赖预定义的动画序列。

```ts title="content/labels/start.label.ts" groupId="narrative_language"
import { canvas, newLabel } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

export const startLabel = newLabel("start", [
    async () => {
        const live2d = new Live2D({
            source: "shizuku",
            xAlign: 0.3,
            yAlign: 1,
            scale: 0.5,
        });
        await live2d.ready;
        canvas.add("shizuku", live2d);
        canvas.animate(
            live2d,
            [
                [{ x: canvas.width * 0.7 }, { duration: 2, ease: "linear" }],
                [{ x: canvas.width * 0.3 }, { duration: 2, ease: "linear" }],
            ],
            { repeat: Infinity },
        );
    },
]);
```

<Accordion title="停止动作" id="stop-motions">

使用 [`stopMotions`](/jsdoc/pixi-vn-live2d/index/classes/Live2D#stopmotions) 函数，可以停止模型当前播放的所有动作以及任何口型同步音频。

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
import { canvas, newLabel } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

export const startLabel = newLabel("start", [
    async () => {
        const live2d = new Live2D({
            source: "shizuku",
            xAlign: 0.5,
            yAlign: 1,
            scale: 0.5,
        });
        await live2d.ready;
        canvas.add("shizuku", live2d);
        live2d.motion("tap_body");
    },
    () => {
        canvas.find<Live2D>("shizuku")?.stopMotions();
    },
]);
```

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
# pause
# stop motions on live2d shizuku
# pause
-> DONE
```
