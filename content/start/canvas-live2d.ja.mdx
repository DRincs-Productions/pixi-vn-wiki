<Accordion title="Live2D とは？" id="what-is-live2d">

Live2D は、2D イラストを自然に動かし、フレームごとに描き直すことなく滑らかで表現豊かなアニメーションを作成できる技術です。 Spine 2D のような骨格（ボーン）ではなく、Live2D モデルは 1 枚のイラストで構成されます。その各部分は **パラメーター**（角度、目の開き具合、口の形など）によって変形・合成され、**モーション**（事前定義されたアニメーションクリップ）や **表情**（表情の変化などに用いる、事前定義されたパラメーター設定）で制御されます。

キャラクターに命を吹き込むため、ビジュアルノベル、ゲーム、インタラクティブアプリ（特に VTuber 関連）で広く利用されています。

Live2D について詳しくは、[Live2D の公式サイト](https://www.live2d.com/)をご覧ください。

</Accordion>

</Accordions>

**Pixi’VN** プロジェクトでは、Live2D 連携を使用してキャラクターの Live2D モデルを表示し、アニメーションさせることができます。この連携は [untitled-pixi-live2d-engine](https://github.com/Untitled-Story/untitled-pixi-live2d-engine) をラップするものです。これは **PixiJS/Live2D の公式プラグインではなく**、Live2D と PixiJS を橋渡しするコミュニティ管理のエンジンです。これにより、その機能を Pixi’VN プロジェクト内で直接使用できます。

## インストール

既存の JavaScript プロジェクトに Live2D パッケージをインストールするには、次のいずれかのコマンドを使用します：

```npm
npm install @drincs/pixi-vn-live2d
```

:::danger

メインファイルで、`Game.init` を呼び出す前に、起動時に `extensions.add(Live2DPlugin)` を呼び出す必要があります。

:::

```ts title="main.ts"
import { extensions } from "pixi.js";
import { Live2DPlugin } from "@drincs/pixi-vn-live2d/core";
extensions.add(Live2DPlugin);

Game.init(body, {
    // ...
});
```

## 使用方法

[`Live2D`](/jsdoc/pixi-vn-live2d/index/classes/Live2D) コンポーネントは、ほかの Pixi’VN コンポーネントと同じように使用できます。 Spine とは異なり、Live2D モデルは `Assets.load` で事前に読み込む必要がありません。`Assets.add` でエイリアスを登録するだけで、`Live2D` がモデルを解決して取得します。

モデルの取得は非同期で行われるため、[`ready`](/jsdoc/pixi-vn-live2d/index/classes/Live2D#ready) の Promise が解決するまで、モデルを安全に使用できません。生成直後に `await` で完了を待ち、読み込んだモデルに依存する情報（サイズなど）を参照する前に準備を完了させてください。

例：

```ts tab="Typescript" title="main.ts" groupId="narrative_language"
import { canvas } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

const live2d = new Live2D({
    source: "shizuku",
    xAlign: 0.5,
    yAlign: 1,
    scale: 0.5,
});
await live2d.ready;
canvas.add("shizuku", live2d);
```

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
# show live2d shizuku xAlign 0.5 yAlign 1 scale 0.5
-> DONE
```

```ts tab="src/assets/index.ts"
import { AssetsManifest } from "@drincs/pixi-vn";

/**
 * Manifest for the assets used in the game.
 * You can read more about the manifest here: https://pixijs.com/8.x/guides/components/assets#loading-multiple-assets
 */
export const manifest: AssetsManifest = {
    bundles: [
        {
            name: "start",
            assets: [
                {
                    alias: "shizuku",
                    src: "https://cdn.jsdelivr.net/gh/guansss/pixi-live2d-display/test/assets/shizuku/shizuku.model.json",
                },
            ],
        },
    ],
};
```

<Accordion title="モーション" id="motion">

Live2D モデルのアニメーションは **モーショングループ**（例: `idle`、`tap_body`）にまとめられ、各グループには 1 つ以上のモーションクリップが含まれます。 [`motion`](/jsdoc/pixi-vn-live2d/index/classes/Live2D#motion) 関数でモーションを再生できます。クリップのインデックスを省略すると、グループ内のクリップがランダムに再生されます。

デフォルトでは、モデルは `idle`（Cubism 2）または `Idle`（Cubism 4）のモーショングループを自動的にループ再生します。この動作は `idleMotionGroup` オプションで設定できるため、タップやクリックへの反応など、意図的に一度だけ再生するアニメーションにのみ `motion` を呼び出せば十分です。

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
import { canvas, newLabel } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

export const startLabel = newLabel("start", [
    async () => {
        const live2d = new Live2D({
            source: "shizuku",
            xAlign: 0.5,
            yAlign: 1,
            scale: 0.5,
        });
        await live2d.ready;
        canvas.add("shizuku", live2d);
    },
    () => {
        canvas.find<Live2D>("shizuku")?.motion("tap_body");
    },
]);
```

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
# show live2d shizuku xAlign 0.5 yAlign 1 scale 0.5
# pause
# play motion tap_body on live2d shizuku
# pause
-> DONE
```

<Accordion title="表情" id="expression">

Live2D モデルには複数の **表情** を定義できます。これらは通常、顔の表情に使用するパラメーター値のプリセットであり、[`expression`](/jsdoc/pixi-vn-live2d/index/classes/Live2D#expression) 関数を使って実行時に切り替えられます。 `motion` と同様に、ID を省略すると表情がランダムに選ばれます。

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
import { canvas, newLabel } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

export const startLabel = newLabel("start", [
    async () => {
        const live2d = new Live2D({
            source: "shizuku",
            xAlign: 0.5,
            yAlign: 1,
            scale: 0.5,
        });
        await live2d.ready;
        canvas.add("shizuku", live2d);
    },
    () => {
        canvas.find<Live2D>("shizuku")?.expression("f01");
    },
]);
```

<Accordion title="Live2D + motion.js アニメーション" id="motion-js">

以下の例のように、Live2D のモーションと Pixi’VN の従来のモーションベースのアニメーション（[`canvas.animate`](/jsdoc/pixi-vn/index/interfaces/CanvasManagerInterface#animate)）を組み合わせることができます。

より高度なゲームでは、事前定義されたシーケンスだけに頼らず、ボタンを押すなどのイベントで起動するティッカーから Live2D を直接制御することもできます。

```ts title="content/labels/start.label.ts" groupId="narrative_language"
import { canvas, newLabel } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

export const startLabel = newLabel("start", [
    async () => {
        const live2d = new Live2D({
            source: "shizuku",
            xAlign: 0.3,
            yAlign: 1,
            scale: 0.5,
        });
        await live2d.ready;
        canvas.add("shizuku", live2d);
        canvas.animate(
            live2d,
            [
                [{ x: canvas.width * 0.7 }, { duration: 2, ease: "linear" }],
                [{ x: canvas.width * 0.3 }, { duration: 2, ease: "linear" }],
            ],
            { repeat: Infinity },
        );
    },
]);
```

<Accordion title="モーションを停止する" id="stop-motions">

[`stopMotions`](/jsdoc/pixi-vn-live2d/index/classes/Live2D#stopmotions) 関数を使うと、モデルで再生中のすべてのモーションと、リップシンク用の音声を停止できます。

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
import { canvas, newLabel } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

export const startLabel = newLabel("start", [
    async () => {
        const live2d = new Live2D({
            source: "shizuku",
            xAlign: 0.5,
            yAlign: 1,
            scale: 0.5,
        });
        await live2d.ready;
        canvas.add("shizuku", live2d);
        live2d.motion("tap_body");
    },
    () => {
        canvas.find<Live2D>("shizuku")?.stopMotions();
    },
]);
```

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
# show live2d shizuku xAlign 0.5 yAlign 1 scale 0.5
# play motion tap_body on live2d shizuku
# pause
# stop motions on live2d shizuku
# pause

```
