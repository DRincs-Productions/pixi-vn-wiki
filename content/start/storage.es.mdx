<Accordion title="¿Qué es el storage de juego?" id="what-is-storage">

El storage de juego es un lugar donde puedes guardar las variables que quieres mantener entre sesiones de juego.

</Accordion>

</Accordions>

Es esencial entender que si las variables no se guardan en la memoria del juego, el motor no podrá gestionarlas cuando <DynamicLink href="/start/save#load">cargues una partida guardada</DynamicLink> o cuando <DynamicLink href="/start/labels-flow#go-back">retrocedas</DynamicLink>.

Además, en el archivo del juego puedes guardar cualquier tipo de variable, excepto `class` y `function` (porque no se pueden convertir a JSON), como: `string`, `number`, `boolean`, `object`, `array`, etc. Si quieres guardar "flags" (booleanos), se recomienda usar la <DynamicLink href="/start/flags">funcionalidad de flags</DynamicLink>, un sistema de gestión de flags muy eficiente.

<Callout title="ink" type="info">

Puedes usar este método con la sintaxis *ink*. Más información <DynamicLink href="/ink/storage">aquí</DynamicLink>.

</Callout>

## Establecer

Para establecer una variable en el storage de juego, usa [`storage.set`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#set).

```ts
import { storage } from "@drincs/pixi-vn";

storage.set("myVariable", 42);
```

## Obtener

Para obtener una variable del storage de juego, usa [`storage.get`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#get).

```ts
import { storage } from "@drincs/pixi-vn";

const myVariable = storage.get("myVariable");
```

## Eliminar

Para eliminar una variable del storage de juego, usa [`storage.remove`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#remove).

```ts
import { storage } from "@drincs/pixi-vn";

storage.remove("myVariable");
```

## Otras funcionalidades

<Accordions>

<Accordion title="Variables del sistema" id="system-variables">

En el storage de juego, hay algunas variables del sistema que utiliza el motor del juego. Todas las variables del sistema comienzan con el prefijo `___`.
Por lo tanto, evita usar este prefijo en tus variables.

Puedes obtener todas las claves de las variables del sistema desde la constante [`SYSTEM_RESERVED_STORAGE_KEYS`](/jsdoc/pixi-vn/index/variables/SYSTEM_RESERVED_STORAGE_KEYS).

</Accordion>

<Accordion title="Keyv" id="keyv">

Todo el sistema de storage se desarrolló usando `Map`, un objeto nativo de JavaScript, por lo que puedes usar Keyv para interactuar con el storage de juego.

**¿Qué es Keyv?** Keyv es un sistema de almacenamiento simple de clave-valor. Es un sistema muy fácil de usar y muy popular en la comunidad de Node.js. Keyv se puede combinar con otras librerías, como [Cacheable](https://cacheable.org/) (Caching para Node.js basado en Keyv). Puedes aprender más en el [sitio web de Keyv](https://keyv.org/).

**¿Cómo usar Keyv con Pixi’VN?** Puedes usar Keyv con Pixi’VN creando una nueva instancia de Keyv y pasando el objeto storage como parámetro.

```ts
import { storage } from "@drincs/pixi-vn";
import Keyv from "keyv";

const keyvStorage = new Keyv({ store: storage.base });

keyvStorage.get<string>("myValue").then((value) => {
    console.log(value);
});
```

</Accordion>

<Accordion title="Variables de storage predeterminadas" id="default-storage-variables">

Puedes establecer el valor inicial de las variables de storage.

Estas variables tendrán las siguientes características:

* Si se eliminan o se establecen como undefined o null, el valor se establecerá automáticamente en el valor predeterminado (por lo que nunca podrán ser undefined o null).
* Los valores predeterminados no se guardarán en las partidas guardadas, por lo que puedes cambiarlos de una versión a otra sin ningún problema.

Puedes establecer las variables de storage predeterminadas usando el objeto [`storage.default`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#default).

```ts
import { storage } from "@drincs/pixi-vn";

storage.default = {
    myVariable: 42,
    anotherVariable: "Hello, world!",
};
```

</Accordion>
