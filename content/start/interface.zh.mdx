<Accordion title="什么是 UI？" id="what-is-ui">

UI 是 User Interface（用户界面）的缩写。 它指的是用户与数字设备、应用程序或网站进行交互所使用的视觉元素和交互组件。 界面（UI）包括用户会接触到的所有内容，例如按钮、菜单、图标、文本框和布局。 界面（UI）设计的目标是创建一个既美观又实用的界面，为用户提供流畅、直观的体验。

</Accordion>

</Accordions>

Pixi’VN 不提供用于创建游戏界面（UI）的内置组件，也不会重新发明 JavaScript 生态系统中已有的东西。 它不会将你锁定在某个特定框架中，而是让你可以使用任何你偏好的外部 JavaScript 框架来构建界面，因此你可以借助 React、Vue 等系统来创建复杂、高性能的**界面（UI）**。

这种灵活性也让 Pixi’VN 非常适合 AI 辅助开发：由于界面（UI）是使用标准且被广泛使用的框架构建的，而不是专有系统，AI 编程助手已经非常熟悉这些工具，能够非常有效地生成、理解和修改界面代码。

Pixi’VN 提供了一些功能，以提升与其他 JavaScript 框架的兼容性：

<Accordions>

<Accordion title="添加 HTML 界面层" id="adding-html-ui-layers">

**什么是 HTML 界面层？** HTML 界面层是添加在 PixiJS 画布（canvas）上方的一个 HTML 元素，其尺寸与画布相同。 这使你可以使用 React 或 Vue 等 JavaScript 框架来创建界面。

要添加 HTML 界面层，你可以使用 [`canvas.addHtmlLayer`](/jsdoc/pixi-vn/index/interfaces/CanvasManagerInterface#addhtmllayer) 函数。

```ts tab="main.ts"
const root = document.getElementById("root");
if (!root) {
    throw new Error("root element not found");
}
const htmlLayer = canvas.addHtmlLayer("ui", root, {
    position: "absolute",
    pointerEvents: "none",
    userSelect: "none",
});
```

```html tab="index.html"
<!doctype html>
<html lang="en">
    <body>
        <div id="root"></div>
        <script type="module" src="/src/main.ts"></script>
    </body>
</html>
```

要获取该层的 HTML 元素，你可以使用 [`canvas.getHtmlLayer`](/jsdoc/pixi-vn/index/interfaces/CanvasManagerInterface#gethtmllayer) 函数。

要移除一个 HTML 界面层，你可以使用 [`canvas.removeHtmlLayer`](/jsdoc/pixi-vn/index/interfaces/CanvasManagerInterface#removehtmllayer) 函数。

</Accordion>

<Accordion title="如何启用 HTML 界面交互？" id="how-to-enable-ui-interaction">

默认情况下，HTML 界面层的所有 HTML 元素都设置了 `pointer-events: none` 样式。 这意味着这些 HTML 元素不会拦截任何鼠标或触摸事件，从而让 PixiJS 画布接收所有事件。 当你想在画布中显示图片或视频，且不希望界面干扰它时，这非常有用。

因此，你必须只为需要与用户交互的组件设置 `pointer-events: auto` 样式。

例如：

```css tab="Shadcn - Tailwind CSS" title="styles.css"
@layer components {
    [data-slot="button"],
    [data-slot="card"],
    [data-slot="resizable-handle"],
    [data-slot="scroll-area"],
    [data-slot="scroll-area-scrollbar"],
    [data-slot="toggle"] {
        pointer-events: auto;
    }
}
```

```tsx tab="React"
export default function NextButton() {
    return (
        <button
            style={{
                pointerEvents: "auto",
            }}
        >
            Next
        </button>
    );
}
```

```vue tab="Vue"
<template>
    <button style="pointer-events: auto;">Next</button>
</template>
```

</Accordion>

<Accordion title="添加 PixiJS 界面层" id="adding-pixijs-ui-layers">

**什么是 PixiJS 界面层？** 它是一个 PixiJS Container。 与专门用于 Pixi’VN 功能的主 Container 不同：

* 界面的当前状态不会被包含在存档中。
* 它的性能更好。 Pixi’VN 不会对它执行任何检查。
* 你不能使用 Pixi’VN 的功能。
* 由于它是一个核心 PixiJS 组件，你可以添加所有与 PixiJS 兼容的组件。

要添加一个 PixiJS 界面层，你可以使用 [`canvas.addLayer`](/jsdoc/pixi-vn/index/interfaces/CanvasManagerInterface#addlayer) 函数。

例如：

```ts title="src/main.ts"
const container = canvas.addLayer("ui");
```

要获取该层的 PixiJS Container，你可以使用 [`canvas.getLayer`](/jsdoc/pixi-vn/index/interfaces/CanvasManagerInterface#getlayer) 函数。

要移除一个 PixiJS 界面层，你可以使用 [`canvas.removeLayer`](/jsdoc/pixi-vn/index/interfaces/CanvasManagerInterface#removelayer) 函数。

</Accordion>

## 界面（UI）与画布（canvas）之间的区别

按照 Pixi’VN 的设计理念，界面（UI）与画布（canvas）是两个独立且互不依赖的元素。 界面位于画布上方，用于创建按钮、表单等。 画布用于显示图片、视频等。

关于画布当前状态的所有信息都会包含在存档中，并且可以恢复到之前某个 step 的状态。 界面的当前状态不会被包含在存档中。 因此，你需要<DynamicLink href="/start/interface-connect-storage">自行管理，将所需信息保存</DynamicLink>到<DynamicLink href="/start/storage">游戏存储（game storage）</DynamicLink>或浏览器存储中。

在画布中，你可以在每个 step 中添加组件。 而在界面中不能这样做，但你可以创建多个<DynamicLink href="/start/interface-connect-storage">「界面（screen）」并在它们之间导航</DynamicLink>。

在画布中你只能添加 Pixi’VN 组件。 而在界面中，你可以添加任何 HTML/PixiJS 组件，或使用任何 UI 组件库，因此可以创建更加复杂的界面。
