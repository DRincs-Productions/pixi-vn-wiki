<Accordion title="什么是 UI？" id="what-is-ui">

UI 是“用户界面”（User Interface）的英文缩写。 它指的是用户与数字设备、应用程序或网站进行交互所使用的视觉元素和交互组件。 UI 包括用户与之交互的一切内容，例如按钮、菜单、图标、文本框和布局。 UI 设计的目标是创建一个既美观又实用的界面，为用户提供流畅直观的体验。

</Accordion>

</Accordions>

Pixi’VN 不提供用于创建游戏 UI 的内置组件，也不会重新发明 JavaScript 生态系统中已经存在的东西。 它不会将你限制在某个特定框架中，而是让你可以使用任何你喜欢的外部 JavaScript 框架来构建 UI，从而可以利用 React、Vue 等系统，创建复杂且高性能的 **UI 界面**。

这种灵活性也使 Pixi’VN 非常适合 AI 辅助开发：由于 UI 是使用标准且广泛使用的框架构建的，而非专有系统，AI 编程助手已经非常熟悉这些工具，因此能够非常有效地生成、理解和修改 UI 代码。

Pixi’VN 提供了一些功能来提升与其他 JavaScript 框架的兼容性：

<Accordions>

<Accordion title="添加 HTML UI 层" id="adding-html-ui-layers">

**什么是 HTML UI 层？** HTML UI 层是添加在 PixiJS 画布上方、并与画布尺寸相同的 HTML 元素。 这样你就可以使用 React 或 Vue 等 JavaScript 框架来创建 UI。

要添加 HTML UI 层，你可以使用 [`canvas.htmlLayers.add`](/jsdoc/pixi-vn/index/interfaces/CanvasHtmlLayersInterface#add) 函数。

```ts tab="main.ts"
const root = document.getElementById("root");
if (!root) {
    throw new Error("root element not found");
}
const htmlLayer = canvas.htmlLayers.add("ui", root, {
    position: "absolute",
    pointerEvents: "none",
    userSelect: "none",
});
```

```html tab="index.html"
<!doctype html>
<html lang="en">
    <body>
        <div id="root"></div>
        <script type="module" src="/src/main.ts"></script>
    </body>
</html>
```

要获取该层的 HTML 元素，你可以使用 [`canvas.htmlLayers.get`](/jsdoc/pixi-vn/index/interfaces/CanvasHtmlLayersInterface#get) 函数。

要移除 HTML UI 层，你可以使用 [`canvas.htmlLayers.remove`](/jsdoc/pixi-vn/index/interfaces/CanvasHtmlLayersInterface#remove) 函数。

</Accordion>

<Accordion title="如何启用 HTML UI 交互？" id="how-to-enable-ui-interaction">

默认情况下，HTML UI 层的所有 HTML 元素都具有 `pointer-events: none` 样式。 这意味着这些 HTML 元素不会拦截任何鼠标或触摸事件，从而使 PixiJS 画布可以接收所有事件。 当你想在画布中显示图片或视频，并且不希望 UI 对其造成干扰时，这非常有用。

因此，你必须仅为需要与用户交互的组件设置 `pointer-events: auto` 样式。

例如：

```css tab="Shadcn - Tailwind CSS" title="styles.css"
@layer components {
    [data-slot="button"],
    [data-slot="card"],
    [data-slot="resizable-handle"],
    [data-slot="scroll-area"],
    [data-slot="scroll-area-scrollbar"],
    [data-slot="toggle"] {
        pointer-events: auto;
    }
}
```

```tsx tab="React"
export default function NextButton() {
    return (
        <button
            style={{
                pointerEvents: "auto",
            }}
        >
            Next
        </button>
    );
}
```

```vue tab="Vue"
<template>
    <button style="pointer-events: auto;">Next</button>
</template>
```

</Accordion>

<Accordion title="添加 PixiJS UI 层" id="adding-pixijs-ui-layers">

**什么是 PixiJS UI 层？** 它是一个 PixiJS Container。 与仅用于 Pixi’VN 功能的主 Container 不同：

* UI 的当前状态不会包含在存档中。
* 它具有更好的性能。 Pixi’VN 不会对其进行任何检查。
* 你不能使用 Pixi’VN 的功能。
* 由于它是 PixiJS 的核心组件，你可以添加所有与 PixiJS 兼容的组件。

要添加 PixiJS UI 层，你可以使用 [`canvas.layers.add`](/jsdoc/pixi-vn/index/interfaces/CanvasLayersInterface#add) 函数。

例如：

```ts title="src/main.ts"
const container = canvas.layers.add("ui");
```

要获取该层的 PixiJS Container，你可以使用 [`canvas.layers.get`](/jsdoc/pixi-vn/index/interfaces/CanvasLayersInterface#get) 函数。

要移除 PixiJS UI 层，你可以使用 [`canvas.layers.remove`](/jsdoc/pixi-vn/index/interfaces/CanvasLayersInterface#remove) 函数。

</Accordion>

</Accordions>

## UI 与画布的区别

按照 Pixi’VN 的设计理念，UI 和画布是两个不同且相互独立的元素。 UI 位于画布上方，用于创建按钮、表单等。 画布用于显示图片、视频等。

有关画布当前状态的所有信息都会包含在存档中，并且可以恢复到之前某一步骤的状态。 UI 的当前状态不会包含在存档中。 因此，你必须<DynamicLink href="/start/interface-connect-storage">自行管理，将所需信息保存</DynamicLink>到<DynamicLink href="/start/storage">游戏存储</DynamicLink>或浏览器存储中。

在画布中，你可以在每个步骤中添加组件。 在 UI 中你无法这样做，你可以创建多个<DynamicLink href="/start/interface-connect-storage">“界面”并在它们之间切换</DynamicLink>。

在画布中，你只能添加 Pixi’VN 组件。 在 UI 中，你可以添加任何 HTML/PixiJS 组件，或使用任何 UI 组件库，从而创建更加复杂的界面。
