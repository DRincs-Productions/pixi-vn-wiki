---
title: 存储类
description: |
  说明如何创建属性通过 `StoredClassModel` 存储的类。
---

Pixi’VN 提供了一个抽象类 [`StoredClassModel`](/jsdoc/pixi-vn/index/classes/StoredClassModel)，你可以使用它来创建属性保存在游戏存储中的类。

```ts
const CITY_CATEGORY = "city";

export default class City extends StoredClassModel {
    constructor(id: string, props: CityProps) {
        super(CITY_CATEGORY, id);
        // ...
    }
}
```

```ts
const milan = new City("milan", {
    // ...
});
```

## 存储属性

要将类的属性存储在游戏存储中，请使用 [`getStorageProperty`](/jsdoc/pixi-vn/index/classes/StoredClassModel#getstorageproperty) 和 [`setStorageProperty`](/jsdoc/pixi-vn/index/classes/StoredClassModel#setstorageproperty) 辅助方法。

```ts
export default class City extends StoredClassModel {
    constructor(id: string, props: CityProps) {
        // ...
    }

    get inhabitants(): number {
        return this.getStorageProperty<string>("inhabitants") || "";
    }
    set inhabitants(value: number) {
        this.setStorageProperty("inhabitants", value);
    }
}
```

```ts
const milan = new City("milan", {
    // ...
});

milan.inhabitants = 100000;
```
