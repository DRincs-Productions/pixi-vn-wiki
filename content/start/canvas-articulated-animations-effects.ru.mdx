---
title: Шарнирные анимации
description: Узнайте, как использовать шарнирные анимации — функции, построенные на основе canvas.animate, для создания сложных эффектов, таких как тряска, на канвас-компонентах Pixi’VN.
---

Шарнирные анимации — это функции, которые используют функцию [`canvas.animate`](/jsdoc/pixi-vn/index/interfaces/CanvasManagerInterface#animate) для создания анимаций, которые можно применять к канвас-компонентам. Эти функции обычно используются для создания таких эффектов, как тряска, подпрыгивание или другие сложные анимации, включающие несколько шагов или компонентов.

The examples below use the `effects` namespace introduced in the upcoming **v1.9.5**.
Import it from `@drincs/pixi-vn` or `@drincs/pixi-vn/canvas`. In v1.9.4, import `shakeEffect`
directly; that export remains available but deprecated in v1.9.5.

<Accordion title="Тряска" id="shake">

The [`effects.shakeEffect`](/jsdoc/pixi-vn/index/namespaces/effects/functions/shakeEffect) function is an articulated animation that shakes a component.

```ts tab="content/labels/start.label.ts"
import {
    CANVAS_APP_GAME_LAYER_ALIAS,
    effects,
    newLabel,
    showImage,
} from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [
    async () => {
        await showImage("bg", "bg", { scale: 1.3 });
        await showImage("alien", "alien", { align: 0.5 });
        effects.shakeEffect("alien"); // [!code focus]
    },
    async () => {
        effects.shakeEffect(CANVAS_APP_GAME_LAYER_ALIAS); // [!code focus]
    },
]);
```

```ts tab="assets/index.ts"
import { AssetsManifest } from "@drincs/pixi-vn";

/**
 * Manifest for the assets used in the game.
 * You can read more about the manifest here: https://pixijs.com/8.x/guides/components/assets#loading-multiple-assets
 */
export const manifest: AssetsManifest = {
    bundles: [
        {
            name: "start",
            assets: [
                {
                    alias: "alien",
                    src: "https://pixijs.com/assets/eggHead.png",
                },
                {
                    alias: "bg",
                    src: "https://pixijs.com/assets/bg_grass.jpg",
                },
            ],
        },
    ],
};
```

<Accordion title="Bounce" id="bounce">

The [`effects.bounceEffect`](/jsdoc/pixi-vn/index/namespaces/effects/functions/bounceEffect) function displaces a component towards a direction and back, decaying over a number of bounces - like it's hopping on the spot.

```ts tab="content/labels/start.label.ts"
import { effects, newLabel, showImage } from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [
    async () => {
        await showImage("alien", "alien", { align: 0.5 });
        await effects.bounceEffect("alien"); // [!code focus]
    },
    async () => {
        await effects.bounceEffect("alien", { direction: "left", distance: 50, bounces: 4 }); // [!code focus]
    },
]);
```

<Accordion title="Pulse" id="pulse">

```ts tab="content/labels/start.label.ts"

export const startLabel = newLabel("start", [
    async () => {
        await showImage("alien", "alien", { align: 0.5 });
        await effects.pulseEffect("alien"); // [!code focus]
    },
    async () => {
        await effects.pulseEffect("alien", { pulses: 1, scale: 1.5 }); // [!code focus]
    },
]);
```

<Accordion title="Punch" id="punch">

The [`effects.punchEffect`](/jsdoc/pixi-vn/index/namespaces/effects/functions/punchEffect) function is a single one-shot attack-and-recover animation (not decaying like the effects above) on a component's `scale`, `x`, `y`, or `rotation`, with an optional overshoot on the recovery.

```ts tab="content/labels/start.label.ts"
import { effects, newLabel, showImage } from "@drincs/pixi-vn";

    async () => {
        await showImage("alien", "alien", { align: 0.5 });
        await effects.punchEffect("alien"); // [!code focus]
    },
    async () => {
        await effects.punchEffect("alien", { mode: "scale", strength: 0.5 }); // [!code focus]
    },
]);
```

<Accordion title="Glitch" id="glitch-effect">

The [`effects.glitchEffect`](/jsdoc/pixi-vn/index/namespaces/effects/functions/glitchEffect) function plays one or more digital-corruption bursts (displaced slices, plus an optional RGB channel split) on a component, without removing or showing it. Works best on detailed, high-contrast images - it barely reads on flat colors.

```ts tab="content/labels/start.label.ts"
import { effects, newLabel, showImage } from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [
    async () => {
        await showImage("alien", "alien", { align: 0.5 });
        await effects.glitchEffect("alien"); // [!code focus]
    },
    async () => {
        await effects.glitchEffect("alien", { strength: 80, bursts: 5, rgbSplit: 12 }); // [!code focus]
    },
]);
```

<Accordion title="Vignette pulse" id="vignette-pulse-effect">

The [`effects.vignettePulseEffect`](/jsdoc/pixi-vn/index/namespaces/effects/functions/vignettePulseEffect) function pulses a darkening vignette in from a component's corners and back out, decaying over a number of pulses. Needs a full-frame background/image to be visible - it darkens the element's own corners, so a character sprite with transparent margins around it won't show much.

```ts tab="content/labels/start.label.ts"
import {
    CANVAS_APP_GAME_LAYER_ALIAS,
    effects,
    newLabel,
    showImage,
} from "@drincs/pixi-vn";

export const startLabel = newLabel("start", [
    async () => {
        await showImage("background", "bg_grass");
        await effects.vignettePulseEffect(CANVAS_APP_GAME_LAYER_ALIAS); // [!code focus]
    },
    async () => {
        await effects.vignettePulseEffect(CANVAS_APP_GAME_LAYER_ALIAS, { radius: 0.7, blur: 0.6, pulses: 3 }); // [!code focus]
    },
]);
```
