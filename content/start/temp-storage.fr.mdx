---
title: Stockage temporaire
description: Explique comment utiliser le stockage temporaire dans Pixi’VN pour les variables qui ne sont nécessaires que pendant une période narrative spécifique.
---

Dans de nombreux cas, il est utile d'utiliser des variables uniquement pendant une certaine période de la narration. Avec le stockage normal, il faudrait supprimer manuellement ces variables lorsqu'elles ne sont plus nécessaires, afin de garder les sauvegardes légères et efficaces.

Pour résoudre ce problème, Pixi’VN dispose d'un système de stockage temporaire. Les variables temporaires initialisées dans une `label` seront supprimées lorsque la `label` sera fermée. Si une autre `label` est appelée depuis celle-ci, la variable temporaire restera accessible depuis la `label` enfant. Cependant, si une autre `label` est appelée avec `jump` (ainsi la `label` actuelle sera fermée et la nouvelle sera démarrée), la variable temporaire ne sera plus accessible.

## Définir

To set a temporary variable, use [`storage.temp.set`](/jsdoc/pixi-vn/index/interfaces/StorageTempInterface#set).

```ts
import { storage } from "@drincs/pixi-vn";

storage.temp.set("myTempVariable", 42);
```

## Obtenir

Pour obtenir une variable temporaire, utilisez la fonction normale [`storage.get`](/jsdoc/pixi-vn/index/interfaces/StorageManagerInterface#get).

## Supprimer

To remove a temporary variable, use [`storage.temp.remove`](/jsdoc/pixi-vn/index/interfaces/StorageTempInterface#remove).

```ts
import { storage } from "@drincs/pixi-vn";

storage.temp.remove("myTempVariable");
```
