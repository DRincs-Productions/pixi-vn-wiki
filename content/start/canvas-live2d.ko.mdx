<Accordion title="Live2D란 무엇인가요?" id="what-is-live2d">

Live2D는 2D 일러스트가 자연스럽게 움직이도록 만들어, 매 프레임을 다시 그리지 않고도 부드럽고 풍부한 표현의 애니메이션을 제작할 수 있는 기술입니다. Spine 2D처럼 뼈대 골격을 사용하는 대신 Live2D 모델은 하나의 일러스트로 이루어지며, 각 부분을 **매개변수**(각도, 눈의 개폐 정도, 입 모양 등)로 변형하고 혼합합니다. 이러한 변화는 **모션**(미리 정의된 애니메이션 클립)과 **표정**(얼굴 표정 등에 쓰이는 미리 정의된 매개변수 설정)으로 제어됩니다.

캐릭터에 생동감을 불어넣기 위해 비주얼 노벨, 게임, 인터랙티브 애플리케이션(특히 VTuber 관련 분야)에서 널리 사용됩니다.

Live2D에 관한 자세한 내용은 [Live2D 공식 웹사이트](https://www.live2d.com/)에서 확인할 수 있습니다.

</Accordion>

</Accordions>

**Pixi’VN** 프로젝트에서 Live2D 연동 기능을 사용하면 캐릭터의 Live2D 모델을 표시하고 애니메이션을 적용할 수 있습니다.
이 연동은 [untitled-pixi-live2d-engine](https://github.com/Untitled-Story/untitled-pixi-live2d-engine)을 감싸는 래퍼입니다. 이는 **공식 PixiJS/Live2D 플러그인이 아니라**, Live2D와 PixiJS를 연결하는 커뮤니티 유지 관리 엔진으로, 해당 기능을 Pixi’VN 프로젝트에서 직접 사용할 수 있게 합니다.

## 설치

기존 JavaScript 프로젝트에 Live2D 패키지를 설치하려면 다음 명령어 중 하나를 사용하세요:

```npm
npm install @drincs/pixi-vn-live2d
```

:::danger

메인 파일에서 시작 시 `Game.init`을 호출하기 전에 `extensions.add(Live2DPlugin)`을 호출해야 합니다.

:::

```ts title="main.ts"
import { extensions } from "pixi.js";
import { Live2DPlugin } from "@drincs/pixi-vn-live2d/core";
extensions.add(Live2DPlugin);

Game.init(body, {
    // ...
});
```

## 사용법

[`Live2D`](/jsdoc/pixi-vn-live2d/index/classes/Live2D) 컴포넌트는 다른 Pixi’VN 컴포넌트와 동일한 방식으로 사용할 수 있습니다. Spine과 달리 Live2D 모델은 `Assets.load`로 미리 불러올 필요가 없습니다. `Assets.add`로 별칭을 등록하기만 하면 `Live2D`가 모델을 직접 찾아서 가져옵니다.

모델을 가져오는 작업은 비동기식이므로 [`ready`](/jsdoc/pixi-vn-live2d/index/classes/Live2D#ready) 프로미스가 완료되기 전에는 안전하게 사용할 수 없습니다. 모델을 생성한 직후 `await`로 완료를 기다리고, 로드된 모델에 의존하는 정보(예: 크기)를 읽기 전에 준비가 끝났는지 확인하세요.

예를 들어:

```ts tab="Typescript" title="main.ts" groupId="narrative_language"
import { canvas } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

const live2d = new Live2D({
    source: "shizuku",
    xAlign: 0.5,
    yAlign: 1,
    scale: 0.5,
});
await live2d.ready;
canvas.add("shizuku", live2d);
```

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
# show live2d shizuku xAlign 0.5 yAlign 1 scale 0.5
-> DONE
```

```ts tab="src/assets/index.ts"
import { AssetsManifest } from "@drincs/pixi-vn";

/**
 * Manifest for the assets used in the game.
 * You can read more about the manifest here: https://pixijs.com/8.x/guides/components/assets#loading-multiple-assets
 */
export const manifest: AssetsManifest = {
    bundles: [
        {
            name: "start",
            assets: [
                {
                    alias: "shizuku",
                    src: "https://cdn.jsdelivr.net/gh/guansss/pixi-live2d-display/test/assets/shizuku/shizuku.model.json",
                },
            ],
        },
    ],
};
```

<Accordion title="모션" id="motion">

Live2D 모델의 애니메이션은 **모션 그룹**(예: `idle`, `tap_body`)으로 구성되며, 각 그룹에는 하나 이상의 모션 클립이 포함됩니다. [`motion`](/jsdoc/pixi-vn-live2d/index/classes/Live2D#motion) 함수로 모션을 재생할 수 있습니다. 클립 인덱스를 생략하면 해당 그룹의 클립 중 하나가 무작위로 재생됩니다.

기본적으로 모델은 `idle`(Cubism 2) 또는 `Idle`(Cubism 4) 모션 그룹을 자동으로 반복 재생합니다. 이 동작은 `idleMotionGroup` 옵션으로 설정할 수 있으므로, 탭이나 클릭에 반응하는 일회성 애니메이션처럼 특정 동작을 실행할 때만 `motion`을 호출하면 됩니다.

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
import { canvas, newLabel } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

export const startLabel = newLabel("start", [
    async () => {
        const live2d = new Live2D({
            source: "shizuku",
            xAlign: 0.5,
            yAlign: 1,
            scale: 0.5,
        });
        await live2d.ready;
        canvas.add("shizuku", live2d);
    },
    () => {
        canvas.find<Live2D>("shizuku")?.motion("tap_body");
    },
]);
```

```ink tab="ink" title="ink/start.ink" groupId="narrative_language"
=== start ===
# show live2d shizuku xAlign 0.5 yAlign 1 scale 0.5
# pause
# play motion tap_body on live2d shizuku
# pause
-> DONE
```

<Accordion title="표정" id="expression">

Live2D 모델은 여러 **표정**을 정의할 수 있습니다. 이는 일반적으로 얼굴 표정에 사용되는 매개변수 값의 프리셋이며, [`expression`](/jsdoc/pixi-vn-live2d/index/classes/Live2D#expression) 함수를 사용하여 실행 중에 전환할 수 있습니다. `motion`과 마찬가지로 ID를 생략하면 무작위 표정이 선택됩니다.

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
import { canvas, newLabel } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

export const startLabel = newLabel("start", [
    async () => {
        const live2d = new Live2D({
            source: "shizuku",
            xAlign: 0.5,
            yAlign: 1,
            scale: 0.5,
        });
        await live2d.ready;
        canvas.add("shizuku", live2d);
    },
    () => {
        canvas.find<Live2D>("shizuku")?.expression("f01");
    },
]);
```

<Accordion title="Live2D + motion.js 애니메이션" id="motion-js">

아래 예시처럼 Live2D 모션을 Pixi’VN의 전통적인 모션 기반 애니메이션([`canvas.animate`](/jsdoc/pixi-vn/index/interfaces/CanvasManagerInterface#animate))과 결합할 수 있습니다.

더 고급 게임에서는 미리 정의된 시퀀스에만 의존하지 않고 버튼 누르기 등의 이벤트로 실행되는 티커를 통해 Live2D를 직접 제어할 수도 있습니다.

```ts title="content/labels/start.label.ts" groupId="narrative_language"
import { canvas, newLabel } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

export const startLabel = newLabel("start", [
    async () => {
        const live2d = new Live2D({
            source: "shizuku",
            xAlign: 0.3,
            yAlign: 1,
            scale: 0.5,
        });
        await live2d.ready;
        canvas.add("shizuku", live2d);
        canvas.animate(
            live2d,
            [
                [{ x: canvas.width * 0.7 }, { duration: 2, ease: "linear" }],
                [{ x: canvas.width * 0.3 }, { duration: 2, ease: "linear" }],
            ],
            { repeat: Infinity },
        );
    },
]);
```

<Accordion title="모션 중지" id="stop-motions">

[`stopMotions`](/jsdoc/pixi-vn-live2d/index/classes/Live2D#stopmotions) 함수를 사용하면 모델에서 현재 재생 중인 모든 모션과 립싱크 오디오를 중지할 수 있습니다.

```ts tab="Typescript" title="content/labels/start.label.ts" groupId="narrative_language"
import { canvas, newLabel } from "@drincs/pixi-vn";
import { Live2D } from "@drincs/pixi-vn-live2d";

export const startLabel = newLabel("start", [
    async () => {
        const live2d = new Live2D({
            source: "shizuku",
            xAlign: 0.5,
            yAlign: 1,
            scale: 0.5,
        });
        await live2d.ready;
        canvas.add("shizuku", live2d);
        live2d.motion("tap_body");
    },
    () => {
        canvas.find<Live2D>("shizuku")?.stopMotions();
    },
]);
```
