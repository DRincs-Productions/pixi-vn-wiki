---
title: Gestión de banderas
description: Explica cómo usar banderas booleanas en Pixi’VN para controlar el flujo del juego.
---

Pixi’VN proporciona funciones para gestionar "banderas de juego". Las banderas de juego son valores booleanos utilizados para controlar el flujo del juego o para almacenar otros valores booleanos en el almacenamiento del juego.

Este mecanismo tiene un impacto mucho menor en el tamaño de las partidas guardadas que el uso del almacenamiento normal, por lo que se recomienda usar banderas para los valores booleanos que cambian con frecuencia.

## Establecer

Para establecer una bandera, usa la función [`storage.flags.set`](/jsdoc/pixi-vn/index/interfaces/StorageFlagsInterface#set).

```ts
import { storage } from "@drincs/pixi-vn";

storage.flags.set("flag1", true);
```

## Obtener

Para obtener una bandera, usa la función [`storage.flags.get`](/jsdoc/pixi-vn/index/interfaces/StorageFlagsInterface#get).

```ts
import { storage } from "@drincs/pixi-vn";

const flag1 = storage.flags.get("flag1");
```
