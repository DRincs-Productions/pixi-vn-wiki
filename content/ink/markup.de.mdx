Die **Integration von *ink* und Pixi’VN** bietet zusätzliche Funktionen, die die Verwendung von Komponenten erleichtern, die <DynamicLink href="/start/markup-markdown">Markup</DynamicLink> in den Text einfügen.

## Zeilenumbrüche

Um einen Zeilenumbruch einzufügen, kannst du die Escape-Sequenz `\n` verwenden.

<Callout>

Da wir in unserem Fall Markdown zur Darstellung von Zeilenumbrüchen verwenden, benötigen wir zwei davon: `\n\n`.

</Callout>

Zum Beispiel:

```ink title="ink"
=== start ===
Hello, this is a test. \\n\\n This is a new line.
```

## Markdown

In Pixi’VN empfiehlt es sich, Markdown zur Gestaltung deines Textes zu verwenden. Wenn du <DynamicLink href="/start/markup-markdown">Markdown in deinem Projekt implementiert hast</DynamicLink>, kannst du deinen Text in ***ink*** mit Markdown-Syntax formatieren.

Beachte dabei, dass viele Zeichen der Markdown-Syntax auch von der ***ink*-Syntax** verwendet werden, zum Beispiel `#`, `*`, `/`, `~`, `-`, `|` usw. Um Konflikte zu vermeiden, kannst du das Escape-Zeichen `\` vor das Markdown-Zeichen setzen.

Zum Beispiel:

```ink title="ink"
Hello, this is some *italic* text and this is some **bold** text.
```

## CSS

Du kannst auch Tailwind-CSS-Klassen verwenden, um Text mit HTML zu formatieren.

Zum Beispiel:

```ink title="ink"
<span class="inline-block text-blue-500">some *blue* text</span>.
<span class="inline-block text-red-500">some *red* text</span>.
<span class="inline-block text-green-500">some *green* text</span>.
```
