---
title: Prompt di input
description: |
  Come richiedere al giocatore un input testuale o numerico in ink usando lo "# script" di Pixi’VN e accedere al risultato all'interno della narrazione.
---

L'**integrazione *ink* + Pixi’VN** introduce uno "# script" che consente di mostrare all'utente un <DynamicLink href="/start/input">prompt di input</DynamicLink>. To do this, you need to use the following syntax:

```ink tab="ink"
# request input type string
```

```txt tab="CLI"
# request input [<parameters>]

where:
    parameters (Optional) = a space-separated list of property/value pairs. If a value contains spaces, wrap it in double quotes.
```

`parameters` disponibili (tutti facoltativi): [`type`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonInputRequest#valuetype), [`default`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonInputRequest#defaultvalue).

:::tip

Il valore inserito viene salvato nell'archivio con la chiave di sistema `_input_value_`, quindi puoi fare riferimento a `{ _input_value_ }` nei tuoi contenuti ink.

:::

Ad esempio:

```ink title="ink/start.ink"
=== start ===
Hello,
# request input type string // [!code focus]
<>what is your name?
My name is { _input_value_ } // [!code focus]
# request input type number default 18 // [!code focus]
How old are you?
I am { _input_value_ } years old // [!code focus]
# request input type "html textarea" // [!code focus]
Describe who you are:
{ _input_value_ } // [!code focus]
Restart
-> DONE
```
