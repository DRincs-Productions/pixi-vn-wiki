Pixi’VN позволяет создавать интерактивные истории с помощью ***ink*** — языка сценариев, предназначенного для сюжетов с разветвлениями.

<Accordions>

<Accordion title="Что такое ink?" id="what-is-ink">

***ink*** — простой язык сценариев для интерактивных историй, используемый в играх вроде 80 Days, Heaven's Vault и Sorcery! Подробнее можно узнать на [сайте *ink*](https://www.inklestudios.com/ink/).

</Accordion>

<Accordion title="Зачем использовать ink?" id="why-use-ink">

Писать повествование непосредственно на **JavaScript/TypeScript** может быть долго и сложно, особенно начинающим разработчикам. ***ink*** гораздо проще изучать и использовать для написания сценариев.

Начинающие разработчики могут начать с <DynamicLink href="/start#project-initialization">шаблона *ink*</DynamicLink>, а затем постепенно изучать JavaScript/TypeScript для более сложных возможностей.

</Accordion>

</Accordions>

**Интеграция *ink* и Pixi’VN** использует [inkjs](https://github.com/inkle/inkjs) и [PixiVNJson](/jsdoc/pixi-vn-json) для разбора **кода *ink*** и создания JSON, который Pixi’VN может интерпретировать. Это означает, что JavaScript/TypeScript и ***ink*** используют общее хранилище и холст, а вы можете запускать ***ink*** `knots` (или `labels`) из JavaScript/TypeScript и наоборот. Вы получаете преимущества обоих подходов: пишите повествование на ***ink***, а для мини-игр и сложных анимаций используйте JavaScript/TypeScript.

```ink title="ink/start.ink"
=== start ===
We arrived into London at 9.45pm exactly.

* "There is not a moment to lose!"[] I declared.
 -> hurry_outside

* "Monsieur, let us savour this moment!"[] I declared.
 My master clouted me firmly around the head and dragged me out of the door.
 -> dragged_outside

* [We hurried home] -> hurry_outside

=== hurry_outside ===
We hurried home to Savile Row -> as_fast_as_we_could

=== dragged_outside ===
He insisted that we hurried home to Savile Row
-> as_fast_as_we_could

=== as_fast_as_we_could ===
<> as fast as we could.
-> start
```

## Установка

:::tip[Шаблоны]

Начинаете новый проект Pixi’VN? Воспользуйтесь <DynamicLink href="/start#project-initialization">шаблоном</DynamicLink>, в который уже включён *ink*.

:::

Чтобы установить пакет *ink* в существующий проект JavaScript, используйте одну из следующих команд:

```npm
npm install @drincs/pixi-vn @drincs/pixi-vn-ink
```

### Инициализация

После установки загрузите **скрипт *ink*** с помощью [`importInkText`](/jsdoc/pixi-vn-ink/index/functions/importInkText):

```typescript title="main.ts"
import { importInkText } from '@drincs/pixi-vn-ink'

const inkText = `
=== start ===
Hello
-> END
`

importInkText([inkText, ...])
```

Теперь вы можете выполнить **`knot` в *ink*** (или `label`) с помощью <DynamicLink href="/start/labels#run-a-label">функций Pixi’VN</DynamicLink>:

```typescript title="main.ts"
import { narration } from "@drincs/pixi-vn";

narration.call(`start`, {});
```

<Accordion title="Импорт текста из файлов .ink" id="import-ink-files">

:::tip

В этом руководстве используется [Vite](https://vitejs.dev/), но тот же подход применим и в других средах.

:::

Для импорта файлов `.ink` необходимо настроить проект так, чтобы они обрабатывались как текстовые файлы.

Для этого выполните следующие шаги:

* Объявите модуль `*.ink` в `ink.d.ts`.
* Добавьте `.ink` в `assetsInclude` файла `vite.config.ts`.
* Импортируйте файл с параметром `?raw`, чтобы получить его текстовое содержимое.

```ts tab="main.ts"
import { importInkText } from '@drincs/pixi-vn-ink'
import startLabel from './ink/start.ink?raw'

importInkText([startLabel, ...])
```

```ts tab="vite.config.ts"
export default defineConfig({
    // ...
    assetsInclude: ["**/*.ink"],
});
```

```ts tab="ink.d.ts"
declare module "*.ink" {
    const value: string;
    export default value;
}
```

</Accordion>

<Accordion title="Включение базовых хэштег-команд" id="base-hashtag-commands">

Pixi’VN содержит встроенные <DynamicLink href="/ink/hashtag">Hashtag Commands</DynamicLink> — стандартные команды `#` для взаимодействия с холстом (например, `# show`, `# moveIn` и т. д.), но они **не регистрируются автоматически**. Вызовите [`addBaseHashtagCommands`](/jsdoc/pixi-vn-ink/index/functions/addBaseHashtagCommands) один раз при настройке приложения, чтобы включить эти команды.

```ts title="content/ink/hashtag-commands.ts"
import { addBaseHashtagCommands } from "@drincs/pixi-vn-ink";

addBaseHashtagCommands();
```

</Accordion>

## Синтаксис, игнорируемый Pixi’VN

Некоторые конструкции синтаксиса *ink* игнорируются Pixi’VN. Вы можете использовать их в своём **скрипте *ink*** (например, для тестирования в редакторе Inky), но Pixi’VN их проигнорирует.

<Accordions>

<Accordion title="INCLUDE" id="include">

`INCLUDE` — инструкция *ink* для включения другого файла *ink*. В Pixi’VN для загрузки нескольких файлов *ink* вместо этого следует использовать [`importInkText`](/jsdoc/pixi-vn-ink/index/functions/importInkText), поэтому `INCLUDE` игнорируется.

</Accordion>

<Accordion title="Определения функций" id="function-definitions">

Определения функций игнорируются Pixi’VN. Подробнее можно прочитать на странице <DynamicLink href="/ink/functions">Функции</DynamicLink>.

</Accordion>

<Accordion title="Повествование вне knots" id="narration-outside-the-knots">

Повествование вне `knots` (или `labels`) игнорируется, за исключением переменных.

Например:

```ink title="ink"
VAR my_var = false // ✅ This will be handled (because it is a variable)
Hello // ❌ This will be ignored  [!code warning]
-> start // ❌ This will be ignored [!code warning]
=== start === // ✅ This will be handled
My name is John // ✅ This will be handled
-> DONE // ✅ This will be handled
```

</Accordion>

</Accordions>

## Другие возможности

<Accordions>

<Accordion title="Различия между обычным ink и ink в Pixi’VN" id="ink-differences">

* **Доступ к элементам LIST**: в стандартном ***ink*** можно ссылаться на элемент списка как по короткому имени (например, `sword`), так и по полному имени (например, `items.sword`); эти варианты равнозначны. В ***ink* для Pixi’VN** необходимо **всегда** использовать полную форму `items.sword`. Если написать только `sword`, будет найдена обычная запись хранилища с ключом `"sword"` — это **не** ссылка на элемент списка. Это относится ко всем объявлениям `LIST`.

* Поскольку «Threads» не поддерживаются в Pixi’VN, символ `\<-` соответствует <DynamicLink href="/ink/labels#call">вызову knot</DynamicLink>.

* В этом случае:

  ```ink title="ink"
  { shuffle:
    -  2 of Diamonds.
      'You lose this time!' crowed the croupier.
  }
  ```

  **В обычном *ink*** вы увидите два отдельных диалога: первый — `2 of Diamonds.`, второй — `'You lose this time!' crowed the croupier.`.

  **В *ink* для Pixi’VN** вместо двух отдельных диалогов вы увидите один: `2 of Diamonds.\n\n'You lose this time!' crowed the croupier.`. В <DynamicLink href="/ink/markup#markdown-on-ink">Markdown</DynamicLink> это будет выглядеть так:

  ```txt
  2 of Diamonds.
  'You lose this time!' crowed the croupier.
  ```

* Если `weave` (в следующем примере — `shove`) связан с одноразовым выбором и открывается через `-> shove`, это не делает такой выбор недоступным. Чтобы он стал недоступен, необходимо выбрать соответствующий вариант обычным способом.

  Вот пример:

  ```ink title="ink"
  -> start
  === start ===
  * [1] -> shove
  * (shove) [2] 2
  * {shove} [3] -> END
  -  -> start
  -> DONE
  ```

  Если вы выберете вариант `1`, при следующем открытии `start`:

  * при использовании **обычного *ink*** будет доступен только вариант `3`. Вариант `2` скрыт, поскольку **обычный *ink*** знает, что вы уже приняли это одноразовое решение через `-> shove`.
  * при использовании ***ink* для Pixi’VN** можно будет выбрать вариант `2` или `3`. Вариант `2` не скрыт, поскольку ***ink* для Pixi’VN** не знает, что `shove` связан с выбором.

  Чтобы `start` работал одинаково в **обычном *ink*** и в ***ink* для Pixi’VN**, необходимо написать следующий код:

  ```ink title="ink"
  -> start
  === start ===
  * [1] -> shove
  * (shove) {!shove} [2] 2
  * {shove} [3] -> END
  -  -> start
  -> DONE
  ```

</Accordion>
