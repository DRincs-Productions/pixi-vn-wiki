  Come presentare e gestire i menu di scelta in ink nativo, comprese le scelte utilizzabili una sola volta, persistenti, condizionali e di ripiego. Compatibile con l'integrazione di Pixi’VN.
---

:::tip

L'**integrazione di *ink* + Pixi’VN** supporta le scelte native di *ink* senza introdurre nuovi tipi di scelta. Per tutti i dettagli sulla sintassi e sul comportamento delle scelte, consulta la [documentazione ufficiale di ink](https://www.inklestudios.com/ink/).

:::

Puoi chiedere al giocatore di effettuare una scelta in *ink* usando un elenco di voci contrassegnate da `*` o `+`, seguite dal testo della scelta. Il testo della scelta viene mostrato al giocatore, che seleziona un'opzione per proseguire nella storia.

* `*` indica una scelta che può essere effettuata una sola volta.
* `+` indica una scelta che può essere effettuata più volte (scelta persistente).

```ink title="ink/start.ink"
=== start ===
* Go to Paris
  You decide to visit Paris. -> visit_paris
+ Go to London -> visit_london
* Stay at home
  You decide to stay at home. -> DONE
```

## Nascondere il testo delle scelte

Per impostazione predefinita, il testo dell'opzione selezionata viene mostrato nuovamente nell'output. Se il testo visibile di una scelta è racchiuso tra parentesi quadre, viene mostrato solo nel menu di scelta e non nell'output successivo.

```ink title="ink/start.ink"
=== start ===
Hello world!
* [Hello back!]
 Nice to hear from you!
```

Le parentesi quadre dividono il contenuto dell'opzione: il testo prima delle parentesi viene mostrato sia nel menu sia nell'output; quello al loro interno compare solo nel menu; quello dopo compare solo nell'output. Questo è utile per le scelte nei dialoghi:

```ink title="ink/start.ink"
=== start ===
"What's that?" my master asked.
* "I am somewhat tired[."]," I repeated.
 "Really," he responded. "How deleterious."
```

## Varianti delle scelte

<Accordions>

<Accordion title="Scelte di ripiego" id="fallback-choices">

Le scelte di ripiego non vengono mai mostrate al giocatore, ma vengono selezionate automaticamente dal motore quando non sono disponibili altre opzioni.

Una scelta di ripiego è semplicemente una scelta senza testo visibile:

```ink tab="ink"
* -> out_of_options
```

```txt tab="CLI"
* -> <knot_name>

where:
    knot_name = the name of the knot to jump to when no other choice is available
```

Ad esempio:

```ink title="ink/start.ink"
=== start ===
 You search desperately for a friendly face in the crowd.
 * The woman in the hat[?] pushes you roughly aside. -> find_help
 * The man with the briefcase[?] looks disgusted as you stumble past him. -> find_help
 * -> // fallback
  But it is too late: you collapse onto the station platform. This is the end.
  -> END
```

</Accordion>

<Accordion title="Scelte condizionali" id="conditional-choices">

Puoi abilitare o disabilitare le scelte tramite condizioni. Il controllo più semplice consiste nel verificare se il giocatore ha già visitato un determinato `knot` o `stitch`.

```ink title="ink"
* { not visit_paris }  [Go to Paris] -> visit_paris
+ { visit_paris }      [Return to Paris] -> visit_paris
* { visit_paris.met_estelle } [Telephone Mme Estelle] -> phone_estelle
```

Nota: la condizione `knot_name` è vera se è stato visitato un qualsiasi `stitch` all'interno di quel knot. Le condizioni non annullano il comportamento di utilizzo singolo delle opzioni `*`: usa `+` per le opzioni ripetibili.

</Accordion>
