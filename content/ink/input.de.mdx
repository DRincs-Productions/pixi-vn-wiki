---
title: Eingabeaufforderung
description: |
  So forderst du den Spieler in ink mit dem "# script" von Pixi’VN zur Eingabe von Text oder Zahlen auf und greifst innerhalb deiner Geschichte auf das Ergebnis zu.
---

Die ***ink* + Pixi’VN-Integration** führt ein "# script" ein, mit dem du dem Benutzer eine <DynamicLink href="/start/input">Eingabeaufforderung</DynamicLink> anzeigen kannst. To do this, you need to use the following syntax:

```ink tab="ink"
# request input type string
```

```txt tab="CLI"
# request input [<parameters>]

where:
    parameters (Optional) = a space-separated list of property/value pairs. If a value contains spaces, wrap it in double quotes.
```

Verfügbare `parameters` (alle optional): [`type`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonInputRequest#valuetype), [`default`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonInputRequest#defaultvalue).

:::tip

Der eingegebene Wert wird im Speicher unter dem Systemschlüssel `_input_value_` abgelegt. Du kannst daher in deinem ink-Inhalt mit `{ _input_value_ }` darauf zugreifen.

:::

Zum Beispiel:

```ink title="ink/start.ink"
=== start ===
Hello,
# request input type string // [!code focus]
<>what is your name?
My name is { _input_value_ } // [!code focus]
# request input type number default 18 // [!code focus]
How old are you?
I am { _input_value_ } years old // [!code focus]
# request input type "html textarea" // [!code focus]
Describe who you are:
{ _input_value_ } // [!code focus]
Restart
-> DONE
```
