La **integración de *ink* con Pixi’VN** ofrece funciones adicionales para facilitar el uso de componentes que incorporan <DynamicLink href="/start/markup-markdown">marcado</DynamicLink> al texto.

## Saltos de línea

Para crear un salto de línea, puedes utilizar el carácter de escape `\n`.

<Callout>

En nuestro caso, como usamos Markdown para mostrar el salto de línea, necesitaremos dos: `\n\n`.

</Callout>

Por ejemplo:

```ink title="ink"
=== start ===
Hello, this is a test. \\n\\n This is a new line.
```

## Markdown

En Pixi’VN se recomienda utilizar Markdown para dar formato al texto. Si has <DynamicLink href="/start/markup-markdown">implementado Markdown en tu proyecto</DynamicLink>, podrás usar la sintaxis de Markdown para dar formato al texto en ***ink***.

Para ello, ten en cuenta que muchos símbolos de la sintaxis de Markdown también se utilizan en la **sintaxis de *ink***, como `#`, `*`, `/`, `~`, `-`, `|`, etc. Para evitar conflictos, puedes colocar el carácter de escape `\` delante del símbolo de Markdown.

Por ejemplo:

```ink title="ink"
Hello, this is some *italic* text and this is some **bold** text.
```

## CSS

También puedes usar clases de Tailwind CSS para dar formato al texto mediante HTML.

Por ejemplo:

```ink title="ink"
<span class="inline-block text-blue-500">some *blue* text</span>.
<span class="inline-block text-red-500">some *red* text</span>.
<span class="inline-block text-green-500">some *green* text</span>.
```
