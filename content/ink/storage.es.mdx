:::tip

Puedes obtener más información sobre el uso de variables en ink en la [documentación oficial](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md#part-3-variables-and-logic).

***ink*** también admite variables temporales y globales que almacenan datos numéricos, contenido o incluso comandos que controlan el flujo de la historia. Dispone de un sistema lógico completo e incluye estructuras adicionales que ayudan a organizar mejor la lógica, a menudo compleja, de una historia con ramificaciones.

En la **integración de *ink* con Pixi’VN**, las variables `VAR` y `CONST` equivalen a las <DynamicLink href="/start/storage">variables del almacenamiento</DynamicLink>, mientras que las variables `temp` equivalen a las <DynamicLink href="/start/storage#temporary-storage">variables temporales del almacenamiento</DynamicLink>.

El nombre de las variables de ***ink*** se corresponde con la clave de una variable en el <DynamicLink href="/start/storage">almacenamiento</DynamicLink>.

## Define

:::tip

En JavaScript/TypeScript, esta funcionalidad se corresponde con <DynamicLink href="/start/storage#default-storage-variables">«Variables de almacenamiento predeterminadas»</DynamicLink>.

:::

Puedes definir una variable en ***ink*** con el siguiente código:

```ink tab="ink"
VAR myVariable = 42
```

```txt tab="CLI"
VAR <variable_name> = <value>

where:
    variable_name = the name of the variable
    value = the initial value of the variable
```

## Establecer

:::tip

En JavaScript/TypeScript, esta funcionalidad se corresponde con <DynamicLink href="/start/storage#set">`storage.set`</DynamicLink>.

:::

Puedes establecer el valor de una variable en ***ink*** con el siguiente código:

```ink tab="ink"
~ myVariable = 100
```

```txt tab="CLI"
~ <variable_name> = <value>

where:
    variable_name = the name of an already declared variable
    value = the new value to assign
```

## Obtener

:::tip

En JavaScript/TypeScript, esta funcionalidad se corresponde con <DynamicLink href="/start/storage#get">`storage.get`</DynamicLink>.

:::

En ink, las variables se pueden utilizar para diferentes fines. Para cada uno de estos fines, la forma de obtener el valor de una variable es distinta.

```ink tab="ink"
The value of myDuration is: {myDuration}
```

```txt tab="CLI"
{<variable_name>}

where:
    variable_name = the name of the variable to print or evaluate
```

Por ejemplo:

```ink title="ink"
The value of myDuration is: {myDuration}
# show image bg /image.png with dissolve duration {myDuration}
{myDuration > 5:
    The duration is greater than 5.
- else:
    The duration is 5 or less.
}
```
