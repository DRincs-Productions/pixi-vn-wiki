L’**integrazione tra *ink* e Pixi’VN** offre alcune funzionalità aggiuntive per facilitare l’uso di componenti che introducono il <DynamicLink href="/start/markup-markdown">markup</DynamicLink> nel testo.

## Interruzioni di riga

Per andare a capo, puoi usare il carattere di escape `\n`.

<Callout>

Nel nostro caso, poiché usiamo Markdown per visualizzare l’interruzione di riga, ne servono due: `\n\n`.

</Callout>

Ad esempio:

```ink title="ink"
=== start ===
Hello, this is a test. \\n\\n This is a new line.
```

## Markdown

Su Pixi’VN si consiglia di usare Markdown per formattare il testo. Se hai <DynamicLink href="/start/markup-markdown">implementato Markdown nel tuo progetto</DynamicLink>, puoi utilizzare la sintassi Markdown per formattare il testo in ***ink***.

Per farlo, tieni presente che molti simboli della sintassi Markdown sono usati anche dalla **sintassi di *ink***, ad esempio `#`, `*`, `/`, `~`, `-`, `|`, ecc. Per evitare conflitti, puoi inserire il carattere di escape `\` prima del simbolo Markdown.

Ad esempio:

```ink title="ink"
Hello, this is some *italic* text and this is some **bold** text.
```

## CSS

Puoi anche usare le classi Tailwind CSS per formattare il testo tramite HTML.

Ad esempio:

```ink title="ink"
<span class="inline-block text-blue-500">some *blue* text</span>.
<span class="inline-block text-red-500">some *red* text</span>.
<span class="inline-block text-green-500">some *green* text</span>.
```
