## Переносы строк

Чтобы перейти на новую строку, можно использовать управляющую последовательность `\n`.

<Callout>

В нашем случае, поскольку для отображения переноса строки используется Markdown, понадобятся два переноса: `\n\n`.

</Callout>

Например:

```ink title="ink"
=== start ===
Hello, this is a test. \\n\\n This is a new line.
```

## Markdown

В Pixi’VN рекомендуется использовать Markdown для оформления текста. Если вы <DynamicLink href="/start/markup-markdown">добавили поддержку Markdown в свой проект</DynamicLink>, то сможете использовать синтаксис Markdown для оформления текста в ***ink***.

При этом учитывайте, что многие символы синтаксиса Markdown также используются в **синтаксисе *ink***, например `#`, `*`, `/`, `~`, `-`, `|` и т. д. Чтобы избежать конфликтов, поместите символ экранирования `\` перед символом Markdown.

Например:

```ink title="ink"
Hello, this is some *italic* text and this is some **bold** text.
```

## CSS

Вы также можете использовать классы Tailwind CSS для оформления текста с помощью HTML.

Например:

```ink title="ink"
<span class="inline-block text-blue-500">some *blue* text</span>.
<span class="inline-block text-red-500">some *red* text</span>.
<span class="inline-block text-green-500">some *green* text</span>.
```
