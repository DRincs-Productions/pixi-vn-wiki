:::tip

ink에서 변수를 사용하는 방법에 대한 자세한 내용은 [공식 문서](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md#part-3-variables-and-logic)를 참고하세요.

:::

***ink***&#xB294; 임시 변수와 전역 변수를 모두 지원하며, 숫자 데이터와 콘텐츠, 스토리 진행을 제어하는 명령까지 저장할 수 있습니다. 논리 기능이 충실하며, 분기형 스토리의 복잡한 논리를 체계적으로 관리하는 데 도움이 되는 추가 구조도 제공합니다.

**_ink_와 Pixi’VN의 통합**에서 `VAR`와 `CONST` 변수는 <DynamicLink href="/start/storage">스토리지 변수</DynamicLink>에 해당하고, `temp` 변수는 <DynamicLink href="/start/storage#temporary-storage">스토리지의 임시 변수</DynamicLink>에 해당합니다.

***ink*** 변수 이름은 <DynamicLink href="/start/storage">스토리지</DynamicLink>의 변수 키와 일치합니다.

## Define

:::tip

JavaScript/TypeScript에서 이 기능은 <DynamicLink href="/start/storage#default-storage-variables">‘기본 스토리지 변수’</DynamicLink>에 해당합니다.

:::

다음 코드를 사용해 ***ink***&#xC5D0;서 변수를 정의할 수 있습니다.

```ink tab="ink"
VAR myVariable = 42
```

```txt tab="CLI"
VAR <variable_name> = <value>

where:
    variable_name = the name of the variable
    value = the initial value of the variable
```

## 설정

:::tip

JavaScript/TypeScript에서 이 기능은 <DynamicLink href="/start/storage#set">`storage.set`</DynamicLink>에 해당합니다.

:::

다음 코드를 사용해 ***ink***&#xC5D0;서 변수에 값을 설정할 수 있습니다.

```ink tab="ink"
~ myVariable = 100
```

```txt tab="CLI"
~ <variable_name> = <value>

where:
    variable_name = the name of an already declared variable
    value = the new value to assign
```

## 가져오기

:::tip

JavaScript/TypeScript에서 이 기능은 <DynamicLink href="/start/storage#get">`storage.get`</DynamicLink>에 해당합니다.

:::

ink에서는 변수를 다양한 용도로 사용할 수 있습니다. 용도에 따라 변수의 값을 가져오는 방법도 달라집니다.

```ink tab="ink"
The value of myDuration is: {myDuration}
```

```txt tab="CLI"
{<variable_name>}

where:
    variable_name = the name of the variable to print or evaluate
```

예를 들어:

```ink title="ink"
The value of myDuration is: {myDuration}
# show image bg /image.png with dissolve duration {myDuration}
{myDuration > 5:
    The duration is greater than 5.
- else:
    The duration is 5 or less.
}
```
