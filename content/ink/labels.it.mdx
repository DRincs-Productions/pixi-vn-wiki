<Accordion title="Che cos'è un `knot`?" id="what-is-a-knot">

Come spiegato nella [documentazione ufficiale](https://www.inklestudios.com/ink/web-tutorial/), la storia è composta da più sezioni collegate tra loro, chiamate `knots` nella **terminologia di *ink***. In ***ink***, l'inizio di un `knot` è indicato da almeno due segni di uguale a sinistra del nome del `knot` e, facoltativamente, anche a destra.

```ink tab="ink"
=== london ===
```

```txt tab="CLI"
=== <knot_name> ===

where:
    knot_name = the name of the knot
```

</Accordion>

<Accordion title="Ci sono differenze tra `label` e `knot`?" id="label-vs-knot">

No, sono la stessa cosa. In Pixi’VN, quando crei un `knot` con ***ink***, viene creato internamente un `label` e salvato nel registro.

</Accordion>

</Accordions>

## Eseguire un knot

Per eseguire un `knot` puoi usare i seguenti metodi:

<Accordions>

<Accordion title="Divert `-> start` (salto a un `label`)" id="jump">

Puoi eseguire un `knot` usando l'operatore Divert, rappresentato dalla sintassi `-> start`. Corrisponde alla <DynamicLink href="/start/labels#jump-to-a-label">funzionalità `jump`</DynamicLink> della libreria Pixi’VN.

```ink tab="ink"
-> after
```

```txt tab="CLI"
-> <knot_name>

where:
    knot_name = the name of the knot to jump to
```

Ad esempio:

```ink title="ink/start.ink"
=== start ===
Start
-> after

=== after ===
After
End
-> DONE
```

</Accordion>

<Accordion title="Tunnel `-> start ->` o Thread `<- start`  (chiamata a un `label`)" id="call">

Puoi eseguire un `knot` usando l'operatore Tunnels, rappresentato dalla sintassi `-> start ->`. Corrisponde alla <DynamicLink href="/start/labels#call-to-a-label">funzionalità `call`</DynamicLink> della libreria Pixi’VN.

```ink tab="ink"
-> guard_dialogue ->
```

```txt tab="CLI"
-> <knot_name> ->

where:
    knot_name = the name of the knot to call
```

Oppure, usando la sintassi Threads, scrivi il simbolo `\<-` seguito dal nome del `knot`:

```ink tab="ink"
<- guard_dialogue
```

```txt tab="CLI"
<- <knot_name>

where:
    knot_name = the name of the knot to call
```

:::tip[Threads]

A differenza di **ink nativo**, nell'**integrazione ink + Pixi’VN** i "Threads" non sono supportati, quindi il simbolo `\<-` corrisponde alla chiamata di un `knot` anziché funzionare come operatore "Thread".

:::

:::tip

Per semplicità, nell'**integrazione ink + Pixi’VN**, `->->` e `-> DONE` chiudono correttamente il `label`, quindi sono equivalenti.

:::

Ad esempio:

```ink title="ink/start.ink"
VAR reputation = 0

-> start
=== start ===
You are in the square.

* [Talk to the guard]
    -> guard_dialogue ->
    You return to the square.
    -> start
    You don't see this line because you are sent back to the city before.

* {reputation >= 1} [Ask for a favor]
    The guard helps you.
    -> END

=== guard_dialogue ===
The guard looks at you.

* [Greet]
    "Hello citizen."
    ~ reputation += 1
->->

* [Insult]
    "Hey you!"
    ~ reputation -= 1

->->
```

</Accordion>

## Altre funzionalità

<Accordions>

<Accordion title="Parametri" id="parameters">

Una forma particolarmente utile di variabile temporanea è il **parametro**. Qualsiasi knot o stitch può ricevere un valore come parametro, che viene trattato come una variabile temporanea locale all'interno di quel knot:

```ink title="ink/start.ink"
=== start ===
*   [Accuse Hastings]
        -> accuse("Hastings")
*   [Accuse Mrs Black]
        -> accuse("Claudia")
*   [Accuse myself]
        -> accuse("myself")

=== accuse(who) ===
    "I accuse {who}!" Poirot declared.
    "Really?" Japp replied. "{who == "myself":You did it?|{who}?}"
    "And why not?" Poirot shot back.
```

I parametri sono il modo corretto per passare un valore temporaneo da un knot o stitch a un altro, perché le normali variabili `temp` non sono accessibili al di fuori dello stitch in cui sono state dichiarate.

</Accordion>

<Accordion title="Knot ricorsivi con parametri" id="recursive-knots-with-parameters">

Le variabili temporanee (inclusi i parametri) possono essere utilizzate in sicurezza nei knot ricorsivi:

```ink title="ink/start.ink"
-> add_one_to_one_hundred(0, 1)

=== add_one_to_one_hundred(total, x) ===
    ~ total = total + x
    { x == 100:
        -> finished(total)
    - else:
        -> add_one_to_one_hundred(total, x + 1)
    }

=== finished(total) ===
    "The result is {total}!" you announce.
    -> END
```

</Accordion>

<Accordion title="Passare le destinazioni di deviazione come parametri" id="sending-divert-targets-as-parameters">

Anche gli indirizzi dei knot possono essere passati come parametri. Usa `->` per indicare che un parametro è una destinazione di deviazione:

```ink title="ink/start.ink"
=== sleeping_in_hut ===
    You lie down and close your eyes.
    -> generic_sleep(-> waking_in_the_hut)

=== generic_sleep(-> waking) ===
    You sleep perchance to dream etc. etc.
    -> waking

=== waking_in_the_hut ===
    You get back to your feet, ready to continue your journey.
```

</Accordion>

<Accordion title="Deviazione nello stesso `step`" id="diverting-in-the-same-step">

Per impostazione predefinita, una deviazione verso un altro `knot` viene eseguita nello `step` successivo, quindi il contenuto di destinazione viene mostrato solo quando il flusso prosegue:

```ink title="ink/start.ink"
=== start ===
It is, first and foremost...
-> add2

=== add2 ===
...a story about the twelve labors of Hercules.
-> DONE
```

Se la deviazione viene inserita subito dopo il testo, senza un'interruzione di riga, il `knot` di destinazione viene eseguito nello stesso `step` del testo precedente, quindi entrambi vengono mostrati insieme:

```ink title="ink/start.ink"
=== start ===
It is, first and foremost...-> add2

=== add2 ===
...a story about the twelve labors of Hercules.
-> DONE
```

</Accordion>

</Accordions>
