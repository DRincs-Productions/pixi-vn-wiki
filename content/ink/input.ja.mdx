---
title: 入力プロンプト
description: |
  Pixi’VN の「# script」を使って ink でプレイヤーにテキストや数値の入力を求め、物語の中でその結果を参照する方法を説明します。
---

***ink* + Pixi’VN 連携**では、ユーザーに <DynamicLink href="/start/input">入力プロンプト</DynamicLink> を表示するための「# script」が導入されています。 To do this, you need to use the following syntax:

```ink tab="ink"
# request input type string
```

```txt tab="CLI"
# request input [<parameters>]

where:
    parameters (Optional) = a space-separated list of property/value pairs. If a value contains spaces, wrap it in double quotes.
```

使用できる `parameters`（すべて省略可能）：[`type`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonInputRequest#valuetype)、[`default`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonInputRequest#defaultvalue)。

:::tip

入力された値はシステムキー `_input_value_` を使ってストレージに保存されるため、ink のコンテンツ内で `{ _input_value_ }` を参照できます。

:::

例：

```ink title="ink/start.ink"
=== start ===
Hello,
# request input type string // [!code focus]
<>what is your name?
My name is { _input_value_ } // [!code focus]
# request input type number default 18 // [!code focus]
How old are you?
I am { _input_value_ } years old // [!code focus]
# request input type "html textarea" // [!code focus]
Describe who you are:
{ _input_value_ } // [!code focus]
Restart
-> DONE
```
