Pixi’VN에서는 분기형 스토리를 위해 설계된 스크립팅 언어 ***ink***&#xB97C; 사용하여 인터랙티브 서사를 작성할 수 있습니다.

<Accordions>

<Accordion title="ink란 무엇인가요?" id="what-is-ink">

***ink***&#xB294; 인터랙티브 스토리를 위한 간단한 스크립팅 언어로, 80 Days, Heaven's Vault, Sorcery! 등의 게임에서 사용됩니다. 자세한 내용은 [*ink* 공식 웹사이트](https://www.inklestudios.com/ink/)에서 확인하세요.

</Accordion>

<Accordion title="왜 ink를 사용하나요?" id="why-use-ink">

서사를 **JavaScript/TypeScript**로 직접 작성하는 것은 특히 초보자에게 시간이 많이 들고 복잡할 수 있습니다. ***ink***&#xB294; 배우기도, 작성하기도 훨씬 쉽습니다.

처음 시작하는 개발자는 <DynamicLink href="/start#project-initialization">*ink* 템플릿</DynamicLink>으로 시작한 다음 고급 기능을 위해 JavaScript/TypeScript를 점차 배울 수 있습니다.

</Accordion>

</Accordions>

**_ink_와 Pixi’VN 통합**은 [inkjs](https://github.com/inkle/inkjs)와 [PixiVNJson](/jsdoc/pixi-vn-json)을 사용하여 ***ink* 코드**를 파싱하고 Pixi’VN이 해석할 수 있는 JSON을 생성합니다. 즉, JavaScript/TypeScript와 ***ink***&#xB294; 동일한 저장소와 캔버스를 공유하며, JavaScript/TypeScript에서 ***ink*** `knots`(또는 `labels`)를 실행하거나 반대로 실행할 수 있습니다. 두 방식의 장점을 모두 활용할 수 있습니다. 서사는 ***ink***&#xB85C; 작성하고, 미니게임이나 고급 애니메이션에는 JavaScript/TypeScript를 사용하세요.

```ink title="ink/start.ink"
=== start ===
We arrived into London at 9.45pm exactly.

* "There is not a moment to lose!"[] I declared.
 -> hurry_outside

* "Monsieur, let us savour this moment!"[] I declared.
 My master clouted me firmly around the head and dragged me out of the door.
 -> dragged_outside

* [We hurried home] -> hurry_outside

=== hurry_outside ===
We hurried home to Savile Row -> as_fast_as_we_could

=== dragged_outside ===
He insisted that we hurried home to Savile Row
-> as_fast_as_we_could

=== as_fast_as_we_could ===
<> as fast as we could.
-> start
```

## 설치

:::tip[템플릿]

새 Pixi’VN 프로젝트를 시작하시나요? _ink_가 이미 포함된 <DynamicLink href="/start#project-initialization">템플릿</DynamicLink>을 사용하세요.

:::

기존 JavaScript 프로젝트에 *ink* 패키지를 설치하려면 다음 명령어 중 하나를 사용하세요:

```npm
npm install @drincs/pixi-vn @drincs/pixi-vn-ink
```

### 초기화

설치 후 [`importInkText`](/jsdoc/pixi-vn-ink/index/functions/importInkText)를 사용하여 ***ink* 스크립트**를 불러오세요:

```typescript title="main.ts"
import { importInkText } from '@drincs/pixi-vn-ink'

const inkText = `
=== start ===
Hello
-> END
`

importInkText([inkText, ...])
```

이제 <DynamicLink href="/start/labels#run-a-label">Pixi’VN 함수</DynamicLink>를 사용하여 ***ink* `knot`**(또는 `label`)를 실행할 수 있습니다:

```typescript title="main.ts"
import { narration } from "@drincs/pixi-vn";

narration.call(`start`, {});
```

<Accordion title=".ink 파일에서 텍스트 가져오기" id="import-ink-files">

:::tip

이 가이드는 [Vite](https://vitejs.dev/)를 사용하지만 같은 방식은 다른 환경에도 적용할 수 있습니다.

:::

`.ink` 파일을 가져오려면 프로젝트에서 해당 파일을 텍스트 파일로 처리하도록 설정해야 합니다.

다음 단계를 따르세요:

* `ink.d.ts`에서 `*.ink` 모듈을 선언하세요.
* `vite.config.ts`의 `assetsInclude`에 `.ink`를 추가하세요.
* 파일에 `?raw`를 붙여 가져오면 텍스트 내용을 얻을 수 있습니다.

```ts tab="main.ts"
import { importInkText } from '@drincs/pixi-vn-ink'
import startLabel from './ink/start.ink?raw'

importInkText([startLabel, ...])
```

```ts tab="vite.config.ts"
export default defineConfig({
    // ...
    assetsInclude: ["**/*.ink"],
});
```

```ts tab="ink.d.ts"
declare module "*.ink" {
    const value: string;
    export default value;
}
```

</Accordion>

<Accordion title="Vite.js 플러그인" id="vite-plugin">

개발 편의성을 높이려면 [`vitePluginInk`](https://pixi-vn.com/jsdoc/pixi-vn-ink/vite/functions/vitePluginInk)를 사용하세요:

```ts tab="vite.config.ts"
import { defineConfig } from "vite";
import { vitePluginInk } from "@drincs/pixi-vn-ink/vite";
export default defineConfig({
    // ...
    plugins: [
        // other plugins...
        vitePluginInk(),
    ],
});
```

```ts tab="main.ts"
import { setupInkHmrListener } from "@drincs/pixi-vn-ink/vite-listener";

setupInkHmrListener();
```

```ts tab="utils/ink-utility.ts"
async function getInkText() {
    const files = import.meta.glob<string>("../ink/*.ink", {
        eager: true,
        import: "default",
    });
    return await Promise.all(
        Object.values(files).map(async (importFile) => {
            return importFile;
        }),
    );
}
```

<Accordion title="기본 해시태그 명령 활성화" id="base-hashtag-commands">

Pixi’VN에는 캔버스와 상호작용하는 기본 `#` 명령(예: `# show`, `# moveIn` 등)인 <DynamicLink href="/ink/hashtag">Hashtag Commands</DynamicLink>가 내장되어 있지만 **자동으로 등록되지는 않습니다**. 활성화하려면 앱 설정 중에 [`addBaseHashtagCommands`](/jsdoc/pixi-vn-ink/index/functions/addBaseHashtagCommands)를 한 번 호출하세요.

```ts title="content/ink/hashtag-commands.ts"
import { addBaseHashtagCommands } from "@drincs/pixi-vn-ink";

addBaseHashtagCommands();
```

</Accordion>

## Pixi’VN에서 무시하는 구문

일부 *ink* 구문은 Pixi’VN에서 무시됩니다. ***ink* 스크립트**에서 사용할 수는 있지만(예: Inky 편집기에서 테스트할 때) Pixi’VN은 이러한 구문을 무시합니다.

<Accordions>

<Accordion title="INCLUDE" id="include">

`INCLUDE`는 다른 *ink* 파일을 포함하는 *ink* 명령문입니다. Pixi’VN에서는 여러 *ink* 파일을 불러올 때 [`importInkText`](/jsdoc/pixi-vn-ink/index/functions/importInkText)를 대신 사용해야 하므로 `INCLUDE`는 무시됩니다.

</Accordion>

<Accordion title="함수 정의" id="function-definitions">

함수 정의는 Pixi’VN에서 무시됩니다. 자세한 내용은 <DynamicLink href="/ink/functions">함수</DynamicLink> 페이지를 참고하세요.

</Accordion>

<Accordion title="knots 외부의 서사" id="narration-outside-the-knots">

변수를 제외하고 `knots`(또는 `labels`) 외부에 있는 서사는 무시됩니다.

예를 들어:

```ink title="ink"
VAR my_var = false // ✅ This will be handled (because it is a variable)
Hello // ❌ This will be ignored  [!code warning]
-> start // ❌ This will be ignored [!code warning]
=== start === // ✅ This will be handled
My name is John // ✅ This will be handled
-> DONE // ✅ This will be handled
```

</Accordion>

</Accordions>

## 기타 기능

<Accordions>

<Accordion title="기본 ink와 Pixi’VN ink의 차이점" id="ink-differences">

* **LIST 항목 접근**: 기본 ***ink***&#xC5D0;서는 목록 항목을 짧은 이름(예: `sword`)이나 정규화된 이름(예: `items.sword`)으로 참조할 수 있으며 둘은 동일합니다. **Pixi’VN *ink***&#xC5D0;서는 정규화된 형식인 `items.sword`를 **항상** 사용해야 합니다. `sword`만 입력하면 키가 문자열 `"sword"`인 일반 저장소 항목으로 해석되며, 목록 항목을 가리키는 것은 **아닙니다**. 이 규칙은 모든 `LIST` 선언에 적용됩니다.

* Pixi’VN은 "Threads"를 지원하지 않으므로 `\<-` 기호는 <DynamicLink href="/ink/labels#call">knot 호출</DynamicLink>에 해당합니다.

* 이 경우:

  ```ink title="ink"
  { shuffle:
    -  2 of Diamonds.
      'You lose this time!' crowed the croupier.
  }
  ```

  **기본 *ink***&#xC5D0;서는 서로 다른 두 대화가 표시됩니다. 첫 번째는 `2 of Diamonds.`, 두 번째는 `'You lose this time!' crowed the croupier.`입니다.

  **Pixi’VN *ink***&#xC5D0;서는 서로 다른 두 대화가 아니라 다음 대화가 표시됩니다: `2 of Diamonds.\n\n'You lose this time!' crowed the croupier.`. <DynamicLink href="/ink/markup#markdown-on-ink">Markdown</DynamicLink>에서는 다음과 같이 표시됩니다:

  ```txt
  2 of Diamonds.
  'You lose this time!' crowed the croupier.
  ```

* `weave`(다음 예에서는 `shove`)가 한 번만 선택할 수 있는 선택지에 연결되어 있고 `-> shove`로 열리더라도 해당 선택지가 무효화되지는 않습니다. 선택지를 무효화하려면 평소처럼 직접 선택해야 합니다.

  예시는 다음과 같습니다:

  ```ink title="ink"
  -> start
  === start ===
  * [1] -> shove
  * (shove) [2] 2
  * {shove} [3] -> END
  -  -> start
  -> DONE
  ```

  선택지 `1`을 선택한 경우 두 번째로 `start`를 열면:

  * **기본 *ink***&#xB97C; 사용하면 선택지 `3`만 선택할 수 있습니다. 선택지 `2`는 한 번만 선택할 수 있으므로, **기본 *ink***&#xB294; `-> shove`를 통해 이미 해당 선택을 했다고 판단하여 숨깁니다.
  * **Pixi’VN *ink***&#xB97C; 사용하면 선택지 `2` 또는 `3`을 선택할 수 있습니다. 선택지 `2`는 숨겨지지 않습니다. **Pixi’VN *ink***&#xB294; `shove`가 선택지와 연결되어 있다는 사실을 모르기 때문입니다.

  **기본 *ink***&#xC640; **Pixi’VN *ink*** 모두에서 `start`가 같은 방식으로 동작하게 하려면 다음 코드를 작성해야 합니다:

  ```ink title="ink"
  -> start
  === start ===
  * [1] -> shove
  * (shove) {!shove} [2] 2
  * {shove} [3] -> END
  -  -> start
  -> DONE
  ```

</Accordion>

</Accordions>
