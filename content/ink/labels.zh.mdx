<Accordion title="什么是 `knot`？" id="what-is-a-knot">

如[官方文档](https://www.inklestudios.com/ink/web-tutorial/)所述，故事由多个相互连接的部分组成，在 ***ink* 术语**中，这些部分称为 `knots`。在 ***ink*** 中，`knot` 的开头通过在 `knot` 名称左侧添加至少两个等号来标识，也可以选择在右侧添加等号。

```ink tab="ink"
=== london ===
```

```txt tab="CLI"
=== <knot_name> ===

where:
    knot_name = the name of the knot
```

</Accordion>

<Accordion title="`label` 和 `knot` 有什么区别吗？" id="label-vs-knot">

没有，它们是同一个概念。在 Pixi’VN 中，当你使用 ***ink*** 创建 `knot` 时，系统会在内部创建一个 `label` 并将其保存到注册表中。

</Accordion>

</Accordions>

## 执行 knot

你可以通过以下方法执行 `knot`：

<Accordions>

<Accordion title="Diverts `-> start`（跳转到 `label`）" id="jump">

你可以使用 Divert 运算符执行 `knot`，其语法为 `-> start`。这对应 Pixi’VN 库中的 <DynamicLink href="/start/labels#jump-to-a-label">`jump` 功能</DynamicLink>。

```ink tab="ink"
-> after
```

```txt tab="CLI"
-> <knot_name>

where:
    knot_name = the name of the knot to jump to
```

例如：

```ink title="ink/start.ink"
=== start ===
Start
-> after

=== after ===
After
End
-> DONE
```

<PixiVnExample path="ink/narration/jump" ink />

</Accordion>

<Accordion title="Tunnels `-> start ->` 或 Threads `<- start`  （调用 `label`）" id="call">

你可以使用 Tunnels 运算符执行 `knot`，其语法为 `-> start ->`。这对应 Pixi’VN 库中的 <DynamicLink href="/start/labels#call-to-a-label">`call` 功能</DynamicLink>。

```ink tab="ink"
-> guard_dialogue ->
```

```txt tab="CLI"
-> <knot_name> ->

where:
    knot_name = the name of the knot to call
```

或者，使用 Threads 语法，在 `\<-` 符号后面写上 `knot` 的名称：

```ink tab="ink"
<- guard_dialogue
```

```txt tab="CLI"
<- <knot_name>

where:
    knot_name = the name of the knot to call
```

:::tip[Threads]

与**原生 ink** 不同，**ink + Pixi’VN 集成**不支持“Threads”，因此 `\<-` 符号表示调用 `knot`，而不是使用“Thread”运算符。

:::

:::tip

为简化操作，在 **ink + Pixi’VN 集成**中，`->->` 和 `-> DONE` 都能正确结束 `label`，因此两者是等效的。

:::

例如：

```ink title="ink/start.ink"
VAR reputation = 0

-> start
=== start ===
You are in the square.

* [Talk to the guard]
    -> guard_dialogue ->
    You return to the square.
    -> start
    You don't see this line because you are sent back to the city before.

* {reputation >= 1} [Ask for a favor]
    The guard helps you.
    -> END

=== guard_dialogue ===
The guard looks at you.

* [Greet]
    "Hello citizen."
    ~ reputation += 1
->->

* [Insult]
    "Hey you!"
    ~ reputation -= 1

->->
```

</Accordion>

## 其他功能

<Accordions>

<Accordion title="参数" id="parameters">

**参数**是一种特别有用的临时变量。任何 knot 或 stitch 都可以接收一个值作为参数，该值将在对应 knot 内被视为局部临时变量：

```ink title="ink/start.ink"
=== start ===
*   [Accuse Hastings]
        -> accuse("Hastings")
*   [Accuse Mrs Black]
        -> accuse("Claudia")
*   [Accuse myself]
        -> accuse("myself")

=== accuse(who) ===
    "I accuse {who}!" Poirot declared.
    "Really?" Japp replied. "{who == "myself":You did it?|{who}?}"
    "And why not?" Poirot shot back.
```

参数是在不同 knot 或 stitch 之间传递临时值的正确方式，因为普通的 `temp` 变量无法在声明它们的 stitch 之外访问。

</Accordion>

<Accordion title="带参数的递归 knots" id="recursive-knots-with-parameters">

临时变量（包括参数）可以安全地用于递归 knots 中：

```ink title="ink/start.ink"
-> add_one_to_one_hundred(0, 1)

=== add_one_to_one_hundred(total, x) ===
    ~ total = total + x
    { x == 100:
        -> finished(total)
    - else:
        -> add_one_to_one_hundred(total, x + 1)
    }

=== finished(total) ===
    "The result is {total}!" you announce.
    -> END
```

</Accordion>

<Accordion title="将跳转目标作为参数传递" id="sending-divert-targets-as-parameters">

knot 的地址也可以作为参数传递。使用 `->` 表示某个参数是跳转目标：

```ink title="ink/start.ink"
=== sleeping_in_hut ===
    You lie down and close your eyes.
    -> generic_sleep(-> waking_in_the_hut)

=== generic_sleep(-> waking) ===
    You sleep perchance to dream etc. etc.
    -> waking

=== waking_in_the_hut ===
    You get back to your feet, ready to continue your journey.
```

</Accordion>

<Accordion title="在同一个 `step` 内跳转" id="diverting-in-the-same-step">

默认情况下，跳转到另一个 `knot` 的操作会在下一个 `step` 执行，因此只有在流程继续后，才会显示跳转目标的内容：

```ink title="ink/start.ink"
=== start ===
It is, first and foremost...
-> add2

=== add2 ===
...a story about the twelve labors of Hercules.
-> DONE
```

如果将跳转语句直接放在文本之后，中间不换行，那么目标 `knot` 会与前面的文本在同一个 `step` 中执行，因此两者会一起显示：

```ink title="ink/start.ink"
=== start ===
It is, first and foremost...-> add2

=== add2 ===
...a story about the twelve labors of Hercules.
-> DONE
```

</Accordion>

</Accordions>
