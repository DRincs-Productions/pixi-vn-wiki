---
title: Запрос ввода
description: |
  Как запросить у игрока ввод текста или числа в ink с помощью «# script» Pixi’VN и использовать полученное значение в повествовании.
---

**Интеграция *ink* + Pixi’VN** добавляет «# script», позволяющий показать пользователю <DynamicLink href="/start/input">запрос ввода</DynamicLink>. To do this, you need to use the following syntax:

```ink tab="ink"
# request input type string
```

```txt tab="CLI"
# request input [<parameters>]

where:
    parameters (Optional) = a space-separated list of property/value pairs. If a value contains spaces, wrap it in double quotes.
```

Доступные `parameters` (все необязательны): [`type`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonInputRequest#valuetype), [`default`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonInputRequest#defaultvalue).

:::tip

Введённое значение сохраняется в хранилище под системным ключом `_input_value_`, поэтому на него можно ссылаться в содержимом ink через `{ _input_value_ }`.

:::

Например:

```ink title="ink/start.ink"
=== start ===
Hello,
# request input type string // [!code focus]
<>what is your name?
My name is { _input_value_ } // [!code focus]
# request input type number default 18 // [!code focus]
How old are you?
I am { _input_value_ } years old // [!code focus]
# request input type "html textarea" // [!code focus]
Describe who you are:
{ _input_value_ } // [!code focus]
Restart
-> DONE
```
