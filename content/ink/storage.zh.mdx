---
title: 存储
description: 了解如何使用 Pixi’VN 存储在 ink 中定义、设置和获取全局变量与临时变量。
---

:::tip

有关在 ink 中使用变量的更多信息，请参阅[官方文档](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md#part-3-variables-and-logic)。

:::

***ink*** 还支持临时变量和全局变量，可用于存储数值、内容，甚至控制故事流程的命令。它具备完善的逻辑功能，还提供额外的结构，帮助更好地组织分支故事中通常较为复杂的逻辑。

在 ***ink* 与 Pixi’VN 的集成**中，`VAR` 和 `CONST` 变量相当于<DynamicLink href="/start/storage">存储变量</DynamicLink>，而 `temp` 变量相当于<DynamicLink href="/start/storage#temporary-storage">存储中的临时变量</DynamicLink>。

***ink*** 变量的名称对应于<DynamicLink href="/start/storage">存储</DynamicLink>中变量的键。

## Define

:::tip

在 JavaScript/TypeScript 中，此功能对应于 <DynamicLink href="/start/storage#default-storage-variables">“默认存储变量”</DynamicLink>。

:::

可以使用以下代码在 ***ink*** 中定义变量：

```ink tab="ink"
VAR myVariable = 42
```

```txt tab="CLI"
VAR <variable_name> = <value>

where:
    variable_name = the name of the variable
    value = the initial value of the variable
```

## 设置

:::tip

在 JavaScript/TypeScript 中，此功能对应于 <DynamicLink href="/start/storage#set">`storage.set`</DynamicLink>。

:::

可以使用以下代码在 ***ink*** 中设置变量的值：

```ink tab="ink"
~ myVariable = 100
```

```txt tab="CLI"
~ <variable_name> = <value>

where:
    variable_name = the name of an already declared variable
    value = the new value to assign
```

## 获取

:::tip

在 JavaScript/TypeScript 中，此功能对应于 <DynamicLink href="/start/storage#get">`storage.get`</DynamicLink>。

:::

在 ink 中，变量可以用于不同的目的。根据用途不同，获取变量值的方式也有所不同。

```ink tab="ink"
The value of myDuration is: {myDuration}
```

```txt tab="CLI"
{<variable_name>}

where:
    variable_name = the name of the variable to print or evaluate
```

例如：

```ink title="ink"
The value of myDuration is: {myDuration}
# show image bg /image.png with dissolve duration {myDuration}
{myDuration > 5:
    The duration is greater than 5.
- else:
    The duration is 5 or less.
}
```
