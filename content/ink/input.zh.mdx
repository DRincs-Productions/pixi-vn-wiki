---
title: 输入提示
description: |
  如何使用 Pixi’VN 的“# script”在 ink 中请求玩家输入文本或数字，并在叙事内容中访问输入结果。
---

***ink* + Pixi’VN 集成**引入了一个“# script”，可向用户显示<DynamicLink href="/start/input">输入提示</DynamicLink>。 To do this, you need to use the following syntax:

```ink tab="ink"
# request input type string
```

```txt tab="CLI"
# request input [<parameters>]

where:
    parameters (Optional) = a space-separated list of property/value pairs. If a value contains spaces, wrap it in double quotes.
```

可用的 `parameters`（均为可选）：[`type`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonInputRequest#valuetype)、[`default`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonInputRequest#defaultvalue)。

:::tip

输入的值会以系统键 `_input_value_` 保存在存储中，因此你可以在 ink 内容中通过 `{ _input_value_ }` 引用它。

:::

例如：

```ink title="ink/start.ink"
=== start ===
Hello,
# request input type string // [!code focus]
<>what is your name?
My name is { _input_value_ } // [!code focus]
# request input type number default 18 // [!code focus]
How old are you?
I am { _input_value_ } years old // [!code focus]
# request input type "html textarea" // [!code focus]
Describe who you are:
{ _input_value_ } // [!code focus]
Restart
-> DONE
```
