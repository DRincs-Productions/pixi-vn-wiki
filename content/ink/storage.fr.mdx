:::tip

Vous trouverez plus d’informations sur l’utilisation des variables dans ink dans la [documentation officielle](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md#part-3-variables-and-logic).

:::

***ink*** prend également en charge les variables temporaires et globales, qui permettent de stocker des données numériques, du contenu ou même des commandes contrôlant le déroulement de l’histoire. Son système logique est complet et comprend également des structures supplémentaires qui facilitent l’organisation de la logique souvent complexe d’un récit à embranchements.

Dans l’**intégration de *ink* avec Pixi’VN**, les variables `VAR` et `CONST` correspondent aux <DynamicLink href="/start/storage">variables du stockage</DynamicLink>, tandis que les variables `temp` correspondent aux <DynamicLink href="/start/storage#temporary-storage">variables temporaires du stockage</DynamicLink>.

Le nom des variables ***ink*** correspond à la clé d’une variable dans le <DynamicLink href="/start/storage">stockage</DynamicLink>.

## Define

:::tip

En JavaScript/TypeScript, cette fonctionnalité correspond aux <DynamicLink href="/start/storage#default-storage-variables">« Variables de stockage par défaut »</DynamicLink>.

:::

Vous pouvez définir une variable dans ***ink*** avec le code suivant :

```ink tab="ink"
VAR myVariable = 42
```

```txt tab="CLI"
VAR <variable_name> = <value>

where:
    variable_name = the name of the variable
    value = the initial value of the variable
```

## Définir

:::tip

En JavaScript/TypeScript, cette fonctionnalité correspond à <DynamicLink href="/start/storage#set">`storage.set`</DynamicLink>.

:::

Vous pouvez attribuer une valeur à une variable dans ***ink*** avec le code suivant :

```ink tab="ink"
~ myVariable = 100
```

```txt tab="CLI"
~ <variable_name> = <value>

where:
    variable_name = the name of an already declared variable
    value = the new value to assign
```

## Obtenir

:::tip

En JavaScript/TypeScript, cette fonctionnalité correspond à <DynamicLink href="/start/storage#get">`storage.get`</DynamicLink>.

:::

Dans ink, les variables peuvent servir à différents usages. Pour chacun de ces usages, la façon d’obtenir la valeur d’une variable est différente.

```ink tab="ink"
The value of myDuration is: {myDuration}
```

```txt tab="CLI"
{<variable_name>}

where:
    variable_name = the name of the variable to print or evaluate
```

Par exemple :

```ink title="ink"
The value of myDuration is: {myDuration}
# show image bg /image.png with dissolve duration {myDuration}
{myDuration > 5:
    The duration is greater than 5.
- else:
    The duration is 5 or less.
}
```
