---
title: Solicitud de entrada
description: |
  Cómo solicitar al jugador que introduzca texto o un número en ink mediante el "# script" de Pixi’VN y acceder al resultado desde la narración.
---

La **integración de *ink* + Pixi’VN** introduce un "# script" que permite mostrar al usuario una <DynamicLink href="/start/input">solicitud de entrada</DynamicLink>. To do this, you need to use the following syntax:

```ink tab="ink"
# request input type string
```

```txt tab="CLI"
# request input [<parameters>]

where:
    parameters (Optional) = a space-separated list of property/value pairs. If a value contains spaces, wrap it in double quotes.
```

`parameters` disponibles (todos opcionales): [`type`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonInputRequest#valuetype), [`default`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonInputRequest#defaultvalue).

:::tip

El valor introducido se guarda en el almacenamiento con la clave del sistema `_input_value_`, por lo que puedes hacer referencia a `{ _input_value_ }` en tu contenido de ink.

:::

Por ejemplo:

```ink title="ink/start.ink"
=== start ===
Hello,
# request input type string // [!code focus]
<>what is your name?
My name is { _input_value_ } // [!code focus]
# request input type number default 18 // [!code focus]
How old are you?
I am { _input_value_ } years old // [!code focus]
# request input type "html textarea" // [!code focus]
Describe who you are:
{ _input_value_ } // [!code focus]
Restart
-> DONE
```
