Pixi’VN 允许你使用 ***ink*** 编写交互式叙事，这是一种专为分支故事设计的脚本语言。

<Accordions>

<Accordion title="什么是 ink？" id="what-is-ink">

***ink*** 是一种用于交互式故事的简单脚本语言，在 80 Days、Heaven's Vault 和 Sorcery! 等游戏中得到了应用。你可以在 [*ink* 官方网站](https://www.inklestudios.com/ink/)了解更多信息。

</Accordion>

<Accordion title="为什么使用 ink？" id="why-use-ink">

直接使用 **JavaScript/TypeScript** 编写叙事可能既费时又复杂，尤其是对初学者而言。 ***ink*** 则更容易学习和编写。

新手开发者可以先使用 <DynamicLink href="/start#project-initialization">*ink* 模板</DynamicLink>，再逐步学习 JavaScript/TypeScript 以实现高级功能。

</Accordion>

</Accordions>

***ink* 与 Pixi’VN 的集成**使用 [inkjs](https://github.com/inkle/inkjs) 和 [PixiVNJson](/jsdoc/pixi-vn-json) 解析 ***ink* 代码**，并生成 Pixi’VN 可以理解的 JSON。这意味着 JavaScript/TypeScript 与 ***ink*** 共享相同的存储空间和画布，你可以从 JavaScript/TypeScript 启动 ***ink*** 的 `knots`（或 `labels`），反之亦然。你可以兼得两者的优势：使用 ***ink*** 编写叙事，使用 JavaScript/TypeScript 制作小游戏或高级动画。

```ink title="ink/start.ink"
=== start ===
We arrived into London at 9.45pm exactly.

* "There is not a moment to lose!"[] I declared.
 -> hurry_outside

* "Monsieur, let us savour this moment!"[] I declared.
 My master clouted me firmly around the head and dragged me out of the door.
 -> dragged_outside

* [We hurried home] -> hurry_outside

=== hurry_outside ===
We hurried home to Savile Row -> as_fast_as_we_could

=== dragged_outside ===
He insisted that we hurried home to Savile Row
-> as_fast_as_we_could

=== as_fast_as_we_could ===
<> as fast as we could.
-> start
```

## 安装

:::tip[模板]

准备开始一个新的 Pixi’VN 项目吗？使用已经包含 *ink* 的<DynamicLink href="/start#project-initialization">模板</DynamicLink>。

:::

要在现有的 JavaScript 项目中安装 *ink* 软件包，请使用以下命令之一：

```npm
npm install @drincs/pixi-vn @drincs/pixi-vn-ink
```

### 初始化

安装后，使用 [`importInkText`](/jsdoc/pixi-vn-ink/index/functions/importInkText) 加载你的 ***ink* 脚本**：

```typescript title="main.ts"
import { importInkText } from '@drincs/pixi-vn-ink'

const inkText = `
=== start ===
Hello
-> END
`

importInkText([inkText, ...])
```

现在，你可以使用 <DynamicLink href="/start/labels#run-a-label">Pixi’VN 函数</DynamicLink>运行 ***ink* 的 `knot`**（或 `label`）：

```typescript title="main.ts"
import { narration } from "@drincs/pixi-vn";

narration.call(`start`, {});
```

<Accordion title="从 .ink 文件导入文本" id="import-ink-files">

:::tip

本指南使用 [Vite](https://vitejs.dev/)，但相同的原理也适用于其他环境。

:::

要导入 `.ink` 文件，需要配置项目以将它们作为文本文件处理。

具体步骤如下：

* 在 `ink.d.ts` 中声明 `*.ink` 模块。
* 在 `vite.config.ts` 的 `assetsInclude` 中添加 `.ink`。
* 使用 `?raw` 导入文件，以获取其文本内容。

```ts tab="main.ts"
import { importInkText } from '@drincs/pixi-vn-ink'
import startLabel from './ink/start.ink?raw'

importInkText([startLabel, ...])
```

```ts tab="vite.config.ts"
export default defineConfig({
    // ...
    assetsInclude: ["**/*.ink"],
});
```

```ts tab="ink.d.ts"
declare module "*.ink" {
    const value: string;
    export default value;
}
```

</Accordion>


```ts tab="main.ts"
import { setupInkHmrListener } from "@drincs/pixi-vn-ink/vite-listener";

```

```ts tab="utils/ink-utility.ts"
async function getInkText() {
    const files = import.meta.glob<string>("../ink/*.ink", {
        eager: true,
        import: "default",
    });
    return await Promise.all(
        Object.values(files).map(async (importFile) => {
            return importFile;
        }),
    );
}
```

<Accordion title="启用基础井号命令" id="base-hashtag-commands">

Pixi’VN 内置了一组 <DynamicLink href="/ink/hashtag">Hashtag Commands</DynamicLink>（用于与画布交互的默认 `#` 命令，例如 `# show`、`# moveIn` 等），但它们**不会自动注册**。在应用设置过程中调用一次 [`addBaseHashtagCommands`](/jsdoc/pixi-vn-ink/index/functions/addBaseHashtagCommands)，即可启用这些命令。

```ts title="content/ink/hashtag-commands.ts"
import { addBaseHashtagCommands } from "@drincs/pixi-vn-ink";

addBaseHashtagCommands();
```

## Pixi’VN 忽略的语法

Pixi’VN 会忽略部分 *ink* 语法。你可以在 ***ink* 脚本**中使用这些语法（例如在 Inky 编辑器中进行测试），但 Pixi’VN 会忽略它们。

<Accordions>

<Accordion title="INCLUDE" id="include">

`INCLUDE` 是 *ink* 中用于包含另一个 *ink* 文件的语句。在 Pixi’VN 中，你应改用 [`importInkText`](/jsdoc/pixi-vn-ink/index/functions/importInkText) 加载多个 *ink* 文件，因此 `INCLUDE` 会被忽略。

</Accordion>

<Accordion title="函数定义" id="function-definitions">

Pixi’VN 会忽略函数定义。你可以在 <DynamicLink href="/ink/functions">函数</DynamicLink>页面了解更多信息。

</Accordion>

<Accordion title="knots 外部的叙事" id="narration-outside-the-knots">

除了变量之外，`knots`（或 `labels`）外部的叙事内容都会被忽略。

例如：

```ink title="ink"
VAR my_var = false // ✅ This will be handled (because it is a variable)
Hello // ❌ This will be ignored  [!code warning]
-> start // ❌ This will be ignored [!code warning]
=== start === // ✅ This will be handled
My name is John // ✅ This will be handled
-> DONE // ✅ This will be handled
```

</Accordion>

## 其他功能

<Accordions>

<Accordion title="原生 ink 与 Pixi’VN ink 的区别" id="ink-differences">

* **LIST 条目访问**：在原生 ***ink*** 中，可以使用简短名称（例如 `sword`）或限定名称（例如 `items.sword`）引用列表条目，两者等效。在 **Pixi’VN *ink*** 中，**始终**必须使用限定形式 `items.sword`。仅写 `sword` 会解析为键为字符串 `"sword"` 的普通存储条目，**不会**指向列表成员。这适用于所有 `LIST` 声明。

* 由于 Pixi’VN 不支持“Threads”，`\<-` 符号相当于 <DynamicLink href="/ink/labels#call">调用 knot</DynamicLink>。

* 在这种情况下：

  ```ink title="ink"
  { shuffle:
    -  2 of Diamonds.
      'You lose this time!' crowed the croupier.
  }
  ```

  **在原生 *ink* 中**，你会看到两段不同的对话：第一段是 `2 of Diamonds.`，第二段是 `'You lose this time!' crowed the croupier.`。

  **在 Pixi’VN *ink* 中**，你不会看到两段独立的对话，而是以下内容：`2 of Diamonds.\n\n'You lose this time!' crowed the croupier.`。在 <DynamicLink href="/ink/markup#markdown-on-ink">Markdown</DynamicLink> 中，它会这样显示：

  ```txt
  2 of Diamonds.
  'You lose this time!' crowed the croupier.
  ```

* 如果一个 `weave`（在下例中为 `shove`）与一次性选项关联，并通过 `-> shove` 打开，那么该选项不会因此失效。要使其失效，你仍需按正常方式选择该选项。

  例如：

  ```ink title="ink"
  -> start
  === start ===
  * [1] -> shove
  * (shove) [2] 2
  * {shove} [3] -> END
  -  -> start
  -> DONE
  ```

  如果你选择了选项 `1`，那么第二次打开 `start` 时：

  * 如果使用**原生 *ink***，你只能选择选项 `3`。选项 `2` 会被隐藏，因为**原生 *ink***&#x77E5;道你已通过 `-> shove` 做出过这个一次性选择。
  * 如果使用 **Pixi’VN *ink***，你可以选择选项 `2` 或 `3`。选项 `2` 不会被隐藏，因为 **Pixi’VN *ink*** 不知道 `shove` 与某个选项相关联。

  要让 `start` 在**原生 *ink***&#x548C; **Pixi’VN *ink*** 中具有相同的逻辑，你需要编写以下代码：

  ```ink title="ink"
  -> start
  === start ===
  * [1] -> shove
  * (shove) {!shove} [2] 2
  * {shove} [3] -> END
  -  -> start
  -> DONE
  ```
