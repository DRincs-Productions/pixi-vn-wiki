***ink* と Pixi’VN の連携**では、テキストに <DynamicLink href="/start/markup-markdown">マークアップ</DynamicLink> を導入するコンポーネントを使いやすくする追加機能が提供されます。

## 改行

改行するには、エスケープ文字 `\n` を使用できます。

<Callout>

この場合、Markdown で改行を表示するには、`\n\n` のように二つの改行指定が必要です。

</Callout>

例：

```ink title="ink"
=== start ===
Hello, this is a test. \\n\\n This is a new line.
```

## Markdown

Pixi’VN では、テキストの装飾に Markdown を使用することを推奨します。プロジェクトに <DynamicLink href="/start/markup-markdown">Markdown を実装している</DynamicLink>場合、***ink*** 内のテキストを Markdown 構文で装飾できます。

その際、Markdown 構文の多くの記号は ***ink* の構文** でも使用されることに注意してください。たとえば `#`、`*`、`/`、`~`、`-`、`|` などです。競合を避けるには、Markdown の記号の前にエスケープ文字 `\` を置きます。

例：

```ink title="ink"
Hello, this is some *italic* text and this is some **bold** text.
```

## CSS

HTML と Tailwind CSS のクラスを使ってテキストを装飾することもできます。

例：

```ink title="ink"
<span class="inline-block text-blue-500">some *blue* text</span>.
<span class="inline-block text-red-500">some *red* text</span>.
<span class="inline-block text-green-500">some *green* text</span>.
```
