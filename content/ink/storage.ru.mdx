:::tip

Подробнее об использовании переменных в ink можно прочитать в [официальной документации](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md#part-3-variables-and-logic).

***ink*** также поддерживает временные и глобальные переменные, в которых можно хранить числа, данные и даже команды управления ходом истории. Он предоставляет полноценные средства работы с логикой и дополнительные конструкции, которые помогают упорядочить зачастую сложную логику разветвлённого сюжета.

При **интеграции *ink* с Pixi’VN** переменные `VAR` и `CONST` соответствуют <DynamicLink href="/start/storage">переменным в хранилище</DynamicLink>, а переменные `temp` — <DynamicLink href="/start/storage#temporary-storage">временным переменным в хранилище</DynamicLink>.

Имя переменной в ***ink*** соответствует ключу переменной в <DynamicLink href="/start/storage">хранилище</DynamicLink>.

## Define

:::tip

В JavaScript/TypeScript эта возможность соответствует <DynamicLink href="/start/storage#default-storage-variables">«Переменным хранилища по умолчанию»</DynamicLink>.

:::

В ***ink*** можно определить переменную с помощью следующего кода:

```ink tab="ink"
VAR myVariable = 42
```

```txt tab="CLI"
VAR <variable_name> = <value>

where:
    variable_name = the name of the variable
    value = the initial value of the variable
```

## Установка

:::tip

В JavaScript/TypeScript эта возможность соответствует <DynamicLink href="/start/storage#set">`storage.set`</DynamicLink>.

:::

В ***ink*** можно задать значение переменной с помощью следующего кода:

```ink tab="ink"
~ myVariable = 100
```

```txt tab="CLI"
~ <variable_name> = <value>

where:
    variable_name = the name of an already declared variable
    value = the new value to assign
```

## Получить

:::tip

В JavaScript/TypeScript эта возможность соответствует <DynamicLink href="/start/storage#get">`storage.get`</DynamicLink>.

:::

В ink переменные можно использовать для разных целей. В зависимости от назначения переменной способы получения её значения различаются.

```ink tab="ink"
The value of myDuration is: {myDuration}
```

```txt tab="CLI"
{<variable_name>}

where:
    variable_name = the name of the variable to print or evaluate
```

Например:

```ink title="ink"
The value of myDuration is: {myDuration}
# show image bg /image.png with dissolve duration {myDuration}
{myDuration > 5:
    The duration is greater than 5.
- else:
    The duration is 5 or less.
}
```
