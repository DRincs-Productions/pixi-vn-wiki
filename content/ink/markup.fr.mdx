L’**intégration d’*ink* à Pixi’VN** offre des fonctionnalités supplémentaires pour faciliter l’utilisation de composants qui introduisent du <DynamicLink href="/start/markup-markdown">balisage</DynamicLink> dans le texte.

## Retours à la ligne

Pour créer un retour à la ligne, vous pouvez utiliser le caractère d’échappement `\n`.

<Callout>

Dans notre cas, comme nous utilisons Markdown pour afficher le retour à la ligne, il nous en faut deux : `\n\n`.

</Callout>

Par exemple :

```ink title="ink"
=== start ===
Hello, this is a test. \\n\\n This is a new line.
```

## Markdown

Dans Pixi’VN, il est recommandé d’utiliser Markdown pour mettre en forme votre texte. Si vous avez <DynamicLink href="/start/markup-markdown">implémenté Markdown dans votre projet</DynamicLink>, vous pourrez utiliser la syntaxe Markdown pour mettre en forme votre texte dans ***ink***.

Pour cela, gardez à l’esprit que de nombreux symboles de la syntaxe Markdown sont également utilisés par la **syntaxe d’*ink***, notamment `#`, `*`, `/`, `~`, `-`, `|`, etc. Pour éviter les conflits, vous pouvez placer le caractère d’échappement `\` avant le symbole Markdown.

Par exemple :

```ink title="ink"
Hello, this is some *italic* text and this is some **bold** text.
```

## CSS

Vous pouvez également utiliser les classes Tailwind CSS pour mettre en forme le texte à l’aide de HTML.

Par exemple :

```ink title="ink"
<span class="inline-block text-blue-500">some *blue* text</span>.
<span class="inline-block text-red-500">some *red* text</span>.
<span class="inline-block text-green-500">some *green* text</span>.
```
