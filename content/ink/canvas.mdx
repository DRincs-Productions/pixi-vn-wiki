The **_ink_ + Pixi’VN integration** introduces a "# script" that allows you to show, edit, remove, and animate a <DynamicLink href="/start/canvas-components">canvas component</DynamicLink>.

```ink tab="ink/start.ink"
=== start ===
# show image eggHead x 20 y 20
# show image flowerTop x 220 y 20 with dissolve
# show image helmlok x 20 y 220 with movein
# show image skully x 220 y 220 with zoomin
# pause
# move eggHead x 300 y 0
# rotate flowerTop
# edit image helmlok alpha 0.5
# shake skully
# pause
# remove image eggHead
# remove image flowerTop with dissolve duration 2
# remove image helmlok with moveout
# remove image skully with zoomout
# pause
-> DONE
```

## Components functions

### Show

You can use the `show` to <DynamicLink href="/start/canvas-image#show">show</DynamicLink> a canvas component in **_ink_**. To do this, you need to use the following syntax:

```ink tab="ink"
# show image eggHead
# show image "eggHead 2" eggHead xAlign 1 yAlign 1
# show image flowerTop xAlign 0 yAlign 1 visible true cursor "pointer" alpha 0.5
# show video my_video xAlign 1 yAlign 0
# show text hello "Hello, this is a text" xAlign 0.5 yAlign 0.5 style \\\{ "fill": "red", "fontSize": 30 \\\}
```

```txt tab="CLI"
# show <component type> <alias> [<source>] [<parameters>]

where:
    component type = the component type to show. Available types: `image`, `video`, `text`.
    alias = the alias to identify the component. Use double quotes if it contains spaces.
    source (Optional) = the alias or URL of the asset to use as the texture source. If not set, `alias` will be used as the source.
    parameters (Optional) = a space-separated list of property/value pairs. If a value is a string and includes spaces, you must use double quotes.
```

Available `parameters` (all optional) are the properties of [`PixiVNJsonCanvasImageVideoShowProps`](/jsdoc/pixi-vn-json/index/interfaces/PixiVNJsonCanvasImageVideoShowProps#properties) or [`PixiVNJsonCanvasTextShowProps`](/jsdoc/pixi-vn-json/index/interfaces/PixiVNJsonCanvasTextShowProps#properties).

```txt tab="CLI"
where:
```

```txt tab="CLI"
    transition parameters (Optional) = a space-separated list of property/value pairs corresponding to the transition options. If a value is a string and includes spaces, you must use double quotes.
```

Available `transition parameters` (all optional) are the properties of [`PixiVNJsonMediaTransiotions`](/jsdoc/pixi-vn-json/index/interfaces/PixiVNJsonMediaTransiotions).

### Edit

You can use the `edit` to edit a canvas component in **_ink_**. To do this, you need to use the following syntax:

```ink tab="ink"
# edit image bg position \{ "x": 20, "y": 30 \} visible true cursor "pointer" alpha 0.5
```

```txt tab="CLI"
# edit <component type> <alias> [<parameters>]

where:
    component type = the component type to edit. Available types: `image`, `imagecontainer`, `video`, `text`,  `canvaselement`.
    alias = the alias to identify the component. Use double quotes if it contains spaces.
    parameters (Optional) = a space-separated list of property/value pairs. If a value contains spaces, wrap it in double quotes. If a value is an object, pass valid JSON and escape the braces for ink.
```

Available `parameters` (all optional) vary by component:

- `image`: properties of [`ImageSpriteMemory`](/jsdoc/pixi-vn/index/interfaces/ImageSpriteMemory#properties).
- `video`: properties of [`VideoSpriteMemory`](/jsdoc/pixi-vn/index/interfaces/VideoSpriteMemory#properties).
- `imagecontainer`: properties of [`ImageContainerMemory`](/jsdoc/pixi-vn/index/interfaces/ImageContainerMemory#properties).
- `text`: properties of [`TextMemory`](/jsdoc/pixi-vn/index/interfaces/TextMemory#properties).

```txt tab="CLI"

where:
    component type = the component type to remove. Available types: `image`, `imagecontainer`, `video`, `text`.
    alias = the alias to identify the component. Use double quotes if it contains spaces.
```

## Animate

You can use the `animate` to use the <DynamicLink href="/start/canvas-motion">animations</DynamicLink> in **_ink_**. To do this, you need to use the following syntax:

```ink tab="ink"
# animate alien angle 360 options duration 1
```

```txt tab="CLI"
# animate <alias> <keyframes> options <parameters>

where:
    alias = the alias to identify the component. Use double quotes if it contains spaces.
    keyframes = a space-separated list of property/value pairs representing the properties to animate and the values to reach. If a value contains spaces, wrap it in double quotes. If a value is an object, pass valid JSON and escape the braces for ink.
    parameters (Optional) = a space-separated list of property/value pairs corresponding to the `options` parameter of the motion library. If a value contains spaces, wrap it in double quotes. If a value is an object, pass valid JSON and escape the braces for ink.
```

The `keyframes` define the **target state** you want the component's properties to reach (e.g. a position, scale, or opacity), while `parameters` define **how** to get there (e.g. duration, easing).

Available `keyframes` vary by component:

- `image`: properties of [`ImageSpriteMemory`](/jsdoc/pixi-vn/index/interfaces/ImageSpriteMemory#properties).
- `video`: properties of [`VideoSpriteMemory`](/jsdoc/pixi-vn/index/interfaces/VideoSpriteMemory#properties).
- `imagecontainer`: properties of [`ImageContainerMemory`](/jsdoc/pixi-vn/index/interfaces/ImageContainerMemory#properties).
- `text`: properties of [`TextMemory`](/jsdoc/pixi-vn/index/interfaces/TextMemory#properties).

Available `parameters` (all Optional) can include all the [`motion` options](https://motion.dev/docs/animate#options) and additional parameters you would use in JS/TS. You can find all the `parameters` in detail in [`PixiVNJsonAnimateBaseOptions`](/jsdoc/pixi-vn-json/index/interfaces/PixiVNJsonAnimateBaseOptions).

Here are some examples:
