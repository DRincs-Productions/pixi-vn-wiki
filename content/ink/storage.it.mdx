title: Storage

---

:::tip

Puoi trovare ulteriori informazioni sull’uso delle variabili in ink nella [documentazione ufficiale](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md#part-3-variables-and-logic).

:::

Anche ***ink*** supporta le variabili, sia temporanee sia globali, per memorizzare dati numerici, contenuti e persino comandi che controllano il flusso della storia. Dispone di un sistema logico completo e di alcune strutture aggiuntive che aiutano a organizzare meglio la logica, spesso complessa, di una storia a bivi.

Nell’**integrazione di *ink* con Pixi’VN**, le variabili `VAR` e `CONST` corrispondono alle <DynamicLink href="/start/storage">variabili dello storage</DynamicLink>, mentre le variabili `temp` corrispondono alle <DynamicLink href="/start/storage#temporary-storage">variabili temporanee dello storage</DynamicLink>.

Il nome delle variabili di ***ink*** corrisponde alla chiave di una variabile nello <DynamicLink href="/start/storage">storage</DynamicLink>.

## Define

:::tip

In JavaScript/TypeScript, questa funzionalità corrisponde a <DynamicLink href="/start/storage#default-storage-variables">«Variabili predefinite dello storage»</DynamicLink>.

:::

Puoi definire una variabile in ***ink*** con il seguente codice:

```ink tab="ink"
VAR myVariable = 42
```

```txt tab="CLI"
VAR <variable_name> = <value>

where:
    variable_name = the name of the variable
    value = the initial value of the variable
```

## Impostare

:::tip

In JavaScript/TypeScript, questa funzionalità corrisponde a <DynamicLink href="/start/storage#set">`storage.set`</DynamicLink>.

:::

Puoi impostare il valore di una variabile in ***ink*** con il seguente codice:

```ink tab="ink"
~ myVariable = 100
```

```txt tab="CLI"
~ <variable_name> = <value>

where:
    variable_name = the name of an already declared variable
    value = the new value to assign
```

## Ottenere

:::tip

In JavaScript/TypeScript, questa funzionalità corrisponde a <DynamicLink href="/start/storage#get">`storage.get`</DynamicLink>.

:::

In ink, le variabili possono essere usate per scopi diversi. Il modo di ottenere il valore di una variabile varia a seconda dello scopo.

```ink tab="ink"
The value of myDuration is: {myDuration}
```

```txt tab="CLI"
{<variable_name>}

where:
    variable_name = the name of the variable to print or evaluate
```

Ad esempio:

```ink title="ink"
The value of myDuration is: {myDuration}
# show image bg /image.png with dissolve duration {myDuration}
{myDuration > 5:
    The duration is greater than 5.
- else:
    The duration is 5 or less.
}
```
