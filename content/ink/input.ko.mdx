title: 입력 프롬프트
description: |
  Pixi’VN의 "# script"를 사용해 ink에서 플레이어에게 텍스트 또는 숫자 입력을 요청하고, 이야기 안에서 그 결과에 접근하는 방법입니다.
---

***ink* + Pixi’VN 통합**은 사용자에게 <DynamicLink href="/start/input">입력 프롬프트</DynamicLink>를 표시할 수 있는 "# script"를 도입합니다. To do this, you need to use the following syntax:

```ink tab="ink"
# request input type string
```

```txt tab="CLI"
# request input [<parameters>]

where:
    parameters (Optional) = a space-separated list of property/value pairs. If a value contains spaces, wrap it in double quotes.
```

사용 가능한 `parameters`(모두 선택 사항): [`type`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonInputRequest#valuetype), [`default`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonInputRequest#defaultvalue).

:::tip

입력한 값은 시스템 키 `_input_value_`로 저장소에 저장되므로 ink 콘텐츠에서 `{ _input_value_ }`를 참조할 수 있습니다.

:::

예를 들어:

```ink title="ink/start.ink"
=== start ===
Hello,
# request input type string // [!code focus]
<>what is your name?
My name is { _input_value_ } // [!code focus]
# request input type number default 18 // [!code focus]
How old are you?
I am { _input_value_ } years old // [!code focus]
# request input type "html textarea" // [!code focus]
Describe who you are:
{ _input_value_ } // [!code focus]
Restart
-> DONE
```
