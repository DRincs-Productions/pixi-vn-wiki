:::tip

***ink* + Pixi’VN 連携**は、新しい選択肢の種類を追加することなく、*ink* 本来の選択肢に対応しています。選択肢の構文と動作について詳しくは、[ink の公式ドキュメント](https://www.inklestudios.com/ink/)をご覧ください。

:::

*ink* では、`*` または `+` を付けた項目の後に選択肢テキストを書くことで、プレイヤーに選択を求めることができます。選択肢テキストがプレイヤーに表示され、プレイヤーはいずれかを選んで物語を進めます。

* `*` は一度だけ選べる選択肢を示します。
* `+` は何度でも選べる選択肢（繰り返し選択可能な選択肢）を示します。

```ink title="ink/start.ink"
=== start ===
* Go to Paris
  You decide to visit Paris. -> visit_paris
+ Go to London -> visit_london
* Stay at home
  You decide to stay at home. -> DONE
```

## 選択肢テキストを出力しない

デフォルトでは、選択した項目のテキストが出力にも再び表示されます。選択肢の表示テキストを角括弧で囲むと、そのテキストは選択肢メニューにのみ表示され、選択後の出力には表示されません。

```ink title="ink/start.ink"
=== start ===
Hello world!
* [Hello back!]
 Nice to hear from you!
```

角括弧は選択肢の内容を分割します。括弧の前のテキストはメニューと出力の両方に表示され、括弧内のテキストはメニューにのみ表示され、括弧の後のテキストは出力にのみ表示されます。これはセリフの選択肢で役立ちます：

```ink title="ink/start.ink"
=== start ===
"What's that?" my master asked.
* "I am somewhat tired[."]," I repeated.
 "Really," he responded. "How deleterious."
```

## 選択肢のバリエーション

<Accordions>

<Accordion title="フォールバック選択肢" id="fallback-choices">

フォールバック選択肢はプレイヤーには表示されず、ほかに選択可能な項目がない場合にエンジンによって自動的に選ばれます。

フォールバック選択肢とは、表示する選択肢テキストがない選択肢のことです：

```ink tab="ink"
* -> out_of_options
```

```txt tab="CLI"
* -> <knot_name>

where:
    knot_name = the name of the knot to jump to when no other choice is available
```

例：

```ink title="ink/start.ink"
=== start ===
 You search desperately for a friendly face in the crowd.
 * The woman in the hat[?] pushes you roughly aside. -> find_help
 * The man with the briefcase[?] looks disgusted as you stumble past him. -> find_help
 * -> // fallback
  But it is too late: you collapse onto the station platform. This is the end.
  -> END
```

</Accordion>

<Accordion title="条件付き選択肢" id="conditional-choices">

条件を使って選択肢を有効または無効にできます。最も簡単な判定方法は、プレイヤーが特定の `knot` または `stitch` をすでに訪れたかどうかを確認することです。

```ink title="ink"
* { not visit_paris }  [Go to Paris] -> visit_paris
+ { visit_paris }      [Return to Paris] -> visit_paris
* { visit_paris.met_estelle } [Telephone Mme Estelle] -> phone_estelle
```

注：`knot_name` の判定は、その knot 内のいずれかの `stitch` を訪問していれば真になります。条件を指定しても `*` の選択肢が一度しか選べないという性質は変わりません。繰り返し選べる選択肢には `+` を使ってください。

</Accordion>

</Accordions>
