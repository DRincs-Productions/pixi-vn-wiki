---
title: ストレージ
description: Pixi’VN のストレージを使って、ink のグローバル変数と一時変数を定義・設定・取得する方法を学びます。
---

:::tip

ink での変数の使い方について詳しくは、[公式ドキュメント](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md#part-3-variables-and-logic)を参照してください。

:::

***ink*** は一時変数とグローバル変数の両方をサポートしており、数値やコンテンツ、さらには物語の進行を制御するコマンドも保存できます。論理処理の機能が充実しており、分岐する物語で複雑になりがちなロジックを整理するための追加構造も用意されています。

***ink* と Pixi’VN の連携**では、`VAR` と `CONST` は<DynamicLink href="/start/storage">ストレージ変数</DynamicLink>に、`temp` は<DynamicLink href="/start/storage#temporary-storage">ストレージの一時変数</DynamicLink>に相当します。

***ink*** の変数名は、<DynamicLink href="/start/storage">ストレージ</DynamicLink>内の変数のキーに対応します。

## Define

:::tip

JavaScript/TypeScript では、この機能は <DynamicLink href="/start/storage#default-storage-variables">「デフォルトのストレージ変数」</DynamicLink>に相当します。

:::

***ink*** では、次のコードで変数を定義できます。

```ink tab="ink"
VAR myVariable = 42
```

```txt tab="CLI"
VAR <variable_name> = <value>

where:
    variable_name = the name of the variable
    value = the initial value of the variable
```

## 設定

:::tip

JavaScript/TypeScript では、この機能は <DynamicLink href="/start/storage#set">`storage.set`</DynamicLink> に相当します。

:::

***ink*** では、次のコードで変数に値を設定できます。

```ink tab="ink"
~ myVariable = 100
```

```txt tab="CLI"
~ <variable_name> = <value>

where:
    variable_name = the name of an already declared variable
    value = the new value to assign
```

## 取得

:::tip

JavaScript/TypeScript では、この機能は <DynamicLink href="/start/storage#get">`storage.get`</DynamicLink> に相当します。

:::

ink では、変数をさまざまな目的に使用できます。目的によって、変数の値を取得する方法が異なります。

```ink tab="ink"
The value of myDuration is: {myDuration}
```

```txt tab="CLI"
{<variable_name>}

where:
    variable_name = the name of the variable to print or evaluate
```

例：

```ink title="ink"
The value of myDuration is: {myDuration}
# show image bg /image.png with dissolve duration {myDuration}
{myDuration > 5:
    The duration is greater than 5.
- else:
    The duration is 5 or less.
}
```
