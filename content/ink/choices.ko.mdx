:::tip

***ink* + Pixi’VN 통합**은 새로운 선택지 유형을 추가하지 않고도 _ink_의 기본 선택지를 지원합니다. 선택지 구문과 동작에 대한 자세한 내용은 [ink 공식 문서](https://www.inklestudios.com/ink/)를 참고하세요.

:::

_ink_에서는 `*` 또는 `+` 기호로 시작하는 목록에 선택지 텍스트를 작성하여 플레이어에게 선택을 요청할 수 있습니다. 선택지 텍스트가 플레이어에게 표시되며, 플레이어는 옵션 하나를 선택해 이야기를 계속 진행합니다.

* `*`는 한 번만 선택할 수 있는 선택지를 나타냅니다.
* `+`는 여러 번 선택할 수 있는 선택지(반복 선택지)를 나타냅니다.

```ink title="ink/start.ink"
=== start ===
* Go to Paris
  You decide to visit Paris. -> visit_paris
+ Go to London -> visit_london
* Stay at home
  You decide to stay at home. -> DONE
```

## 선택지 텍스트 출력 생략하기

기본적으로 선택된 옵션의 텍스트는 출력에 다시 표시됩니다. 선택지의 표시 텍스트를 대괄호로 묶으면 해당 텍스트는 선택 메뉴에만 표시되고 이후 출력에는 표시되지 않습니다.

```ink title="ink/start.ink"
=== start ===
Hello world!
* [Hello back!]
 Nice to hear from you!
```

대괄호는 선택지 내용을 나눕니다. 괄호 앞의 텍스트는 메뉴와 출력에 모두 표시되고, 괄호 안의 텍스트는 메뉴에만, 괄호 뒤의 텍스트는 출력에만 표시됩니다. 대사 선택지를 만들 때 유용합니다:

```ink title="ink/start.ink"
=== start ===
"What's that?" my master asked.
* "I am somewhat tired[."]," I repeated.
 "Really," he responded. "How deleterious."
```

## 선택지 변형

<Accordions>

<Accordion title="대체 선택지" id="fallback-choices">

대체 선택지는 플레이어에게 표시되지 않으며, 다른 선택지가 없을 때 엔진이 자동으로 선택합니다.

대체 선택지는 화면에 표시할 선택지 텍스트가 없는 선택지입니다:

```ink tab="ink"
* -> out_of_options
```

```txt tab="CLI"
* -> <knot_name>

where:
    knot_name = the name of the knot to jump to when no other choice is available
```

예를 들어:

```ink title="ink/start.ink"
=== start ===
 You search desperately for a friendly face in the crowd.
 * The woman in the hat[?] pushes you roughly aside. -> find_help
 * The man with the briefcase[?] looks disgusted as you stumble past him. -> find_help
 * -> // fallback
  But it is too late: you collapse onto the station platform. This is the end.
  -> END
```

</Accordion>

<Accordion title="조건부 선택지" id="conditional-choices">

조건을 사용해 선택지를 활성화하거나 비활성화할 수 있습니다. 가장 간단한 검사는 플레이어가 특정 `knot` 또는 `stitch`를 이전에 방문했는지 확인하는 것입니다.

```ink title="ink"
* { not visit_paris }  [Go to Paris] -> visit_paris
+ { visit_paris }      [Return to Paris] -> visit_paris
* { visit_paris.met_estelle } [Telephone Mme Estelle] -> phone_estelle
```

참고: `knot_name` 검사는 해당 knot 안의 `stitch` 중 하나라도 방문했다면 참이 됩니다. 조건을 사용해도 `*` 선택지의 일회성 특성은 바뀌지 않습니다. 반복해서 선택할 수 있는 선택지에는 `+`를 사용하세요.

</Accordion>

</Accordions>
