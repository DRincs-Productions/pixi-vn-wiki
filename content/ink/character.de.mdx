## Verwendung

### Einen Charakter einem Dialog zuordnen

Du kannst in ***ink*** einen Charakter einem Dialog zuordnen. To do this, you need to use the following syntax:

```ink tab="ink"
mc: Hello
```

```txt tab="CLI"
<character_id>: <text>

where:
    character_id = character identifier
    text = any text message
```

Zum Beispiel:

```ink tab="ink/start.ink"
=== start ===
mc: Hello, I'm Liam.
-> DONE
```

```ts tab="values/characters.ts"
import { CharacterBaseModel, RegisteredCharacters } from "@drincs/pixi-vn";

export const mc = new CharacterBaseModel("mc", {
    name: "Liam",
});

RegisteredCharacters.add(mc);
```

### Den Charakternamen im Dialogtext verwenden

Du kannst den Namen eines Charakters in Dialogen verwenden. To do this, you need to use the following syntax:

```ink tab="ink"
Hello, [mc].
```

```txt tab="CLI"
[<character_id>]

where:
    character_id = character identifier
```

Zum Beispiel:

```ink tab="ink/start.ink"
=== start ===
Hello, [mc].
-> DONE
```

```ts tab="values/characters.ts"
import { CharacterBaseModel, RegisteredCharacters } from "@drincs/pixi-vn";

export const mc = new CharacterBaseModel("mc", {
    name: "Liam",
});

RegisteredCharacters.add(mc);
```

<Accordions>

<Accordion title="Implementierung" id="replace-implementation">

Um diese Syntax zu verwenden, musst du eine <DynamicLink href="/ink/replacement">Textersetzung</DynamicLink> registrieren, die die Charakter-ID durch den Charakternamen ersetzt.

:::tip[Vorlagen]

Diese Textersetzung ist bereits in allen Vorlagen enthalten.

:::

Du kannst beispielsweise die folgende Textersetzung hinzufügen:

```ts title="content/ink/text-replaces.ts"
import { TextReplaces } from "@drincs/pixi-vn-ink";
import { RegisteredCharacters } from "@drincs/pixi-vn/characters";

TextReplaces.add((key) => RegisteredCharacters.get(key)?.name, {
    name: "character name",
    validation: "characterId",
    type: "after-translation",
    i18nInterpolation: true,
    description:
        "Replaces a character ID with the character's name in the game.",
});
```

## Bearbeiten

Du kannst die Informationen eines Charakters in ***ink*** bearbeiten, beispielsweise seinen Namen ändern. To do this, you need to use the following syntax:

```ink tab="ink"
# rename mc Liam
```

```txt tab="CLI"
# rename <character_id> <new_name>

where:
    character_id = character identifier
    new_name = the new name for the character
```

Zum Beispiel:

```ink tab="ink/start.ink"
=== start ===
mc: Hello, I'm [mc].
# request input string
mc: My name is:
# rename mc {_input_value_}
mc: My name is [mc]
-> DONE
```

```ts tab="values/characters.ts"
import { CharacterBaseModel, RegisteredCharacters } from "@drincs/pixi-vn";

export const mc = new CharacterBaseModel("mc", {
    name: "Liam",
});

RegisteredCharacters.add(mc);
```

<Accordions>

<Accordion title="Implementierung" id="rename-implementation">

Um diese Syntax zu verwenden, musst du einen <DynamicLink href="/ink/hashtag">Hashtag-Befehl</DynamicLink> registrieren, der den Charakter umbenennt.

:::tip[Vorlagen]

Dieser Hashtag-Befehl ist bereits in allen Vorlagen enthalten.

:::

Du kannst beispielsweise den folgenden Hashtag-Befehl hinzufügen:

```ts title="content/ink/hashtag-commands.ts"
import { characterIdsEnum } from "@/pixi-vn.keys.gen";
import { HashtagCommands } from "@drincs/pixi-vn-ink";
import { RegisteredCharacters } from "@drincs/pixi-vn/characters";
import zod from "zod";

HashtagCommands.add(
    async (script) => {
        const character = RegisteredCharacters.get(script[1]);
        if (character) {
            character.name = script[2];
        }
        return true;
    },
    {
        name: "character rename",
        description: `Renames a character in the game.

\`\`\`ink
# rename <characterId> <newName>
\`\`\``,
        validation: zod.tuple([
            zod.literal("rename"),
            zod.enum(characterIdsEnum),
            zod.string(),
        ]),
    },
);
```

</Accordion>

</Accordions>

## Charakter-Emotionen

Du kannst die <DynamicLink href="/start/character#character-emotions">Charakter-Emotionen</DynamicLink> in ***ink*** verwenden. Dazu verwendest du einfach eine spezielle ID, die sich aus der Charakter-ID, dem Trennzeichen `@` und der Emotion zusammensetzt:

```ink tab="ink"
mc@happy: Hi, I'm Liam. I'm very happy today.
```

```txt tab="CLI"
<character_id>@<emotion>: <text>

where:
    character_id = character identifier
    emotion = the emotion defined in JavaScript/TypeScript
    text = any text message
```

Zum Beispiel:

```ink tab="ink/start.ink"
=== start ===
mc@happy: Hi, I'm Liam. I'm very happy today.
-> DONE
```

```ts tab="values/characters.ts"
import { CharacterBaseModel, RegisteredCharacters } from "@drincs/pixi-vn";

export const mc = new CharacterBaseModel("mc", {
    name: "Liam",
});

export const mcHappy = new CharacterBaseModel(
    { id: "mc", emotion: "happy" },
    {
        name: "Liam happy",
    },
);

RegisteredCharacters.add([mc, mcHappy]);
```
