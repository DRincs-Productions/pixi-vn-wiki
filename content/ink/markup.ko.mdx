**_ink_와 Pixi’VN의 통합**은 텍스트에 <DynamicLink href="/start/markup-markdown">마크업</DynamicLink>을 적용하는 컴포넌트를 더 쉽게 사용할 수 있도록 추가 기능을 제공합니다.

## 줄바꿈

줄을 바꾸려면 이스케이프 문자 `\n`을 사용할 수 있습니다.

<Callout>

이 경우 Markdown으로 줄바꿈을 표시하므로 `\n\n`처럼 두 개가 필요합니다.

</Callout>

예를 들어:

```ink title="ink"
=== start ===
Hello, this is a test. \\n\\n This is a new line.
```

## Markdown

Pixi’VN에서는 텍스트에 스타일을 적용할 때 Markdown을 사용하는 것이 좋습니다. 프로젝트에 <DynamicLink href="/start/markup-markdown">Markdown을 구현했다면</DynamicLink> ***ink***&#xC5D0;서 Markdown 문법으로 텍스트 서식을 지정할 수 있습니다.

이때 Markdown 문법에 사용되는 많은 기호가 ***ink* 문법**에서도 사용된다는 점에 유의하세요. 예를 들어 `#`, `*`, `/`, `~`, `-`, `|` 등이 있습니다. 충돌을 피하려면 Markdown 기호 앞에 이스케이프 문자 `\`를 넣으면 됩니다.

예를 들어:

```ink title="ink"
Hello, this is some *italic* text and this is some **bold** text.
```

## CSS

Tailwind CSS 클래스를 사용하여 HTML로 텍스트 서식을 지정할 수도 있습니다.

예를 들어:

```ink title="ink"
<span class="inline-block text-blue-500">some *blue* text</span>.
<span class="inline-block text-red-500">some *red* text</span>.
<span class="inline-block text-green-500">some *green* text</span>.
```
