:::tip

Weitere Informationen zur Verwendung von Variablen in ink findest du in der [offiziellen Dokumentation](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md#part-3-variables-and-logic).

:::

***ink*** unterstützt auch temporäre und globale Variablen, die Zahlen, Inhalte oder sogar Befehle zur Steuerung des Handlungsverlaufs speichern können. Es bietet umfassende Logikfunktionen und zusätzliche Strukturen, mit denen sich die oft komplexe Logik einer verzweigten Geschichte besser organisieren lässt.

Bei der **Integration von *ink* und Pixi’VN** entsprechen die Variablen `VAR` und `CONST` den <DynamicLink href="/start/storage">Variablen im Speicher</DynamicLink>, während die Variablen `temp` den <DynamicLink href="/start/storage#temporary-storage">temporären Variablen im Speicher</DynamicLink> entsprechen.

Der Name einer Variablen in ***ink*** entspricht dem Schlüssel einer Variablen im <DynamicLink href="/start/storage">Speicher</DynamicLink>.

## Define

:::tip

In JavaScript/TypeScript entspricht diese Funktion den <DynamicLink href="/start/storage#default-storage-variables">„Standard-Speichervariablen“</DynamicLink>.

:::

Du kannst eine Variable in ***ink*** mit folgendem Code definieren:

```ink tab="ink"
VAR myVariable = 42
```

```txt tab="CLI"
VAR <variable_name> = <value>

where:
    variable_name = the name of the variable
    value = the initial value of the variable
```

## Setzen

:::tip

In JavaScript/TypeScript entspricht diese Funktion <DynamicLink href="/start/storage#set">`storage.set`</DynamicLink>.

:::

Du kannst einer Variablen in ***ink*** mit folgendem Code einen Wert zuweisen:

```ink tab="ink"
~ myVariable = 100
```

```txt tab="CLI"
~ <variable_name> = <value>

where:
    variable_name = the name of an already declared variable
    value = the new value to assign
```

## Abrufen

:::tip

In JavaScript/TypeScript entspricht diese Funktion <DynamicLink href="/start/storage#get">`storage.get`</DynamicLink>.

:::

In ink können Variablen für verschiedene Zwecke verwendet werden. Je nach Verwendungszweck unterscheidet sich die Art, wie der Wert einer Variablen abgerufen wird.

```ink tab="ink"
The value of myDuration is: {myDuration}
```

```txt tab="CLI"
{<variable_name>}

where:
    variable_name = the name of the variable to print or evaluate
```

Zum Beispiel:

```ink title="ink"
The value of myDuration is: {myDuration}
# show image bg /image.png with dissolve duration {myDuration}
{myDuration > 5:
    The duration is greater than 5.
- else:
    The duration is 5 or less.
}
```
