:::tip

ink의 임시 변수에 대한 자세한 내용은 [공식 문서](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md#4-temporary-variables)를 참고하세요.

:::

전역 변수가 다루기 불편할 때도 있습니다. ***ink***&#xB294; 빠른 로컬 계산을 위한 **임시 변수**를 제공합니다. 전역 변수(`VAR`)와 달리, 임시 변수는 **정의된 knot 또는 stitch를 벗어나면 즉시 폐기됩니다**.

**_ink_와 Pixi’VN의 통합**에서 `temp` 변수는 <DynamicLink href="/start/storage#temporary-storage">스토리지의 임시 변수</DynamicLink>에 해당합니다.

## Define

:::tip

JavaScript/TypeScript에서 이 기능은 <DynamicLink href="/start/storage#temporary-storage">스토리지의 임시 변수</DynamicLink>에 해당합니다.

:::

논리 줄을 나타내는 `~` 안에서 `temp` 키워드로 임시 변수를 선언합니다:

```ink tab="ink"
~ temp myTemp = 42
```

```txt tab="CLI"
~ temp <variable_name> = <value>

where:
    variable_name = the name of the temporary variable
    value = the initial value of the variable
```

***ink***&#xC5D0;서 지원하는 모든 자료형을 사용할 수 있습니다. 정수, 부동 소수점 수, 불리언, 문자열이 포함됩니다.

```ink title="ink/start.ink"
=== near_north_pole ===
    ~ temp number_of_warm_things = 0
    { blanket:
        ~ number_of_warm_things++
    }
    { ear_muffs:
        ~ number_of_warm_things++
    }
    { gloves:
        ~ number_of_warm_things++
    }
    { number_of_warm_things > 2:
        Despite the snow, I felt incorrigibly snug.
    - else:
        That night I was colder than I have ever been.
    }
```

`number_of_warm_things` 변수는 knot에 진입할 때 생성되고 벗어날 때 폐기됩니다.

## 설정

:::tip

JavaScript/TypeScript에서 이 기능은 <DynamicLink href="/start/storage#set">`storage.set`</DynamicLink>에 해당합니다.

:::

처음 선언한 뒤에는 `temp` 키워드를 다시 쓰지 않고 동일한 `~` 구문으로 임시 변수에 값을 다시 할당할 수 있습니다:

```ink tab="ink"
~ score = score + 10
```

```txt tab="CLI"
~ <variable_name> = <expression>

where:
    variable_name = the name of an already declared temporary variable
    expression = the new value, which can reference the variable itself
```

예를 들어:

```ink title="ink"
~ temp score = 0
~ score = score + 10
~ score++
```

## 가져오기

임시 변수의 값을 가져오려면 일반적인 <DynamicLink href="/ink/storage#get">`storage.get` 함수</DynamicLink>를 사용하세요.

***ink*** 안에서는 다른 변수와 마찬가지로 표현식, 인라인 출력 또는 조건문에서 변수 이름을 사용해 임시 변수의 값을 읽습니다:

```ink tab="ink"
The duration is: {duration}
```

```txt tab="CLI"
{<variable_name>}

where:
    variable_name = the name of the temporary variable to print or evaluate
```

예를 들어:

```ink title="ink"
~ temp duration = 3

The duration is: {duration}
{ duration > 2:
    It's a long scene.
- else:
    It's a short scene.
}
```
