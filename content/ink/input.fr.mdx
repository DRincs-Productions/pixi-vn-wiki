---
title: Invite de saisie
description: |
  Comment demander au joueur de saisir du texte ou un nombre dans ink à l'aide du « # script » de Pixi’VN et utiliser le résultat dans votre récit.
---

L'**intégration *ink* + Pixi’VN** introduit un « # script » qui permet d'afficher une <DynamicLink href="/start/input">invite de saisie</DynamicLink> à l'utilisateur. To do this, you need to use the following syntax:

```ink tab="ink"
# request input type string
```

```txt tab="CLI"
# request input [<parameters>]

where:
    parameters (Optional) = a space-separated list of property/value pairs. If a value contains spaces, wrap it in double quotes.
```

`parameters` disponibles (tous facultatifs) : [`type`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonInputRequest#valuetype), [`default`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonInputRequest#defaultvalue).

:::tip

La valeur saisie est enregistrée dans le stockage sous la clé système `_input_value_`. Vous pouvez donc utiliser `{ _input_value_ }` dans votre contenu ink.

:::

Par exemple :

```ink title="ink/start.ink"
=== start ===
Hello,
# request input type string // [!code focus]
<>what is your name?
My name is { _input_value_ } // [!code focus]
# request input type number default 18 // [!code focus]
How old are you?
I am { _input_value_ } years old // [!code focus]
# request input type "html textarea" // [!code focus]
Describe who you are:
{ _input_value_ } // [!code focus]
Restart
-> DONE
```
