***ink* 与 Pixi’VN 的集成**提供了一些附加功能，便于使用在文本中引入 <DynamicLink href="/start/markup-markdown">标记</DynamicLink> 的组件。

## 换行

要换行，可以使用转义字符 `\n`。

<Callout>

在我们的示例中，由于使用 Markdown 显示换行，因此需要两个换行符：`\n\n`。

</Callout>

例如：

```ink title="ink"
=== start ===
Hello, this is a test. \\n\\n This is a new line.
```

## Markdown

在 Pixi’VN 中，建议使用 Markdown 为文本添加样式。如果你已经在项目中<DynamicLink href="/start/markup-markdown">实现了 Markdown</DynamicLink>，就可以在 ***ink*** 中使用 Markdown 语法设置文本样式。

为此，请注意 Markdown 语法中的许多符号也用于 ***ink* 语法**，例如 `#`、`*`、`/`、`~`、`-`、`|` 等。为避免冲突，可以在 Markdown 符号前添加转义字符 `\`。

例如：

```ink title="ink"
Hello, this is some *italic* text and this is some **bold** text.
```

## CSS

你也可以使用 Tailwind CSS 类，通过 HTML 设置文本样式。

例如：

```ink title="ink"
<span class="inline-block text-blue-500">some *blue* text</span>.
<span class="inline-block text-red-500">some *red* text</span>.
<span class="inline-block text-green-500">some *green* text</span>.
```
