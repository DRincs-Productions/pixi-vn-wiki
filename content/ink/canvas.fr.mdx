The ***ink* + Pixi’VN integration** introduces a "# script" that allows you to show, edit, remove, and animate a <DynamicLink href="/start/canvas-components">canvas component</DynamicLink>.

```ink tab="ink/start.ink"
=== start ===
# show image eggHead x 20 y 20
# show image flowerTop x 220 y 20 with dissolve
# show image helmlok x 20 y 220 with movein
# show image skully x 220 y 220 with zoomin
# pause
# move eggHead x 300 y 0
# rotate flowerTop
# edit image helmlok alpha 0.5
# shake skully
# pause
# remove image eggHead
# remove image flowerTop with dissolve duration 2
# remove image helmlok with moveout
# remove image skully with zoomout
# pause
-> DONE
```

## Fonctions des composants

### Afficher

You can use the `show` to <DynamicLink href="/start/canvas-image#show">show</DynamicLink> a canvas component in ***ink***. To do this, you need to use the following syntax:

```ink tab="ink"
# show image eggHead
# show image "eggHead 2" eggHead xAlign 1 yAlign 1
# show image flowerTop xAlign 0 yAlign 1 visible true cursor "pointer" alpha 0.5
# show video my_video xAlign 1 yAlign 0
# show text hello "Hello, this is a text" xAlign 0.5 yAlign 0.5 style \\{ "fill": "red", "fontSize": 30 \\}
```

```txt tab="CLI"
# show <component type> <alias> [<source>] [<parameters>]

where:
    component type = the component type to show. Available types: `image`, `video`, `text`.
    alias = the alias to identify the component. Use double quotes if it contains spaces.
    source (Optional) = the alias or URL of the asset to use as the texture source. If not set, `alias` will be used as the source.
    parameters (Optional) = a space-separated list of property/value pairs. If a value is a string and includes spaces, you must use double quotes.
```

Available `parameters` (all optional) are the properties of [`PixiVNJsonCanvasImageVideoShow`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonCanvasImageVideoShow) or [`PixiVNJsonCanvasTextShow`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonCanvasTextShow).

<Accordion title="Show with transition" id="show-with-transition">

If you want to show the canvas component with a <DynamicLink href="/start/canvas-transition">transition</DynamicLink>, you can add into the parameters the `with {transition type}`.

```ink tab="ink/start.ink"
# show eggHead with dissolve duration 3
temp durationVar = 3
# show eggHead eggHead2 with fade duration {durationVar}
# show flowerTop x 20 y 30 with movein direction left
# show helmlok x 20 y 30 with zoomin
# show skully x 20 y 30 with pushin
```

```txt tab="CLI"
# show <component type> <alias> [<source>] [<parameters>] with <transition type> [<transition parameters>]

where:
    component type = the component type to show. Available types: `image`, `imagecontainer`, `video`, `text`.
    alias = the alias to identify the component. Use double quotes if it contains spaces.
    source (Optional) = the alias or URL of the asset to use as the texture source. If not set, `alias` will be used as the source.
    parameters (Optional) = a space-separated list of property/value pairs. If a value is a string and includes spaces, you must use double quotes.
    transition type = the transition to use. Available types: `dissolve`, `fade`, `movein`, `zoomin`, `pushin`.
    transition parameters (Optional) = a space-separated list of property/value pairs corresponding to the transition options. If a value is a string and includes spaces, you must use double quotes.
```

Available `transition parameters` (all optional) are the properties of [`PixiVNJsonMediaTransiotions`](/jsdoc/pixi-vn-json/index/type-aliases/PixiVNJsonMediaTransiotions).

### Modifier

You can use the `edit` to edit a canvas component in ***ink***. To do this, you need to use the following syntax:

```ink tab="ink"
# edit image bg position { "x": 20, "y": 30 } visible true cursor "pointer" alpha 0.5
```

```txt tab="CLI"
# edit <component type> <alias> [<parameters>]

where:
    component type = the component type to edit. Available types: `image`, `imagecontainer`, `video`, `text`,  `canvaselement`.
    alias = the alias to identify the component. Use double quotes if it contains spaces.
    parameters (Optional) = a space-separated list of property/value pairs. If a value contains spaces, wrap it in double quotes. If a value is an object, pass valid JSON and escape the braces for ink.
```

Available `parameters` (all optional) are the properties of  [`ImageSpriteMemory`](/jsdoc/pixi-vn-json/index/type-aliases/ImageSpriteMemory),  [`VideoSpriteMemory`](/jsdoc/pixi-vn-json/index/type-aliases/VideoSpriteMemory),  [`ImageContainerMemory`](/jsdoc/pixi-vn-json/index/type-aliases/ImageContainerMemory) or [`TextMemory`](/jsdoc/pixi-vn-json/index/type-aliases/TextMemory).


```txt tab="CLI"

where:
    component type = the component type to remove. Available types: `image`, `imagecontainer`, `video`, `text`.
    alias = the alias to identify the component. Use double quotes if it contains spaces.
```

## Animate

You can use the `animate` to use the <DynamicLink href="/start/canvas-motion">animations</DynamicLink> in ***ink***. To do this, you need to use the following syntax:

```ink title="ink"
# animate {alias} {keyframes} options {parameters}
```

* `keyframes`: a space-separated list of property/value pairs representing the properties to animate and the values to reach. If a value contains spaces, wrap it in double quotes. If a value is a object, pass valid JSON and escape the braces for ***ink*** (e.g. `\{ "placeholder": "Enter your name", "maxLength": 20 \}`). Valid parameters vary by component:
  * `image` and `video`: [`PixiJS.Sprite`](https://pixijs.com/8.x/guides/components/sprites) and <DynamicLink href="/start/canvas-position">`properties for positioning`</DynamicLink> properties.
  * `text`: [`PixiJS.Text`](https://pixijs.com/8.x/guides/components/text) and <DynamicLink href="/start/canvas-position">`properties for positioning`</DynamicLink> properties.
  * `imagecontainer`: [`PixiJS.Container`](https://pixijs.com/8.x/guides/components/containers) and <DynamicLink href="/start/canvas-position">`properties for positioning`</DynamicLink> properties.
* `parameters` (Optional): a space-separated list of property/value pairs. Corresponds to the `options` parameter of their Javascript counterpart. If a value contains spaces, wrap it in double quotes. If a value is a object, pass valid JSON and escape the braces for ***ink*** (e.g. `\{ "placeholder": "Enter your name", "maxLength": 20 \}`). You can add all the [`motion` options](https://motion.dev/docs/animate#options) and additional parameters you would use in JS/TS.
