## 일시 정지

"# script"를 실행하면 시스템은 다음 `step`으로 이동하기 위해 <DynamicLink href="/start/labels-flow#continue">`continue`</DynamicLink>를 수행합니다. 예를 들어 이 경우 이미지와 대화 텍스트가 표시됩니다.

```ink title="ink/start.ink"
=== start ===
# show image alien eggHead
Hello, world!
-> DONE
```

`# pause`를 사용하면 다음 `step`으로 진행하는 것을 멈추고 흐름이 재개될 때까지 대화 텍스트를 지울 수 있습니다. 대화를 표시하지 않고 이미지를 보여 주거나 상태를 변경할 때 유용합니다.

구문은 다음과 같습니다:

```ink tab="ink"
# pause
```

```txt tab="CLI"
# pause
```

예를 들어:

```ink tab="ink/start.ink"
=== start ===
# show image alien eggHead
# pause
Hello, world!
-> DONE
```

```ts tab="assets/manifest.ts"
import { AssetsManifest } from "@drincs/pixi-vn";
```

## 계속하기

일반적으로 대화 다음에 선택지가 제시되면 서사는 두 개의 `steps`를 사용합니다. 첫 번째는 대화만 표시하고, 두 번째는 대화와 선택지를 함께 표시합니다.

```ink title="ink/start.ink"
=== start ===
Who are we going to rescue: the kitten or the wizard?
* [workplace_midground_kitten] 
    -> END
* [workplace_midground_wizard]
    -> END
```

대화와 선택지를 하나의 `step`에 함께 표시하려면 대화 줄 끝에 `<># continue`를 추가합니다. 이렇게 하면 불필요한 `step` 하나를 줄일 수 있습니다.

```ink tab="ink"
Who are we going to rescue: the kitten or the wizard?<># continue
```

```txt tab="CLI"
<text><># continue

where:
    text = the dialogue text
```

예를 들어:

```ink title="ink/start.ink"
=== start ===
Who are we going to rescue: the kitten or the wizard?<># continue
* [workplace_midground_kitten] 
    -> END
* [workplace_midground_wizard]
    -> END
```
