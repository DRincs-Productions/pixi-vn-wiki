---
title: 临时存储
description: 了解如何使用 Pixi’VN 存储，在 ink 的 knot 或 stitch 内定义、设置和获取局部临时变量。
---

:::tip

有关 ink 中临时变量的更多信息，请参阅[官方文档](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md#4-temporary-variables)。

:::

有时使用全局变量并不方便。 ***ink*** 提供用于快速局部计算的**临时变量**。与全局变量（`VAR`）不同，临时变量会在**故事离开定义该变量的 knot 或 stitch 时立即被丢弃**。

在 ***ink* 与 Pixi’VN 的集成**中，`temp` 变量相当于<DynamicLink href="/start/storage#temporary-storage">存储中的临时变量</DynamicLink>。

## Define

:::tip

在 JavaScript/TypeScript 中，此功能对应于 <DynamicLink href="/start/storage#temporary-storage">存储中的临时变量</DynamicLink>。

:::

在 `~` 逻辑行中使用 `temp` 关键字声明临时变量：

```ink tab="ink"
~ temp myTemp = 42
```

```txt tab="CLI"
~ temp <variable_name> = <value>

where:
    variable_name = the name of the temporary variable
    value = the initial value of the variable
```

可以使用 ***ink*** 支持的任何类型：整数、浮点数、布尔值或字符串。

```ink title="ink/start.ink"
=== near_north_pole ===
    ~ temp number_of_warm_things = 0
    { blanket:
        ~ number_of_warm_things++
    }
    { ear_muffs:
        ~ number_of_warm_things++
    }
    { gloves:
        ~ number_of_warm_things++
    }
    { number_of_warm_things > 2:
        Despite the snow, I felt incorrigibly snug.
    - else:
        That night I was colder than I have ever been.
    }
```

变量 `number_of_warm_things` 在进入 knot 时创建，离开时被丢弃。

## 设置

:::tip

在 JavaScript/TypeScript 中，此功能对应于 <DynamicLink href="/start/storage#set">`storage.set`</DynamicLink>。

:::

初次声明后，可以使用相同的 `~` 语法重新为临时变量赋值（无需重复 `temp` 关键字）：

```ink tab="ink"
~ score = score + 10
```

```txt tab="CLI"
~ <variable_name> = <expression>

where:
    variable_name = the name of an already declared temporary variable
    expression = the new value, which can reference the variable itself
```

例如：

```ink title="ink"
~ temp score = 0
~ score = score + 10
~ score++
```

## 获取

要获取临时变量的值，请使用常规的 <DynamicLink href="/ink/storage#get">`storage.get` 函数</DynamicLink>。

在 ***ink*** 中，读取临时变量的方式与其他变量完全相同：在表达式、行内输出或条件中使用变量名即可：

```ink tab="ink"
The duration is: {duration}
```

```txt tab="CLI"
{<variable_name>}

where:
    variable_name = the name of the temporary variable to print or evaluate
```

例如：

```ink title="ink"
~ temp duration = 3

The duration is: {duration}
{ duration > 2:
    It's a long scene.
- else:
    It's a short scene.
}
```
