---
title: Navigation Quest Time Routine (NQTR)
---

**What is NQTR?** NQTR (Navigation Quest Time Routine) is an extension for Pixi’VN that adds advanced systems for navigation, quests, time management, and game state handling. It is fully customizable and extensible, enabling developers to implement complex game mechanics with ease.

## Installation

:::tip[Plantillas]

Starting a new Pixi’VN project? Use a <DynamicLink href="/start#project-initialization">template</DynamicLink> that already includes NQTR.

:::

To install the NQTR package in an existing JavaScript project, use one of the following commands:

```npm
npm install @drincs/nqtr
```

<Accordions>

<Accordion title="*ink* integration" id="ink">

To access NQTR features you can add a handler to *ink*'s hashtag commands.

```ts tab="utils/ink-utility.ts"
import { nqtrHandler } from "@drincs/nqtr/ink";
import { HashtagCommands } from "@drincs/pixi-vn-ink";

export function initializeInk() {
    HashtagCommands.add(nqtrHandler());
    // ...
}
```

</Accordion>

<Accordion title="Vite.js plugin" id="vite-plugin">

For a better developer experience, use [`vitePluginNqtr`](/jsdoc/nqtr/vite/functions/vitePluginNqtr):

```ts tab="vite.config.ts"
import { defineConfig } from "vite";
import { vitePluginNqtr } from "@drincs/nqtr/vite";

export default defineConfig({
    // ...
    plugins: [
        // other plugins...
        vitePluginNqtr(),
    ],
});
```

</Accordion>

<Accordion title="`OnRunProps`" id="onrunprops">

:::tip[Plantillas]

In all templates, the `OnRunProps` interface is already overridden. You can find it in the `nqtr.d.ts` file.

:::

Some NQTR functions require you to pass an [`OnRunProps`](/jsdoc/nqtr/index/interfaces/OnRunProps) object as a parameter. This allows you to customize and access properties in system-triggered functions.
You can override the `OnRunProps` interface in your `.d.ts` file to specify required parameters.

```ts title="nqtr.d.ts"
import { narration } from "@drincs/pixi-vn";

declare module "@drincs/pixi-vn" {
    interface OnRunProps {
        navigate: (route: string) => void;
    }
}
```

</Accordion>

<Accordion title="Agent Skills" id="agent-skills">

NQTR ships a set of [Agent Skills](https://www.skills.sh/) that teach AI coding assistants how to correctly use each part of the library. If the project uses *ink*, the skills prefer *ink* hashtag commands over TypeScript labels.

> In LM Studio Bionic, ask the agent to install skills from `https://github.com/DRincs-Productions/nqtr`, or add the skill files in **Settings → Skills**. To reuse skills installed for Codex or Claude Code, enable **Settings → Skills → Use skills found in other apps**.

**Codex**:

```npm
npx skills@latest add DRincs-Productions/nqtr@latest --skill '*' --agent codex -g -y
```

**Claude Code**:

```npm
npx skills@latest add DRincs-Productions/nqtr@latest --skill '*' --agent claude-code -g -y
```

**Other agents**:

```npm
npx skills@latest add DRincs-Productions/nqtr@latest --all -y
```
